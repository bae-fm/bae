ફોલ્ડર આયાત માટે ઑડિયો અને અન્ય ફાઇલો સપ્લાય કરે છે. તમે પસંદ કરો છો કે તેનો સંપાદનયોગ્ય મેટાડેટા ઓનલાઈન રિલીઝ, ફાઈલોના પોતાના ટૅગ્સ અથવા ખાલી ફોર્મથી શરૂ થાય છે.

Importing desktop (macOS, Windows) પર થાય છે. તમારી files read થાય છે, ક્યારેય બદલાતી નથી: bae કશું move, rename, retag અથવા re-encode કરતું નથી. Import પછી files ક્યાં રહે છે તે માટે [Storage અને offline](/gu/guide/storage) જુઓ.

## Watched folders

**Import** section પર switch કરો અને folder ઉમેરો: તેને પસંદ કરો, window પર drag કરો, અથવા <kbd>⌘I</kbd> દબાવો. ત્યારથી bae folder watch કરે છે. તેમાં મૂકાયેલું નવું music પોતાની રીતે new candidates તરીકે દેખાય છે; તમારે હાથથી re-scan કરવું પડતું નથી. હજુ download થઈ રહેલા folders પૂરા થાય ત્યાં સુધી ignore થાય છે.

Scan releases ને rips ખરેખર જે shapes લે છે તેમાં ઓળખે છે:

| Layout | તે કેવું દેખાય છે |
|--------|-------------------|
| File per track | `01 - Song.flac`, `02 - Song.flac`, ... |
| CUE + image | `album.cue` + `album.flac`, આખા disc માટે એક file |
| Multi-disc | `CD1/`, `CD2/` subfolders, અંદર કોઈ પણ shape |
| Collections | folders નો folder, દરેક પોતાનો release |

bae જે formats વગાડે છે તે import કરે છે: FLAC, MP3, APE, ALAC અને `.m4a` માં AAC, WAV, AIFF, Ogg Vorbis, Opus, WavPack, અને DSD (`.dsf`/`.dff`). Folder માં artwork અને documents (CUE sheets, rip logs, text files) ઓળખાય છે અને release સાથે રાખવામાં આવે છે.

## મેટાડેટા સ્ત્રોત પસંદ કરો

દરેક ઉમેદવાર ત્રણ સમાન મેટાડેટા સ્ત્રોતો ઑફર કરે છે: **લુકઅપ**, **ફાઇલ ટૅગ્સ** અને **મેન્યુઅલ**. સ્ત્રોત ખોલવાથી માત્ર તેની સપાટી દેખાય છે; તે ઉમેદવાર આયાત કરશે તે સ્ત્રોતને બદલતું નથી. જ્યારે તમે સ્પષ્ટપણે દબાવીને પસંદ કરો, **ફાઇલ ટૅગ્સનો ઉપયોગ કરો** પસંદ કરો અથવા **મેન્યુઅલી દાખલ કરો** પસંદ કરો ત્યારે જ સ્રોત ઉમેદવારનો મેટાડેટા સીડ બની જાય છે.

### શોધ

લુકઅપ એ એકમાત્ર સ્ત્રોત છે જે રિલીઝને ઓળખે છે. તે રિપ લોગ અથવા CUE શીટમાંથી ડિસ્ક ID વાંચે છે, બારકોડ્સ અને કેટલોગ ટેક્સ્ટને ઓળખે છે, મ્યુઝિકબ્રેન્ઝ અને ડિસ્કોગ્સ ક્વેરીઝ કરે છે અને પરિણામો સાથે મેળ ખાય છે. સ્વચાલિત ઓળખ આ જ લુકઅપ પાથનો ઉપયોગ કરે છે. તે ત્યારે જ ચાલે છે જ્યારે **આપમેળે લુકઅપ ઉમેદવારોને ઓળખો** સક્ષમ હોય અને ડિફૉલ્ટ સપાટી લુકઅપ માટે ઉકેલાઈ જાય. લુકઅપ દાખલ કરવું અને શોધ શરૂ કરવાથી તે સેટિંગને ધ્યાનમાં લીધા વિના સ્પષ્ટપણે ચલાવી શકાય છે. આમાંથી કોઈ પણ કાર્ય ફાઇલ ટૅગ્સ અથવા મેન્યુઅલમાં ચાલતું નથી.

### ફાઇલ ટૅગ

ફાઇલ ટૅગ્સ એમ્બેડેડ ઑડિયો ટૅગ્સ અને CUE મેટાડેટા ત્યારે જ વાંચે છે જ્યારે તમે તેને ખોલો અને bae ને વાંચવા માટે કહો. પૂર્વાવલોકનની સમીક્ષા કરો, પછી તે ચોક્કસ સ્નેપશોટને બીજ તરીકે સંગ્રહિત કરવા માટે **ફાઇલ ટૅગ્સનો ઉપયોગ કરો** પસંદ કરો. જો ઉમેદવાર અથવા અવલોકન કરેલ ઑડિઓ ફાઇલો પૂર્વાવલોકન પછી બદલાય તો પુસ્તકાલયમાં લખતા પહેલા આયાત નિષ્ફળ જાય છે.

### મેન્યુઅલ

મેન્યુઅલ કોઈ ટૅગ્સ, ફોલ્ડર પુરાવા અથવા ઑનલાઇન પ્રદાતાઓ વાંચતું નથી. ખાલી સંપાદનયોગ્ય પ્રકાશન અને ઉમેદવારના ભૌતિક ટ્રૅક લેઆઉટ સાથે પ્રારંભ કરવા માટે **મેન્યુઅલી દાખલ કરો** પસંદ કરો.

આયાત સેટિંગ્સમાં, **ઓપન બિનસીડ્ડ ઉમેદવારો** માં પસંદ કરે છે કે બિનસીડિત ઉમેદવાર કઈ સપાટી પર પ્રથમ ખુલે છે. **છેલ્લે વપરાયેલ** તમે સ્પષ્ટપણે ખોલેલા છેલ્લા સ્ત્રોતને ઉકેલે છે. આ સેટિંગ સપાટી પસંદ કરે છે, બીજ નહીં; સ્પષ્ટ સ્ત્રોત ક્રિયા હજુ પણ પુષ્ટિ કરે છે કે આયાત શું ઉપયોગ કરશે.

## Confirm અને import

Confirmation pane બતાવે છે કે import શું write કરશે:

- **Cover.** Databases ના art, તમારા folder ની images, અથવા files માં embedded art માંથી પસંદ કરેલું. તમે તેને પછીથી બદલી શકો છો.
- **Metadata.** Album, artist, year, label, catalog number, country, barcode, અને દરેક track: કશું save થાય તે પહેલાં અહીં બધું editable છે.
- **Storage.** Cloud home connected હોય તો, bae files ને તમારા cloud માં manage કરે કે નહીં, અને local copy પણ રાખવી કે નહીં તે પસંદ કરો. [Storage અને offline](/gu/guide/storage) જુઓ.

Import background માં ચાલે છે: bae દરેક track cleanly decode થાય છે કે નહીં તે verify કરે છે, album અને દરેક track માટે loudness માપે છે, release save કરે છે, અને managed imports માટે upload શરૂ કરે છે. Candidate list આગળના folder પર જાય છે, અને release તરત playable બને છે.

## Data sources

**MusicBrainz** માટે account કે key જોઈએ નહીં. **Discogs** માટે તમારો પોતાનો free API token જોઈએ; Settings માં paste કરો, અને તે કામ કરવાનું બંધ કરે તો bae તમને કહે છે. Token વગર, Discogs search અને Discogs-sourced metadata ઉપલબ્ધ નથી, અને બાકી બધું કામ કરે છે. બંને services rate-limited છે; bae limits અંદર રહેવા requests pace કરે છે.

Rips નો folder પોતાના વિશે લગભગ કશું જાણતો નથી. તે કયા release માંથી આવ્યો, pressing, label, credits, track 12 ખરેખર ક્યાં પૂરો થાય છે: આ બધું MusicBrainz અને Discogs જેવા databases માં રહે છે, તમારા filenames માં નહીં. Importing એ રીતે bae બંનેને જોડે છે: તમે તેને તમારા music તરફ બતાવો છો, તે શોધે છે કે દરેક folder કયો release છે, અને library folder ને તે release તરીકે record કરે છે.

Importing desktop (macOS, Windows) પર થાય છે. તમારી files read થાય છે, ક્યારેય બદલાતી નથી: bae કશું move, rename, retag અથવા re-encode કરતું નથી. Import પછી files ક્યાં રહે છે તે માટે [Storage અને offline](/gu/guide/storage) જુઓ.

## Watched folders

**Import** section પર switch કરો અને folder ઉમેરો: તેને પસંદ કરો, window પર drag કરો, અથવા <kbd>⌘I</kbd> દબાવો. ત્યારથી bae folder watch કરે છે. તેમાં મૂકાયેલું નવું music પોતાની રીતે new candidates તરીકે દેખાય છે; તમારે હાથથી re-scan કરવું પડતું નથી. હજુ download થઈ રહેલા folders પૂરા થાય ત્યાં સુધી ignore થાય છે.

Scan releases ને rips ખરેખર જે shapes લે છે તેમાં ઓળખે છે:

| Layout | તે કેવું દેખાય છે |
|--------|-------------------|
| File per track | `01 - Song.flac`, `02 - Song.flac`, ... |
| CUE + image | `album.cue` + `album.flac`, આખા disc માટે એક file |
| Multi-disc | `CD1/`, `CD2/` subfolders, અંદર કોઈ પણ shape |
| Collections | folders નો folder, દરેક પોતાનો release |

bae જે formats વગાડે છે તે import કરે છે: FLAC, MP3, APE, ALAC અને `.m4a` માં AAC, WAV, AIFF, Ogg Vorbis, Opus, WavPack, અને DSD (`.dsf`/`.dff`). Folder માં artwork અને documents (CUE sheets, rip logs, text files) ઓળખાય છે અને release સાથે રાખવામાં આવે છે.

## Release ઓળખવું

Candidate પસંદ કરો અને bae તેને ઓળખવાનું શરૂ કરે છે. Tags પરથી guess કરવા કરતાં, તે folder માં evidence વાંચે છે અને દરેક ભાગ lookup કરે છે:

- **Disc ID.** CD ના exact track layout નો fingerprint, rip log અથવા CUE sheet પરથી computed. Match થાય ત્યારે તે precise CD edition ઓળખે છે.
- **Barcode.** Folder માં cover scans પરથી text recognition વાપરીને, અથવા CUE sheet માંથી વાંચેલો.
- **Catalog numbers અને text.** Artwork તથા file અને folder names માં મળેલા catalog numbers, results narrow કરવા માટે વપરાય છે.

Signals ને MusicBrainz અને Discogs સામે એક જ સમયે lookup કરવામાં આવે છે, અને results cross-check થાય છે. દરેક signal results ઉપર badge તરીકે દેખાય છે: શું મળ્યું, ક્યાંથી આવ્યું (origin માટે hover: disc TOC, CUE sheet, cover scan, folder name), અને કોઈ signal misleading હોય તો તેને બંધ કરી શકો છો.

ત્રણ outcomes:

- **Found.** Evidence એક release group પર agree કરે છે. તમે તેની list માંથી exact pressing પસંદ કરો છો.
- **Conflict.** બે signals જુદા releases તરફ બતાવે છે, જેમ કે disc ID અને barcode disagree કરે. bae બંને sides બતાવે છે અને તમે કયા પર trust કરવું તે પસંદ કરો છો, અથવા signal ignore કરો છો.
- **Nothing found.** હાથથી search કરો: artist અને album, catalog number, અથવા barcode, બંને databaseમાંથી કોઈ સામે. Artwork માંથી ઓળખાયેલ text autocomplete તરીકે આપવામાં આવે છે.

તમે **skip identifying** પણ કરી શકો છો અને unknown release તરીકે import કરી શકો છો. પછી bae names માટે તમારી files ના embedded tags પર પાછું જાય છે, અને database માં release હોય અથવા તમારા પાસે વધુ સારું evidence હોય ત્યારે તમે પછીથી re-identify કરી શકો છો.

## Exact અથવા approximate

તમે match પસંદ કરો ત્યારે bae તેને તમારી files સામે check કરે છે, અને track count mismatch flag કરે છે. પછી તમે declare કરો છો કે match શું છે:

- **Exact**: તમારી files આ pressing છે.
- **Metadata only**: album સાચો છે, પણ જરૂરી નથી કે આ જ exact pressing હોય. bae metadata વાપરે છે અને pressing approximate છે તે યાદ રાખે છે.

જો release પહેલેથી તમારી library માં હોય, અથવા એ જ album નું બીજું pressing હોય, તો duplicate import કરતાં પહેલાં bae તમને કહે છે.

## Confirm અને import

Confirmation pane બતાવે છે કે import શું write કરશે:

- **Cover.** Databases ના art, તમારા folder ની images, અથવા files માં embedded art માંથી પસંદ કરેલું. તમે તેને પછીથી બદલી શકો છો.
- **Metadata.** Album, artist, year, label, catalog number, country, barcode, અને દરેક track: કશું save થાય તે પહેલાં અહીં બધું editable છે.
- **Storage.** Cloud home connected હોય તો, bae files ને તમારા cloud માં manage કરે કે નહીં, અને local copy પણ રાખવી કે નહીં તે પસંદ કરો. [Storage અને offline](/gu/guide/storage) જુઓ.

Import background માં ચાલે છે: bae દરેક track cleanly decode થાય છે કે નહીં તે verify કરે છે, album અને દરેક track માટે loudness માપે છે, release save કરે છે, અને managed imports માટે upload શરૂ કરે છે. Candidate list આગળના folder પર જાય છે, અને release તરત playable બને છે.

## Data sources

**MusicBrainz** માટે account કે key જોઈએ નહીં. **Discogs** માટે તમારો પોતાનો free API token જોઈએ; Settings માં paste કરો, અને તે કામ કરવાનું બંધ કરે તો bae તમને કહે છે. Token વગર, Discogs search અને Discogs-sourced metadata ઉપલબ્ધ નથી, અને બાકી બધું કામ કરે છે. બંને services rate-limited છે; bae limits અંદર રહેવા requests pace કરે છે.

title: Storage અને offline
description: તમારું music ક્યાં રહે છે, અને network વગર શું વાગે છે
---

તમારી files તમારી જ રહે છે. bae તેમને ક્યારેય move, rename અથવા rewrite કરતું નથી; storage જે પ્રશ્નનો જવાબ આપે છે તે ફક્ત આ છે કે દરેક release ની *playable copy* ક્યાં રહે છે: device પર, તમારા cloud માં, કે બંનેમાં.

## Unmanaged અને managed

દરેક release બેમાંથી એક છે, import વખતે પસંદ કરેલું અને કોઈ પણ સમયે બદલી શકાય તેવું:

- **Unmanaged**: bae તમારી files જ્યાં છે ત્યાં catalog કરે છે અને ત્યાંથી વગાડે છે. કશું copy થતું નથી. Release દરેક synced device પર catalog માં હોય છે, પરંતુ તેનું audio ફક્ત તેને import કરનાર machine પર રહે છે.
- **Managed**: files encrypted થઈને cloud home પર upload થાય છે. હવે દરેક device release વગાડી શકે છે, demand પર stream કરીને અથવા offline માટે download કરીને. Upload તમારી original files ને સ્પર્શતું નથી; locally તેમને વાપરતાં રહેવું કે નહીં તે તમારો નિર્ણય છે (import વખતે **Keep local copy** તેમને pin કરે છે).

બે સ્થિતિ વચ્ચે જવું release-level action છે: **Manage** unmanaged release upload કરે છે; **Make local** managed release ની files તમે પસંદ કરેલા folder માં download કરે છે, અને તે ફરી plain files તરીકે તમારી છે.

## Streaming અને cache

Managed releases everywhere વાગે છે, network મળે તો: playback file ને તમારા cloud માંથી stream કરે છે, અને bytes local cache માં રાખે છે જેથી next play તરત અને network વગર થાય. Cache budget અંદર પોતે manage થાય છે (દરેક device પર audio માટે 20 GB), જગ્યા ઓછી પડે ત્યારે જે તમે વગાડ્યું નથી તે evict કરે છે. Covers અને artist images અલગ cache થાય છે, જેથી મોટું album તમારા artwork ને બહાર ધકેલી ન શકે.

## Offline માટે pinning

Release pin કરવાથી આખું download થાય છે અને રાખવામાં આવે છે: pinned music ક્યારેય evict થતું નથી અને હંમેશા offline વાગે છે. Release ના storage sheet અથવા Storage Manager માંથી pin કરો; unpin files ને normal cache માં પાછી મૂકે છે, જ્યાં તે playable રહે છે પણ reclaimable છે. Phone પર pinned downloads progress સીધી library માં બતાવે છે.

## Storage Manager

Desktop નો Storage Manager (<kbd>⌘0</kbd>) એક window માં આખું picture છે:

- દરેક release તેની size અને state સાથે: unmanaged, managed, uploading. Filter, sort, many select કરો, બધાં પર એકસાથે act કરો.
- **Downloads**: ચાલી રહેલા pin downloads, pausable, retryable.
- **Exports**: export queue. [Exporting](/gu/guide/exporting) જુઓ.
- **Uploads**: sync outbox, per-release progress, throughput અને time remaining, pending deletions, pause અને resume.

## Deleting

Managed release delete કરવાથી તે library અને cloud home માંથી દૂર થાય છે. Unmanaged release delete કરવાથી ફક્ત catalog entry દૂર થાય છે: bae જે files ત્યાં મૂકી ન હોય તેને ક્યારેય delete કરતું નથી.

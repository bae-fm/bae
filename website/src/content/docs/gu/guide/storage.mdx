તમારી files તમારી જ રહે છે. bae તેમને ક્યારેય move, rename અથવા rewrite કરતું નથી; storage જે પ્રશ્નનો જવાબ આપે છે તે ફક્ત આ છે કે દરેક release ની *playable copy* ક્યાં રહે છે: device પર, તમારા cloud માં, કે બંનેમાં.

## સ્થાનિક અને cloud માં

દરેક release બેમાંથી એક છે, import વખતે પસંદ કરેલું અને કોઈ પણ સમયે બદલી શકાય તેવું:

- **સ્થાનિક**: bae તમારી files જ્યાં છે ત્યાં સૂચિબદ્ધ કરે છે અને ત્યાંથી વગાડે છે. કશું copy થતું નથી. release ની માહિતી sync થાય છે, તેથી દરેક ઉપકરણ album, તેના tracks અને cover બતાવે છે, પણ તેનું audio import કરનાર machine પર જ રહે છે, અને બીજાં ઉપકરણો તેને વગાડી શકતાં નથી.
- **Cloud માં**: files encrypt થઈને cloud home પર upload થાય છે. હવે દરેક ઉપકરણ release વગાડી શકે છે, માંગ પર stream કરીને અથવા offline માટે download કરીને. Upload તમારી મૂળ files ને સ્પર્શતું નથી.

Import વખતે, cloud home જોડાયેલું હોય તો, **Cloud** નવો release upload કરે છે અને **Pinned** તેની files આ ઉપકરણ પર પણ રાખે છે. પછી **Move to Cloud** કોઈ સ્થાનિક release upload કરે છે; bae પહેલાં ચકાસે છે કે import પછી દરેક file બદલાઈ નથી, અને બદલાયેલી file upload અટકાવે છે. **Make Local…** cloud ના release ની files તમે પસંદ કરેલા ફોલ્ડરમાં copy કરે છે, દરેક નકલ ચકાસે છે અને release ને ત્યાંથી વગાડે છે; તે ફરી તમારી સામાન્ય files બને છે, અને બીજાં ઉપકરણો તેને હવે વગાડી શકતાં નથી.

## Streaming અને cache

Cloud માંના releases network મળે તો બધે વાગે છે: playback file ને તમારા cloud માંથી stream કરે છે, અને bytes સ્થાનિક cache માં રાખે છે જેથી પછીનું વગાડવું તરત અને network વગર થાય. Cache પોતાની મર્યાદામાં પોતાને સંભાળે છે (દરેક ઉપકરણ પર audio માટે 20 GB), જગ્યા ઓછી પડે ત્યારે જે તમે વગાડ્યું નથી તે કાઢે છે. Covers અને કલાકારની છબીઓ અલગ cache થાય છે, જેથી મોટું album તમારું artwork બહાર ધકેલી ન શકે.

## Offline માટે pinning

Release pin કરવાથી આખું download થાય છે અને રાખવામાં આવે છે: pinned music ક્યારેય evict થતું નથી અને હંમેશા offline વાગે છે. Release ના storage sheet અથવા Storage Manager માંથી pin કરો; unpin files ને normal cache માં પાછી મૂકે છે, જ્યાં તે playable રહે છે પણ reclaimable છે. Phone પર pinned downloads progress સીધી library માં બતાવે છે.

## Storage Manager

Desktop નો Storage Manager (<kbd>⌘0</kbd>) એક window માં આખું picture છે:

- દરેક release તેના કદ અને સ્થિતિ સાથે: સ્થાનિક, cloud માં, upload થઈ રહ્યું. Filter કરો, ક્રમ બદલો, ઘણાં પસંદ કરો, બધાં પર એકસાથે ક્રિયા કરો.
- **Downloads**: ચાલી રહેલા pin downloads, pausable, retryable.
- **Exports**: export queue. [Exporting](/gu/guide/exporting) જુઓ.
- **Uploads**: sync outbox, per-release progress, throughput અને time remaining, pending deletions, pause અને resume.

## Deleting

Cloud માંનો release કાઢી નાખવાથી તે લાઇબ્રેરીમાંથી અને તેની નકલો cloud home માંથી દૂર થાય છે. સ્થાનિક release કાઢી નાખવાથી ફક્ત catalog entry દૂર થાય છે. બંને રીતે bae તમારી પોતાની files ક્યારેય કાઢતું નથી.

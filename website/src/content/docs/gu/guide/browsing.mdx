title: બ્રાઉઝિંગ અને શોધ
description: લાઇબ્રેરીમાં તમારો માર્ગ શોધો
---

એ જ લાઇબ્રેરી, તમે જે રીતે તેના વિશે વિચારો છો તે રીતે browse કરેલી: record જોઈએ ત્યારે album દ્વારા, classical shelves માં હો ત્યારે composer દ્વારા, અને નામ ખબર હોય ત્યારે search દ્વારા.

## Albums

Default view covers ની grid છે. તેને title, artist, year અથવા date added પ્રમાણે, કોઈ પણ દિશામાં sort કરો; તમે અનેક માપદંડો stack કરી શકો છો, અને પસંદગી યાદ રહે છે. Album પર click કરવાથી તેના releases અને tracks દેખાય છે. ઉપરનું **Shuffle Library** button તમારી પાસે જે બધું છે તેમાં playback શરૂ કરે છે.

## Composers અને works

Composer view classical સાંભળવા માટે બનાવેલો છે, જ્યાં album ઘણી વાર ખોટું unit હોય છે. Composers તેમના works સાથે સૂચિબદ્ધ થાય છે; work તેના parts, તે કયા releases પર છે, અને તેની recordings બતાવે છે. Composers ને name પ્રમાણે, તમારી પાસે તેમની કેટલી works છે તે પ્રમાણે, અથવા તેઓ કેટલા releases પર દેખાય છે તે પ્રમાણે sort કરો. આ view ત્યાં હોય છે જ્યાં તમારી metadata work અને composer credits ધરાવે છે, જે MusicBrainz થી ઓળખાયેલા releases સામાન્ય રીતે ધરાવે છે.

## Search

Title bar માંથી search (દબાવો <kbd>/</kbd>) તમે type કરો તેમ albums, tracks, composers અને works શોધે છે. Result પસંદ કરવાથી ત્યાં jump થાય છે.

## Phone પર

iOS અને Android એ જ લાઇબ્રેરી એ જ રીતે browse કરે છે: album grid, composer view, search, અને દરેક album માટે release પસંદગી. Sync refresh કરવા માટે નીચે ખેંચો.

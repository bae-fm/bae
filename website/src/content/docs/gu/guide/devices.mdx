bae ખાતું નથી. લાઇબ્રેરીમાં દરેક વ્યક્તિ પાસે પોતાની કી હોય છે, જે તેના બધા ઉપકરણો વહેંચે છે અને ઓપરેટિંગ સિસ્ટમના keyring માં રાખે છે; લાઇબ્રેરી લોકોને આ કી વડે ઓળખે છે. કોણ સામેલ છે તેમાં થતો દરેક ફેરફાર સહી થઈને cloud home માં રખાય છે, વચ્ચે કોઈ વગર.

બે જુદા દરવાજા, બે જુદી પરિસ્થિતિઓ માટે:

- **પુનઃસ્થાપન**: તમારું પોતાનું નવું અથવા ફરી ઇન્સ્ટોલ કરેલું ઉપકરણ તમારા restore code થી જોડાય છે. બીજું કોઈ ઉપકરણ તેને મંજૂર કરતું નથી: code માં તમારી કી હોય છે, એટલે તે જાતે જ સાબિત કરે છે કે ઉપકરણ તમારું છે.
- **જોડાવું**: બીજી વ્યક્તિ admin ના આમંત્રણથી જોડાય છે, જે તેની વિનંતી મંજૂર કરે છે.

## તમારું પોતાનું ઉપકરણ ઉમેરવું

નવા ઉપકરણ પર **Restore from cloud** પસંદ કરો અને તેને restore code આ ત્રણમાંથી કોઈ એક રીતે આપો:

- તમારા બીજા કોઈ ઉપકરણ પર Settings, Library માં **Show restore code...** હેઠળ દેખાતો QR code **સ્કેન** કરો.
- Apple ઉપકરણો પર તેને iCloud Keychain માંથી **પસંદ** કરો: તમારા બીજા ઉપકરણોએ ત્યાં સાચવેલા restore codes ની યાદી bae બતાવે છે.
- તેને **પેસ્ટ** કરો અથવા ટાઇપ કરો.

પૂછવામાં આવે ત્યારે સ્ટોરેજ પ્રદાતામાં સાઇન ઇન કરો. S3 પર ઉપકરણને તમારી access key પણ જોઈએ: QR code તેને code ની સાથે જ લાવે છે, તેથી સ્કેન કરવું પૂરતું છે, અને ટાઇપ કરેલો code key માંગે છે. પછી નવું ઉપકરણ લાઇબ્રેરી ડાઉનલોડ કરે છે અને sync શરૂ કરે છે.

લાઇબ્રેરી લોડ થાય ત્યાં સુધી ઉપકરણ તેનું નામ નહીં, પણ તે ક્યાં સંગ્રહિત છે તે બતાવે છે: Dropbox અને OneDrive માટે ખાતાનો ઇમેઇલ, S3 માટે bucket અને endpoint, અથવા iCloud. લોડ થયા પછી તે લાઇબ્રેરીનું હાલનું નામ બતાવે છે.

## વ્યક્તિને આમંત્રણ આપવું

કોઈ admin Settings, Library, **Invite a Person...** ખોલે છે, ભૂમિકા પસંદ કરે છે અને તે વ્યક્તિના ખાતાનો ઇમેઇલ દાખલ કરે છે; S3 પર તેના બદલે તેના માટે બનાવેલી access key. bae લાઇબ્રેરીનું ફોલ્ડર તે ખાતા સાથે શેર કરે છે અને આમંત્રણ QR code તરીકે બતાવે છે.

પોતાના ઉપકરણ પર તે વ્યક્તિ **Join a library** પસંદ કરે છે, આમંત્રણ સ્કેન અથવા પેસ્ટ કરે છે, પોતાનું નામ લખે છે અને પોતાના ખાતામાં સાઇન ઇન કરે છે. વિનંતી admin ના ઉપકરણ પર **Waiting to join** હેઠળ દેખાય છે, અને admin તેને મંજૂર અથવા નામંજૂર કરે છે. મંજૂરી પછી નવું ઉપકરણ લાઇબ્રેરી ડાઉનલોડ કરે છે, અને દરેક ઉપકરણ નવી વ્યક્તિને નામથી બતાવે છે. આમંત્રણ એક દિવસમાં સમાપ્ત થાય છે, અને તેની વિનંતી ફક્ત તેને બનાવનાર ઉપકરણ જ મંજૂર કરી શકે છે. વિગતો [ઓળખ અને સભ્યપદ](/gu/reference/membership) માં.

## Members અને roles

Settings, Library દરેક વ્યક્તિ અને તેના ઉપકરણો બતાવે છે, અને તેમાંથી કયું આ ઉપકરણ છે તે પણ. જે વ્યક્તિ લાઇબ્રેરીને cloud સાથે જોડે છે તે તેની પહેલી **admin** છે; admin બીજાઓને **admin** અથવા **સભ્ય** તરીકે આમંત્રિત કરે છે અને કોઈની ભૂમિકા બદલી શકે છે. બધા લાઇબ્રેરી વાંચે અને સંપાદિત કરે છે. ફક્ત admins જ લોકોને આમંત્રિત કરે, દૂર કરે અને લાઇબ્રેરીનું નામ બદલે છે.

## Device દૂર કરવું

દરેક વ્યક્તિ પોતાના ઉપકરણો દૂર કરી શકે છે, અને admin કોઈના પણ ઉપકરણ દૂર કરી શકે છે, જેથી બધા ઉપકરણો ગુમાવનાર વ્યક્તિ અટકી ન જાય. ત્યાર પછી દૂર કરેલું ઉપકરણ જે મોકલે તે કશું ગણાતું નથી. પ્રદાતા પાસે શું કરવાનું બાકી છે તે પણ bae બતાવે છે, જેમ કે તે ઉપકરણને તમારા ખાતામાંથી સાઇન આઉટ કરવું: Dropbox, OneDrive અને iCloud કોઈ ખાતાના એક જ ઉપકરણને જાતે અલગ કરી શકતા નથી.

કોઈ વ્યક્તિને દૂર કરવી, જે ફક્ત admin કરી શકે છે, તેના ઉપકરણો અને તેણે ખાનગી રાખેલું બધું પણ દૂર કરે છે. ઘર સાથે વહેંચેલાં તેના rating, ઇતિહાસ અને playlists તેના નામે જ રહે છે. લાઇબ્રેરીની કી બદલાઈ જાય છે, તેથી પછી લખાયેલું કશું તેના માટે વાંચી શકાય તેવું નથી. તેણે પહેલેથી copy કરેલું તેની પાસે જ રહે છે: મોકલેલો ડેટા પાછો લઈ શકાતો નથી.

## રિસ્ટોર કોડ

Restore code એક લાઇબ્રેરી માટેની તમારી કી અને તે ક્યાં સંગ્રહિત છે તે એક જ string માં રાખે છે. તેમાં સ્ટોરેજનો પાસવર્ડ, સાઇન-ઇન કે લાઇબ્રેરીનું નામ નથી. Settings, Library માં **Show restore code...** તેને બતાવે છે; તેને password manager જેવી સલામત જગ્યાએ રાખો.

Apple પ્લેટફોર્મ પર code આપમેળે iCloud Keychain માં પણ રખાય છે, તેથી તમારા Apple Account માં સાઇન ઇન કરેલું નવું Mac અથવા iPhone તેને યાદીમાંથી પસંદ કરી શકે છે.

જેની પાસે code અને તમારા સ્ટોરેજની પહોંચ છે, તે તમારી જેમ લાઇબ્રેરી ખોલી શકે છે, તેથી તેને ગુપ્ત રાખો.

## Locking

લાઇબ્રેરીની encryption key ઓપરેટિંગ સિસ્ટમના keyring માં રહે છે. keyring લૉક હોય ત્યાં સુધી, જેમ કે તમારું સત્ર લૉક હોય ત્યારે, bae લાઇબ્રેરીને લૉક બતાવે છે અને keyring અનલૉક થતાં જ તેને ખોલે છે; **Try again** હાથથી ફરી પ્રયાસ કરે છે.

## Phone પર

iOS અને Android આ જ રીતે જોડાય છે અને પુનઃસ્થાપિત થાય છે; આ જ તેમની આખી શરૂઆત છે. ફોન લાઇબ્રેરીને પોતાનામાંથી દૂર પણ કરી શકે છે: પહેલાં તે પોતાને લાઇબ્રેરીના સભ્યોમાંથી દૂર કરે છે, જેના માટે તમારા સ્ટોરેજ સાથે જોડાણ જોઈએ, પછી પોતાની સ્થાનિક નકલ કાઢી નાખે છે. cloud માંની લાઇબ્રેરી રહે છે.

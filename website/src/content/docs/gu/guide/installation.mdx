## બે editions

bae બે editions માં મળે છે, બંને એ જ source માંથી built:

- **bae**, full app: S3, Google Drive, Dropbox, OneDrive, અને iCloud sync.
- **baeium**, proprietary parts વગર: ફક્ત S3-compatible storage, OAuth providers નહીં, iCloud/CloudKit નહીં, telemetry નહીં.

તે side by side install થાય છે, દરેકની પોતાની library અને પોતાની (iCloud-Keychain-synced) keys સાથે. નીચે તમને જે ગમે તે પસંદ કરો.

## iOS

iOS builds **sideloading માટે unsigned `.ipa` files** છે. [AltStore](https://altstore.io) અથવા [Sideloadly](https://sideloadly.io) સાથે install કરો, અથવા તમારા પોતાના Apple ID સાથે Xcode માં re-sign કરો (free Apple ID baeium માટે ચાલે છે). App Store distribution હજુ set up નથી.

## Windows

Windows download એ installer છે, જે app ને per-user install કરે છે અને જાતે up to date રાખે છે. Builds signed નથી, એટલે first launch પર SmartScreen warning આપી શકે છે. દરેક [GitHub release](https://github.com/bae-fm/bae/releases) સાથે portable zip પણ હોય છે, જે જ્યાં હોય ત્યાં જ ચાલે છે. Windows પર માત્ર full edition જ publish થાય છે.

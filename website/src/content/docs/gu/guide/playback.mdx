## Original quality

Transcoding નથી, loudness rewrite નથી, server re-encode નથી; audio device file ના પોતાના sample rate પર ચાલે છે. તમે જે rip કર્યું તે જ વાગે છે. bae જે દરેક format import કરે છે તે વગાડે છે: FLAC, MP3, APE, ALAC, AAC, WAV, AIFF, Ogg Vorbis, Opus, WavPack, DSD.

## Side breaks

Vinyl અને cassette releases માં sides હોય છે, અને કેટલાક records તેમના વચ્ચેની pause ઇરાદાપૂર્વક વાપરે છે. Playback settings માં **Pause between sides** ચાલુ કરો અને bae દરેક side boundary પર playback pause કરે છે, તમને continue કરવા prompt કરે છે, flipping વગરનું flip. ## Queue

Playback પાસે હંમેશા context હોય છે: તમે શરૂ કરેલો release, અથવા તમે shuffle કર્યું હોય તો આખી library. Queue બે lanes બતાવે છે:

- **Up Next**: તમે હાથથી queued કરેલા tracks, પહેલા વાગે છે. Tracks drag કરો, reorder કરો, remove કરો.
- **Playing from**: બાકીનું context, તેની પોતાની shuffle toggle સાથે.

**Play Next** અને **Add to Queue** દરેક track અને album પર છે. Repeat off, context repeat, અને one track repeat વચ્ચે cycle કરે છે.

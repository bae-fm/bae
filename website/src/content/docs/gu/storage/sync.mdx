## સિંક

sync તમારા cloud home દ્વારા થાય છે. દરેક ફેરફાર encrypted changeset બનાવે છે.

## bae

ઘણા ઉપકરણો sync કરવા bae સ્થાનિક identity, library key અને cloud home વાપરે છે.

## સંગ્રહ

ફાઇલો self-managed, local-managed અથવા cloud-managed હોઈ શકે.

## એન્ક્રિપ્શન

Opaque cloud home ડેટા ઉપકરણ છોડે તે પહેલાં એન્ક્રિપ્ટ કરે છે.

title: Resumen
description: Cómo está compuesto bae
---

bae es un gestor de biblioteca musical que usa identidad descentralizada y cifrado de extremo a extremo sobre almacenamiento intercambiable para sincronización multidispositivo sin servidor propio.

## Identidad

Cada dispositivo tiene un par de claves generado localmente (Ed25519/X25519). Las claves públicas son identidades. No hay servidor central de identidad.

## Cifrado

Una clave simétrica por biblioteca, compartida entre los dispositivos de la biblioteca. Todo lo que hay en el cloud home se cifra antes de salir del dispositivo. El proveedor de almacenamiento ve blobs opacos. Consulta [Cifrado](/es/architecture/encryption).

## Almacenamiento

Intercambiable. Cualquier proveedor cloud comercial (Google Drive, Dropbox, OneDrive, iCloud Drive), cualquier bucket compatible con S3 (AWS, B2, R2, Wasabi, MinIO) o uso solo local sin nube. Un único trait `CloudHome` abstrae las diferencias. Consulta [Cloud Home](/es/architecture/cloud-home).

## Sincronización

Los dispositivos se sincronizan mediante el cloud home usando conjuntos de cambios cifrados. Cada edición produce una diferencia binaria compacta; otros dispositivos la descargan y aplican. Los conflictos se resuelven automáticamente con último escritor gana y relojes lógicos híbridos. Una biblioteca se sincroniza entre varios dispositivos mediante una cadena de membresía y conjuntos de cambios firmados. Consulta [Sincronización](/es/storage/sync).

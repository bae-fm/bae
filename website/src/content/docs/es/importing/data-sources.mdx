bae usa servicios externos durante la importación para obtener metadatos y arte. Esto es lo que aporta cada servicio y cómo configurarlo.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> es una enciclopedia musical abierta y la fuente principal de metadatos de bae. Proporciona:

- Listas completas de pistas
- Información de grupos de ediciones
- Códigos ISRC
- Coincidencia de tabla de contenidos de CD para identificar CDs con precisión
- URLs externas vinculadas, incluidas referencias cruzadas de Discogs

### Autenticación

No hace falta clave de API. MusicBrainz es gratuito y abierto.

### Límites de uso

MusicBrainz aplica una media de 1 solicitud por segundo por dirección IP. Si superas este límite, MusicBrainz devuelve errores 503 y puede bloquear temporalmente tu IP. bae separa las solicitudes automáticamente para mantenerse dentro del límite.

### Más información

Consulta la <a href="https://musicbrainz.org/doc/MusicBrainz_API" target="_blank">documentación de la API de MusicBrainz</a> y los <a href="https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting" target="_blank">detalles de límites de uso</a>.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> es una base de datos musical y mercado. Es especialmente útil para:

- Ediciones y prensajes en vinilo
- Créditos detallados: productor, ingeniero, etc.
- Números de catálogo y códigos de barras
- Información de sellos

### Autenticación

Discogs requiere un token personal de API. Lo configuras durante la configuración inicial de bae y necesitas tu propio token.

### Límites de uso

Discogs permite 60 solicitudes autenticadas por minuto. bae gestiona esto automáticamente.

### Empezar

Obtén tu token en <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a>. Pégalo durante la configuración y queda listo.

bae completa tu biblioteca con metadatos de bases de datos en línea durante la importación.

## Qué se guarda

Cuando importas un álbum, bae guarda:

- **Información del álbum**: título, artista, año
- **Información de pistas**: nombres, duraciones, números de disco y pista
- **Arte**: portadas desde MusicBrainz Cover Art Archive y Discogs
- **Información de edición**: sello, número de catálogo, código de barras, país, formato
- **IDs externos**: ID de edición de Discogs e IDs de edición y artista de MusicBrainz

Todos los metadatos provienen de MusicBrainz y Discogs y se guardan en la base de datos de bae. bae no lee ni escribe etiquetas incrustadas. Tus archivos nunca se modifican. Tanto si son gestionados, movidos al almacenamiento de bae, como no gestionados, dejados en su lugar, los bytes no cambian.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> es una enciclopedia musical abierta y la fuente principal de metadatos de bae. Proporciona listas completas de pistas, información de grupos de ediciones, códigos ISRC y coincidencia de tabla de contenidos de CD para identificación precisa.

No hace falta clave de API. MusicBrainz es gratuito y abierto. Aplica una media de 1 solicitud por segundo por dirección IP; bae separa las solicitudes automáticamente.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> es una base de datos musical y mercado, especialmente útil para ediciones de vinilo, créditos detallados, números de catálogo e información de sellos.

Discogs requiere un token personal de API. Obtén el tuyo en <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a> y pégalo durante la configuración. El límite es de 60 solicitudes autenticadas por minuto; bae gestiona esto automáticamente.

## El servidor MCP

Activa el servidor MCP en Settings, Automation. Sirve el Model Context Protocol por HTTP en un puerto local (47777 de forma predeterminada), así que clientes MCP como Claude pueden explorar tu biblioteca, buscar lanzamientos y actuar sobre ellos. El acceso requiere un token al portador: cópialo desde el mismo panel de configuración, y rótalo allí cuando quieras cortar el acceso a todo lo que lo tenía.

El servidor está desactivado de forma predeterminada y solo se ejecuta mientras la app lo hace.

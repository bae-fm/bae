ਤੁਸੀਂ ਜੋ ਸਾਫਟਵੇਅਰ ਚਲਾਉਂਦੇ ਹੋ, ਉਹ ਸੰਗ੍ਰਹਿ ਨੂੰ ਚਲਾ ਸਕਦਾ ਹੈ: MCP ਉੱਤੇ AI ਏਜੰਟ, ਅਤੇ ਕਮਾਂਡ-ਲਾਈਨ ਸਾਧਨ ਉੱਤੇ ਸਕ੍ਰਿਪਟਾਂ। ਦੋਵੇਂ ਉਹੀ ਕਾਰਵਾਈਆਂ ਦਿੰਦੇ ਹਨ ਜੋ UI ਵਰਤਦਾ ਹੈ: ਖੋਜ, ਰਿਲੀਜ਼ ਵੇਰਵੇ, ਆਯਾਤ, ਭੰਡਾਰਣ ਕਾਰਵਾਈਆਂ, ਸੁਣਾਈ ਹਾਲਤ।

## MCP ਸਰਵਰ

ਸੈਟਿੰਗਾਂ, Automation ਵਿੱਚ MCP ਸਰਵਰ ਚਾਲੂ ਕਰੋ। ਇਹ ਸਥਾਨਕ ਪੋਰਟ ਉੱਤੇ HTTP ਰਾਹੀਂ ਮਾਡਲ Context Protocol ਦਿੰਦਾ ਹੈ (ਮੂਲ 47777), ਇਸ ਲਈ Claude ਵਰਗੇ MCP ਕਲਾਇੰਟ ਤੁਹਾਡਾ ਸੰਗ੍ਰਹਿ ਵੇਖ ਸਕਦੇ ਹਨ, ਰਿਲੀਜ਼ ਲੱਭ ਸਕਦੇ ਹਨ, ਅਤੇ ਉਨ੍ਹਾਂ ਉੱਤੇ ਕਾਰਵਾਈ ਕਰ ਸਕਦੇ ਹਨ। ਪਹੁੰਚ ਲਈ ਧਾਰਕ ਟੋਕਨ ਚਾਹੀਦਾ ਹੈ: ਉਸੇ ਸੈਟਿੰਗਾਂ pane ਤੋਂ ਇਸਨੂੰ ਕਾਪੀ ਕਰੋ, ਅਤੇ ਜਦੋਂ ਵੀ ਉਸ ਟੋਕਨ ਵਾਲੀ ਹਰ ਚੀਜ਼ ਕੱਟਣੀ ਹੋਵੇ, ਉੱਥੇ ਹੀ ਇਸਨੂੰ rotate ਕਰੋ।

ਸਰਵਰ ਮੂਲ ਤੌਰ ਉੱਤੇ ਬੰਦ ਹੁੰਦਾ ਹੈ ਅਤੇ ਐਪ ਚੱਲਣ ਵੇਲੇ ਹੀ ਚੱਲਦਾ ਹੈ।

## ਕਮਾਂਡ ਲਾਈਨ

`bae` CLI ਉਹੀ ਕਾਰਵਾਈਆਂ ਟਰਮੀਨਲ ਤੋਂ ਚਲਾਉਂਦਾ ਹੈ: JSON ਅੰਦਰ, JSON ਬਾਹਰ, ਸਕ੍ਰਿਪਟਾਂ ਲਈ ਢੁੱਕਵਾਂ। ਇਹ MCP ਕਲਾਇੰਟ ਵਜੋਂ ਵੀ ਕੰਮ ਕਰ ਸਕਦਾ ਹੈ, ਡੈਸਕਟਾਪ ਦੇ ਸਰਵਰ ਨੂੰ stdio ਨਾਲ ਜੋੜਦਾ ਹੈ ਉਹਨਾਂ ਸਾਧਨਾਂ ਲਈ ਜੋ ਸਥਾਨਕ MCP ਪ੍ਰਕਿਰਿਆ ਦੀ ਉਮੀਦ ਕਰਦੇ ਹਨ।

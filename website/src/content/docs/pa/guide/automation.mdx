## MCP ਸਰਵਰ

ਸੈਟਿੰਗਾਂ, Automation ਵਿੱਚ MCP ਸਰਵਰ ਚਾਲੂ ਕਰੋ। ਇਹ ਸਥਾਨਕ ਪੋਰਟ ਉੱਤੇ HTTP ਰਾਹੀਂ ਮਾਡਲ Context Protocol ਦਿੰਦਾ ਹੈ (ਮੂਲ 47777), ਇਸ ਲਈ Claude ਵਰਗੇ MCP ਕਲਾਇੰਟ ਤੁਹਾਡਾ ਸੰਗ੍ਰਹਿ ਵੇਖ ਸਕਦੇ ਹਨ, ਰਿਲੀਜ਼ ਲੱਭ ਸਕਦੇ ਹਨ, ਅਤੇ ਉਨ੍ਹਾਂ ਉੱਤੇ ਕਾਰਵਾਈ ਕਰ ਸਕਦੇ ਹਨ। ਪਹੁੰਚ ਲਈ ਧਾਰਕ ਟੋਕਨ ਚਾਹੀਦਾ ਹੈ: ਉਸੇ ਸੈਟਿੰਗਾਂ pane ਤੋਂ ਇਸਨੂੰ ਕਾਪੀ ਕਰੋ, ਅਤੇ ਜਦੋਂ ਵੀ ਉਸ ਟੋਕਨ ਵਾਲੀ ਹਰ ਚੀਜ਼ ਕੱਟਣੀ ਹੋਵੇ, ਉੱਥੇ ਹੀ ਇਸਨੂੰ rotate ਕਰੋ।

ਸਰਵਰ ਮੂਲ ਤੌਰ ਉੱਤੇ ਬੰਦ ਹੁੰਦਾ ਹੈ ਅਤੇ ਐਪ ਚੱਲਣ ਵੇਲੇ ਹੀ ਚੱਲਦਾ ਹੈ।

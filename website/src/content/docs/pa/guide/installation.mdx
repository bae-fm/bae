## ਦੋ ਸੰਸਕਰਣ

bae ਇੱਕੋ ਸਰੋਤ ਤੋਂ ਬਣੇ ਦੋ ਸੰਸਕਰਣਾਂ ਵਿੱਚ ਮਿਲਦਾ ਹੈ:

- **bae**, ਪੂਰੀ ਐਪ: S3, Google Drive, Dropbox, OneDrive, ਅਤੇ iCloud ਸਮਕਾਲੀਕਰਨ।
- **baeium**, proprietary ਹਿੱਸਿਆਂ ਤੋਂ ਬਿਨਾ: ਸਿਰਫ਼ S3-compatible ਭੰਡਾਰਣ, ਕੋਈ OAuth ਦਾਤੇ ਨਹੀਂ, ਕੋਈ iCloud/CloudKit ਨਹੀਂ, ਕੋਈ ਟੈਲੀਮੀਟਰੀ ਨਹੀਂ।

ਇਹ ਨਾਲ-ਨਾਲ ਇੰਸਟਾਲ ਹੁੰਦੇ ਹਨ, ਹਰ ਇੱਕ ਦਾ ਆਪਣਾ ਸੰਗ੍ਰਹਿ ਅਤੇ ਆਪਣੀਆਂ (iCloud-Keychain-ਸਮਕਾਲੀਕਰਿਤ) ਕੁੰਜੀਆਂ। ਹੇਠਾਂ ਜੋ ਚਾਹੋ ਚੁਣੋ।

## iOS

iOS ਬਣਾਵਟਾਂ **unsigned `.ipa` files for sideloading** ਹਨ। [AltStore](https://altstore.io) ਜਾਂ [Sideloadly](https://sideloadly.io) ਨਾਲ ਇੰਸਟਾਲ ਕਰੋ, ਜਾਂ ਆਪਣੇ Apple ID ਨਾਲ Xcode ਵਿੱਚ re-sign ਕਰੋ (ਮੁਫ਼ਤ Apple ID baeium ਲਈ ਕੰਮ ਕਰਦਾ ਹੈ)। App ਰੱਖਦਾ ਵੰਡ ਹਾਲੇ ਸੈੱਟ ਨਹੀਂ।

## Windows

Windows ਲਈ download ਇੱਕ installer ਹੈ, ਜੋ ਐਪ ਨੂੰ ਪ੍ਰਤੀ-ਵਰਤੋਂਕਾਰ ਸਥਾਪਤ ਕਰਦਾ ਹੈ ਅਤੇ ਆਪਣੇ ਆਪ ਅੱਪਡੇਟ ਰਹਿੰਦਾ ਹੈ। ਬਣਾਵਟਾਂ signed ਨਹੀਂ ਹਨ, ਇਸ ਲਈ ਪਹਿਲੀ ਵਾਰ ਚਲਾਉਣ ਉੱਤੇ SmartScreen ਚੇਤਾਵਨੀ ਦੇ ਸਕਦਾ ਹੈ। ਹਰ [GitHub release](https://github.com/bae-fm/bae/releases) ਨਾਲ ਇੱਕ portable zip ਵੀ ਹੁੰਦੀ ਹੈ, ਜੋ ਥਾਂ ਉੱਤੇ ਹੀ ਚੱਲਦੀ ਹੈ। Windows ਉੱਤੇ ਸਿਰਫ਼ ਪੂਰਾ ਸੰਸਕਰਣ ਹੀ ਪ੍ਰਕਾਸ਼ਿਤ ਹੁੰਦਾ ਹੈ।

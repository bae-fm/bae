## ਸਿੰਕ

sync ਤੁਹਾਡੇ cloud home ਰਾਹੀਂ ਹੁੰਦਾ ਹੈ। ਹਰ ਬਦਲਾਅ encrypted changeset ਬਣਾਉਂਦਾ ਹੈ।

## bae

ਕਈ ਡਿਵਾਈਸ sync ਕਰਨ ਲਈ bae ਸਥਾਨਕ ਪਛਾਣ, library key ਅਤੇ cloud home ਵਰਤਦਾ ਹੈ।

## ਸਟੋਰੇਜ

ਫਾਈਲਾਂ self-managed, local-managed ਜਾਂ cloud-managed ਹੋ ਸਕਦੀਆਂ ਹਨ।

## ਇਨਕ੍ਰਿਪਸ਼ਨ

Opaque cloud home ਡਾਟਾ ਡਿਵਾਈਸ ਛੱਡਣ ਤੋਂ ਪਹਿਲਾਂ ਇਨਕ੍ਰਿਪਟ ਕਰਦਾ ਹੈ।

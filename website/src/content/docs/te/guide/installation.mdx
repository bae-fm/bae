## రెండు editions

ప్రతి వేదిక ఒకే మూలం నుంచి నిర్మించిన రెండు editions లో వస్తుంది:

- **bae**, పూర్తి app: S3, Google Drive, Dropbox, OneDrive, మరియు iCloud సమకాలీకరణ.
- **baeium**, proprietary భాగాలు లేకుండా: S3-compatible నిల్వ మాత్రమే, OAuth providers లేవు, iCloud/CloudKit లేదు, telemetry లేదు.

అవి పక్కపక్కనే install అవుతాయి, ప్రతి దానికి తన లైబ్రరీ, తన (iCloud-Keychain-synced) కీలు ఉంటాయి. కింద మీకు నచ్చినదాన్ని ఎంచుకోండి.

## iOS

iOS builds sideloading కోసం **unsigned `.ipa` ఫైళ్లు**. [AltStore](https://altstore.io) లేదా [Sideloadly](https://sideloadly.io) తో install చేయండి, లేదా మీ స్వంత Apple ID తో Xcode లో re-sign చేయండి (ఉచిత Apple ID baeium కు పనిచేస్తుంది). App Store distribution ఇంకా setup కాలేదు.

Windows builds unpackaged app యొక్క **unsigned** zips. Extract చేసి `bae.exe` / `baeium.exe` నడపండి. SmartScreen మొదటి launch లో హెచ్చరిక చూపవచ్చు.

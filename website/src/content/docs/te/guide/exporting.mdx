బంధించకపోవడం రెండు దిశల్లో వర్తిస్తుంది: bae లోపలికి వచ్చేటప్పుడు మీ ఫైళ్లను మార్చదు, బయటికి వెళ్లేటప్పుడు వాటిని ఆపి ఉంచదు. స్థానిక విడుదలలు ఇప్పటికే మీ సంచయాల్లోని ఫైళ్లే. క్లౌడ్‌లోని విడుదలలను ఎప్పుడైనా byte-for-byte మళ్లీ స్థానికంగా చేయవచ్చు. మీకు *వేరే* రూపం కావలసినప్పుడు, ఉదాహరణకు ఫోన్‌కు తగిన encode, Save as… మూల ఫైళ్లను తాకకుండా దాన్ని తయారు చేస్తుంది.

## రెండు ఎగుమతులు

- **Export…**: ఆల్బమ్ మెనూ లేదా Storage managerలో, ఒక విడుదల ఫైళ్లను byte-for-byte ఒక సంచయానికి కాపీ చేస్తుంది.
- **Save as…**: ట్రాక్‌పై, లేదా విడుదల కోసం ఆల్బమ్ మెనూలో, మీరు ఎంచుకున్న formatకు మారుస్తుంది, ఉదాహరణకు కారు లేదా ఫోన్ కోసం FLAC నుండి MP3. ఇది కొత్త ఫైళ్లను రాస్తుంది; మూల ఫైళ్లు ఉన్నట్టే ఉంటాయి.

రెండూ పురోగతి చూపే క్యూలో నడుస్తాయి. మీరు వాటిని పాజ్ చేయవచ్చు, రద్దు చేయవచ్చు; విఫలమైన పని మీరు రద్దు చేసే వరకు దాని లోపంతో క్యూలో ఉంటుంది. Save క్యూలో చేర్చిన సమయంలోని format, settingsను ఉంచుకుంటుంది, కాబట్టి తర్వాత వాటిని మార్చినా క్యూలో ఇప్పటికే ఉన్నదేదీ మారదు.

## Formats

Format అంటే ఒక పేరు, ఒక codec: FLAC, WAV, AIFF, MP3, AAC లేదా Opus. అవి Settings, Save asలో **Formats** కింద ఉంటాయి. **Add format…** ఒకదాన్ని చేర్చుతుంది, దాని మెనూలోని **Edit…**, **Delete…** దాన్ని మారుస్తాయి లేదా తొలగిస్తాయి. Formatకు ఒక **Name**, ఒక **Format**, నాణ్యతకు ఒక setting ఉంటాయి. పేర్లు ప్రత్యేకంగా ఉంటాయి, కానీ రెండు format ఒకే దాన్ని రాయవచ్చు. కొత్త formatకు దాని codec పేరు వస్తుంది, ఆ పేరు వాడుకలో ఉంటే సంఖ్య చేరుతుంది ("FLAC", "FLAC (2)"). FLAC, MP3 ముందే ఉన్నాయి.

ప్రతి format ట్రాక్‌లకు, విడుదలలకు రెండింటికీ పనిచేస్తుంది. Save as windowలో **Format** pop-up అన్ని formatలను చూపి, మీరు చివరిగా వాడినదాంతో మొదలవుతుంది. దాని చివరి అంశం **Edit formats…** settingsలో Save asను తెరుస్తుంది; pop-up అక్కడ చేసిన మార్పులను అనుసరిస్తుంది, అక్కడ చేర్చిన format వెంటనే ఎంపికవుతుంది.

## నాణ్యత

- **Bit depth**, FLAC, WAV, AIFF కోసం: **Same as source** లేదా **16-bit**. Lossy మూలానికి సొంత depth ఉండదు, కాబట్టి అది 16 bitలో రాయబడుతుంది.
- **Bitrate**, MP3, AAC, Opus కోసం: ఆ codec encoder రాసే bitrateల జాబితా. MP3: 32, 40, 48, 56, 64, 80, 96, 112, 128, 160, 192, 224, 256, 320 kbps. AAC: 96, 128, 160, 192, 256, 320 kbps. Opus: 64, 96, 128, 160, 192, 256 kbps.

## పేర్లు

Settings, Save asలో **Names** కింద, ఒక **File name** pattern, ఒక **Folder name** pattern అన్ని formatలకు వర్తిస్తాయి. Pattern అంటే మీరు తిరిగి అమర్చే, తీసివేసే, చేర్చే భాగాల వరుస, అది చేసే పేరు preview చూపబడుతుంది. ఫైల్ పేరులో title, artist, album, year, track number, disc number, మొత్తం tracks ఉపయోగించవచ్చు. సంచయం పేరులో artist, album, year, label, catalog number ఉపయోగించవచ్చు; విడుదల పేర్కొనని భాగం విడిచిపెట్టబడుతుంది.

ట్రాక్‌పై Save as… pattern పేరును సూచిస్తుంది, వేరే format ఎంచుకుంటే extension మాత్రమే మారుతుంది. విడుదలను save చేస్తే దాని ఫైళ్లు folder pattern పేరు పెట్టిన సంచయంలో రాయబడతాయి. విడుదల save ఎప్పుడూ ఫైల్‌ను మార్చదు: మీ drive‌లో రెండు పేర్లు ఒకే ఫైల్ అయితే save విఫలమవుతుంది. ఒక ట్రాక్‌పై Save as… ఉన్న ఫైల్‌ను మీరు నిర్ధారించినప్పుడు మాత్రమే మారుస్తుంది.

## ప్రతి ట్రాక్‌కు ఒక ఫైల్

ప్రతి save ప్రతి ట్రాక్‌కు ఒక ఫైల్ రాస్తుంది, ఖాళీలకు ఒకే నియమంతో. Pregap, నిల్వ చేసినది లేదా సృష్టించినది, ముందున్న ట్రాక్ చివరకు వెళ్తుంది, ట్రాక్ 1కి ముందున్న దాచిన audio ట్రాక్ 1 ఆరంభంలో ఉంటుంది. ఒక image, CUE sheetగా నిల్వ చేసిన విడుదల ట్రాక్ గుర్తుల వద్ద విభజించబడుతుంది. Save as… CUE sheet రాయదు.

## Encode చేయడానికి బదులు కాపీ

ఎంచుకున్న lossless formatలో ఇప్పటికే ఉన్న, format రాసే depthలో ఉన్న పూర్తి ఫైల్ అయిన ట్రాక్‌ను మళ్లీ encode చేయకుండా కాపీ చేస్తారు. WAV, AIFF 16 లేదా 24 bitలో లెక్కకు వస్తాయి. దాని tags, cover, పేరు కొత్తగా రాయబడతాయి. Lossy format ఎప్పుడూ encode చేస్తుంది.

## అదనపు

Settings, Save asలో **Extras** కింద మూడు switchలు ప్రతి formatకూ వర్తిస్తాయి. అన్నీ మొదట ఆన్‌లో ఉంటాయి.

- **Embed cover art**: ప్రతి ఫైల్‌లో cover ఉంచుతుంది.
- **Cover image in the folder**: విడుదల save దాని సంచయంలో `cover.jpg` కూడా రాస్తుంది.
- **Loudness tags**: import సమయంలో bae కొలిచిన loudness నుండి ప్రతి ఫైల్‌లో ట్రాక్, ఆల్బమ్ ReplayGain gain, peak రాస్తుంది.

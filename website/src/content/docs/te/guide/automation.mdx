## MCP సర్వర్

Settings, Automation లో MCP సర్వర్‌ను ఆన్ చేయండి. అది Model Context Protocol ను HTTP ద్వారా స్థానిక పోర్టులో అందిస్తుంది (డిఫాల్ట్‌గా 47777), కాబట్టి Claude వంటి MCP క్లయింట్లు మీ గ్రంథాలయాన్ని చూడగలవు, విడుదలలను వెతకగలవు, వాటిపై చర్యలు తీసుకోగలవు. ప్రాప్యతకు bearer టోకెన్ కావాలి: అదే సెట్టింగ్‌ల ప్యాన్ నుంచి దాన్ని కాపీ చేయండి; ఆ టోకెన్ ఉన్న అన్నింటి ప్రాప్యతను నిలిపేయాలనుకుంటే అక్కడే కొత్తదాన్ని సృష్టించండి.

సర్వర్ డిఫాల్ట్‌గా ఆఫ్‌లో ఉంటుంది; యాప్ నడుస్తున్నప్పుడే అది నడుస్తుంది.

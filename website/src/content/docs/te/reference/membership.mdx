bae లో ఎక్కడా ఖాతా వ్యవస్థ లేదు. గ్రంథాలయంలోని ప్రతి వ్యక్తీ ఒక coven *సభ్యుడు*: యాదృచ్ఛిక, శాశ్వత సభ్య id మరియు రెండు కీ జతలు, ఒకటి సంతకానికి, ఒకటి కీలు దానికి ముద్రించబడటానికి; ఆ వ్యక్తి అన్ని పరికరాలూ వాటిని పంచుకుని ప్రతి పరికరపు OS keyring లో ఉంచుతాయి. పరికరం అంటే ఒక ఇన్‌స్టాలేషన్, తన స్వంత id తో, ఒక సభ్యుడికి చెందినది. గ్రంథాలయంలో ఎవరు ఉన్నారు అనేది మేఘ నిల్వ ఇంట్లోని సంతకం చేసిన రికార్డుల సమితి; ప్రతి సభ్యుడి పరికరం వాటిని తనిఖీ చేస్తుంది, ఏ సర్వరూ జారీ చేయదు. వ్యవస్థ [coven](https://coven.bae.fm) ది; bae దాన్ని ఎలా వాడుతుందో ఈ పుట చూపిస్తుంది.

## Membership records

మేఘ నిల్వ ఇంట్లో గ్రంథాలయపు మొత్తం చరిత్ర ఒక సంఖ్యాక్రమ వరుస, ప్రతి పరికరం దాన్ని ఒకే క్రమంలో అమలు చేస్తుంది. సభ్యత్వం లేదా సెట్టింగ్‌ల మార్పు ఆ వరుసలో ఒక *admin entry*, రచయిత కీతో సంతకం చేయబడి, దానికి వెంటనే ముందున్న స్థితి ఆధారంగా నిర్ణయించబడుతుంది; కాబట్టి ప్రతి పరికరం తానే అదే నిర్ణయానికి వస్తుంది. రచయితకు అది చేసే హక్కు ఉంటేనే entry లెక్కలోకి వస్తుంది, గ్రంథాలయం ఎల్లప్పుడూ కనీసం ఒక admin ను ఉంచుతుంది.

పరికరం పంపే ప్రతి మార్పూ ఈ రికార్డుకు వ్యతిరేకంగా తనిఖీ చేయబడుతుంది: ప్రస్తుత సభ్యుడి సంతకం, తొలగించబడని పరికరం నుంచి. తొలగించిన పరికరాలు లేదా సభ్యుల నుంచి, ఎప్పుడూ జోడించని కీల నుంచి, లేదా చెల్లని సంతకాలతో వచ్చే మార్పులు లెక్కలోకి రావు. నిల్వ సేవ రికార్డులను ఉంచుతుంది కానీ వాటిని నకిలీ చేయలేదు.

## Roles

**Admin** మరియు **సభ్యుడు** ఇద్దరూ గ్రంథాలయాన్ని చదువుతారు, రాస్తారు: coven గ్రంథాలయంలో రాసేటప్పుడు ఏ అనుమతినీ తనిఖీ చేయదు, కాబట్టి చదవడానికి-మాత్రమే పాత్ర నిలవలేదు. admins అదనంగా వ్యక్తులను ఆహ్వానిస్తారు, తొలగిస్తారు, పాత్రలు మారుస్తారు, గ్రంథాలయం పేరు మారుస్తారు. గ్రంథాలయానికి దాని మేఘ నిల్వ ఇంటిని ఇచ్చే వ్యక్తి దాని మొదటి admin.

| చర్య | ఎవరు |
|---|---|
| వ్యక్తిని ఆహ్వానించడం | admin |
| పరికరాన్ని జోడించడం | వ్యక్తి స్వయంగా, కొత్త పరికరం నుంచి, తమ restore code తో |
| పరికరాన్ని తొలగించడం | దాని వ్యక్తి, లేదా ఏ admin అయినా |
| వ్యక్తిని తొలగించడం | admin |
| గ్రంథాలయం పేరు మార్చడం | admin |

వ్యక్తి profile, ratings, చరిత్ర, playlists owner వరుసలు: ఆ వ్యక్తి పరికరాలు మాత్రమే వాటిని మార్చగలవు, కాబట్టి ఒకరి పేరున నమోదైన rating నిజంగా వారిదే.

## మీ స్వంత పరికరాన్ని జోడించడం

restore code పరికరం దాని వ్యక్తికి చెందినదని నిరూపిస్తుంది, కాబట్టి ఏ ఆమోదమూ అవసరం లేదు:

1. కొత్త పరికరం కోడ్‌ను పొందుతుంది: వ్యక్తి మరో పరికరం చూపే QR కోడ్‌ను స్కాన్ చేసి, Apple పరికరాల్లో iCloud Keychain నుంచి, లేదా టైప్ చేసి.
2. అది నిల్వను చేరుతుంది: Dropbox, OneDrive లో వ్యక్తి స్వంత ఖాతాలో sign in చేసి, S3 లో వారి access key తో, దాన్ని QR కోడ్ కోడ్‌తో పాటు తెస్తుంది.
3. అది గ్రంథాలయాన్ని లోడ్ చేసి, కోడ్ కీలు ప్రస్తుత సభ్యుడివేనని తనిఖీ చేసి, ఆ కీలతో సంతకం చేసిన entry ద్వారా తనను కొత్త పరికరంగా నమోదు చేసుకుంటుంది.

కీలు తర్వాత మారిన కోడ్ విఫలమవుతుంది. పునరుద్ధరణ ఎల్లప్పుడూ కొత్త పరికరాన్ని సృష్టిస్తుంది; అది మరో ఇన్‌స్టాలేషన్ పంపని సవరణలను కాపాడదు.

## ఒక వ్యక్తిని ఆహ్వానించడం

1. admin వ్యక్తి సేవా ఖాతాను నమోదు చేసి వారి పాత్రను ఎంచుకుంటారు. bae గ్రంథాలయపు సంచయాన్ని ఆ ఖాతాతో పంచుకుంటుంది, లేదా S3 లో వారి కోసం access key సృష్టిస్తుంది, తర్వాత ఆహ్వానాన్ని చూపిస్తుంది: గ్రంథాలయపు స్థానం, ఆ వ్యక్తి కోసం ఎంచుకున్న సభ్య id, ఒకసారి వాడే రహస్యం, గ్రంథాలయపు ప్రస్తుత పేరు ఉన్న QR కోడ్. అది సృష్టించిన ఒక రోజు తర్వాత గడువు ముగుస్తుంది.
2. వ్యక్తి పరికరం దాన్ని స్కాన్ చేసి, వారి స్వంత ఖాతాలో sign in చేసి, వారి కీ జతలను సృష్టించి, నిల్వలో చేరిక అభ్యర్థనను రాస్తుంది; అది ఆహ్వాన రహస్యం నుంచి తీసిన కీతో గుప్తీకరించబడి, వారి కొత్త కీతో సంతకం చేయబడుతుంది.
3. రహస్యాన్ని కలిగి ఉన్న ఏకైక పరికరమైన admin పరికరం అభ్యర్థనను చూపిస్తుంది, admin దాన్ని ఆమోదిస్తారు.
4. ఆమోదం ప్రతి store key ను వ్యక్తి కొత్త ముద్ర కీకి ముద్రించి, తర్వాత వారిని అంగీకరించే entry ను జోడిస్తుంది.
5. కొత్త పరికరం తన కీలను తెరిచి, గ్రంథాలయాన్ని లోడ్ చేసి, తనను నమోదు చేసుకుని, వ్యక్తి టైప్ చేసిన పేరుతో వారి profile ను రాస్తుంది.

ఆహ్వానాన్ని తిరస్కరిస్తే, లేదా గడువు ముగియనిస్తే, అది ఇచ్చిన సేవా ప్రాప్యత వెనక్కి తీసుకోబడుతుంది.

## తొలగింపు

పరికరాన్ని లేదా వ్యక్తిని తొలగించడం ఒక admin entry, వరుసలో దాని స్థానం చరిత్రలో ఒక గీత: తొలగించిన పరికరం లేదా వ్యక్తి ఆ తర్వాత పంపేది లెక్కలోకి రాదు, ముందే వచ్చినది నిలుస్తుంది. వ్యక్తిని తొలగించడం వారి పరికరాలనూ వ్యక్తిగత circle నూ తొలగిస్తుంది, వారి దగ్గర ఉన్న కీలు మరింత డేటా రాసే ముందు మార్చబడతాయి ([గుప్తీకరణ](/te/reference/encryption#కీ-మార్పిడి) చూడండి). నిల్వ ప్రాప్యతను తెంచడం సేవ పని: గ్రంథాలయం ఉన్న ఖాతా పరికరం సంచయాన్ని పంచుకోవడం ఆపుతుంది, S3 లో వ్యక్తి access key తొలగించబడుతుంది. తొలగించిన పరికరంలో ఇప్పటికే సమకాలీకరించబడినది దాని దగ్గరే ఉంటుంది; డేటాను వెనక్కి తీసుకోలేము.

## పునరుద్ధరణ కోడ్లు

restore code లో సభ్యుడి id మరియు వారి ప్రస్తుత ప్రైవేట్ కీ జతలు, గ్రంథాలయపు store id మరియు దాని నిల్వ స్థానం ఉంటాయి; నిల్వ ఆధారాలు, sign-in టోకెన్లు లేదా గ్రంథాలయం పేరు ఎప్పుడూ ఉండవు. అది కోరినప్పుడు చూపబడుతుంది, Apple వేదికలపై స్వయంచాలకంగా iCloud Keychain లో సేవ్ అవుతుంది, గ్రంథాలయమంత సున్నితమైనది: అదీ నిల్వ ప్రాప్యతా ఉన్నవారే గ్రంథాలయానికి ఆ వ్యక్తి. ప్రతి పరికరాన్నీ తమ కోడ్‌నూ పోగొట్టుకున్న వ్యక్తిని admin వారి ప్రస్తుత సభ్య id కి మళ్లీ ఆహ్వానించవచ్చు; ఇది వారి కీలను మారుస్తుంది.

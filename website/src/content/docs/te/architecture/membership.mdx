## సభ్యత్వం

Membership chain ఏ పరికరాలు లైబ్రరీని చదవగలవు, రాయగలవు అని నమోదు చేస్తుంది.

## bae

అనేక పరికరాలను sync చేయడానికి bae స్థానిక identity, library key, cloud home ఉపయోగిస్తుంది.

## నిల్వ

ఫైల్‌లు self-managed, local-managed, లేదా cloud-managed కావచ్చు.

## ఎన్‌క్రిప్షన్

Opaque cloud home డేటా పరికరం విడిచే ముందు ఎన్‌క్రిప్ట్ చేస్తుంది.

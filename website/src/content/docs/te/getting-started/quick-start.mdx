## త్వరిత ప్రారంభం

లైబ్రరీ సృష్టించి, స్థానిక FLAC ఫోల్డర్‌ను దిగుమతి చేసి, MusicBrainz లేదా Discogs సరిపోలికను ఎంచుకోండి.

## bae

అనేక పరికరాలను sync చేయడానికి bae స్థానిక identity, library key, cloud home ఉపయోగిస్తుంది.

## నిల్వ

ఫైల్‌లు self-managed, local-managed, లేదా cloud-managed కావచ్చు.

## ఎన్‌క్రిప్షన్

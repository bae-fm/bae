## مطابقت پذیری

sync آپ کے cloud home سے ہوتا ہے۔ ہر تبدیلی encrypted changeset بناتی ہے۔

## bae

کئی آلات sync کرنے کے لیے bae مقامی شناخت، library key، اور cloud home استعمال کرتا ہے۔

## اسٹوریج

فائلیں self-managed، local-managed، یا cloud-managed ہو سکتی ہیں۔

## خفیہ کاری

Opaque cloud home ڈیٹا کو آلے سے نکلنے سے پہلے خفیہ کرتا ہے۔

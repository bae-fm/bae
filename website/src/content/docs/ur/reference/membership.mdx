bae میں کہیں بھی اکاؤنٹ کا نظام نہیں۔ لائبریری کا ہر شخص ایک coven *رکن* ہے: ایک بے ترتیب، مستقل رکن id اور دو کلید جوڑے، ایک دستخط کے لیے اور ایک جس کے لیے کلیدیں مہر بند ہوتی ہیں؛ اس شخص کے سب آلات انہیں بانٹتے ہیں اور ہر آلے کے OS کلید خانہ میں رکھتے ہیں۔ آلہ ایک تنصیب ہے، اپنی id کے ساتھ، جو ایک رکن کی ہے۔ لائبریری میں کون ہے یہ کلاؤڈ گھر میں دستخط شدہ ریکارڈوں کا مجموعہ ہے، جسے ہر رکن کا آلہ جانچتا ہے، کوئی سرور جاری نہیں کرتا۔ نظام [coven](https://coven.bae.fm) کا ہے؛ یہ صفحہ دکھاتا ہے کہ bae اسے کیسے استعمال کرتا ہے۔

## رکنیت ریکارڈ

کلاؤڈ گھر میں لائبریری کی پوری تاریخ ایک شمار شدہ ترتیب ہے، اور ہر آلہ اسے ایک ہی ترتیب میں لاگو کرتا ہے۔ رکنیت یا ترتیبات کی تبدیلی اس ترتیب میں ایک *admin entry* ہے، لکھنے والے کی کلید سے دستخط شدہ اور اپنے فوراً پہلے کی حالت کی بنیاد پر طے، اس لیے ہر آلہ خود اسی فیصلے پر پہنچتا ہے۔ entry تبھی شمار ہوتی ہے جب لکھنے والے کو یہ کرنے کا حق ہو، اور لائبریری ہمیشہ کم از کم ایک admin رکھتی ہے۔

آلے کی بھیجی ہر تبدیلی اس ریکارڈ سے جانچی جاتی ہے: موجودہ رکن کا دستخط، ایسے آلے سے جو ہٹایا نہیں گیا۔ ہٹائے گئے آلات یا ارکان سے، کبھی شامل نہ کی گئی کلیدوں سے، یا غلط دستخطوں والی تبدیلیاں شمار نہیں ہوتیں۔ فراہم کنندہ ریکارڈ رکھتا ہے مگر انہیں جعلی نہیں بنا سکتا۔

## کردار

**Admin** اور **رکن** دونوں لائبریری پڑھتے اور لکھتے ہیں: coven لائبریری میں لکھنے پر کوئی اجازت نہیں جانچتا، اس لیے صرف پڑھنے والا کردار قائم نہیں رہ سکتا۔ admins اس کے علاوہ لوگوں کو مدعو کرتے اور ہٹاتے ہیں، کردار بدلتے ہیں اور لائبریری کا نام بدلتے ہیں۔ جو شخص لائبریری کو اس کا کلاؤڈ گھر دیتا ہے وہ اس کا پہلا admin ہے۔

| عمل | کون |
|---|---|
| شخص کو مدعو کرنا | admin |
| آلہ شامل کرنا | شخص خود، نئے آلے سے، اپنے restore code کے ساتھ |
| آلہ ہٹانا | اس کا شخص، یا کوئی بھی admin |
| شخص کو ہٹانا | admin |
| لائبریری کا نام بدلنا | admin |

شخص کی profile، ratings، تاریخ اور playlists owner قطاریں ہیں: صرف اس شخص کے آلات انہیں بدل سکتے ہیں، اس لیے کسی کے نام درج rating واقعی اسی کی ہے۔

## اپنا آلہ شامل کرنا

restore code ثابت کرتا ہے کہ آلہ اس کے شخص کا ہے، اس لیے کسی منظوری کی ضرورت نہیں:

1. نیا آلہ code حاصل کرتا ہے: شخص کے کسی دوسرے آلے پر دکھایا گیا QR code اسکین کر کے، Apple آلات پر iCloud Keychain سے، یا ٹائپ کر کے۔
2. یہ ذخیرہ تک پہنچتا ہے: Dropbox اور OneDrive پر شخص کے اپنے اکاؤنٹ میں sign in کر کے، S3 پر اس کی access key سے، جو QR code code کے ساتھ لاتا ہے۔
3. یہ لائبریری لوڈ کرتا ہے، جانچتا ہے کہ code کی کلیدیں موجودہ رکن کی ہیں، اور ان کلیدوں سے دستخط شدہ entry کے ذریعے خود کو نئے آلے کے طور پر درج کرتا ہے۔

جس code کی کلیدیں بعد میں بدل چکی ہوں وہ ناکام ہوتا ہے۔ بحالی ہمیشہ نیا آلہ بناتی ہے؛ یہ کسی دوسری تنصیب کی نہ بھیجی گئی ترمیمات نہیں بچاتی۔

## کسی شخص کو مدعو کرنا

1. admin شخص کا فراہم کنندہ اکاؤنٹ درج کرتا ہے اور اس کا کردار چنتا ہے۔ bae لائبریری کا پوشہ اس اکاؤنٹ کے ساتھ بانٹتا ہے، یا S3 پر اس کے لیے access key بناتا ہے، اور دعوت دکھاتا ہے: ایک QR code جس میں لائبریری کی جگہ، اس شخص کے لیے چنی گئی رکن id، ایک بار استعمال ہونے والا راز اور لائبریری کا موجودہ نام ہوتا ہے۔ یہ بننے کے ایک دن بعد ختم ہو جاتی ہے۔
2. شخص کا آلہ اسے اسکین کرتا ہے، اس کے اپنے اکاؤنٹ میں sign in کرتا ہے، اس کے کلید جوڑے بناتا ہے اور ذخیرہ میں شمولیت کی درخواست لکھتا ہے، جو دعوت کے راز سے نکالی گئی کلید سے رمز بند اور اس کی نئی کلید سے دستخط شدہ ہوتی ہے۔
3. admin کا آلہ، راز رکھنے والا واحد آلہ، درخواست دکھاتا ہے، اور admin اسے منظور کرتا ہے۔
4. منظوری ہر store key کو شخص کی نئی مہری کلید کے لیے مہر بند کرتی ہے، پھر اسے قبول کرنے والی entry شامل کرتی ہے۔
5. نیا آلہ اپنی کلیدیں کھولتا ہے، لائبریری لوڈ کرتا ہے، خود کو درج کرتا ہے اور شخص کے ٹائپ کیے نام کے ساتھ اس کی profile لکھتا ہے۔

دعوت مسترد کرنے سے، یا اسے ختم ہونے دینے سے، اس کی دی ہوئی فراہم کنندہ رسائی واپس لے لی جاتی ہے۔

## ہٹانا

آلے یا شخص کو ہٹانا ایک admin entry ہے، اور ترتیب میں اس کی جگہ تاریخ میں ایک لکیر ہے: ہٹایا گیا آلہ یا شخص اس کے بعد جو بھیجے وہ شمار نہیں ہوتا، جبکہ پہلے پہنچا ہوا باقی رہتا ہے۔ شخص کو ہٹانا اس کے آلات اور اس کا نجی circle بھی ہٹاتا ہے، اور اس کے پاس رہی کلیدیں مزید ڈیٹا لکھے جانے سے پہلے بدل دی جاتی ہیں ([Encryption](/ur/reference/encryption#کلید-کی-تبدیلی) دیکھیں)۔ ذخیرہ کی رسائی کاٹنا فراہم کنندہ کا کام ہے: جس اکاؤنٹ میں لائبریری ہے اس کا آلہ پوشے کی شراکت بند کرتا ہے، اور S3 پر شخص کی access key حذف کی جاتی ہے۔ ہٹائے گئے آلے پر جو پہلے ہم آہنگ ہو چکا وہ اسی کے پاس رہتا ہے؛ ڈیٹا واپس نہیں لیا جا سکتا۔

## بحالی کوڈ

restore code میں رکن کی id اور اس کے موجودہ نجی کلید جوڑے، لائبریری کی store id اور اس کی ذخیرہ کی جگہ ہوتی ہے؛ ذخیرہ کے credentials، sign-in tokens یا لائبریری کا نام کبھی نہیں۔ یہ مانگنے پر دکھایا جاتا ہے، Apple پلیٹ فارم پر خود بخود iCloud Keychain میں محفوظ ہوتا ہے، اور لائبریری جتنا ہی حساس ہے: جس کے پاس یہ اور ذخیرہ کی رسائی ہو، لائبریری کے لیے وہی وہ شخص ہے۔ ہر آلہ اور اپنا code کھو دینے والے شخص کو admin اس کی موجودہ رکن id پر دوبارہ مدعو کر سکتا ہے، جس سے اس کی کلیدیں بدل جاتی ہیں۔

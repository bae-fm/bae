description: اپنے پوشوں کو حقیقی اجرا سے ملائیں
---

نقلوں کا پوشہ اپنے بارے میں تقریباً کچھ نہیں جانتا۔ وہ اجرا جس سے یہ آیا، pressing، label، credits، ٹریک 12 اصل میں کہاں ختم ہوتا ہے: یہ سب MusicBrainz اور Discogs جیسی databases میں رہتا ہے، آپ کے filenames میں نہیں۔ درآمد وہ طریقہ ہے جس سے bae دونوں کو جوڑتا ہے: آپ اسے اپنی موسیقی دکھاتے ہیں، یہ معلوم کرتا ہے کہ ہر پوشہ کون سا اجرا ہے، اور لائبریری اس پوشے کو اسی اجرا کے طور پر درج کرتی ہے۔

درآمد ڈیسک ٹاپ (macOS، Windows) پر ہوتی ہے۔ آپ کی فائلیں پڑھی جاتی ہیں، کبھی بدلی نہیں جاتیں: bae کچھ منتقل، نام تبدیل، tag تبدیل، یا دوبارہ encode نہیں کرتا۔ درآمد کے بعد فائلیں کہاں رہتی ہیں، اس کے لیے [ذخیرہ and offline](/ur/guide/storage) دیکھیں۔

## نگرانی والے پوشے

**Import** section پر جائیں اور پوشہ شامل کریں: اسے چنیں، کھڑکی پر کھینچ کر ڈالیں، یا <kbd>⌘I</kbd> press کریں۔ bae اس کے بعد پوشے کی نگرانی کرتا ہے۔ اس میں ڈالی گئی نئی موسیقی خود نئے امیدواروں کے طور پر دکھائی دیتی ہے؛ آپ ہاتھ سے دوبارہ اسکین نہیں کرتے۔ جو پوشے ابھی ڈاؤن لوڈ ہو رہے ہوں انہیں مکمل ہونے تک نظر انداز کیا جاتا ہے۔

اسکین نقلوں کی اصل شکلوں میں اجرا پہچانتا ہے:

| ترتیب | شکل |
|--------|------|
| ہر ٹریک کی الگ فائل | `01 - Song.flac`, `02 - Song.flac`, ... |
| CUE + image | `album.cue` + `album.flac`, پوری ڈسک کے لیے ایک فائل |
| کئی ڈسکیں | `CD1/`, `CD2/` ذیلی پوشے، اندر کوئی بھی شکل |
| مجموعے | پوشوں کا پوشہ، ہر ایک اپنا اجرا |

bae وہ شکلیں درآمد کرتا ہے جو یہ چلاتا ہے: FLAC، MP3، APE، ALAC اور `.m4a` میں AAC، WAV، AIFF، Ogg Vorbis، Opus، WavPack، اور DSD (`.dsf`/`.dff`)۔ پوشے میں تصاویر اور documents (CUE sheets، نقل نوشتے، text فائلیں) پہچانے جاتے ہیں اور اجرا کے ساتھ رکھے جاتے ہیں۔

## اجرا کی شناخت

امیدوار منتخب کریں اور bae اسے شناخت کرنا شروع کرتا ہے۔ tags سے اندازہ لگانے کے بجائے، یہ پوشے میں موجود شہادت پڑھتا ہے اور ہر ٹکڑا تلاش کرتا ہے:

- **Disc ID.** CD کی ٹھیک ٹریک ترتیب کا fingerprint، نقل نوشتہ یا CUE sheet سے نکالا ہوا۔ ملنے پر یہ ٹھیک CD edition پہچانتا ہے۔
- **Barcode.** پوشے میں غلاف اسکین سے text recognition کے ذریعے، یا CUE sheet سے پڑھا ہوا۔
- **Catalog numbers and text.** تصاویر، فائل اور پوشہ ناموں میں ملے فہرست اعداد، نتائج محدود کرنے کے لیے استعمال ہوتے ہیں۔

اشاروں کو MusicBrainz اور Discogs کے مقابل ایک ہی وقت میں دیکھا جاتا ہے، اور نتائج کی باہمی پڑتال ہوتی ہے۔ ہر اشارہ نتائج کے اوپر نشان کے طور پر آتا ہے: آپ دیکھ سکتے ہیں کیا ملا، کہاں سے آیا (origin کے لیے hover کریں: disc TOC، CUE sheet، غلاف اسکین، پوشہ name)، اور اگر کوئی گمراہ کر رہا ہو تو الگ اشارے بند کر سکتے ہیں۔

تین نتیجے:

- **Found.** شہادت ایک اجرا گروہ پر متفق ہے۔ آپ اس کی فہرست سے ٹھیک pressing چنتے ہیں۔
- **Conflict.** دو اشارے مختلف اجرا کی طرف جاتے ہیں، مثلاً disc ID اور barcode متفق نہ ہوں۔ bae دونوں رخ دکھاتا ہے اور آپ چنتے ہیں کس پر بھروسا کرنا ہے، یا اشارہ نظر انداز کرتے ہیں۔
- **Nothing found.** ہاتھ سے تلاش کریں: artist اور album، فہرست عدد، یا barcode، کسی بھی database کے مقابل۔ تصاویر سے پہچانا گیا متن autocomplete کے طور پر پیش ہوتا ہے۔

آپ **skip identifying** بھی کر سکتے ہیں اور نامعلوم اجرا کے طور پر درآمد کر سکتے ہیں۔ bae پھر ناموں کے لیے آپ کی فائلوں کے جڑے ہوئے tags پر fallback کرتا ہے، اور آپ بعد میں دوبارہ شناخت کر سکتے ہیں، جب اجرا database میں موجود ہو یا آپ کے پاس بہتر شہادت ہو۔

## عین یا تخمینی

جب آپ ملان منتخب کرتے ہیں، bae اسے آپ کی فائلوں کے مقابل جانچتا ہے، اور ٹریک تعداد mismatch دکھاتا ہے۔ پھر آپ بتاتے ہیں کہ ملان کیا ہے:

- **Exact**: آپ کی فائلیں یہی pressing ہیں۔
- **Metadata only**: البم درست ہے، مگر ضروری نہیں کہ یہی عین pressing ہو۔ bae میٹا معلومات استعمال کرتا ہے اور یاد رکھتا ہے کہ pressing تخمینی ہے۔

اگر اجرا پہلے سے آپ کی لائبریری میں ہے، یا اسی البم کی دوسری pressing ہے، bae نقل درآمد سے پہلے بتاتا ہے۔

## تصدیق اور درآمد

تصدیقی خانہ وہ سب دکھاتا ہے جو درآمد لکھے گی:

- **Cover.** databases کے art، آپ کے پوشے کی images، یا فائلوں میں جڑے ہوئے art سے چنا ہوا۔ آپ اسے بعد میں بدل سکتے ہیں۔
- **میٹا معلومات۔** Album، artist، year، label، فہرست عدد، country، barcode، اور ہر ٹریک: کچھ بھی محفوظ ہونے سے پہلے یہی قابل ترمیم ہے۔
- **ذخیرہ۔** اگر کلاؤڈ گھر جڑا ہے، چنیں کہ bae فائلوں کو آپ کے کلاؤڈ میں منظم کرے، اور مقامی نقل بھی رکھے یا نہیں۔ [ذخیرہ اور آف لائن](/ur/guide/storage) دیکھیں۔

درآمد پس منظر میں چلتی ہے: bae تصدیق کرتا ہے کہ ہر ٹریک صاف decode ہوتا ہے، البم اور ہر ٹریک کے لیے loudness ناپتا ہے، اجرا محفوظ کرتا ہے، اور منظم درآمدات کے لیے اپ لوڈ شروع کرتا ہے۔ امیدوار فہرست اگلے پوشے پر چلی جاتی ہے، اور اجرا فوراً چلایا جا سکتا ہے۔

## ڈیٹا کے ذرائع

**MusicBrainz** کو اکاؤنٹ یا کلید نہیں چاہیے۔ **Discogs** آپ کا اپنا مفت API token مانگتا ہے؛ اسے ترتیبات میں چسپاں کریں، اور bae بتاتا ہے اگر یہ کام کرنا چھوڑ دے۔ token کے بغیر Discogs تلاش اور Discogs سے آئی میٹا معلومات دستیاب نہیں ہوتیں، اور باقی سب کام کرتا ہے۔ دونوں خدمات کی درخواستوں پر حد ہے؛ bae درخواستوں کو ان حدود کے اندر رکھنے کے لیے رفتار قابو میں رکھتا ہے۔

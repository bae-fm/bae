پوشہ درآمد کے لیے آواز اور دوسری فائلیں دیتا ہے۔ آپ چنتے ہیں کہ اس کی قابل ترمیم میٹا معلومات کسی آن لائن اجرا سے شروع ہوں، پوشے کی اپنی میٹا معلومات سے، یا خالی فارم سے۔

درآمد ڈیسک ٹاپ (macOS، Windows) پر ہوتی ہے۔ آپ کی فائلیں پڑھی جاتی ہیں، کبھی بدلی نہیں جاتیں: bae کچھ بھی منتقل، نام تبدیل، دوبارہ tag یا دوبارہ encode نہیں کرتا۔ درآمد کے بعد فائلیں کہاں رہتی ہیں، اس کے لیے [ذخیرہ اور آف لائن](/ur/guide/storage) دیکھیں۔

## نگرانی والے پوشے

**Import** section پر جائیں اور پوشہ شامل کریں: اسے چنیں، کھڑکی پر کھینچ کر ڈالیں، یا <kbd>⌘I</kbd> دبائیں۔ bae اس کے بعد پوشے کی نگرانی کرتا ہے۔ اس میں ڈالی گئی نئی موسیقی خود نئے امیدواروں کے طور پر دکھائی دیتی ہے؛ آپ ہاتھ سے دوبارہ اسکین نہیں کرتے۔ جو پوشے ابھی ڈاؤن لوڈ ہو رہے ہوں انہیں مکمل ہونے تک نظر انداز کیا جاتا ہے۔

اسکین اجرا کو ان شکلوں میں پہچانتا ہے جن میں نقلیں واقعی ہوتی ہیں:

| ترتیب | کیسی دکھتی ہے |
|--------|-------------------|
| ہر ٹریک کی الگ فائل | `01 - Song.flac`, `02 - Song.flac`, … |
| CUE + image | `album.cue` + `album.flac`، پوری ڈسک کے لیے ایک فائل |
| کئی ڈسکیں | `CD1/`, `CD2/` ذیلی پوشے، اندر کوئی بھی شکل |
| مجموعے | پوشوں کا پوشہ، ہر ایک اپنا اجرا |

bae وہ شکلیں درآمد کرتا ہے جو یہ چلاتا ہے: FLAC، MP3، APE، ALAC اور `.m4a` میں AAC، WAV، AIFF، Ogg Vorbis، Opus، WavPack، اور DSD (`.dsf`/`.dff`)۔ پوشے میں تصاویر اور دستاویزات (CUE sheets، نقل نوشتے، text فائلیں) پہچانی جاتی ہیں اور اجرا کے ساتھ رکھی جاتی ہیں۔

## میٹا معلومات کا مسودہ بھریں

ہر امیدوار کا میٹا معلومات کا ایک قابل ترمیم مسودہ ہوتا ہے۔ یہ خالی شروع ہو سکتا ہے، کسی آن لائن اجرا سے بھرا جا سکتا ہے، یا پوشے کی اپنی فائلوں کی بتائی باتوں سے۔ خالی مسودے میں ٹائپ کرنا براہ راست اندراج ہے، میٹا معلومات کا الگ ماخذ نہیں۔

کارڈ کے **Identify** کنٹرول Identify صفحے تک جانے کے دو راستے دیتے ہیں، جو اس میں فرق رکھتے ہیں کہ کیا شروع کرتے ہیں۔ **Automatic** اسے کھولتا ہے اور ہر بار شناخت کا نیا دور مانگتا ہے، امیدوار کے پاس پہلے سے جو بھی ہو — پہلے سے چلتا دور نئے کے لیے چھوڑ دیا جاتا ہے۔ **Search** وہی صفحہ اس کی ٹائپ کی ہوئی تلاش پر کھولتا ہے اور کچھ شروع نہیں کرتا۔ دونوں میں سے کوئی مسودہ نہیں بدلتا؛ کوئی نتیجہ لاگو کرنے سے مسودہ بدل جاتا ہے اور قابل ترمیم کارڈ واپس آ جاتا ہے۔ کارڈ کے مینو میں وہ دو حکم ہیں جو مسودے کو وہیں دوبارہ لکھتے ہیں: **Reset to file metadata**، جو اسے اس سے بدل دیتا ہے جو امیدوار کی اپنی فائلیں، sheets اور پوشے کا نام بتاتے ہیں، اور **Clear metadata**، جو اسے خالی کر دیتا ہے۔ دونوں پہلے پوچھتے ہیں، اور کوئی بھی امیدوار کی فائلوں یا ٹریک ترتیب کو نہیں چھوتا۔

### شناخت

Identify صفحہ وہ اجرا ڈھونڈتا ہے جو پوشہ دراصل ہے۔ یہ پوشے سے ثبوت پڑھتا ہے اور ہر ٹکڑا تلاش کرتا ہے:

- **ڈسک ID۔** CD کی بالکل درست ٹریک ترتیب کا fingerprint، نقل نوشتے یا CUE sheet سے نکالا گیا۔ جب یہ ملتا ہے تو بالکل درست CD ایڈیشن کی شناخت کرتا ہے۔
- **بارکوڈ۔** پوشے میں غلاف کے اسکینوں سے متن پہچان کے ذریعے پڑھا گیا، یا CUE sheet سے۔
- **کیٹلاگ نمبر اور متن۔** تصاویر پر اور فائلوں اور پوشوں کے ناموں میں ملے کیٹلاگ نمبر، نتائج محدود کرنے کے لیے۔

اشارے ایک ہی وقت میں MusicBrainz اور Discogs پر تلاش کیے جاتے ہیں، اور نتائج ایک دوسرے سے جانچے جاتے ہیں۔ ہر اشارہ نتائج کے اوپر ایک badge کے طور پر دکھتا ہے: آپ دیکھ سکتے ہیں کہ کیا ملا، کہاں سے آیا (ماخذ کے لیے hover کریں: disc TOC، CUE sheet، غلاف کا اسکین، پوشے کا نام)، اور اگر کوئی اشارہ گمراہ کن ہو تو اسے الگ سے بند کر سکتے ہیں۔

تین نتیجے:

- **ملا۔** ثبوت ایک ہی release group پر متفق ہے۔ آپ اس کی فہرست سے بالکل درست pressing چنتے ہیں۔
- **ٹکراؤ۔** دو اشارے مختلف اجرا کی طرف اشارہ کرتے ہیں، مثلاً ڈسک ID اور بارکوڈ متفق نہیں۔ bae دونوں طرف دکھاتا ہے اور آپ چنتے ہیں کس پر بھروسا کریں، یا کسی اشارے کو نظر انداز کرتے ہیں۔
- **کچھ نہیں ملا۔** ہاتھ سے تلاش کریں: فنکار اور البم، کیٹلاگ نمبر، یا بارکوڈ، کسی بھی database میں۔ تصاویر سے پہچانا گیا متن autocomplete کے طور پر پیش کیا جاتا ہے۔

ماخذ براؤزر تلاش کا فارم، شناخت کی پیش رفت، اشارے اور نتائج ایک ساتھ دکھاتا ہے۔ کوئی نتیجہ چننے سے وہ قطار پیش رفت کے ساتھ کھلی رہتی ہے جب تک bae پورا اجرا لاتا ہے، پھر اسے مسودے پر لاگو کر دیتا ہے۔ نتیجے والا کارڈ MusicBrainz یا Discogs ماخذ chip دکھاتا ہے۔ کارڈ پر **Automatic** اسے شروع سے دوبارہ چلاتا ہے؛ **Search** ٹائپ کی ہوئی تلاش پر واپس جاتا ہے، جو پہلے مل چکا وہ وہیں موجود رہتا ہے۔

خودکار شناخت یہی راستہ استعمال کرتی ہے۔ جب امیدوار شامل ہوتا ہے تو اس کا مسودہ اس کی فائلوں، sheets اور پوشے کے نام سے بنتا ہے۔ Settings، Import میں ترتیب **Identify automatically** ہر اس امیدوار کے لیے شناخت چلاتی ہے جس کی ابھی موجود فائلوں کا کوئی نتیجہ نہیں؛ اسے بند رکھیں تو ہر دور آپ خود شروع کرتے ہیں۔ پہلے سے بھرا مسودہ نقطۂ آغاز ہے، جواب نہیں، اس لیے یہ کسی دور کو نہیں روکتا۔

### فائل کی میٹا معلومات

فائل کی میٹا معلومات تب پڑھی جاتی ہیں جب امیدوار شامل ہونے پر پیشگی بھرائی انہیں پڑھتی ہے، اور پھر جب بھی **Reset to file metadata** چنا جائے۔ دونوں صورتوں میں مسودہ بالکل اسی پڑھائی سے بدل جاتا ہے — فائلوں میں شامل صوتی tags، CUE میٹا معلومات، اور پوشے کا اپنا نام — اور کارڈ اسی پر دوبارہ بنتا ہے۔ اگر پڑھائی کے بعد امیدوار یا اس کی صوتی فائلیں بدل گئی ہوں تو درآمد لائبریری میں لکھنے سے پہلے ناکام ہو جاتی ہے۔

جب تک مسودے میں وہی پڑھائی ہو، قابل ترمیم کارڈ ایک دھیما File metadata chip دکھاتا ہے۔ صرف ٹائپ کر کے بھرے گئے مسودے کا کوئی ماخذ chip نہیں ہوتا۔

## تصدیق اور درآمد

تصدیقی خانہ وہ سب دکھاتا ہے جو درآمد لکھے گی:

- **غلاف۔** databases کی تصاویر، آپ کے پوشے کی تصویروں، یا فائلوں میں شامل تصاویر سے چنا جاتا ہے۔ امیدوار کی گیلری سے کوئی تصویر غلاف کے خانے پر کھینچ کر ڈالیں، یا اسے بعد میں بدلیں۔
- **میٹا معلومات۔** البم، فنکار، سال، label، کیٹلاگ نمبر، ملک، بارکوڈ، اور ہر ٹریک: کچھ بھی محفوظ ہونے سے پہلے یہیں قابل ترمیم۔
- **ذخیرہ۔** اگر کلاؤڈ گھر جڑا ہے تو اجرا کو وہاں اپ لوڈ کرنے کے لیے **Cloud** چنیں، اور اس کی فائلیں اس آلے پر بھی رکھنے کے لیے **Pinned**۔ ورنہ اجرا مقامی ہے: اس کی معلومات آپ کے دوسرے آلات سے ہم آہنگ ہوتی ہیں، اور اس کی آواز اسی آلے پر رہتی ہے۔ [ذخیرہ اور آف لائن](/ur/guide/storage) دیکھیں۔

درآمد پس منظر میں چلتی ہے: bae جانچتا ہے کہ ہر ٹریک صاف decode ہوتا ہے، البم اور ہر ٹریک کی loudness ناپتا ہے، اجرا محفوظ کرتا ہے، اور کلاؤڈ درآمدات کے لیے اپ لوڈ شروع کرتا ہے۔ امیدواروں کی فہرست اگلے پوشے پر چلی جاتی ہے، اور اجرا فوراً سنا جا سکتا ہے۔

## ڈیٹا کے ذرائع

**MusicBrainz** کو اکاؤنٹ یا کلید نہیں چاہیے۔ **Discogs** آپ کا اپنا مفت API token مانگتا ہے؛ اسے Settings، Import میں چسپاں کریں، اور bae بتاتا ہے اگر یہ کام کرنا چھوڑ دے۔ token کے بغیر Discogs تلاش اور Discogs سے آئی میٹا معلومات دستیاب نہیں ہوتیں، اور باقی سب کام کرتا ہے۔ دونوں خدمات کی درخواستوں پر حد ہے؛ bae درخواستوں کو ان حدود کے اندر رکھنے کے لیے رفتار قابو میں رکھتا ہے۔

## MCP سرور

ترتیبات، Automation میں MCP سرور چالو کریں۔ یہ Model Context Protocol کو مقامی پورٹ پر HTTP کے ذریعے پیش کرتا ہے (طے شدہ طور پر 47777)، اس لیے Claude جیسے MCP کلائنٹ آپ کی لائبریری دیکھ سکتے ہیں، اجرا تلاش کر سکتے ہیں، اور ان پر عمل کر سکتے ہیں۔ رسائی کے لیے bearer token چاہیے: اسے اسی ترتیبات pane سے کاپی کریں، اور جب بھی آپ اسے رکھنے والی ہر چیز کی رسائی بند کرنا چاہیں، وہیں اسے rotate کریں۔

سرور طے شدہ طور پر بند رہتا ہے اور صرف ایپ چلنے کے دوران چلتا ہے۔

bae اکاؤنٹ نہیں ہوتا۔ آلے کی شناخت ایک کلیدی جوڑا ہے جو وہ اپنے لیے بناتا ہے اور operating system کے کلید خانہ میں رکھتا ہے؛ لائبریری آلات کو ان کی کلیدوں سے پہچانتی ہے۔ آلہ شامل کرنے کا مطلب ہے کہ موجودہ آلہ نئے آلے کے لیے رمز نگاری سے گواہی دے، بیچ میں کوئی نہ ہو۔

دو الگ دروازے، دو الگ حالتوں کے لیے:

- **Joining**: نیا آلہ ایسے آلے سے منظور ہوتا ہے جس کے پاس پہلے سے لائبریری ہے۔ اسے اپنا فون، یا کسی اور شخص کا آلہ شامل کرنے کے لیے استعمال کریں۔
- **Restoring**: آپ کا اپنا نیا یا دوبارہ نصب شدہ آلہ recovery code استعمال کر کے کلاؤڈ گھر سے لائبریری براہ راست واپس لاتا ہے۔ کوئی منظور کرنے والا شامل نہیں۔

## آلہ شامل کرنا

ایک ایسے آلے پر جس میں پہلے سے لائبریری موجود ہے، ایک مالک سیٹنگز، ڈیوائسز، **ایک آلہ شامل کریں۔** کھولتا ہے۔ bae ایک جوڑا بنانے کا کوڈ بطور QR دکھاتا ہے اور مقامی نیٹ ورک پر سننا شروع کر دیتا ہے۔

نئے آلے پر، **لائبریری میں شامل ہوں۔** کو منتخب کریں اور اس کوڈ کو اسکین کریں۔ پوچھے جانے پر سٹوریج فراہم کرنے والے میں سائن ان کریں۔ دونوں ڈیوائسز نئے ڈیوائس کا فنگر پرنٹ دکھاتی ہیں۔ ان کا موازنہ کریں، پھر موجودہ ڈیوائس پر منظوری دیں۔ نیا آلہ اسی مقامی کنکشن کے ذریعے اپنی مہر بند رسائی حاصل کرتا ہے، لائبریری کو ڈاؤن لوڈ کرتا ہے، اور مطابقت پذیری شروع کرتا ہے۔ کوئی کوڈ واپس نہیں جاتا ہے۔

جوڑا بنانے کے کوڈ میں نہ تو لائبریری کی کلید ہوتی ہے اور نہ ہی دیرپا اسٹوریج کی اسناد ہوتی ہیں، اور جوڑا بنانے میں رکاوٹ یا مسترد ہونے سے کچھ حاصل نہیں ہوتا ہے۔ تفصیلات [شناخت اور رکنیت](/ur/reference/membership) میں۔

## ارکان اور کردار

ترتیبات، آلات ہر رکن دکھاتا ہے: fingerprint، کردار، اور یہ کہ اس آلے سے کون سا تعلق ہے۔ بنیاد رکھنے والا آلہ **مالک** ہے؛ اس کے منظور کردہ آلات **ارکان** کے طور پر شامل ہوتے ہیں۔ دونوں لائبریری پڑھتے اور لکھتے ہیں؛ صرف مالکان آلات منظور اور ہٹا سکتے ہیں۔

## آلہ ہٹانا

Owners کسی بھی رکن کو ہٹا سکتے ہیں۔ ہٹانا صرف دروازہ بند نہیں کرتا: لائبریری کی رمز بندی کی کلید بدلی جاتی ہے، اور ہٹائے گئے آلے کو نئی کلید کبھی نہیں ملتی۔ جو اس نے پہلے نقل کیا وہ اس کے پاس رہتا ہے، بھیجا ہوا ڈیٹا واپس نہیں لیا جا سکتا، لیکن اس مقام کے بعد لائبریری جو کچھ لکھتی ہے وہ اس کے لیے پڑھے جانے کے قابل نہیں ہوتا۔

## Recovery codes

Recovery code آپ کی اپنی لائبریری کے لیے bearer secret ہے: کلاؤڈ گھر coordinates اور رمز بندی کی کلید، ایک ہی عبارت میں۔ ترتیبات میں **Show recovery code** اسے دکھاتا ہے؛ اسے password manager جیسی محفوظ جگہ میں رکھیں۔ نئے آلے پر code کے ساتھ **Restore from cloud** لائبریری دوبارہ بناتا ہے، منظور کرنے والے کی ضرورت نہیں۔

Apple پلیٹ فارم پر code خودکار طور پر iCloud Keychain میں بھی رکھا جاتا ہے، اس لیے آپ کے Apple ID میں signed in نیا Mac یا iPhone ایک tap سے واپس لا سکتا ہے۔

جس کے پاس code ہے، اس کے پاس لائبریری ہے، اس لیے اسے کلید ہی سمجھیں۔

## قفل لگانا

**Lock Library** آلے کے کلید خانہ سے رمز بندی کی کلید ہٹا دیتا ہے۔ لائبریری disk پر رہتی ہے، مگر پڑھی نہیں جا سکتی، جب تک کوئی دوبارہ کلید نہ دے؛ bae قبول کرنے سے پہلے اسے محفوظ fingerprint سے ملاتا ہے۔ اسے ایسے laptop کے لیے استعمال کریں جو گھر سے باہر جاتا ہے۔

## فون پر

iOS اور Android بالکل اسی طرح شامل اور واپس لاتے ہیں؛ یہی ان کی پوری ابتدائی ترتیب ہے۔ فون لائبریری کی اپنی نقل بھی ہٹا سکتا ہے (ترتیبات، remove from this آلہ)، جو مقامی فائلیں حذف کرتا ہے اور کلاؤڈ میں کچھ نہیں چھیڑتا۔

bae اکاؤنٹ نہیں ہے۔ لائبریری میں ہر شخص کی اپنی کلیدیں ہیں، جو اس کے سب آلات بانٹتے ہیں اور operating system کے کلید خانہ میں رکھتے ہیں؛ لائبریری لوگوں کو ان کلیدوں سے پہچانتی ہے۔ کون شامل ہے، اس کی ہر تبدیلی پر دستخط ہوتے ہیں اور وہ کلاؤڈ گھر میں رکھی جاتی ہے، بیچ میں کوئی نہیں۔

دو الگ دروازے، دو الگ حالتوں کے لیے:

- **آلہ شامل کرنا**: آپ کا اپنا نیا یا دوبارہ نصب شدہ آلہ آپ کے بازیابی کوڈ سے شامل ہوتا ہے۔ کوئی دوسرا آلہ اسے منظور نہیں کرتا: کوڈ میں آپ کی کلیدیں ہیں، اس لیے وہ خود ثابت کرتا ہے کہ آلہ آپ کا ہے۔
- **شمولیت**: کوئی دوسرا شخص admin کی دعوت سے شامل ہوتا ہے، جو اس کی درخواست منظور کرتا ہے۔

## اپنا آلہ شامل کرنا

نئے Mac پر **Add device** چنیں؛ Android فون پر **Scan a code** یا **Enter a code**۔ اسے اپنا بازیابی کوڈ ان تین میں سے کسی طریقے سے دیں:

- اپنے کسی دوسرے آلے پر Settings، Library میں **Add device…** کے تحت دکھنے والا QR code **اسکین** کریں۔
- Apple آلات پر اسے iCloud Keychain سے **چنیں**: bae وہ بازیابی کوڈ دکھاتا ہے جو آپ کے دوسرے آلات نے وہاں محفوظ کیے ہیں۔
- اسے **چسپاں** کریں یا ٹائپ کریں۔

پوچھے جانے پر ذخیرہ فراہم کنندہ میں sign in کریں۔ S3 پر آلے کو آپ کی access key بھی چاہیے: QR code اسے code کے ساتھ ہی لاتا ہے، اس لیے اسکین کرنا کافی ہے، اور ٹائپ کیا گیا code کلید مانگتا ہے۔ پھر نیا آلہ لائبریری ڈاؤن لوڈ کر کے ہم آہنگی شروع کرتا ہے۔

لائبریری لوڈ ہونے تک آلہ اس کا نام نہیں بلکہ یہ دکھاتا ہے کہ وہ کہاں محفوظ ہے: Dropbox اور OneDrive کے لیے اکاؤنٹ کا ای میل، S3 کے لیے bucket اور endpoint، یا iCloud۔ لوڈ ہونے کے بعد یہ لائبریری کا موجودہ نام دکھاتا ہے۔

## کسی شخص کو مدعو کرنا

کوئی admin Settings، Library، **Invite a person…** کھولتا ہے، اس شخص کا نام، کردار اور اکاؤنٹ کا ای میل درج کرتا ہے (S3 پر اس کی جگہ اس کے لیے بنائی گئی access key)، اور **In person** یا **Send** چنتا ہے۔ bae لائبریری کا پوشہ اس اکاؤنٹ کے ساتھ بانٹتا ہے اور دعوت QR code کی صورت میں دکھاتا ہے۔

اپنے آلے پر وہ شخص **Join library** چنتا ہے (Android فون پر **Scan a code** یا **Enter a code**)، دعوت اسکین یا چسپاں کرتا ہے، اور اپنے اکاؤنٹ میں sign in کرتا ہے۔ آمنے سامنے دی گئی دعوت اسے درخواست پہنچتے ہی اندر آنے دیتی ہے۔ بھیجی گئی دعوت کے لیے admin کا آلہ درخواست ایک تصدیقی نمبر کے ساتھ دکھاتا ہے، وہی نمبر جو اس شخص کا آلہ دکھاتا ہے، اور admin دونوں کا موازنہ کر کے **Approve** یا **Decline** چنتا ہے۔ منظوری کے بعد نیا آلہ لائبریری ڈاؤن لوڈ کرتا ہے، اور ہر آلہ نئے شخص کو نام سے دکھاتا ہے۔ آمنے سامنے دی گئی دعوت ایک گھنٹہ چلتی ہے، بھیجی گئی دعوت ایک گھنٹہ، ایک دن یا ایک ہفتہ، اور اس کی درخواست صرف وہی آلہ منظور کر سکتا ہے جس نے اسے بنایا۔ تفصیل [شناخت اور رکنیت](/ur/reference/membership) میں۔

## ارکان اور کردار

Settings، Library ہر شخص اور اس کے آلات دکھاتا ہے، اور یہ بھی کہ ان میں یہ آلہ کون سا ہے۔ جو شخص لائبریری کو کلاؤڈ سے جوڑتا ہے وہ اس کا پہلا **admin** ہے؛ admins دوسروں کو **admin** یا **رکن** کے طور پر مدعو کرتے ہیں اور کسی کا بھی کردار بدل سکتے ہیں۔ سب لائبریری پڑھتے اور اس میں ترمیم کرتے ہیں۔ صرف admins لوگوں کو مدعو کرتے، ہٹاتے اور لائبریری کا نام بدلتے ہیں۔

## آلہ ہٹانا

ہر کوئی اپنے آلات ہٹا سکتا ہے، اور admin کسی کا بھی آلہ ہٹا سکتا ہے، تاکہ سب آلات کھو دینے والا شخص پھنس نہ جائے۔ اس کے بعد ہٹایا گیا آلہ جو کچھ بھیجے وہ شمار نہیں ہوتا۔ bae یہ بھی دکھاتا ہے کہ فراہم کنندہ کے پاس کیا کرنا باقی ہے، جیسے اس آلے کو آپ کے اکاؤنٹ سے sign out کرنا: Dropbox، OneDrive اور iCloud کسی اکاؤنٹ کے ایک آلے کو خود الگ نہیں کر سکتے۔

کسی شخص کو ہٹانا، جو صرف admin کر سکتا ہے، اس کے آلات اور وہ سب کچھ بھی ہٹاتا ہے جو اس نے نجی رکھا تھا۔ گھر کے ساتھ بانٹی گئی اس کی ratings، تاریخ اور playlists اسی کے نام سے رہتی ہیں۔ لائبریری کی کلیدیں بدل جاتی ہیں، اس لیے بعد میں لکھا گیا کچھ بھی اس کے لیے پڑھنے کے قابل نہیں۔ جو وہ پہلے نقل کر چکا ہے وہ اسی کے پاس رہتا ہے: بھیجا گیا ڈیٹا واپس نہیں لیا جا سکتا۔

## بازیابی کوڈ

بازیابی کوڈ ایک لائبریری کے لیے آپ کی کلیدیں اور یہ کہ وہ کہاں محفوظ ہے، ایک ہی string میں رکھتا ہے۔ اس میں ذخیرہ کا پاس ورڈ، sign-in یا لائبریری کا نام نہیں۔ Settings، Library میں **Your recovery code** کے تحت **Show code** اسے دکھاتا ہے؛ اسے password manager جیسی محفوظ جگہ رکھیں۔

Apple پلیٹ فارم پر code خود بخود iCloud Keychain میں بھی رکھا جاتا ہے، اس لیے آپ کے Apple Account میں sign in نیا Mac یا iPhone اسے فہرست سے چن سکتا ہے۔

جس کے پاس code اور آپ کے ذخیرہ تک رسائی ہو وہ آپ کی طرح لائبریری کھول سکتا ہے، اس لیے اسے راز رکھیں۔

## قفل لگانا

لائبریری کی رمز بندی کی کلیدیں operating system کے کلید خانہ میں رہتی ہیں۔ جب تک کلید خانہ مقفل ہے، جیسے آپ کا سیشن مقفل ہو، bae لائبریری کو مقفل دکھاتا ہے اور کلید خانہ کھلتے ہی اسے کھول دیتا ہے؛ **Try again** ہاتھ سے دوبارہ کوشش کرتا ہے۔

## فون پر

iOS اور Android بالکل اسی طرح شامل ہوتے اور بحال ہوتے ہیں؛ یہی ان کی پوری ابتدائی ترتیب ہے۔ فون لائبریری کو اپنے آپ سے ہٹا بھی سکتا ہے: پہلے وہ خود کو لائبریری کے ارکان سے ہٹاتا ہے، جس کے لیے آپ کے ذخیرہ سے رابطہ چاہیے، پھر اپنی مقامی نقل مٹا دیتا ہے۔ کلاؤڈ میں لائبریری باقی رہتی ہے۔

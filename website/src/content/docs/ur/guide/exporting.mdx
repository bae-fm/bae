پابندی نہ ہونا دونوں طرف کام کرتا ہے: bae اندر آتے وقت آپ کی فائلیں نہیں بدلتا، اور باہر جاتے وقت انہیں نہیں روکتا۔ مقامی اجرا پہلے ہی آپ کے پوشوں میں موجود فائلیں ہیں۔ کلاؤڈ میں موجود اجرا کسی بھی وقت byte-for-byte دوبارہ مقامی بنائے جا سکتے ہیں۔ اور جب آپ کو *مختلف* شکل چاہیے، جیسے فون کے لیے موزوں encode، تو Save as… اصل فائلوں کو چھوئے بغیر اسے بناتا ہے۔

## دو برآمدات

- **Export…**: album menu یا Storage manager میں، ایک اجرا کی فائلیں byte-for-byte ایک پوشے میں کاپی کرتا ہے۔
- **Save as…**: ٹریک پر، یا اجرا کے لیے album menu میں، آپ کے چنے ہوئے format میں تبدیل کرتا ہے، جیسے گاڑی یا فون کے لیے FLAC سے MP3۔ یہ نئی فائلیں لکھتا ہے؛ اصل فائلیں جیسی ہیں ویسی ہی رہتی ہیں۔

دونوں پیش رفت دکھانے والی قطار میں چلتے ہیں۔ آپ انہیں روک اور منسوخ کر سکتے ہیں؛ ناکام کام آپ کے منسوخ کرنے تک اپنی خرابی کے ساتھ قطار میں رہتا ہے۔ Save قطار میں ڈالتے وقت کا format اور settings رکھتا ہے، اس لیے بعد میں انہیں بدلنے سے قطار میں پہلے سے موجود کچھ نہیں بدلتا۔

## Formats

Format ایک نام اور ایک codec ہے: FLAC، WAV، AIFF، MP3، AAC یا Opus۔ یہ Settings، Save as میں **Formats** کے تحت رکھے جاتے ہیں۔ **Add format…** ایک شامل کرتا ہے، اور اس کے menu کے **Edit…** اور **Delete…** اسے بدلتے یا ہٹاتے ہیں۔ Format کا ایک **Name**، ایک **Format** اور معیار کی ایک setting ہوتی ہے۔ نام منفرد ہوتے ہیں، مگر دو format ایک ہی چیز لکھ سکتے ہیں۔ نئے format کا نام اس کے codec کے نام پر پڑتا ہے، اور نام لیا ہوا ہو تو نمبر جڑ جاتا ہے ("FLAC"، "FLAC (2)")۔ FLAC اور MP3 پہلے سے موجود ہیں۔

ہر format ٹریکس اور اجرا دونوں کے لیے کام کرتا ہے۔ Save as window میں **Format** pop-up تمام formats دکھاتا ہے اور آپ کے آخری استعمال شدہ format سے شروع ہوتا ہے۔ اس کی آخری entry **Edit formats…** settings میں Save as کھولتی ہے؛ pop-up وہاں ہونے والی تبدیلیوں کے ساتھ چلتا ہے، اور وہاں شامل کیا گیا format فوراً چن لیا جاتا ہے۔

## معیار

- **Bit depth**، FLAC، WAV اور AIFF کے لیے: **Same as source** یا **16-bit**۔ Lossy ماخذ کی اپنی depth نہیں ہوتی، اس لیے وہ 16 bit پر لکھا جاتا ہے۔
- **Bitrate**، MP3، AAC اور Opus کے لیے: ان bitrates کی فہرست جو اس codec کا encoder لکھتا ہے۔ MP3: 32, 40, 48, 56, 64, 80, 96, 112, 128, 160, 192, 224, 256, 320 kbps۔ AAC: 96, 128, 160, 192, 256, 320 kbps۔ Opus: 64, 96, 128, 160, 192, 256 kbps۔

## نام

Settings، Save as میں **Names** کے تحت، ایک **File name** pattern اور ایک **Folder name** pattern تمام formats کے لیے چلتے ہیں۔ Pattern حصوں کی ایک قطار ہے جسے آپ ترتیب بدل کر، ہٹا کر اور جوڑ کر بناتے ہیں، اور وہ جو نام بناتا ہے اس کا preview نظر آتا ہے۔ فائل کے نام میں عنوان، فنکار، البم، سال، ٹریک نمبر، ڈسک نمبر اور کل ٹریکس آ سکتے ہیں۔ پوشے کے نام میں فنکار، البم، سال، label اور catalog نمبر آ سکتے ہیں؛ جو حصہ اجرا میں درج نہیں وہ چھوڑ دیا جاتا ہے۔

ٹریک پر Save as… pattern کا نام تجویز کرتا ہے، اور دوسرا format چننے سے صرف extension بدلتی ہے۔ اجرا save کرنے سے اس کی فائلیں folder pattern سے نام پائے ہوئے پوشے میں لکھی جاتی ہیں۔ اجرا save کبھی کوئی فائل نہیں بدلتا: اگر آپ کی drive پر دو نام ایک ہی فائل بنتے ہوں تو save ناکام ہو جاتا ہے۔ ایک ٹریک پر Save as… موجودہ فائل تبھی بدلتا ہے جب آپ تصدیق کریں۔

## ہر ٹریک کی ایک فائل

ہر save ہر ٹریک کی ایک فائل لکھتا ہے، وقفوں کے لیے ایک ہی اصول کے ساتھ۔ Pregap، محفوظ کیا ہوا یا بنایا ہوا، پچھلے ٹریک کے آخر میں جاتا ہے، اور ٹریک 1 سے پہلے کی چھپی آڈیو ٹریک 1 کے شروع میں رہتی ہے۔ ایک image اور CUE sheet کے طور پر محفوظ اجرا ٹریک نشانات پر تقسیم ہوتا ہے۔ Save as… CUE sheet نہیں لکھتا۔

## Encode کرنے کے بجائے کاپی

جو ٹریک پوری فائل ہے اور پہلے سے چنے ہوئے lossless format میں ہے، اس depth پر جو format لکھتا ہے، اسے دوبارہ encode کرنے کے بجائے کاپی کیا جاتا ہے۔ WAV اور AIFF 16 یا 24 bit پر شمار ہوتے ہیں۔ اس کے tags، cover اور نام نئے سرے سے لکھے جاتے ہیں۔ Lossy format ہمیشہ encode کرتا ہے۔

## اضافی

Settings، Save as میں **Extras** کے تحت تین switch ہر format پر لاگو ہوتے ہیں۔ سب شروع میں آن ہوتے ہیں۔

- **Embed cover art**: ہر فائل میں cover رکھتا ہے۔
- **Cover image in the folder**: اجرا save اس کے پوشے میں `cover.jpg` بھی لکھتا ہے۔
- **Loudness tags**: import کے وقت bae کی ناپی ہوئی loudness سے ہر فائل میں ٹریک اور البم کا ReplayGain gain اور peak لکھتا ہے۔

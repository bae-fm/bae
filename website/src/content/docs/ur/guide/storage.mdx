آپ کی فائلیں آپ کی رہتی ہیں۔ bae انہیں کبھی منتقل، نام تبدیل، یا دوبارہ نہیں لکھتا؛ ذخیرہ کاری جس سوال کا جواب دیتی ہے وہ صرف یہ ہے کہ ہر اجرا کی *چلنے والی نقل* کہاں رہتی ہے: آلے پر، آپ کے کلاؤڈ میں، یا دونوں جگہ۔

## غیر منظم اور منظم

ہر اجرا ان میں سے ایک ہے، درآمد پر چنا ہوا اور کسی بھی وقت بدلا جا سکتا ہے:

- **غیر منظم**: bae آپ کی فائلوں کو وہیں فہرست بند کرتا ہے جہاں وہ ہیں اور وہیں سے چلاتا ہے۔ کچھ نقل نہیں ہوتا۔ اجرا ہر ہم آہنگ آلے کے فہرست نامے میں موجود ہوتا ہے، مگر اس کی آواز صرف اس مشین پر رہتی ہے جس نے اسے درآمد کیا۔
- **منظم**: فائلیں رمز بند ہو کر کلاؤڈ گھر پر اپ لوڈ ہوتی ہیں۔ اب ہر آلہ اجرا چلا سکتا ہے، مانگ پر بہا کر یا offline کے لیے ڈاؤن لوڈ کر کے۔ اپ لوڈ سے آپ کی اصل فائلیں untouched رہتی ہیں؛ مقامی طور پر انہیں استعمال کرتے رہنا ہے یا نہیں یہ آپ کا فیصلہ ہے (درآمد پر **Keep local copy** انہیں pin کرتا ہے)۔

دونوں کے بیچ حرکت اجرا کی سطح کا کام ہے: **Manage** غیر منظم اجرا اپ لوڈ کرتا ہے؛ **Make local** منظم اجرا کی فائلیں آپ کے چنے ہوئے پوشے میں ڈاؤن لوڈ کرتا ہے، اور وہ plain فائلیں کے طور پر دوبارہ آپ کی ہوتی ہیں۔

## بہاؤ اور کیش

منظم اجرا ہر جگہ چلتے ہیں، اگر نیٹ ورک اجازت دے: پلے بیک آپ کے کلاؤڈ سے فائل بہاتا ہے، اور بائٹس مقامی کیش میں رکھے جاتے ہیں تاکہ اگلی بار چلانا فوراً ہو۔ کیش ایک حد کے اندر خود سنبھلتا ہے (ہر آلے پر آواز کے لیے 20 GB)، جگہ کم ہونے پر وہ چیز نکالتا ہے جو آپ نے نہیں چلائی۔ غلاف اور فنکار تصاویر الگ کیش ہوتی ہیں، اس لیے بڑا البم آپ کی تصاویر باہر نہیں نکال سکتا۔

## آف لائن کے لیے pin کرنا

اجرا pin کرنے سے وہ پورا ڈاؤن لوڈ ہو کر رکھا جاتا ہے: pinned موسیقی کبھی کیش سے نہیں نکلتی اور ہمیشہ offline چلتی ہے۔ اجرا کی ذخیرہ sheet یا ذخیرہ Manager سے pin کریں؛ unpin فائلوں کو عام کیش میں واپس لے جاتا ہے، جہاں وہ چلنے کے قابل مگر واپس لی جانے کے قابل رہتی ہیں۔ فون پر pinned ڈاؤن لوڈز اپنی پیش رفت لائبریری ہی میں دکھاتے ہیں۔

## ذخیرہ Manager

Desktop کا ذخیرہ Manager (<kbd>⌘0</kbd>) ایک کھڑکی میں پوری تصویر ہے:

- ہر اجرا اپنے size اور حالت کے ساتھ: غیر منظم، منظم، uploading۔ filter، sort، کئی select، سب پر ایک ساتھ action۔
- **Downloads**: pin ڈاؤن لوڈز in flight، pausable، retryable۔
- **Exports**: برآمد قطار۔ [برآمد](/ur/guide/exporting) دیکھیں۔
- **Uploads**: ہم آہنگی outbox، ہر اجرا کی پیش رفت، رفتار اور باقی وقت، زیر التوا حذف، توقف اور دوبارہ شروع کرنے کے ساتھ۔

## حذف کرنا

منظم اجرا حذف کرنے سے وہ لائبریری اور کلاؤڈ گھر سے ہٹتا ہے۔ غیر منظم اجرا حذف کرنے سے صرف فہرست کا اندراج ہٹتا ہے: bae کبھی وہ فائلیں حذف نہیں کرتا جو اس نے وہاں نہیں رکھی تھیں۔

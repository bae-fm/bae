## دو editions

bae دو editions میں آتا ہے، ایک ہی ماخذ سے بنا ہوا:

- **bae**، پوری ایپ: S3، Google Drive، Dropbox، OneDrive، اور iCloud ہم آہنگی۔
- **baeium**، ملکیتی حصوں کے بغیر: صرف S3-compatible ذخیرہ، OAuth فراہم کنندگان نہیں، iCloud/CloudKit نہیں، telemetry نہیں۔

یہ ساتھ ساتھ نصب ہوتے ہیں، ہر ایک اپنی لائبریری اور اپنی (iCloud-Keychain-synced) کلیدوں کے ساتھ۔ نیچے جو چاہیں چنیں۔

## iOS

iOS نسخے بیرونی تنصیب کے لیے **unsigned `.ipa` فائلیں** ہیں۔ [AltStore](https://altstore.io) یا [Sideloadly](https://sideloadly.io) سے نصب کریں، یا اپنے Apple ID کے ساتھ Xcode میں دوبارہ sign کریں (مفت Apple ID baeium کے لیے کام کرتا ہے)۔ App Store سے تقسیم ابھی قائم نہیں۔

## Windows

Windows کا download ایک installer ہے، جو ایپ کو فی صارف انسٹال کرتا ہے اور خود کو تازہ رکھتا ہے۔ نسخے signed نہیں ہیں، اس لیے پہلی launch پر SmartScreen خبردار کر سکتا ہے۔ ہر [GitHub release](https://github.com/bae-fm/bae/releases) کے ساتھ ایک portable zip بھی منسلک ہوتی ہے، جو اپنی جگہ پر ہی چلتی ہے۔ Windows پر صرف مکمل edition شائع ہوتا ہے۔

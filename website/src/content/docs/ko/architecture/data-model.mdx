## 라이브러리와 저장 위치

**라이브러리**는 최상위 엔터티입니다. 고유 신원(`library_id`), 이름, 암호화 키를 가진 음악 컬렉션입니다. 디스크의 **라이브러리 홈**(`~/.bae/libraries/{uuid}/`)에 있으며, 데스크톱 앱은 권위 있는 데이터베이스를 그곳에 씁니다.

라이브러리는 선택적으로 **클라우드 홈**을 가질 수 있습니다. Google Drive 폴더, S3 버킷 등 하나의 클라우드 위치이며 여러 기기 동기화의 허브 역할을 합니다. 라이브러리마다 클라우드 홈은 하나이고 `config.yaml`에 설정됩니다. 자세한 내용은 [클라우드 홈](/ko/architecture/cloud-home)을 참고하세요.

릴리스 파일은 다음 위치 중 하나 이상에 있을 수 있습니다.

- **라이브러리 홈**(`~/.bae/libraries/{uuid}/storage/`) — 로컬 복사본, 오프라인 사용 가능
- **클라우드 홈**(`cloud-home/storage/`) — 암호화된 복사본, 동기화에 사용
- **자체 관리형** — 파일은 디스크의 원래 위치에 남고 bae는 인덱싱만 합니다

릴리스는 로컬 전용, 클라우드 전용, 또는 둘 다일 수 있습니다. 클라우드 전용 파일은 오프라인 재생에 사용할 수 없습니다.

## 디렉터리 레이아웃

### 라이브러리 홈

```
~/.bae/libraries/{uuid}/
  config.yaml                  # 기기별 설정: 동기화 안 됨
  library.db                   # SQLite -- 모든 메타데이터
  images/ab/cd/{id}            # 라이브러리 이미지: 커버, 아티스트 사진
  storage/ab/cd/{file_id}      # 릴리스 파일
```

`config.yaml`은 기기별 설정을 담습니다. 동기화되지 않습니다. 자격 증명은 여기 대신 OS 키링에 들어갑니다.

`images/`와 `storage/` 아래 파일은 해시 기반 레이아웃을 사용합니다. ID의 첫 2자가 접두사 디렉터리, 다음 2자가 하위 디렉터리입니다. 디스크에는 파일명이나 확장자가 없으며, 원래 파일명과 콘텐츠 유형은 데이터베이스에 있습니다. 라이브러리 홈과 클라우드 홈 모두 같은 레이아웃을 사용합니다.

### 클라우드 홈

클라우드 홈은 라이브러리 데이터를 미러링하고 동기화 및 접근 제어 장치를 추가합니다.

| 경로 | 목적 |
|---|---|
| `snapshot.db.enc` | 전체 데이터베이스 스냅샷: 새 기기 부트스트랩 |
| `changes/{device_id}/{seq}.enc` | 증분 동기화 변경 세트 |
| `heads/{device_id}.json.enc` | 기기별 시퀀스 번호 |
| `images/ab/cd/{id}` | 라이브러리 이미지: 암호화됨 |
| `storage/ab/cd/{file_id}` | 릴리스 파일: 암호화됨 |
| `membership/{pubkey}/{seq}.enc` | 멤버십 체인 항목 |
| `keys/{user_pubkey}.enc` | 기기별 래핑된 암호화 키 |

### 키링 항목

`KeyService`가 OS 키링을 사용해 관리합니다. macOS에서는 iCloud 키체인 동기화가 되는 보호 데이터 저장소입니다. 별도 표시가 없으면 모든 항목은 `library_id`로 네임스페이스됩니다.

| 항목 | 범위 | 목적 |
|---|---|---|
| `encryption_master_key` | 라이브러리별 | 파일과 메타데이터 암호화 |
| `cloud_home_credentials` | 라이브러리별 | 직렬화된 enum: S3 access+secret, OAuth 토큰, 또는 없음(iCloud) |
| `discogs_api_key` | 라이브러리별 | Discogs API 접근 |
| `bae_user_signing_key` | 전역 | Ed25519 서명 키 |
| `bae_user_public_key` | 전역 | Ed25519 공개 키 |

## 두 종류의 파일

### 릴리스 파일

릴리스와 함께 온 모든 파일: 오디오, 이미지, CUE 시트, 로그 등입니다. 이는 사용자의 데이터입니다. bae는 이를 가져온 그대로 저장하며, 원본 파일을 보존해 그대로 내보낼 수 있게 합니다.

### 메타데이터 이미지

bae가 만들고 관리하는 이미지이며 릴리스 파일과 별개입니다.

- **릴리스 커버** — 앨범 그리드, 상세 보기, 재생 화면의 표시 아트. 릴리스마다 하나입니다. 릴리스의 파일 또는 MusicBrainz/Discogs에서 올 수 있습니다. bae가 자체 복사본을 만들기 때문에 원본에 영향 없이 자르거나 크기를 조정할 수 있습니다.
- **아티스트 이미지** — 가져오기 중 외부 소스에서 가져옵니다.

## 첫 실행 흐름

**새 라이브러리**: 첫 실행 시 데스크톱 앱은 환영 화면을 표시합니다. 사용자가 새 라이브러리를 만들면 UUID가 생성되고 디렉터리 구조가 만들어진 뒤 앱이 열립니다. `storage/` 디렉터리는 비어 있으며, 사용자가 가져오기를 하면 파일이 나타납니다.

**클라우드 홈에서 복원**: 사용자가 클라우드 홈 자격 증명과 암호화 키를 제공합니다. bae는 스냅샷을 내려받고 더 새로운 변경 세트를 적용한 뒤 이미지를 내려받습니다. 로컬 `storage/`는 비어 있으며, 릴리스 파일은 필요할 때 클라우드 홈에서 스트리밍됩니다.

**로컬에서 클라우드로 전환**: 사용자가 클라우드 제공자에 로그인합니다. bae는 필요하면 암호화 키를 생성하고 전체 스냅샷, 이미지, 릴리스 파일을 올린 뒤 증분 동기화로 전환합니다.

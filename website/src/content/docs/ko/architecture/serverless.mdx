bae는 자체 서버가 없습니다. 모든 기기는 공유 클라우드 홈을 읽고 쓰는 클라이언트입니다. 모든 동기화는 bae가 운영하는 컴퓨터가 아니라 그 저장소를 통해 흐릅니다.

## 클라우드 홈이 만나는 지점

라이브러리의 [클라우드 홈](/ko/architecture/cloud-home)은 사용자가 제어하는 저장소 백엔드의 버킷 또는 폴더입니다. S3 호환 저장소, Google Drive, Dropbox, OneDrive, iCloud를 사용할 수 있습니다. 각 기기는 다음을 수행합니다.

- 암호화된 데이터베이스 변경 세트와 릴리스 파일을 클라우드 홈에 올립니다
- 각 동기화 주기마다 다른 기기의 변경을 그곳에서 내려받습니다

내 기기들은 서로 직접 통신하지 않습니다. 둘 다 같은 클라우드 홈과 동기화하면서 수렴합니다.

## 클라우드 홈에 있는 것

- 암호화된 릴리스 파일: 오디오, 이미지 등
- 암호화된 데이터베이스 스냅샷과 동기화 변경 세트
- 암호화된 라이브러리 이미지
- 누가 라이브러리를 읽거나 쓸 수 있는지 기록하는 멤버십 체인

## 저장소는 내용을 모름

저장소 백엔드는 키를 보관하지 않고 복호화하지 않습니다. 모든 blob은 업로드 전에 클라이언트에서 암호화되고 다운로드 후 클라이언트에서 복호화됩니다. 클라우드 홈은 라이브러리 내용, 메타데이터, 암호화 키를 알지 못합니다. 음악을 읽거나 검색하거나 인덱싱할 수 없습니다. 저장소일 뿐입니다.

다른 기기를 추가하는 것은 이 같은 공유 저장소 위에서 이루어지는 [멤버십](/ko/architecture/membership) 권한 부여입니다. 연결할 서버는 없습니다.

---
title: 가져오기
description: 로컬 파일에서 음악 가져오기
---

bae는 컴퓨터의 FLAC 파일을 가져옵니다. 폴더를 선택하면 bae가 릴리스를 스캔하고, 각 항목을 MusicBrainz 또는 Discogs 항목과 맞춘 뒤 메타데이터를 가져옵니다.

## 시작하기

제목 표시줄에서 **가져오기**를 클릭한 뒤 **로컬 파일**을 선택하고 폴더를 고릅니다.

bae는 폴더를 재귀적으로 스캔하고 릴리스를 감지한 뒤 후보로 표시합니다. 각 후보마다 식별하고, 아트워크를 고르고, 저장 옵션을 선택한 뒤 가져옵니다.

## 지원 형식

FLAC만 지원합니다. 개별 트랙 파일과 CUE+FLAC 디스크 이미지 모두 지원합니다.

| 레이아웃 | 예시 |
|--------|------|
| 트랙별 파일 | `01 - Track Title.flac`, `02 - Track Title.flac`, ... |
| CUE+FLAC | `album.cue` + `album.flac`: CUE 시트로 나뉘는 단일 파일 |
| 여러 디스크 CUE+FLAC | `CD1/disc1.cue` + `CD1/disc1.flac`, `CD2/...` |

## 디렉터리 스캔

디렉터리에 오디오 파일이 바로 들어 있거나, 하위 디렉터리가 디스크 폴더처럼 보이면 하나의 릴리스로 처리됩니다. 예: `CD1`, `CD2`, `Disc 1`, `Disc 2`, 또는 `1`, `2` 같은 숫자 폴더.

디스크 폴더 감지는 휴리스틱을 사용합니다. 하위 디렉터리 이름은 15자 이하여야 하며, 전부 숫자이거나 최소 2자 이상의 공통 접두사를 공유해야 합니다. 이를 통해 여러 디스크 릴리스와 이름이 긴 별도 앨범 모음을 구분합니다.

리프가 아닌 디렉터리는 계속 내려가며 스캔합니다. 최대 깊이는 10입니다. 파일은 오디오, 아트워크(JPG, PNG, WEBP, GIF, BMP), 문서(CUE, LOG, TXT, M3U)로 분류됩니다. 숨김 파일, 0바이트 파일, 손상된 파일: 잘못된 FLAC 헤더나 잘린 오디오는 건너뜁니다.

## 식별

감지된 각 릴리스는 bae가 메타데이터를 가져올 수 있도록 MusicBrainz 또는 Discogs 항목과 맞춰야 합니다.

- **자동** — <a href="https://musicbrainz.org/doc/Disc_ID" target="_blank">MusicBrainz 디스크 ID</a>를 계산해 조회합니다. 두 가지 방법으로 계산할 수 있습니다.
  - LOG 파일에서: EAC, XLD 등
  - CUE 시트와 FLAC 파일에서
- **수동** — 다음 값으로 MusicBrainz와 Discogs를 검색합니다.
  - 아티스트와 앨범 이름
  - 카탈로그 번호
  - 바코드

결과를 선택하면 bae가 트랙 수가 로컬 파일과 맞는지 확인합니다. 맞지 않는 항목은 표시됩니다.

## 확인

맞춘 뒤 릴리스 세부 정보를 검토합니다.

- **아트워크** — bae는 MusicBrainz Cover Art Archive와 Discogs에서 커버 아트를 가져옵니다. 폴더의 이미지 파일: cover.jpg, front.png 등도 사용할 수 있습니다. 아티스트 이미지는 Discogs에서 가져옵니다.
- **저장소** — bae 관리형: 파일을 bae 저장소로 복사하고 클라우드 홈이 설정되어 있으면 암호화해 업로드합니다. 자체 관리형: 파일을 복사하지 않고 원래 위치에서 인덱싱합니다. 파일은 수정되지 않습니다. 자세한 내용은 [저장소 개요](/ko/storage/overview)를 참고하세요.

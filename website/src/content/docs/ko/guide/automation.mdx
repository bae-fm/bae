사용자가 실행하는 소프트웨어로 라이브러리를 조작할 수 있습니다. MCP를 통한 AI 에이전트와 명령줄 도구를 통한 스크립트가 여기에 해당합니다. 둘 다 UI가 쓰는 것과 같은 작업을 제공합니다. 검색, 릴리스 세부 정보, 가져오기, 저장소 작업, 재생 상태입니다.

## MCP 서버

Settings, Automation에서 MCP 서버를 켭니다. 로컬 포트(기본값 47777)에서 HTTP로 Model Context Protocol을 제공하므로 Claude 같은 MCP 클라이언트가 라이브러리를 둘러보고, 릴리스를 찾고, 릴리스에 작업을 수행할 수 있습니다. 접근에는 bearer token이 필요합니다. 같은 설정 창에서 복사하고, 토큰을 가진 모든 접근을 끊고 싶을 때 그곳에서 교체합니다.

서버는 기본으로 꺼져 있으며 앱이 실행 중일 때만 동작합니다.

## 명령줄

`bae` CLI는 터미널에서 같은 작업을 수행합니다. 입력과 출력은 JSON이라 스크립트에 맞습니다. MCP 클라이언트로도 동작할 수 있어, 로컬 MCP 프로세스를 기대하는 도구에 데스크톱 서버를 stdio로 연결합니다.

## 두 에디션

bae는 같은 소스에서 빌드한 두 에디션으로 배포됩니다.

- **bae**, 전체 앱: S3, Google Drive, Dropbox, OneDrive, iCloud 동기화.
- **baeium**, 독점 구성요소 없음: S3 호환 저장소만 지원, OAuth 제공자 없음, iCloud/CloudKit 없음, telemetry 없음.

두 에디션은 나란히 설치되며, 각자 자기 라이브러리와 자기 키(iCloud Keychain으로 동기화됨)를 가집니다. 아래에서 원하는 것을 고르세요.

## iOS

iOS 빌드는 **사이드로드용 서명되지 않은 `.ipa` 파일**입니다. [AltStore](https://altstore.io) 또는 [Sideloadly](https://sideloadly.io)로 설치하거나, 자신의 Apple ID로 Xcode에서 다시 서명합니다(무료 Apple ID는 baeium에 사용할 수 있습니다). App Store 배포는 아직 설정되어 있지 않습니다.

## Windows

Windows 다운로드는 사용자별로 설치하고 스스로 최신 상태를 유지하는 설치 관리자입니다. 빌드는 서명되지 않아 첫 실행 때 SmartScreen 경고가 표시될 수 있습니다. 각 [GitHub 릴리스](https://github.com/bae-fm/bae/releases)에는 그 자리에서 실행되는 휴대용 zip도 함께 첨부됩니다. Windows에는 전체 에디션만 배포됩니다.

## 소스에서 빌드

baeium은 빌드에 독점 구성요소가 필요 없습니다. 무료 provisioning에서 iOS를 빌드하는 내용을 포함해 플랫폼별 직접 빌드 지침은 [repository README](https://github.com/bae-fm/bae#building-baeium-yourself)를 보세요.

폴더는 가져올 오디오 및 기타 파일을 제공합니다. 편집 가능한 메타데이터가 온라인 릴리스, 파일 자체 태그 또는 빈 양식으로 시작되는지 여부를 선택합니다.

가져오기는 데스크톱(macOS, Windows)에서 합니다. 파일은 읽기만 하고 절대 바꾸지 않습니다. bae는 아무것도 이동, 이름 변경, 태그 변경, 재인코딩하지 않습니다. 가져온 뒤 파일이 어디에 있는지는 [저장소와 오프라인](/ko/guide/storage)을 보세요.

## 감시 폴더

**Import** 섹션으로 전환하고 폴더를 추가합니다. 선택하거나, 창으로 끌어다 놓거나, <kbd>⌘I</kbd>를 누릅니다. 그때부터 bae가 폴더를 감시합니다. 새 음악을 그곳에 넣으면 새 후보로 자동 표시됩니다. 손으로 다시 스캔하지 않아도 됩니다. 아직 다운로드 중인 폴더는 끝날 때까지 무시됩니다.

스캔은 실제 리핑본이 가지는 형태를 인식합니다.

| 배치 | 보이는 모습 |
|--------|-------------------|
| 트랙별 파일 | `01 - Song.flac`, `02 - Song.flac`, ... |
| CUE + 이미지 | `album.cue` + `album.flac`, 전체 디스크를 담은 파일 하나 |
| 여러 디스크 | `CD1/`, `CD2/` 하위 폴더, 내부 형태는 둘 중 하나 |
| 모음 | 폴더 안의 폴더들, 각각이 자체 릴리스 |

bae는 재생하는 형식을 가져옵니다. FLAC, MP3, APE, `.m4a`의 ALAC와 AAC, WAV, AIFF, Ogg Vorbis, Opus, WavPack, DSD(`.dsf`/`.dff`)입니다. 폴더 안의 아트워크와 문서(CUE 시트, 리핑 로그, 텍스트 파일)는 인식되어 릴리스와 함께 보관됩니다.

## 메타데이터 소스 선택

모든 후보자는 **조회**, **파일 태그** 및 **수동**이라는 세 가지 동일한 메타데이터 소스를 제공합니다. 소스를 열면 표면만 표시됩니다. 후보자가 가져올 소스는 변경되지 않습니다. 소스는 명시적으로 누르기를 선택하거나 **파일 태그 사용**을 선택하거나 **수동으로 입력**을 선택한 경우에만 후보자의 메타데이터 시드가 됩니다.

### 조회

조회는 릴리스를 식별하는 유일한 소스입니다. 립 로그나 CUE 시트에서 디스크 ID를 읽고, 바코드와 카탈로그 텍스트를 인식하고, MusicBrainz 및 Discogs에 쿼리하고, 결과를 일치시킵니다. 자동 식별은 이와 동일한 조회 경로를 사용합니다. **조회 후보 자동 식별**이 활성화되고 기본 표면이 조회로 확인되는 경우에만 실행됩니다. 조회을 입력하고 검색을 시작하면 해당 설정에 관계없이 명시적으로 검색을 실행할 수 있습니다. 이 작업은 파일 태그나 수동으로 실행되지 않습니다.

### 파일 태그

파일 태그는 포함된 오디오 태그와 CUE 메타데이터를 열고 배에게 읽어달라고 요청할 때만 읽습니다. 미리보기를 검토한 다음 **파일 태그 사용**을 선택하여 정확한 스냅샷을 시드로 저장하세요. 미리 보기 후 후보 또는 관찰된 오디오 파일이 변경되면 라이브러리에 쓰기 전에 가져오기가 실패합니다.

### 수동

수동에서는 태그, 폴더 증거 또는 온라인 공급자를 읽지 않습니다. 수정 가능한 빈 릴리스와 후보자의 실제 트랙 레이아웃으로 시작하려면 **수동으로 입력**을 선택하세요.

가져오기 설정에서 **다음에서 시드되지 않은 후보 열기**는 시드되지 않은 후보가 먼저 열리는 표면을 선택합니다. **마지막 사용**은 명시적으로 연 마지막 소스를 확인합니다. 이 설정은 시드가 아닌 표면을 선택합니다. 명시적인 소스 작업은 가져오기에서 사용할 내용을 계속 확인합니다.

## 확인과 가져오기

확인 창은 가져오기가 쓸 모든 것을 보여줍니다.

- **Cover.** 데이터베이스의 아트, 폴더 안 이미지, 파일에 내장된 아트 중에서 선택됩니다. 나중에 바꿀 수 있습니다.
- **Metadata.** 앨범, 아티스트, 연도, 레이블, 카탈로그 번호, 국가, barcode, 모든 트랙입니다. 저장 전에 여기서 모두 편집할 수 있습니다.
- **Storage.** 클라우드 홈이 연결되어 있으면 bae가 파일을 클라우드에서 관리할지, 로컬 사본도 보관할지 선택합니다. [저장소와 오프라인](/ko/guide/storage)을 보세요.

가져오기는 백그라운드에서 실행됩니다. bae는 모든 트랙이 끝까지 정상 디코딩되는지 확인하고, 앨범과 각 트랙의 loudness를 측정하고, 릴리스를 저장하고, 관리되는 가져오기라면 업로드를 시작합니다. 후보 목록은 다음 폴더로 넘어가고, 릴리스는 바로 재생할 수 있습니다.

## 데이터 소스

**MusicBrainz**는 계정도 키도 필요 없습니다. **Discogs**는 사용자의 무료 API token이 필요합니다. Settings에 붙여 넣으면 bae가 동작을 멈췄을 때 알려줍니다. 토큰이 없으면 Discogs 검색과 Discogs 기반 메타데이터를 쓸 수 없지만, 나머지는 모두 동작합니다. 두 서비스에는 요청 제한이 있습니다. bae는 제한 안에 머무르도록 요청 속도를 조절합니다.

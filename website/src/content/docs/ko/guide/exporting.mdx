잠금이 없다는 말은 양방향입니다. bae는 들어오는 파일을 바꾸지 않고, 나가는 파일도 붙잡아 두지 않습니다. 관리되지 않는 릴리스는 이미 사용자 폴더의 파일입니다. 관리되는 릴리스도 언제든 바이트 단위로 같은 로컬 파일로 되돌릴 수 있습니다. 그리고 휴대폰에 맞는 인코딩이나 굽기에 맞는 이미지처럼 다른 형태가 필요할 때, 내보내기는 원본을 건드리지 않고 그 결과를 만듭니다.

## 두 가지 내보내기

- **Track export**: 트랙을 오른쪽 클릭하고 **Save As**를 누른 뒤 형식을 고르면 됩니다.
- **Release export**: 앨범 메뉴나 Storage Manager에서 전체 릴리스를 폴더로 내보냅니다. 진행률, 일시 정지, 재시도가 있는 대기열에서 실행됩니다.

원본 파일은 그대로 내보냅니다. 그 밖의 항목은 나가는 중에 인코딩됩니다.

## 프리셋

내보내기 형식은 Settings에서 한 번 정의하는 프리셋입니다. FLAC, MP3, Opus, WAV, AIFF와 코덱 매개변수(무손실 형식의 비트 깊이, 손실 형식의 비트레이트), 그리고 title, artist, album, year, track number 같은 토큰으로 만든 파일 이름 템플릿을 지정합니다. 트랙용 기본 프리셋과 릴리스용 기본 프리셋을 정하고, 릴리스 내보내기가 항상 대상 위치를 묻게 할지 고정 폴더를 항상 쓰게 할지도 선택합니다.

## 내보내기의 프리갭

프리갭이 있는 CD 리핑본은 내보낼 때 실제 질문을 만듭니다. 숨은 오디오는 어디로 가야 할까요? 각 프리셋은 정책을 하나 고릅니다.

- **Append to the previous track**: 일반적인 관례입니다. 1번 트랙 앞에 숨은 오디오는 1번 트랙 시작에 둘지 버릴지 선택합니다.
- **Exclude** 프리갭 전체: 트랙 경계를 분명히 두고 숨은 오디오는 제외합니다.
- **Single file with CUE**: 디스크를 오디오 파일 하나와 CUE 시트 하나로 내보내 원래 배치를 그대로 보존합니다.

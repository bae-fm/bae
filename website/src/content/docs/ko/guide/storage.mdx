파일은 사용자의 것입니다. bae는 파일을 이동, 이름 변경, 다시 쓰기 하지 않습니다. 저장소가 답하는 질문은 각 릴리스의 *재생 가능한 사본*이 어디에 있는가뿐입니다. 기기, 사용자의 클라우드, 또는 둘 다입니다.

## 관리되지 않음과 관리됨

모든 릴리스는 둘 중 하나이며, 가져올 때 선택하고 언제든 바꿀 수 있습니다.

- **Unmanaged**: bae가 파일이 있는 곳에서 목록화하고 그곳에서 재생합니다. 아무것도 복사되지 않습니다. 릴리스는 동기화된 모든 기기의 카탈로그에 있지만, 오디오는 가져온 기기에만 있습니다.
- **Managed**: 파일이 암호화되어 클라우드 홈에 업로드됩니다. 이제 모든 기기가 필요할 때 스트리밍하거나 오프라인용으로 내려받아 릴리스를 재생할 수 있습니다. 업로드는 원본 파일을 건드리지 않습니다. 로컬에서 계속 쓸지는 사용자가 정합니다(가져올 때 **Keep local copy**를 선택하면 고정됩니다).

둘 사이의 이동은 릴리스 단위 작업입니다. **Manage**는 관리되지 않는 릴리스를 업로드합니다. **Make local**은 관리되는 릴리스의 파일을 사용자가 고른 폴더에 내려받고, 파일은 다시 일반 파일로 사용자의 것이 됩니다.

## 스트리밍과 캐시

관리되는 릴리스는 네트워크가 허용하는 곳이면 어디서든 재생됩니다. 재생은 사용자의 클라우드에서 파일을 스트리밍하고, 다음 재생이 빠르고 네트워크를 쓰지 않도록 바이트를 로컬 캐시에 보관합니다. 캐시는 예산 안에서 스스로 관리됩니다(각 기기의 오디오 20 GB). 공간이 부족하면 재생하지 않은 항목을 내보냅니다. 커버와 아티스트 이미지는 따로 캐시되므로 큰 앨범이 아트워크를 밀어내지 않습니다.

## 오프라인 고정

릴리스를 고정하면 전체를 내려받고 유지합니다. 고정된 음악은 내보내지지 않으며 항상 오프라인에서 재생됩니다. 릴리스의 저장소 시트나 Storage Manager에서 고정합니다. 고정을 해제하면 파일은 일반 캐시로 돌아가 재생은 가능하지만 회수 대상이 됩니다. 휴대폰에서는 고정 다운로드의 진행률이 라이브러리에 바로 표시됩니다.

## Storage Manager

데스크톱의 Storage Manager(<kbd>⌘0</kbd>)는 전체 그림을 한 창에 보여줍니다.

- 모든 릴리스와 그 크기 및 상태: unmanaged, managed, uploading. 필터, 정렬, 다중 선택, 일괄 작업을 할 수 있습니다.
- **Downloads**: 진행 중인 고정 다운로드입니다. 일시 정지와 재시도가 가능합니다.
- **Exports**: 내보내기 대기열입니다. [내보내기](/ko/guide/exporting)를 보세요.
- **Uploads**: 동기화 outbox입니다. 릴리스별 진행률, 처리량과 남은 시간, 대기 중인 삭제, 일시 정지와 재개를 보여줍니다.

## 삭제

관리되는 릴리스를 삭제하면 라이브러리와 클라우드 홈에서 제거됩니다. 관리되지 않는 릴리스를 삭제하면 카탈로그 항목만 제거됩니다. bae는 자신이 넣지 않은 파일을 절대 삭제하지 않습니다.

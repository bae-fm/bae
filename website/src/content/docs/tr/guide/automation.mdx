## MCP sunucusu

MCP sunucusunu Settings, Automation bölümünden açın. Model Context Protocol'ü HTTP üzerinden yerel bir bağlantı noktasında sunar (varsayılan 47777), böylece Claude gibi MCP istemcileri kitaplığınıza göz atabilir, sürümleri arayabilir ve üzerlerinde işlem yapabilir. Erişim bir bearer token gerektirir: aynı ayarlar bölmesinden kopyalayın ve ona sahip olan her şeyin erişimini kesmek istediğinizde oradan döndürün.

Sunucu varsayılan olarak kapalıdır ve yalnızca uygulama çalışırken çalışır.

## Eşzamanlama

Eşzamanlama cloud home üzerinden geçer. Her değişiklik şifreli changeset üretir; diğer cihazlar indirip uygular.

## bae

bae çoklu cihaz eşzamanlama için yerel kimlikler, kitaplık anahtarı, değiştirilebilir cloud home ve şifreli changeset kullanır.

## Depolama

Dosyalar öz yönetimli, yerel yönetimli veya bulut yönetimli olabilir. Yerel dosyalar çevrimdışı çalışır; bulut dosyaları cloud home üzerinden eşzamanlanır.

## Şifreleme

Opaque cloud home veriyi cihazdan çıkmadan önce şifreler. Browsable cloud home okunabilir yollarda şifresiz dosya saklar.

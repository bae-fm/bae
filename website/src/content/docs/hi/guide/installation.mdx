## दो editions

हर प्लेटफ़ॉर्म दो editions में आता है, एक ही स्रोत से built:

- **bae**, पूरा ऐप: S3, Google Drive, Dropbox, OneDrive, और iCloud समन्वय।
- **baeium**, proprietary parts नहीं: केवल S3-compatible संग्रहण, कोई OAuth providers नहीं, कोई iCloud/CloudKit नहीं, कोई telemetry नहीं।

दोनों साथ-साथ install होते हैं, हर एक की अपनी लाइब्रेरी और अपनी (iCloud-Keychain-synced) कुंजियां होती हैं। नीचे जो चाहें चुनें।

## iOS

iOS builds sideloading के लिए **unsigned `.ipa` फाइलें** हैं। [AltStore](https://altstore.io) या [Sideloadly](https://sideloadly.io) से install करें, या अपने Apple ID से Xcode में re-sign करें (free Apple ID baeium के लिए काम करता है)। App Store distribution अभी set up नहीं है।

लाइब्रेरी को आपके चलाए हुए सॉफ्टवेयर से नियंत्रित किया जा सकता है: MCP पर AI एजेंटों से और कमांड-लाइन टूल पर स्क्रिप्टों से। दोनों वही क्रियाएं खोलते हैं जो ऐप का इंटरफेस इस्तेमाल करता है: खोज, रिलीज का विवरण, आयात, संग्रहण क्रियाएं और चलने की स्थिति।

## MCP सर्वर

MCP सर्वर को Settings, Automation में चालू करें। यह Model Context Protocol को HTTP पर स्थानीय पोर्ट पर चलाता है (डिफॉल्ट 47777), ताकि Claude जैसे MCP क्लाइंट आपकी लाइब्रेरी देख सकें, रिलीज खोज सकें और उन पर काम कर सकें। पहुंच के लिए bearer टोकन चाहिए: उसे उसी सेटिंग्स pane से कॉपी करें, और जब भी उस टोकन वाले सभी क्लाइंटों की पहुंच रोकनी हो, वहीं उसे बदल दें।

सर्वर डिफॉल्ट रूप से बंद रहता है और केवल ऐप के चलने पर चलता है।

## कमांड लाइन

`bae` CLI टर्मिनल से वही क्रियाएं चलाता है: JSON अंदर, JSON बाहर, स्क्रिप्ट के लिए उपयुक्त। यह MCP क्लाइंट की तरह भी काम कर सकता है, डेस्कटॉप के सर्वर को stdio पर उन टूलों से जोड़ते हुए जिन्हें स्थानीय MCP process चाहिए।

bae は、所有しているアルバムの置き場所です。ライブラリはデスクトップで作成し、すべてのデバイスに持っていけます。すでに使っているクラウドストレージを通じて同期され、読めるのは自分のデバイスだけになるよう暗号化されます。

デスクトップアプリ（macOS、Windows）は完全なツールです。ライブラリの作成、音楽のインポート、メタデータの編集を行います。スマートフォンアプリ（iOS、Android）はプレーヤーです。デスクトップで作成したライブラリに参加し、閲覧、ダウンロード、再生を行います。

## ライブラリを作成する

デスクトップで bae を開きます。そのマシンにライブラリがない場合、ウェルカム画面には 3 つの選択肢が表示されます。

- **Create a new library**: これが最初のデバイスの場合。
- **ライブラリに参加**: 誰かが自分のライブラリにあなたを招待した場合。[デバイスとメンバー](/ja/guide/devices#人を招待する) を参照してください。
- **クラウドから復元**: 自分のライブラリで、その復元コードを持っている場合。[デバイスとメンバー](/ja/guide/devices#復元コード) を参照してください。

1 つ作成します。ライブラリはローカルから始まります。すべてはこのマシン上にあり、アカウントは不要で、クラウドを接続するまではクラウドは関与しません。

## 最初のアルバムをインポートする

1. タイトルバーで **Import** セクションに切り替えます。
2. 音楽フォルダーを追加します。選択する、ウィンドウへドラッグする、または <kbd>⌘I</kbd> を押します。
3. bae がフォルダーをスキャンし、見つけたリリースを一覧します。1 つ選びます。
4. bae が MusicBrainz と Discogs に照合し、一致候補を表示します。盤を確認し、カバーを選び、必要な詳細を調整します。
5. **Import** をクリックします。

ファイルは移動、コピー、書き換えされません。bae はファイルがある場所でカタログ化します。識別に手助けが必要な場合を含む流れ全体は、[インポート](/ja/guide/importing) にあります。

## 再生する

**Library** セクションに戻ると、アルバムがグリッドにあります。クリックして再生します。再生には元ファイルが元の品質のまま使われます。[再生](/ja/guide/playback) では、キュー、シャッフルとリピート、bae が保持する詳細である CD プリギャップ、レコードの面の区切り、ギャップレスアルバムを説明します。

## どこへでも持っていく

複数のデバイスでライブラリを使いたいときは、クラウドホームを接続します。自分の Dropbox、OneDrive、iCloud、または任意の S3 互換バケットです。bae がそこへ置くものは、アップロード前にすべて暗号化されます。プロバイダーは保存しますが、読むことはできません。

- [同期](/ja/guide/sync): クラウドホームを接続し、何が同期されるかを確認します。
- [デバイスとメンバー](/ja/guide/devices): スマートフォンや別のデスクトップを追加するか、誰かを招待します。
- [ストレージとオフライン](/ja/guide/storage): 音楽をデバイスに保持する、またはクラウドからストリーミングし、必要なものをオフライン用に固定します。

## 置き場所

各ライブラリは、デスクトップではデータベースを `~/.bae/stores/` の下に、設定を `~/.bae/libraries/` の下に保持します。音声はインポート元の場所に残ります。リリースをクラウドに移動すると暗号化したコピーがアップロードされ、ファイルは元の場所に残ります。鍵と認証情報はファイルではなく、OS のキーリングに保存されます。

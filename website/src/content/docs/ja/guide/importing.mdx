title: インポート
description: 各フォルダーがインポート メタデータを提供する方法を選択します
---

フォルダーは、インポート用のオーディオおよびその他のファイルを提供します。編集可能なメタデータがオンライン リリースで始まるか、ファイル自体のタグで始まるか、空白のフォームで始まるかを選択します。

インポートはデスクトップ（macOS、Windows）で行います。ファイルは読み取られるだけで、変更されません。bae は移動、リネーム、タグ書き換え、再エンコードを行いません。インポート後のファイルの置き場所については、[ストレージとオフライン](/ja/guide/storage) を参照してください。

## 監視フォルダー

**Import** セクションに切り替え、フォルダーを追加します。選択する、ウィンドウへドラッグする、または <kbd>⌘I</kbd> を押します。以後、bae はそのフォルダーを監視します。そこへ追加された新しい音楽は、自動的に新しい候補として表示されます。手作業で再スキャンする必要はありません。まだダウンロード中のフォルダーは、完了するまで無視されます。

スキャンは、リッピングが実際に取る形のリリースを認識します。

| レイアウト | 見た目 |
|--------|-------------------|
| トラックごとにファイル | `01 - Song.flac`, `02 - Song.flac`, ... |
| CUE + イメージ | `album.cue` + `album.flac`、ディスク全体が 1 つのファイル |
| 複数ディスク | `CD1/`, `CD2/` サブフォルダー、内部はどちらの形でも可 |
| コレクション | フォルダーの中にフォルダーがあり、それぞれが独自のリリース |

bae は、再生できる形式をインポートします。FLAC、MP3、APE、`.m4a` 内の ALAC と AAC、WAV、AIFF、Ogg Vorbis、Opus、WavPack、DSD（`.dsf`/`.dff`）です。フォルダー内のアートワークと文書（CUE シート、リッピングログ、テキストファイル）は認識され、リリースと一緒に保持されます。

## メタデータの草稿を埋め込む

それぞれの候補者は編集可能なメタデータ草稿を一つ持っています。これは空白から始まるか、オンラインリリースから入力されるか、またはファイルのタグから入力されます。空白の草稿に入力すると、別のメタデータソースではなく、直接入力されます。

**オンラインで検索…** または **ファイルのタグ...** を開くと、上のカードをそのソースのブラウザに置き換え、ドラフトを変更しません。結果を 適用 すると、ドラフトを置き換え、編集可能なカードに戻ります。カードのメニューを使って、他のリリースを見つけ、ファイルタグを適用、またはメタデータをクリアして空のドラフトに戻ります。メタデータをクリアすると、候補のファイルとトラックレイアウトが保持されます。

### オンラインで検索

オンラインで検索 はリリースを識別する唯一のパスです。リップログまたは CUE シートから ディスクID を計算し、バーコードとカタログテキストを認識し、MusicBrainz と Discogs をクエリし、結果と一致させます。

自動識別も同じ経路を使用します。**デフォルトのメタデータソース**では、新しく見つかった候補に対して**オンラインで検索**、**ファイルのタグ**、**なし**のいずれかを選びます。**オンラインで検索のデフォルトモード**では、**自動**または**手動で検索**を選びます。自動はオンラインで検索を開いたときに証拠抽出、OCR、プロバイダーへの問い合わせ、照合を開始し、手動で検索はこれらを開始しません。ファイルのタグとなしはオンラインで検索を開きません。

### ファイルのタグ

ファイルのタグ はソースを開いたりデフォルトとして設定したときに埋め込みオーディオタグと CUE メタデータを読みます。プレビューを見て、 **適用** を選択して、草稿をそのスナップショットに置き換えます。プレビュー後に候補または観測されたオーディオファイルが変更された場合、ライブラリに書き込む前にインポートは失敗します。

スナップショットを適用した後、編集可能なカードは静かな ファイルのタグ チップを表示します。タイプのみで埋め込まれた草稿はソースチップを持っていません。

## 確認してインポート

確認ペインには、インポートが書き込むものがすべて表示されます。

- ＊＊＊カバー＊＊ データベースのアートワーク、フォルダ内の画像、またはファイルに埋め込まれたアートワークから選択します。候補画像ギャラリーからカバーの四角に画像をドラッグしてください。後で変更してください。
- **Metadata。** アルバム、アーティスト、年、レーベル、カタログ番号、国、バーコード、すべてのトラックです。保存前にここですべて編集できます。
- **Storage。** クラウドホームが接続されている場合、bae にファイルをクラウドで管理させるか、ローカルコピーも保持するかを選びます。[ストレージとオフライン](/ja/guide/storage) を参照してください。

インポートはバックグラウンドで実行されます。bae はすべてのトラックが問題なくデコードできることを検証し、アルバムと各トラックのラウドネスを測定し、リリースを保存し、管理対象インポートではアップロードを開始します。候補一覧は次のフォルダーへ進み、リリースはすぐ再生できます。

## データソース

**MusicBrainz** にはアカウントもキーも不要です。**Discogs** には自分の無料 API トークンが必要です。Settings に貼り付けると、動作しなくなった場合に bae が知らせます。トークンがない場合、Discogs 検索と Discogs 由来のメタデータは使えませんが、それ以外は動作します。どちらのサービスにもレート制限があります。bae は制限内に収まるようリクエストの間隔を調整します。

---
title: インポート
description: フォルダーを実在するリリースに照合する
---

リッピングしたフォルダーは、それ自体についてほとんど何も知りません。元になったリリース、盤、レーベル、クレジット、トラック 12 が実際にどこで終わるか。そうした情報はファイル名ではなく、MusicBrainz や Discogs のようなデータベースにあります。インポートは、bae がその 2 つを結び付ける方法です。音楽を指定すると、各フォルダーがどのリリースかを調べ、ライブラリはそのフォルダーをそのリリースとして記録します。

インポートはデスクトップ（macOS、Windows）で行います。ファイルは読み取られるだけで、変更されません。bae は移動、リネーム、タグ書き換え、再エンコードを行いません。インポート後のファイルの置き場所については、[ストレージとオフライン](/ja/guide/storage) を参照してください。

## 監視フォルダー

**Import** セクションに切り替え、フォルダーを追加します。選択する、ウィンドウへドラッグする、または <kbd>⌘I</kbd> を押します。以後、bae はそのフォルダーを監視します。そこへ追加された新しい音楽は、自動的に新しい候補として表示されます。手作業で再スキャンする必要はありません。まだダウンロード中のフォルダーは、完了するまで無視されます。

スキャンは、リッピングが実際に取る形のリリースを認識します。

| レイアウト | 見た目 |
|--------|-------------------|
| トラックごとにファイル | `01 - Song.flac`, `02 - Song.flac`, ... |
| CUE + イメージ | `album.cue` + `album.flac`、ディスク全体が 1 つのファイル |
| 複数ディスク | `CD1/`, `CD2/` サブフォルダー、内部はどちらの形でも可 |
| コレクション | フォルダーの中にフォルダーがあり、それぞれが独自のリリース |

bae は、再生できる形式をインポートします。FLAC、MP3、APE、`.m4a` 内の ALAC と AAC、WAV、AIFF、Ogg Vorbis、Opus、WavPack、DSD（`.dsf`/`.dff`）です。フォルダー内のアートワークと文書（CUE シート、リッピングログ、テキストファイル）は認識され、リリースと一緒に保持されます。

## リリースの識別

候補を選ぶと、bae が識別を開始します。タグから推測するのではなく、フォルダー内の証拠を読み取り、それぞれを検索します。

- **Disc ID。** CD の正確なトラック配置のフィンガープリントで、リッピングログまたは CUE シートから計算されます。一致すると、正確な CD 版を識別します。
- **バーコード。** フォルダー内のカバースキャンから文字認識で読み取るか、CUE シートから読み取ります。
- **カタログ番号とテキスト。** アートワーク、ファイル名、フォルダー名にあるカタログ番号で、結果を絞り込みます。

シグナルは MusicBrainz と Discogs に同時に照会され、結果は照合されます。各シグナルは結果の上にバッジとして表示されます。何が見つかったか、どこから来たか（由来はホバーで表示されます: disc TOC、CUE sheet、cover scan、folder name）を確認でき、誤解を招くシグナルは個別にオフにできます。

結果は 3 つです。

- **Found。** 証拠が 1 つのリリースグループで一致します。その一覧から正確な盤を選びます。
- **Conflict。** Disc ID とバーコードが一致しないなど、2 つのシグナルが別々のリリースを指します。bae は両方を表示し、どちらを信頼するか選ぶか、シグナルを無視できます。
- **Nothing found。** 手で検索します。アーティストとアルバム、カタログ番号、バーコードを、どちらかのデータベースで検索します。アートワークから認識されたテキストは、自動補完として提示されます。

**Skip identifying** を選び、不明なリリースとしてインポートすることもできます。その場合、bae は名前にファイルの埋め込みタグを使います。後でリリースがデータベースに存在するようになったとき、またはより良い証拠があるときに、再識別できます。

## 正確または近似

一致候補を選ぶと、bae はそれをファイルと照合し、トラック数の不一致を示します。そのうえで、一致の種類を宣言します。

- **Exact**: ファイルはこの盤です。
- **Metadata only**: アルバムは正しいが、必ずしもこの正確な盤ではありません。bae はメタデータを使い、盤が近似であることを記憶します。

そのリリースがすでにライブラリにある場合、または同じアルバムの別の盤がある場合、bae は重複インポートの前に知らせます。

## 確認してインポート

確認ペインには、インポートが書き込むものがすべて表示されます。

- **Cover。** データベースのアート、フォルダー内の画像、またはファイルに埋め込まれたアートから選ばれます。後で変更できます。
- **Metadata。** アルバム、アーティスト、年、レーベル、カタログ番号、国、バーコード、すべてのトラックです。保存前にここですべて編集できます。
- **Storage。** クラウドホームが接続されている場合、bae にファイルをクラウドで管理させるか、ローカルコピーも保持するかを選びます。[ストレージとオフライン](/ja/guide/storage) を参照してください。

インポートはバックグラウンドで実行されます。bae はすべてのトラックが問題なくデコードできることを検証し、アルバムと各トラックのラウドネスを測定し、リリースを保存し、管理対象インポートではアップロードを開始します。候補一覧は次のフォルダーへ進み、リリースはすぐ再生できます。

## データソース

**MusicBrainz** にはアカウントもキーも不要です。**Discogs** には自分の無料 API トークンが必要です。Settings に貼り付けると、動作しなくなった場合に bae が知らせます。トークンがない場合、Discogs 検索と Discogs 由来のメタデータは使えませんが、それ以外は動作します。どちらのサービスにもレート制限があります。bae は制限内に収まるようリクエストの間隔を調整します。

title: 自動化
description: エージェント、スクリプト、コマンドラインからライブラリを操作する
---

ライブラリは、実行中のソフトウェアから操作できます。MCP 経由の AI エージェントと、コマンドラインツール経由のスクリプトです。どちらも UI と同じ操作を公開します。検索、リリースの詳細、インポート、ストレージ操作、再生状態です。

## MCP サーバー

Settings の Automation で MCP サーバーをオンにします。Model Context Protocol をローカルポート（既定では 47777）で HTTP として提供するため、Claude などの MCP クライアントがライブラリを閲覧し、リリースを検索し、操作できます。アクセスにはベアラートークンが必要です。同じ設定ペインからコピーし、そのトークンを持つすべてのアクセスを止めたいときは、そこでローテーションします。

サーバーは既定でオフで、アプリの実行中だけ動作します。

## コマンドライン

`bae` CLI は、同じ操作をターミナルから実行します。入力も出力も JSON なので、スクリプトに適しています。MCP クライアントとしても動作し、ローカル MCP プロセスを期待するツール向けに、デスクトップのサーバーを stdio に橋渡しできます。

ファイルは自分のもののままです。bae は移動、リネーム、書き換えをしません。ストレージが答える問いは、各リリースの*再生可能なコピー*がどこにあるかだけです。デバイス上、クラウド内、またはその両方です。

## 管理外と管理対象

すべてのリリースはどちらか一方で、インポート時に選び、いつでも変更できます。

- **Unmanaged**: bae はファイルがある場所でカタログ化し、そこから再生します。何もコピーされません。リリースは同期されたすべてのデバイスのカタログに存在しますが、音声はインポートしたマシンにだけあります。
- **Managed**: ファイルは暗号化され、クラウドホームへアップロードされます。これで、すべてのデバイスが必要に応じてストリーミングするか、オフライン用にダウンロードして、そのリリースを再生できます。アップロードしても元ファイルは触れられません。ローカルで使い続けるかどうかは自分で決めます（インポート時の **Keep local copy** は固定します）。

2 つの間の移動はリリース単位の操作です。**Manage** は管理外リリースをアップロードします。**Make local** は管理対象リリースのファイルを選んだフォルダーへダウンロードし、通常のファイルとして再び自分のものにします。

## ストリーミングとキャッシュ

管理対象リリースは、ネットワークがあればどこでも再生できます。再生はクラウドからファイルをストリーミングし、バイト列はローカルキャッシュに保持されるため、次回の再生ではすぐ使えます。キャッシュは上限内（各デバイスで音声 20 GB）で自分を管理し、容量が少ないと、再生していないものを退避します。カバーとアーティスト画像は別にキャッシュされるため、大きなアルバムがアートワークを押し出すことはありません。

## オフライン用の固定

リリースを固定すると、全体をダウンロードして保持します。固定した音楽は退避されず、常にオフラインで再生できます。リリースのストレージシートまたは Storage Manager から固定します。固定解除すると、ファイルは通常のキャッシュに戻り、再生可能なままですが、容量回収の対象になります。スマートフォンでは、固定ダウンロードの進行状況がライブラリ内に表示されます。

## Storage Manager

デスクトップの Storage Manager（<kbd>⌘0</kbd>）は、全体像を 1 つのウィンドウに表示します。

- すべてのリリースとそのサイズ、状態: unmanaged、managed、uploading。フィルター、並べ替え、複数選択、一括操作ができます。
- **Downloads**: 実行中の固定ダウンロード。一時停止と再試行ができます。
- **Exports**: エクスポートキューです。[エクスポート](/ja/guide/exporting) を参照してください。
- **Uploads**: 同期の送信待ちです。リリースごとの進行状況、スループット、残り時間、保留中の削除、一時停止と再開が表示されます。

## 削除

管理対象リリースを削除すると、ライブラリとクラウドホームから削除されます。管理外リリースを削除すると、カタログ項目だけが削除されます。bae は自分が置いたものではないファイルを削除しません。

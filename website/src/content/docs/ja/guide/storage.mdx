ファイルは自分のもののままです。bae は移動、リネーム、書き換えをしません。ストレージが答える問いは、各リリースの*再生可能なコピー*がどこにあるかだけです。デバイス上、クラウド内、またはその両方です。

## ローカルとクラウド

すべてのリリースはどちらか一方で、インポート時に選び、いつでも変更できます。

- **ローカル**: bae はファイルがある場所でカタログ化し、そこから再生します。何もコピーされません。リリースの情報は同期されるため、すべてのデバイスにアルバム、トラック、カバーが表示されますが、音声はインポートしたマシンに残り、他のデバイスでは再生できません。
- **クラウド**: ファイルは暗号化され、クラウドホームへアップロードされます。これで、すべてのデバイスが必要に応じてストリーミングするか、オフライン用にダウンロードして、そのリリースを再生できます。アップロードしても元ファイルは触れられません。

インポート時、クラウドホームが接続されていれば、**クラウド** で新しいリリースをアップロードし、**ピン留め済み** でそのファイルをこのデバイスにも保持します。後から **クラウドに移動** でローカルリリースをアップロードできます。bae はまず各ファイルがインポート以降変わっていないことを確認し、変更されたファイルがあるとアップロードを止めます。**ローカルにする…** は、クラウドのリリースのファイルを選んだフォルダーへコピーし、各コピーを確認して、そこからリリースを再生します。ファイルは通常のファイルとして再び自分のものになり、他のデバイスでは再生できなくなります。

## ストリーミングとキャッシュ

クラウドのリリースは、ネットワークがあればどこでも再生できます。再生はクラウドからファイルをストリーミングし、バイト列はローカルキャッシュに保持されるため、次回の再生ではすぐ使えます。キャッシュは上限内（各デバイスで音声 20 GB）で自分を管理し、容量が少ないと、再生していないものを退避します。カバーとアーティスト画像は別にキャッシュされるため、大きなアルバムがアートワークを押し出すことはありません。

## オフライン用の固定

リリースを固定すると、全体をダウンロードして保持します。固定した音楽は退避されず、常にオフラインで再生できます。リリースのストレージシートまたは Storage Manager から固定します。固定解除すると、ファイルは通常のキャッシュに戻り、再生可能なままですが、容量回収の対象になります。スマートフォンでは、固定ダウンロードの進行状況がライブラリ内に表示されます。

## Storage Manager

デスクトップの Storage Manager（<kbd>⌘0</kbd>）は、全体像を 1 つのウィンドウに表示します。

- すべてのリリースとそのサイズ、状態: ローカル、クラウド、アップロード中。フィルター、並べ替え、複数選択、一括操作ができます。
- **Downloads**: 実行中の固定ダウンロード。一時停止と再試行ができます。
- **Exports**: エクスポートキューです。[エクスポート](/ja/guide/exporting) を参照してください。
- **Uploads**: 同期の送信待ちです。リリースごとの進行状況、スループット、残り時間、保留中の削除、一時停止と再開が表示されます。

## 削除

クラウドのリリースを削除すると、ライブラリから削除され、そのコピーもクラウドホームから削除されます。ローカルリリースを削除すると、カタログ項目だけが削除されます。どちらの場合も、bae が自分のファイルを削除することはありません。

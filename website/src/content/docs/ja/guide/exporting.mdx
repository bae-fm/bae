囲い込みがないことには、入口と出口の両方があります。bae は取り込むときにファイルを変更せず、取り出すときにもファイルを閉じ込めません。管理外リリースは、もともとフォルダー内のファイルです。管理対象リリースも、いつでもバイト単位で同じローカルファイルに戻せます。スマートフォン向けのエンコードや書き込み用イメージなど、別の形が必要なときは、元ファイルに触れずにエクスポートで作成します。

## 2 種類のエクスポート

- **Track export**: トラックを右クリックし、**Save As** を選び、形式を選びます。
- **Release export**: アルバムメニューまたは Storage Manager から、リリース全体をフォルダーへエクスポートします。進行状況、一時停止、再試行を持つキューで実行されます。

元ファイルはそのままエクスポートされます。それ以外は出力時にエンコードされます。

## プリセット

エクスポート形式は Settings で一度定義するプリセットです。FLAC、MP3、Opus、WAV、AIFF と、それぞれのコーデックのパラメーター（可逆形式ではビット深度、非可逆形式ではビットレート）、さらにタイトル、アーティスト、アルバム、年、トラック番号などのトークンから組み立てるファイル名テンプレートを指定します。トラック用とリリース用の既定プリセットを設定し、リリースのエクスポートで毎回出力先を尋ねるか、常に固定フォルダーを使うかを選びます。

## エクスポート時のプリギャップ

プリギャップを含む CD リッピングでは、出力時に実際の問題が生じます。隠し音声をどこに置くかです。各プリセットは方針を選びます。

- **Append to the previous track**: 一般的な慣習です。トラック 1 の前に隠れている音声をトラック 1 の先頭に保持するか、破棄するかも選べます。
- **Exclude**: プリギャップを完全に除外します。トラック境界は明確になり、隠し音声は省かれます。
- **Single file with CUE**: ディスクを 1 つの音声ファイルと CUE シートとして出力し、元の配置をそのまま保ちます。

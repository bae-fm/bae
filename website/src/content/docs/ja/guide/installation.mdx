## 2 つのエディション

bae は、同じソースから作られた 2 つのエディションで配布しています。

- **bae**: 完全版アプリです。S3、Google Drive、Dropbox、OneDrive、iCloud 同期を含みます。
- **baeium**: プロプライエタリ部分を含みません。S3 互換ストレージのみ、OAuth プロバイダーなし、iCloud/CloudKit なし、テレメトリなしです。

両方を並べてインストールでき、それぞれが独自のライブラリと独自の（iCloud Keychain で同期される）鍵を持ちます。下から好きな方を選んでください。

## macOS

<DownloadButton platform="macos" edition="full" class="sl-button primary">Download bae for macOS</DownloadButton>
<DownloadButton platform="macos" edition="baeium" class="sl-button">Download baeium for macOS</DownloadButton>

1. ダウンロードした `.dmg` を開きます
2. アプリを Applications フォルダーへドラッグします
3. Applications から開きます

どちらのエディションも、それぞれの Sparkle フィードで自動更新されます。

## iOS

iOS ビルドは、**サイドロード用の署名されていない `.ipa` ファイル**です。[AltStore](https://altstore.io) または [Sideloadly](https://sideloadly.io) でインストールするか、自分の Apple ID で Xcode から再署名します（無料の Apple ID は baeium で使えます）。App Store 配布はまだ設定されていません。

## Windows

Windows のダウンロードはインストーラーで、ユーザーごとにインストールし、自動で最新の状態を保ちます。ビルドは署名されていないため、初回起動時に SmartScreen が警告する場合があります。各 [GitHub リリース](https://github.com/bae-fm/bae/releases) には、その場で実行できるポータブル zip も添付しています。Windows で公開しているのはフルエディションのみです。

## ソースからビルド

baeium のビルドにプロプライエタリなものは不要です。無料プロビジョニングでの iOS を含む、プラットフォーム別のセルフビルド手順は [リポジトリ README](https://github.com/bae-fm/bae#building-baeium-yourself) を参照してください。

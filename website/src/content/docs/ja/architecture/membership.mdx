title: Membership
description: Identity、membership chain、signed changesets

library の membership は、その library を読み書きできる devices の集合です。このページは identity、membership chain、signed changesets、key wrapping を説明します。

## Identity

各 device は初回使用時に生成され OS keyring に保存される Ed25519/X25519 keypair を持ちます。Public keys が identities です。central directory や account server はありません。Public keys は out-of-band で交換されます。

## Membership chain

membership は cloud home の `membership/{pubkey}/{seq}.enc` にある append-only chain of signed entries で追跡されます。各 entry は Add または Remove、対象 device の public key と role を記録し、current owner が署名します。

最初の entry は常に originating device を owner として追加します。chain は構築時に検証され、invalid signatures や non-owners からの entries は拒否されます。

## Signed changesets

cloud home に push される changeset は author device の Ed25519 key で署名されます。pull 時、bae は membership chain により、changeset 作成時に author が authorized device だったことを確認します。unauthorized devices や invalid signatures の changesets は捨てられます。

## Key wrapping

library encryption key は各 device の X25519 public key に sealed-box encrypted され、`keys/{user_pubkey}.enc` に保存されます。意図された受信者だけが private key で unwrap できます。device が revoked されると新しい encryption key が生成され、残りの devices に re-wrapped されます。

## Invite codes

invite code は、新しい device に必要なものをまとめます。library encryption key、cloud home coordinates、storage credentials、new device を追加する signed membership entry です。owner device が new device の public key を受け取った後に code を作り、新しい device はそれを bae に貼り付けて key を unwrap し、cloud home に接続して sync を始めます。

title: 概要
description: bae の構成
---

bae は、分散 identity と end-to-end encryption を、差し替え可能な storage の上で使う音楽ライブラリマネージャーです。これにより、独自サーバーなしで複数デバイス同期を行います。

## Identity

各デバイスはローカル生成の keypair (Ed25519/X25519) を持ちます。Public keys が identities です。中央 identity server はありません。

## Encryption

ライブラリごとに 1 つの symmetric key があり、ライブラリのデバイス間で共有されます。cloud home のすべては、デバイスを離れる前に暗号化されます。storage provider は opaque blobs だけを見ます。詳しくは [暗号化](/ja/architecture/encryption)。

## Storage

Google Drive、Dropbox、OneDrive、iCloud Drive、S3-compatible buckets、または local-only に対応します。1 つの `CloudHome` trait が違いを抽象化します。詳しくは [Cloud Home](/ja/architecture/cloud-home)。

## Sync

デバイスは cloud home を通じて encrypted changesets を同期します。各編集は compact binary diff を作り、他デバイスが pull して適用します。競合は hybrid logical clocks を使う last-writer-wins で解決されます。library は membership chain と signed changesets で複数デバイスに同期されます。詳しくは [同期](/ja/storage/sync)。

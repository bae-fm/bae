---
title: 独自サーバーなし
description: bae が独自サーバーなしで同期する方法
---

bae は独自サーバーを持ちません。各 device は shared cloud home を読み書きする client で、すべての sync は bae が運用する machine ではなく、その storage を通ります。

## cloud home が合流点

library の [cloud home](/ja/architecture/cloud-home) は、自分が管理する storage backend 上の bucket または folder です。S3-compatible storage、Google Drive、Dropbox、OneDrive、iCloud を使えます。各 device は encrypted database changesets と release files を cloud home に push し、他 devices の変更を各 sync cycle で pull します。

devices は直接通信しません。同じ cloud home に対して同期することで収束します。

## cloud home にあるもの

- encrypted release files: audio、images など
- encrypted database snapshots と sync changesets
- encrypted library images
- library を read/write できる人を記録する membership chain

## Zero-knowledge storage

storage backend は keys を持たず、復号しません。各 blob は upload 前に client で暗号化され、download 後に client で復号されます。cloud home は library contents、metadata、encryption keys を知りません。音楽を読む、検索する、index することはできません。別 device を追加することは、同じ shared storage 上の [membership](/ja/architecture/membership) grant です。

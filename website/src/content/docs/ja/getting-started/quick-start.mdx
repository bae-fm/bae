## 概要

bae は音楽ライブラリの作成と整理を助けます。できることは次のとおりです。

1. **音楽をインポート**: ローカルファイル、個別トラック、CUE/FLAC アルバム
2. **メタデータを補完**: MusicBrainz と Discogs から自動取得
3. **ライブラリを閲覧**: アーティスト、アルバム、ジャンル、年で表示

## 最初のインポート

### ローカルファイルをインポート

すでに持っている音楽をインポートするのが最初の手順です。

1. サイドバーの **Import** ボタンをクリック
2. **Local Files** を選択
3. 音楽が入っているフォルダを選択
4. bae がフォルダをスキャンして見つかった内容を表示
5. 対応する MusicBrainz または Discogs のリリースを選択
6. **Import** をクリック

bae はメタデータを取り込み、アートワークをダウンロードし、選択したストレージ方式に従ってファイルを保存します。

### ライブラリの場所

デフォルトでは、bae はライブラリのメタデータを次に保存します。

- **macOS**: `~/.bae/libraries/<library-id>/`

音声ファイルは暗号化されて cloud home にアップロードされるか、self-managed として元の場所でインデックスされます。詳しくは [ストレージ概要](/ja/storage/overview) を参照してください。

## 2 つのエディション

各プラットフォームには、同じソースから作られた 2 つのエディションがあります。

- **bae** — フル版 app: S3、Google Drive、Dropbox、OneDrive、iCloud 同期を含みます。
- **baeium** — プロプライエタリな部分なし: S3 互換ストレージのみ、OAuth プロバイダーなし、iCloud/CloudKit なし、テレメトリなし。

2 つは並べてインストールできます。それぞれ独自のライブラリと、iCloud Keychain で同期される独自の鍵を持ちます。

2. app を Applications フォルダへドラッグする
3. Applications から開く

どちらのエディションも、それぞれの Sparkle フィードで自動更新されます。

## iOS

iOS ビルドは **sideloading 用の未署名 `.ipa` ファイル**です。[AltStore](https://altstore.io) または [Sideloadly](https://sideloadly.io) でインストールするか、自分の Apple ID を使って Xcode で再署名します。無料 Apple ID は baeium で使えます。App Store 配布は設定されていません。

## Windows

Windows ビルドは、パッケージ化されていない app の **未署名** zip です。展開して `bae.exe` または `baeium.exe` を実行します。初回起動時に SmartScreen が警告する場合があります。

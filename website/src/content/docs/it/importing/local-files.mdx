## Importazione

bae analizza cartelle, trova release, legge CUE e FLAC e abbina il risultato a MusicBrainz o Discogs.

## bae

bae usa identità locali, una chiave di libreria, cloud home sostituibili e changeset cifrati per sincronizzare più dispositivi.

## Archiviazione

I file possono essere autogestiti, gestiti in locale o gestiti nel cloud. I file locali funzionano offline; quelli cloud si sincronizzano tramite cloud home.

## Crittografia

Un cloud home opaque cifra i dati prima che lascino il dispositivo. Un cloud home browsable salva file non cifrati in percorsi leggibili.

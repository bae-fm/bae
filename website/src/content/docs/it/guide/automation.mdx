## Il server MCP

Attiva il server MCP in Impostazioni, Automazione. Serve il Model Context Protocol su HTTP su una porta locale (47777 per impostazione predefinita), così client MCP come Claude possono esplorare la tua libreria, cercare release e agire su di esse. L'accesso richiede un token bearer: copialo dallo stesso pannello delle impostazioni e ruotalo lì ogni volta che vuoi revocare l'accesso a tutto ciò che lo aveva.

Il server è disattivato per impostazione predefinita e resta in esecuzione solo mentre l'app è in esecuzione.

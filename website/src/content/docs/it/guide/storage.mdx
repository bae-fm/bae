title: Archiviazione e offline
description: Dove vive la tua musica e cosa suona senza rete

I tuoi file restano tuoi. bae non li sposta, rinomina o riscrive mai; la domanda a cui risponde l'archiviazione è solo dove vive la *copia riproducibile* di ogni release: sul dispositivo, nel tuo cloud o in entrambi.

## Locali e nel cloud

Ogni release è una delle due cose, scelta all'importazione e modificabile in qualunque momento:

- **Locale**: bae cataloga i tuoi file dove si trovano e li riproduce da lì. Nulla viene copiato. I dati della release si sincronizzano, così ogni dispositivo mostra l'album, le sue tracce e la copertina, ma il suo audio resta sulla macchina che l'ha importata, e gli altri dispositivi non possono riprodurla.
- **Nel cloud**: i file vengono cifrati e caricati nella home cloud. Ora ogni dispositivo può riprodurre la release, in streaming su richiesta o scaricandola per l'offline. I tuoi file originali non vengono toccati dal caricamento.

All'importazione, con una home cloud collegata, **Cloud** carica la nuova release e **Fissato** ne conserva anche i file su questo dispositivo. In seguito, **Sposta nel cloud** carica una release locale; bae controlla prima che ogni file sia invariato dall'importazione, e un file cambiato ferma il caricamento. **Rendi locale…** copia i file di una release nel cloud in una cartella che scegli, controlla ogni copia e riproduce la release da lì; tornano tuoi come file normali, e gli altri dispositivi non possono più riprodurla.

## Streaming e cache

Le release nel cloud si riproducono ovunque, se la rete lo consente: la riproduzione legge il file in streaming dal tuo cloud, e i byte vengono conservati in una cache locale così la riproduzione successiva parte dai dati già presenti. La cache si gestisce entro un budget (20 GB per l'audio su ogni dispositivo), eliminando ciò che non hai riprodotto quando lo spazio scarseggia. Copertine e immagini artista sono memorizzate in cache separatamente, così un album grande non può espellere la grafica.

## Fissare per l'offline

Fissare una release la scarica tutta e la conserva: la musica fissata non viene mai espulsa e suona sempre offline. Fissa dal pannello archiviazione della release o dal Gestore archiviazione; rimuovere il fissaggio riporta i file alla cache normale, dove restano riproducibili ma recuperabili. Sul telefono, i download fissati mostrano l'avanzamento direttamente nella libreria.

## Il Gestore archiviazione

Il Gestore archiviazione del desktop (<kbd>⌘0</kbd>) mostra l'intero quadro in una finestra:

- Ogni release con dimensione e stato: locale, nel cloud, in caricamento. Filtra, ordina, seleziona molte, agisci su tutte insieme.
- **Download**: download fissati in corso, sospendibili, ritentabili.
- **Esportazioni**: la coda di esportazione. Vedi [Esportazione](/it/guide/exporting).
- **Caricamenti**: la coda di sincronizzazione in uscita, con avanzamento per release, velocità e tempo rimanente, eliminazioni in sospeso, pausa e ripresa.

## Eliminazione

Eliminare una release nel cloud la rimuove dalla libreria e rimuove le sue copie dalla home cloud. Eliminare una release locale rimuove solo la voce di catalogo. In entrambi i casi, bae non elimina mai i tuoi file.

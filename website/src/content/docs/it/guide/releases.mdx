La maggior parte delle app musicali modella "un album": un titolo, una copertina, una lista tracce. Le collezioni reali non funzionano così. Potresti possedere il CD originale, la rimasterizzazione e una stampa in vinile dello stesso disco, e differiscono per liste tracce, durate, grafica e crediti. bae modella **release**: ogni importazione è una stampa specifica, e le stampe dello stesso album vengono raggruppate.

## Gli album raggruppano release

Nella libreria, un album con più stampe è una voce. La pagina dell'album mostra un selettore di release; ogni release mantiene la propria lista tracce, copertina, anno, etichetta, numero di catalogo e crediti. Una release è la **principale**: quella usata per impostazione predefinita nella griglia album e nella riproduzione. Imposta qualunque release come principale con **Imposta come pubblicazione principale** nel menu dell'album, e scegli una release diversa per l'ascolto in qualunque momento; bae ricorda la tua scelta per album.

## Cosa sa una release

Le release identificate portano la conoscenza dei database, non solo i nomi delle tracce:

- Dettagli della stampa: etichetta, numero di catalogo, codice a barre, paese, formato, anno.
- Crediti: interpreti, produttori, tecnici, per release e per traccia.
- Struttura classica: compositori, opere e le loro parti, collegate alle loro registrazioni. La vista compositori della libreria è costruita da questo; vedi [Esplorazione e ricerca](/it/guide/browsing).
- Identità: quale esatta versione MusicBrainz o Discogs è questa.

Una volta applicati, questi valori appartengono alla release: bae non conserva alcun collegamento alla fonte, e le modifiche li cambiano sul posto.

## Modifica

I metadati sono tuoi da correggere. **Modifica…** nel menu dell'album apre l'editor della release, lo stesso modulo usato dall'importazione: titolo e artista dell'album, dettagli della stampa, e titolo, artista e numerazione di ogni traccia. **Salva** scrive le tue modifiche; **Annulla** le scarta.

Le modifiche vivono solo nel database di bae. I tag incorporati nei tuoi file non vengono mai riscritti; i file restano byte per byte come importati.

## Identificare di nuovo

Se una release è stata importata come sconosciuta, abbinata alla stampa sbagliata o il database è migliorato da allora, i controlli **Identifica** dell'editor eseguono di nuovo l'identificazione sulla release esistente: **Automatico** la identifica dai suoi file, e **Cerca** apre la ricerca digitata. Scegliere una stampa sostituisce subito i valori dell'editor; **Salva** li mantiene, e **Annulla** mantiene ciò che avevi.

## Copertine

Ogni release ha una copertina di visualizzazione. **Cambia copertina** offre la grafica dei database e i file immagine arrivati con la release. bae conserva la propria copia della copertina scelta, dimensionata per la visualizzazione, così la scansione originale nella tua cartella resta intatta. Tocca una copertina ovunque per aprire la galleria completa delle immagini di una release.

## Eliminazione

Eliminare una release la rimuove dalla libreria e, per una release nel cloud, rimuove le sue copie dalla home cloud. I tuoi file non vengono mai eliminati: bae li dimentica soltanto.

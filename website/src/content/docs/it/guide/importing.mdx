Una cartella fornisce l'audio e altri file per un'importazione. Scegli se i suoi metadati modificabili iniziano con una versione online, i tag propri dei file o un modulo vuoto.

L'importazione avviene su desktop (macOS, Windows). I tuoi file vengono letti, mai cambiati: bae non sposta, rinomina, ritagga o ricodifica nulla. Vedi [Archiviazione e offline](/it/guide/storage) per sapere dove vivono i file dopo l'importazione.

## Cartelle osservate

Passa alla sezione **Importa** e aggiungi una cartella: sceglila, trascinala sulla finestra o premi <kbd>⌘I</kbd>. bae osserva la cartella da quel momento in poi. La nuova musica inserita lì appare da sola come nuovi candidati; non devi scansionare di nuovo a mano. Le cartelle ancora in scaricamento vengono ignorate finché non finiscono.

Una scansione riconosce le release nelle forme reali dei rip:

| Layout | Aspetto |
|--------|---------|
| File per traccia | `01 - Canzone.flac`, `02 - Canzone.flac`, ... |
| CUE + immagine | `album.cue` + `album.flac`, un file per l'intero disco |
| Multi-disc | sottocartelle `CD1/`, `CD2/`, con una delle due forme dentro |
| Raccolte | una cartella di cartelle, ciascuna la propria release |

bae importa i formati che riproduce: FLAC, MP3, APE, ALAC e AAC in `.m4a`, WAV, AIFF, Ogg Vorbis, Opus, WavPack e DSD (`.dsf`/`.dff`). Grafica e documenti (fogli CUE, log di rip, file di testo) nella cartella vengono riconosciuti e conservati con la release.

## Compilare la bozza dei metadati

Ogni candidato possiede una bozza di metadati modificabile, che può iniziare vuota, essere compilata da un rilascio online o essere compilata dai tag dei file. La digitazione nella bozza vuota è un'immissione diretta, non una sorgente di metadati separata.

Aprire ** Trova online…** o ** Tag dei file…** sostituisce la scheda in alto con il browser di quella sorgente senza modificare la bozza. Applicaeseguendo un risultato si sostituisce la bozza e si ritorna alla scheda modificabile. Utilizzare il menu della scheda per trovare un'altra release, applicare tag ai file o cancellare i metadati e tornare a una bozza vuota.

### Trova online

Trova online è l'unico percorso che identifica un rilascio: calcola un Disc ID dal registro di rip o dal foglio CUE, riconosce i codici a barre e il testo del catalogo, interroga MusicBrainz e Discogs e fa corrispondere i risultati.

L'identificazione automatica utilizza lo stesso percorso. L'impostazione ** Fonte metadati predefinita ** sceglie ** Trova online **, ** Tag dei file ** o ** Nessuna ** per i candidati appena scoperti. Con Trova online selezionato, ** Identifica automaticamente ** controlla se l'estrazione delle prove, OCR, le query del provider e la corrispondenza iniziano automaticamente. Un comando esplicito di ricerca online o identificazione rimane disponibile quando è disattivato. Nessuna di questo lavoro viene eseguito per Tag dei file o Nessuna.

### Tag dei file

Tag dei file legge i tag audio incorporati e i metadati CUE quando l'origine è aperta o configurata come predefinita. Rivedere l'anteprima, quindi selezionare ** Applica ** per sostituire la bozza con l'istantanea esatta.L'importazione non riesce prima della scrittura nella libreria se i file audio candidati o osservati cambiano dopo l'anteprima.

La scheda modificabile mostra un chip silenzioso Tag dei file dopo che l'istantanea è stata applicata.Una bozza riempita solo da digitazione non ha alcun chip sorgente.

## Confermare e importare

Il pannello di conferma mostra tutto ciò che l'importazione scriverà:

- ** Copertina.** Scelta tra le immagini del database, le immagini nella cartella o le immagini incorporate nei file.Trascina un'immagine dalla galleria dei candidati sul quadrato della copertina, o cambiala in un secondo momento.
- **Metadati.** Album, artista, anno, etichetta, numero di catalogo, paese, codice a barre e ogni traccia: tutto modificabile qui prima che venga salvato qualcosa.
- **Archiviazione.** Se è collegata una home cloud, scegli se bae deve gestire i file nel tuo cloud e se deve conservare anche una copia locale. Vedi [Archiviazione e offline](/it/guide/storage).

L'importazione viene eseguita in background: bae verifica che ogni traccia si decodifichi senza errori, misura la sonorità per l'album e per ogni traccia, salva la release e, per le importazioni gestite, avvia il caricamento. La lista dei candidati passa alla cartella successiva e la release è riproducibile subito.

## Fonti dati

**MusicBrainz** non richiede account né chiave. **Discogs** richiede il tuo token API gratuito; incollalo in Impostazioni, e bae ti dice se smette di funzionare. Senza token, la ricerca Discogs e i metadati provenienti da Discogs non sono disponibili, e tutto il resto funziona. Entrambi i servizi hanno limiti di frequenza; bae dosa le richieste per restare entro i limiti.

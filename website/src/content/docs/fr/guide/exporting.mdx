---
title: Exportation
description: Sortir la musique, dans la forme dont vous avez besoin
---

L’absence d’enfermement joue dans les deux sens : bae ne modifie pas vos fichiers à l’entrée et ne les retient pas à la sortie. Les sorties locales ne sont déjà que des fichiers dans vos dossiers. Les sorties dans le cloud peuvent redevenir locales à tout moment, octet pour octet. Et quand il vous faut une forme *différente*, comme un encodage adapté au téléphone, Enregistrer sous… la produit sans toucher aux originaux.

## Deux exportations

- **Exporter…** : dans le menu de l’album ou le Gestionnaire de stockage, copie les fichiers d’une sortie octet pour octet dans un dossier.
- **Enregistrer sous…** : sur une piste, ou dans le menu de l’album pour une sortie, convertit vers un format de votre choix, par exemple du FLAC en MP3 pour une voiture ou un téléphone. Cela écrit de nouveaux fichiers ; les originaux restent tels quels.

Les deux passent par une file avec progression. Vous pouvez les mettre en pause et les annuler ; un travail échoué reste dans la file avec son erreur jusqu’à ce que vous l’annuliez. Un enregistrement garde le format et les réglages avec lesquels il a été mis en file : les modifier ensuite ne change rien à ce qui est déjà en file.

## Formats

Un format est un nom et un codec : FLAC, WAV, AIFF, MP3, AAC ou Opus. Ils se trouvent dans Réglages, Enregistrer sous, sous **Formats**. **Ajouter un format…** en ajoute un ; les éléments **Modifier…** et **Supprimer…** de son menu le modifient ou le suppriment. Un format a un **Nom**, un **Format** et un réglage de qualité. Les noms sont uniques, mais deux formats peuvent écrire la même chose. Un nouveau format porte le nom de son codec, avec un numéro si ce nom est pris (« FLAC », « FLAC (2) »). FLAC et MP3 sont fournis d’office.

Chaque format fonctionne pour les pistes comme pour les sorties. Dans la fenêtre Enregistrer sous, le menu **Format** liste tous les formats et commence par le dernier utilisé. Son dernier élément, **Modifier les formats…**, ouvre les réglages sur Enregistrer sous ; le menu suit les changements faits là, et un format ajouté là est aussitôt choisi.

## Qualité

- **Résolution**, pour FLAC, WAV et AIFF : **Identique à la source** ou **16-bit**. Une source avec perte n’a pas de résolution propre : elle est écrite en 16 bits.
- **Débit**, pour MP3, AAC et Opus : une liste des débits que l’encodeur du codec écrit. MP3 : 32, 40, 48, 56, 64, 80, 96, 112, 128, 160, 192, 224, 256, 320 kbps. AAC : 96, 128, 160, 192, 256, 320 kbps. Opus : 64, 96, 128, 160, 192, 256 kbps.

## Noms

Sous **Noms** dans Réglages, Enregistrer sous, un modèle de **Nom du fichier** et un modèle de **Nom du dossier** servent pour tous les formats. Un modèle est une rangée d’éléments que vous réordonnez, retirez et ajoutez, avec un aperçu du nom qu’il produit. Un nom de fichier peut utiliser le titre, l’artiste, l’album, l’année, le numéro de piste, le numéro de disque et le nombre de pistes. Un nom de dossier peut utiliser l’artiste, l’album, l’année, le label et le numéro de catalogue ; un élément que la sortie ne renseigne pas est omis.

Enregistrer sous… sur une piste propose le nom du modèle, et choisir un autre format ne change que l’extension. Enregistrer une sortie écrit ses fichiers dans un dossier nommé par le modèle de dossier. L’enregistrement d’une sortie ne remplace jamais un fichier : si deux noms désignent le même fichier sur votre disque, l’enregistrement échoue. Enregistrer sous… sur une seule piste ne remplace un fichier existant qu’après votre confirmation.

## Un fichier par piste

Chaque enregistrement écrit un fichier par piste, avec une seule règle pour les silences. Un pregap, stocké ou généré, va à la fin de la piste précédente, et l’audio caché avant la piste un reste au début de la piste un. Une sortie stockée comme une seule image avec une feuille CUE est découpée aux repères de pistes. Enregistrer sous… n’écrit pas de feuille CUE.

## Copier au lieu d’encoder

Une piste qui est un fichier entier déjà dans le format sans perte choisi, à la résolution que le format écrit, est copiée au lieu d’être réencodée. WAV et AIFF comptent à 16 ou 24 bits. Ses étiquettes, sa pochette et son nom sont réécrits. Un format avec perte encode toujours.

## Options supplémentaires

Sous **Options supplémentaires** dans Réglages, Enregistrer sous, trois interrupteurs s’appliquent à tous les formats. Tous sont activés au départ.

- **Intégrer la pochette** : place la pochette dans chaque fichier.
- **Image de pochette dans le dossier** : l’enregistrement d’une sortie écrit aussi `cover.jpg` dans son dossier.
- **Étiquettes de volume** : écrit pour chaque fichier le gain et le pic ReplayGain de la piste et de l’album, d’après le volume que bae a mesuré à l’import.

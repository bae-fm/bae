## Deux éditions

Chaque plateforme est livrée en deux éditions, construites depuis le même code source :

- **bae**, l’application complète : synchronisation S3, Google Drive, Dropbox, OneDrive et iCloud.
- **baeium**, sans composants propriétaires : stockage compatible S3 uniquement, sans fournisseurs OAuth, sans iCloud/CloudKit, sans télémétrie.

Elles s’installent côte à côte, chacune avec sa propre bibliothèque et ses propres clés synchronisées par le trousseau iCloud. Choisissez ci-dessous celle qui vous convient.

Les deux éditions se mettent à jour automatiquement via leur propre flux Sparkle.

## iOS

Les versions iOS sont des **fichiers `.ipa` non signés pour l’installation latérale**. Installez-les avec [AltStore](https://altstore.io) ou [Sideloadly](https://sideloadly.io), ou resignez-les dans Xcode avec votre propre Apple ID (un Apple ID gratuit fonctionne pour baeium). La distribution sur l’App Store n’est pas encore configurée.

## Windows

Les versions Windows sont des archives zip **non signées** de l’application non empaquetée. Extrayez-les et lancez `bae.exe` / `baeium.exe`. SmartScreen peut afficher un avertissement au premier lancement.

---
title: Synchronisation
description: Synchroniser ta bibliothèque entre appareils
---

bae synchronise ta bibliothèque sur plusieurs appareils via ton cloud home. Chaque modification, importation et suppression se propage automatiquement.

## Configurer la synchronisation

1. Va dans **Réglages > Synchronisation**
2. Connecte-toi avec un fournisseur cloud (Google Drive, Dropbox, OneDrive), utilise iCloud Drive (macOS) ou saisis des identifiants S3
3. bae génère un ID d'appareil et commence à synchroniser

## Fonctionnement

Les changements sont synchronisés de manière incrémentale : chaque modification produit un petit changeset chiffré et envoyé au cloud home. Les autres appareils récupèrent et appliquent les nouveaux changesets. bae synchronise après chaque changement et interroge toutes les 30 secondes pour récupérer les changements des autres appareils. Si le cloud home est inaccessible, la synchronisation réessaie au cycle suivant.

Les nouveaux appareils démarrent depuis un snapshot complet périodique, puis appliquent seulement les changesets postérieurs.

## Résolution des conflits

Quand deux appareils modifient les mêmes données, bae résout les conflits automatiquement avec la règle du dernier écrivain gagnant. Si deux appareils modifient des champs différents de la même édition, les deux changements sont conservés. Les vrais conflits, le même champ modifié des deux côtés, sont résolus par horodatage. Les suppressions gagnent sur les modifications concurrentes.

## Ce qui se synchronise

- Métadonnées : albums, pistes, artistes, labels
- Images d'album et d'artiste
- Fichiers d'éditions, s'ils sont gérés par bae

Les réglages propres à l'appareil (`config.yaml`) ne se synchronisent pas.

## Modes

La synchronisation n'est pas tout ou rien :

- **Local seulement** — pas de cloud home, pas de synchronisation. Tout reste sur un seul appareil.
- **Synchronisé entre tes appareils** — les changesets se synchronisent entre tes appareils via le cloud home, chacun avec son propre ID d'appareil.

## Chiffrement

Toutes les données du cloud home sont chiffrées avant l'envoi. Le fournisseur cloud ne voit jamais de texte en clair. Consulte [Chiffrement](/fr/architecture/encryption).

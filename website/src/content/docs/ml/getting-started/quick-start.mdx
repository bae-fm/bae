## ദ്രുതാരംഭം

ലൈബ്രറി ഉണ്ടാക്കി, പ്രാദേശിക FLAC ഫോൾഡർ ഇറക്കുമതി ചെയ്ത്, MusicBrainz അല്ലെങ്കിൽ Discogs പൊരുത്തം തിരഞ്ഞെടുക്കുക.

## bae

പല ഉപകരണങ്ങൾ sync ചെയ്യാൻ bae പ്രാദേശിക തിരിച്ചറിയൽ, library key, cloud home ഉപയോഗിക്കുന്നു.

## സംഭരണം

ഫയലുകൾ self-managed, local-managed, അല്ലെങ്കിൽ cloud-managed ആയിരിക്കാം.

## എൻക്രിപ്ഷൻ

Opaque cloud home ഡാറ്റ ഉപകരണത്തെ വിട്ടുപോകുന്നതിന് മുമ്പ് എൻക്രിപ്റ്റ് ചെയ്യുന്നു.

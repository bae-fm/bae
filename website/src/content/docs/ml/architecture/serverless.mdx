## സർവർ ഇല്ലാതെ

bae-ക്ക് സ്വന്തം sync server ഇല്ല. ഓരോ ഉപകരണവും അതേ cloud home വായിക്കുകയും എഴുതുകയും ചെയ്യുന്നു.

## bae

പല ഉപകരണങ്ങൾ sync ചെയ്യാൻ bae പ്രാദേശിക തിരിച്ചറിയൽ, library key, cloud home ഉപയോഗിക്കുന്നു.

## സംഭരണം

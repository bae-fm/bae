## ക്ലൗഡ് ഹോം

cloud home എന്നത് Google Drive ഫോൾഡർ, Dropbox ഫോൾഡർ, അല്ലെങ്കിൽ S3 bucket പോലുള്ള ദൂരസ്ഥാനം.

## bae

## Сервер MCP

Увімкніть сервер MCP у Settings, Automation. Він обслуговує Model Context Protocol через HTTP на локальному порту (типово 47777), тож MCP-клієнти на кшталт Claude можуть переглядати вашу бібліотеку, шукати релізи й виконувати дії з ними. Для доступу потрібен bearer token: скопіюйте його з тієї самої панелі налаштувань і змінюйте там, коли хочете відрізати доступ усьому, що його мало.

Сервер типово вимкнений і працює лише тоді, коли працює застосунок.

Бібліотекою може керувати програмне забезпечення, яке ви запускаєте: AI-агенти через MCP і скрипти через інструмент командного рядка. Обидва відкривають ті самі операції, які використовує інтерфейс: пошук, дані релізу, імпорт, дії зі сховищем і стан відтворення.

## Сервер MCP

Увімкніть сервер MCP у Settings, Automation. Він обслуговує Model Context Protocol через HTTP на локальному порту (типово 47777), тож MCP-клієнти на кшталт Claude можуть переглядати вашу бібліотеку, шукати релізи й виконувати дії з ними. Для доступу потрібен bearer token: скопіюйте його з тієї самої панелі налаштувань і змінюйте там, коли хочете відрізати доступ усьому, що його мало.

Сервер типово вимкнений і працює лише тоді, коли працює застосунок.

## Командний рядок

CLI `bae` виконує ті самі операції з термінала: JSON на вході, JSON на виході, придатно для скриптів. Він також може діяти як MCP-клієнт, з'єднуючи сервер настільного застосунку зі stdio для інструментів, які очікують локальний MCP-процес.

title: Експорт
description: Виведіть музику в потрібному вигляді
---

Відсутність прив'язки працює в обидва боки: bae не змінює ваші файли під час імпорту й не тримає їх заручниками під час експорту. Некеровані релізи вже є файлами у ваших папках. Керовані релізи можна будь-коли знову зробити локальними, байт у байт. А коли потрібен інший вигляд — кодування для телефона, образ для запису на диск — експорт створює його, не торкаючись оригіналів.

## Два експорти

- **Track export**: клацніть трек правою кнопкою, **Save As**, виберіть формат.
- **Release export**: з меню альбому або Storage Manager експортує цілий реліз у папку. Виконується через чергу з поступом, паузою та повтором.

Оригінальні файли експортуються як є. Усе інше кодується під час виведення.

## Набори параметрів

Формати експорту — це набори параметрів, які ви один раз задаєте в Settings: FLAC, MP3, Opus, WAV або AIFF, із параметрами кодека (бітова глибина для форматів без втрат, бітрейт для форматів із втратами) і шаблоном імені файла з токенів на кшталт назви, виконавця, альбому, року й номера треку. Задайте типовий набір для треків і один для релізів, а також виберіть, чи експорт релізу завжди питає місце призначення, чи завжди використовує фіксовану папку.

## Прегапи в експорті

CD-рипи з прегапами ставлять реальне питання під час виведення: куди подіти приховане аудіо? Кожен набір параметрів вибирає правило:

- **Append to the previous track**, звична домовленість, із вибором, чи зберігати аудіо, приховане перед першим треком, на початку першого треку, чи відкинути.
- **Exclude** прегапи повністю: чисті межі треків, приховане аудіо пропущено.
- **Single file with CUE**: диск як один аудіофайл плюс CUE sheet, зі збереженням початкової структури.

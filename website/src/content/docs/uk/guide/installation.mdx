## Дві редакції

bae постачається у двох редакціях, зібраних з одного джерела:

- **bae**, повний застосунок: синхронізація через S3, Google Drive, Dropbox, OneDrive та iCloud.
- **baeium**, без власницьких частин: лише S3-сумісне сховище, без OAuth-провайдерів, без iCloud/CloudKit, без телеметрії.

Вони встановлюються поруч, кожна зі своєю бібліотекою та своїми ключами (синхронізованими через iCloud Keychain). Виберіть нижче ту, яка вам підходить.

## iOS

Збірки iOS — це **непідписані файли `.ipa` для sideloading**. Встановіть через [AltStore](https://altstore.io) або [Sideloadly](https://sideloadly.io), або перепідпишіть у Xcode власним Apple ID (безоплатний Apple ID працює для baeium). Поширення через App Store ще не налаштоване.

## Windows

Завантаження для Windows — це інсталятор, який встановлює застосунок для поточного користувача й сам тримає його оновленим. Збірки не підписані, тож SmartScreen може попередити під час першого запуску. До кожного [випуску на GitHub](https://github.com/bae-fm/bae/releases) також додається портативний zip-архів, що працює на місці. Для Windows виходить лише повна редакція.

## Збірка з джерела

Для збирання baeium не потрібне нічого власницьке. Див. [README репозиторію](https://github.com/bae-fm/bae#building-baeium-yourself) з інструкціями для самостійної збірки на кожній платформі, зокрема iOS із free provisioning.

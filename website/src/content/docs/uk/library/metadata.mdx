---
title: Метадані
description: Як bae обробляє метадані альбомів і треків
---

bae заповнює бібліотеку метаданими з online-баз під час імпорту.

## Що зберігається

- **Інформація про альбом**: назва, виконавець, рік
- **Інформація про треки**: назви, тривалості, номери дисків і треків
- **Зображення**: обкладинки з MusicBrainz Cover Art Archive і Discogs
- **Інформація про видання**: label, каталожний номер, штрихкод, країна, формат
- **Зовнішні IDs**: Discogs release ID, MusicBrainz release і artist IDs

Усі метадані надходять з MusicBrainz і Discogs та зберігаються в базі bae. bae не читає і не записує embedded tags. Ваші файли не змінюються: у керованому чи не керованому режимі bytes залишаються тими самими.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> — відкрита музична енциклопедія і головне джерело метаданих bae. API-ключ не потрібен. Запити розносяться автоматично.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> корисний для вінілових видань, credits, каталожних номерів і label-інформації. Потрібен особистий API token з <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a>.

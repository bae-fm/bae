## Дві редакції

Кожна платформа постачається у двох редакціях, зібраних з того самого коду:

- **bae** — повна app: синхронізація з S3, Google Drive, Dropbox, OneDrive та iCloud.
- **baeium** — без власницьких частин: лише S3-сумісне сховище, без OAuth-провайдерів, без iCloud/CloudKit і без телеметрії. Увесь код має ліцензію Apache-2.0.

Вони встановлюються поруч, кожна зі своєю бібліотекою і ключами, синхронізованими через iCloud Keychain.

## iOS

iOS builds — це **непідписані файли `.ipa` для sideloading**. Установіть їх через [AltStore](https://altstore.io) або [Sideloadly](https://sideloadly.io), або перепідпишіть у Xcode своїм Apple ID. Безплатний Apple ID працює для baeium. Поширення через App Store не налаштоване.

## Windows

Windows builds — це **непідписані** zip-архіви непакованої app. Розпакуйте й запустіть `bae.exe` або `baeium.exe`. SmartScreen може попередити під час першого запуску.

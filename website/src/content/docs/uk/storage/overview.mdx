title: Огляд сховища
description: Як bae зберігає ваші музичні файли
---

Файли видання можуть бути в трьох місцях: не керовані, керовані локально або керовані у cloud. Під час імпорту ви вибираєте **кероване** або **не кероване**. Керовані файли копіюються в сховище bae; не керовані залишаються на місці.

## Коротко

|                              | Не кероване      | Кероване — локально | Кероване — cloud |
|------------------------------|------------------|---------------------|------------------|
| Файли зберігаються           | У вашому місці   | `~/.bae/libraries/` | У cloud-провайдера |
| bae копіює при імпорті       | Ні               | Так                 | Так              |
| Доступно offline             | Так              | Так                 | Ні               |
| Шифрується у спокої          | Ні               | Ні                  | Лише opaque home |
| Може синхронізуватися в cloud | Ні              | Так                 | —                |
| Синхронізується на інші пристрої | Ні           | Ні                  | Так              |
| Видалення видання видаляє файли | Ні            | Так                 | Так              |

Не керований режим індексує файли там, де вони вже організовані, без переміщення або копіювання. Керований локальний режим зберігає копію в `~/.bae/libraries/{uuid}/`. Керований cloud mode також передає файли до cloud home.

### Opaque або browsable

**Opaque** шифрує кожен об'єкт ключем бібліотеки й зберігає його в прихованому шляху. Провайдер бачить лише ciphertext. **Browsable** зберігає все без шифрування зі справжніми назвами файлів у id-шляхах, наприклад `storage/{album_id}/{release_id}/{import_folder}/01 Track.flac` і `images/{album_id}/{release_id}/cover.jpg`. Browsable не означає public; доступ контролюють credentials bucket. Дивіться [Шифрування](/uk/architecture/encryption#режими-сховища-opaque-і-browsable).

### Підтримувані провайдери

Google Drive, Dropbox і OneDrive використовують OAuth. iCloud Drive на macOS використовує iCloud container без входу. S3-compatible охоплює AWS S3, Backblaze B2, Cloudflare R2, Wasabi, MinIO тощо й потребує ручних credentials.

## Як це працює

1. Імпортуйте видання й виберіть **кероване** або **не кероване**
2. Керований імпорт копіює файли в локальний home бібліотеки
3. Якщо cloud home налаштовано, файли також передаються туди: шифровано в opaque home, відкрито в browsable home
4. Інші пристрої з тим самим cloud home синхронізуються автоматично

Дивіться [Синхронізація](/uk/storage/sync) і [Шифрування](/uk/architecture/encryption).

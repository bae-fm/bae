bae — менеджер музичної бібліотеки, що використовує decentralized identity і end-to-end encryption поверх змінного сховища для синхронізації кількох пристроїв без власного сервера.

## Ідентичність

Кожен пристрій має локально створену пару ключів Ed25519/X25519. Public keys є identities. Центрального identity server немає.

## Шифрування

Один симетричний ключ на бібліотеку, спільний для її пристроїв. Усе в cloud home шифрується до виходу з пристрою. Провайдер сховища бачить opaque blobs. Дивіться [Шифрування](/uk/architecture/encryption).

## Сховище

Підтримуються Google Drive, Dropbox, OneDrive, iCloud Drive, S3-compatible buckets або local-only режим. Один trait `CloudHome` приховує різниці між backend-ами. Дивіться [Cloud Home](/uk/architecture/cloud-home).

## Синхронізація

Пристрої синхронізуються через cloud home encrypted changeset-ами. Конфлікти розв'язуються last-writer-wins з hybrid logical clocks. Бібліотека синхронізується через membership chain і signed changesets. Дивіться [Синхронізація](/uk/storage/sync).

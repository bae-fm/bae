---
title: Членство
description: Ідентичність, ланцюг членства і підписані changeset-и
---

Членство бібліотеки — це набір пристроїв, яким дозволено читати й писати її. Механізми: identity, membership chain, signed changesets і key wrapping.

## Ідентичність

Кожен пристрій має Ed25519/X25519 keypair, створений при першому використанні й збережений в OS keyring. Public keys є identities. Центрального directory або account server немає; public keys обмінюються поза системою.

## Membership chain

Членство відстежується append-only chain signed entries у cloud home за `membership/{pubkey}/{seq}.enc`. Кожен entry має Add або Remove, public key і role цільового пристрою, і підписується поточним owner. Перший entry додає початковий пристрій як owner. Invalid signatures або entries від non-owners відхиляються.

## Signed changesets

Кожен changeset у cloud home підписаний Ed25519 ключем пристрою-автора. Під час pull bae перевіряє, що автор був authorized device у момент створення changeset. Unauthorized або invalid changesets відкидаються.

## Key wrapping

Encryption key бібліотеки sealed-box encrypted для X25519 public key кожного пристрою й збережений у `keys/{user_pubkey}.enc`. Лише адресат може відкрити його private key. При revoke створюється новий encryption key і повторно wrapping для решти пристроїв.

## Invite codes

Invite code містить encryption key, координати cloud home, storage credentials і signed membership entry для нового пристрою. Owner device генерує код після отримання public key нового пристрою; новий пристрій вставляє його в bae, відкриває ключ, підключається до cloud home і починає sync.

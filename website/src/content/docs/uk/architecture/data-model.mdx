## Бібліотеки й місця зберігання

**Бібліотека** — головна сутність: музична колекція з `library_id`, назвою і ключем шифрування. Вона живе в **library home** на диску (`~/.bae/libraries/{uuid}/`), де desktop app пише авторитетну базу.

Бібліотека може мати **cloud home**: одну cloud location, наприклад Google Drive folder або S3 bucket, для синхронізації кількох пристроїв. Один cloud home на бібліотеку, у `config.yaml`. Дивіться [Cloud Home](/uk/architecture/cloud-home).

Файли видань можуть бути в library home (`~/.bae/libraries/{uuid}/storage/`), cloud home (`cloud-home/storage/`) або не керованими, тобто залишатися на диску.

## Структура директорій

```
~/.bae/libraries/{uuid}/
  config.yaml                  # device-specific settings (not synced)
  library.db                   # SQLite -- all metadata
  images/ab/cd/{id}            # library images
  storage/ab/cd/{file_id}      # release files
```

`config.yaml` не синхронізується; credentials зберігаються в OS keyring. `images/` і `storage/` мають hash layout: перші 2 символи ID — prefix directory, наступні 2 — subdirectory. Оригінальні назви і content types зберігаються в базі.

### Cloud home

| Шлях | Призначення |
|---|---|
| `snapshot.db.enc` | Повний snapshot бази |
| `changes/{device_id}/{seq}.enc` | Incremental sync changesets |
| `heads/{device_id}.json.enc` | Номери послідовності пристроїв |
| `images/ab/cd/{id}` | Encrypted library images |
| `storage/ab/cd/{file_id}` | Encrypted release files |
| `membership/{pubkey}/{seq}.enc` | Membership chain entries |
| `keys/{user_pubkey}.enc` | Wrapped encryption keys |

## Класи файлів

**Файли видань** — audio, images, CUE sheets, logs тощо, збережені так, як імпортовані. **Metadata images** — копії обкладинок і зображень виконавців, якими керує bae.

## Перший запуск

Нова бібліотека створює UUID і структуру директорій. Відновлення з cloud home завантажує snapshot, застосовує newer changesets і images. Перехід з local до cloud передає snapshot, images і release files, потім вмикає incremental sync.

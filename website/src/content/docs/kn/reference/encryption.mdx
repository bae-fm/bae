bae ಮೇಘ ಮನೆಗೆ ಇಡುವ ಎಲ್ಲವೂ ಸಾಧನ ಬಿಡುವ ಮೊದಲು ಎನ್‌ಕ್ರಿಪ್ಟ್ ಆಗುತ್ತದೆ; ಎನ್‌ಕ್ರಿಪ್ಶನ್ ಇಲ್ಲದ ವಿಧಾನ ಇಲ್ಲ. bae ತನ್ನದೇ cryptography ಅನುಷ್ಠಾನಗೊಳಿಸುವುದಿಲ್ಲ: ಸಂಪೂರ್ಣ ಯೋಜನೆ [coven](https://coven.bae.fm) ನದು, ಮತ್ತು bae ಅದನ್ನು ಹೇಗೆ ಬಳಸುತ್ತದೆ ಎಂಬುದನ್ನು ಈ ಪುಟ ವಿವರಿಸುತ್ತದೆ.

## ಕೀಗಳು

| ಕೀ | ಏನು ಮಾಡುತ್ತದೆ |
|---|---|
| store key | ಗ್ರಂಥಾಲಯ ಮತ್ತು ಅದರ ಸದಸ್ಯತ್ವ ದಾಖಲೆಗಳನ್ನು ಎನ್‌ಕ್ರಿಪ್ಟ್ ಮಾಡುತ್ತದೆ |
| ಪ್ರತಿ ವ್ಯಕ್ತಿಯ circle key | ವ್ಯಕ್ತಿ ಖಾಸಗಿಯಾಗಿ ಇಡುವುದನ್ನು ಎನ್‌ಕ್ರಿಪ್ಟ್ ಮಾಡುತ್ತದೆ: ಅವರ ಖಾಸಗಿ ಕೇಳುವ ಇತಿಹಾಸ ಮತ್ತು playlists |
| ಪ್ರತಿ ಕಡತದ ಕೀ | ಒಂದು ಕಡತವನ್ನು ಎನ್‌ಕ್ರಿಪ್ಟ್ ಮಾಡುತ್ತದೆ, ಮತ್ತು ಅದರ ಸಾಲಿನ ಎನ್‌ಕ್ರಿಪ್ಟ್ ಆದ ಬದಲಾವಣೆಗಳ ಒಳಗೆ ಮಾತ್ರ ಸಾಗುತ್ತದೆ |
| ವ್ಯಕ್ತಿಯ ಸಹಿ ಕೀ ಜೋಡಿ | ಅವರ ಸಾಧನಗಳು ಕಳುಹಿಸುವ ಪ್ರತಿಯೊಂದು ಬದಲಾವಣೆಗೆ ಸಹಿ ಮಾಡುತ್ತದೆ |
| ವ್ಯಕ್ತಿಯ ಮುದ್ರೆ ಕೀ ಜೋಡಿ | ಆ ವ್ಯಕ್ತಿಗಾಗಿ ಮುಚ್ಚಿದ ಕೀಗಳನ್ನು ತೆರೆಯುತ್ತದೆ |

store key ಯಾದೃಚ್ಛಿಕ, ಗ್ರಂಥಾಲಯಕ್ಕೆ ಮೇಘ ಮನೆ ಸಿಕ್ಕಾಗ ಸೃಜಿಸಲ್ಪಡುತ್ತದೆ. ವ್ಯಕ್ತಿಯ ಕೀ ಜೋಡಿಗಳನ್ನು ಅವರ ಎಲ್ಲಾ ಸಾಧನಗಳು ಹಂಚಿಕೊಳ್ಳುತ್ತವೆ. ಖಾಸಗಿ ಕೀಗಳು ಮತ್ತು ಗ್ರಂಥಾಲಯದ ಕೀಗಳು OS ಕೀ ಸಂಗ್ರಹ ನಲ್ಲಿ ಇರುತ್ತವೆ, ಕಡತ ಅಥವಾ ಡೇಟಾಬೇಸ್‌ನಲ್ಲಿ ಎಂದಿಗೂ ಇಲ್ಲ. ಅವು ಸಾಧನವನ್ನು ಎರಡು ರೀತಿಯಲ್ಲಿ ತಲುಪುತ್ತವೆ, ಎರಡನ್ನೂ [ಗುರುತು ಮತ್ತು ಸದಸ್ಯತ್ವ](/kn/reference/membership) ನಲ್ಲಿ ವಿವರಿಸಲಾಗಿದೆ: restore code ವ್ಯಕ್ತಿಯ ಸ್ವಂತ ಕೀ ಜೋಡಿಗಳನ್ನು ಸಾಗಿಸುತ್ತದೆ, ಮತ್ತು ಆಹ್ವಾನವನ್ನು ಅನುಮೋದಿಸುವ admin store key ಗಳನ್ನು ಹೊಸ ವ್ಯಕ್ತಿಯ ಮುದ್ರೆ ಕೀಗೆ ಮುಚ್ಚುತ್ತಾರೆ.

## ಕೀ ಬದಲಾವಣೆ

ಕೀ ಎಂದಿಗೂ ಅದರ ಸ್ಥಳದಲ್ಲೇ ಬದಲಾಗುವುದಿಲ್ಲ; ಹೊಸದು ಸೇರಿಸಲ್ಪಡುತ್ತದೆ. ವ್ಯಕ್ತಿಯನ್ನು ತೆಗೆದುಹಾಕಿದ ನಂತರ ಉಳಿದ ಸದಸ್ಯರ ಸಾಧನ ಅಲ್ಲಿ ಇನ್ನಷ್ಟು ದತ್ತಾಂಶ ಬರೆಯುವ ಮೊದಲು ಹೊಸ store key ಅನ್ನು, ಮತ್ತು ಅವರು ಇದ್ದ ಪ್ರತಿಯೊಂದು circle ಗೆ ಹೊಸ ಕೀಯನ್ನು ಸೇರಿಸುತ್ತದೆ: ನಂತರ ಬರೆಯಲ್ಪಟ್ಟೆಲ್ಲವೂ ಅವರಿಗೆ ಓದಲು ಸಾಧ್ಯವಿಲ್ಲ, ಉಳಿದ ಸದಸ್ಯರು ಪ್ರತಿಯೊಂದು ಹಳೆಯ ಕೀಯನ್ನೂ ಇಟ್ಟುಕೊಂಡು ಸಂಪೂರ್ಣ ಇತಿಹಾಸವನ್ನು ಓದಬಹುದು. ಒಂದು ಸಾಧನವನ್ನು ತೆಗೆದುಹಾಕುವುದು ಯಾವುದನ್ನೂ ಬದಲಾಯಿಸುವುದಿಲ್ಲ, ಏಕೆಂದರೆ ವ್ಯಕ್ತಿಯ ಇತರ ಸಾಧನಗಳು ಅದರ ಕೀಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳುತ್ತವೆ; ತೆಗೆದುಹಾಕಿದ ನಂತರ ಆ ಸಾಧನ ಕಳುಹಿಸುವುದು ಲೆಕ್ಕಕ್ಕೆ ಬರುವುದಿಲ್ಲ.

## ಏನು ಮುಚ್ಚಿಡಲಾಗುತ್ತದೆ

ಮನೆಯ ಪ್ರತಿಯೊಂದು ವಸ್ತು: ಬದಲಾವಣೆಗಳು, ಸ್ನ್ಯಾಪ್‌ಶಾಟ್‌ಗಳು, ಸದಸ್ಯತ್ವ ದಾಖಲೆಗಳು ಮತ್ತು ಕಡತಗಳು. ವಿಷಯ XChaCha20-Poly1305 ಬಳಸಿ ಎನ್‌ಕ್ರಿಪ್ಟ್ ಆಗುತ್ತದೆ, ಪ್ರತಿಯೊಂದು ಬದಲಾವಣೆಗೆ Ed25519 ಬಳಸಿ ಸಹಿ ಆಗುತ್ತದೆ, ಮತ್ತು ಕೀಗಳನ್ನು ಜನರಿಗೆ X25519 sealed boxes ಬಳಸಿ ಮುಚ್ಚಲಾಗುತ್ತದೆ. ಕಡತಗಳು 64 KiB chunks ನಲ್ಲಿ ಎನ್‌ಕ್ರಿಪ್ಟ್ ಆಗುತ್ತವೆ, ಪ್ರತಿಯೊಂದು chunk ಪ್ರತ್ಯೇಕವಾಗಿ authenticated ಮತ್ತು ತನ್ನ ಸ್ಥಾನಕ್ಕೆ bound, ಆದ್ದರಿಂದ ಯಾವುದೇ chunk ಅನ್ನು ಪತ್ತೆಯಾಗದೆ ಬದಲಾಯಿಸಲು, ಅದಲುಬದಲು ಮಾಡಲು ಅಥವಾ ಮರುಕ್ರಮಗೊಳಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ. chunking ಕಾರಣದಿಂದಲೇ streaming ಕೆಲಸ ಮಾಡುತ್ತದೆ: player ತಾನು ತರುವ chunks ಅನ್ನು ಮಾತ್ರ decrypt ಮಾಡಬಹುದು.

## ಒದಗಿಸುವವರು ಏನು ನೋಡಬಹುದು

ವಸ್ತುಗಳ ಸಂಖ್ಯೆ, ವಸ್ತುಗಳ ಗಾತ್ರ, ಅಪ್‌ಲೋಡ್ ಸಮಯ, ಯಾವ ಖಾತೆ ಪ್ರತಿಯೊಂದು ವಸ್ತುವನ್ನು ಬರೆಯುತ್ತದೆ, ಮತ್ತು ಯಾವ ಸಾಧನ ಪ್ರತಿಯೊಂದು ಕಡತ ಮತ್ತು ಸ್ನ್ಯಾಪ್‌ಶಾಟ್ ಅನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಿತು, ಏಕೆಂದರೆ ಅವುಗಳ ಮಾರ್ಗಗಳಲ್ಲಿ ಸಾಧನದ ಹೆಸರು ಇರುತ್ತದೆ. ಹೆಸರುಗಳಿಲ್ಲ, ಮೆಟಾಡೇಟಾ ಇಲ್ಲ, ಆಡಿಯೋ ಇಲ್ಲ, ಕಲೆಚಿತ್ರ ಇಲ್ಲ. ಕಡತಗಳು ಯಾದೃಚ್ಛಿಕ ಹೆಸರುಗಳ ಅಡಿಯಲ್ಲಿ ಇರುತ್ತವೆ, ಅವುಗಳ ವಿಷಯದ hash ಅಡಿಯಲ್ಲಿ ಎಂದಿಗೂ ಅಲ್ಲ. ಸರ್ವರ್-ಬದಿ ಮರುಪಡೆಯುವಿಕೆ ಇಲ್ಲ: ಪ್ರತಿಯೊಬ್ಬರೂ ಪ್ರತಿಯೊಂದು ಸಾಧನ ಮತ್ತು ಪ್ರತಿಯೊಂದು restore code ಕಳೆದುಕೊಂಡರೆ ಗ್ರಂಥಾಲಯ ಕಳೆದುಹೋಗುತ್ತದೆ; ಇದೇ ವಿನ್ಯಾಸದ ಉದ್ದೇಶ.

## ಕೀ ಸಂಗ್ರಹದ ಪಾತ್ರ

ಗ್ರಂಥಾಲಯ ತೆರೆಯುವಾಗ ಅದರ ಕೀಗಳನ್ನು OS ಕೀ ಸಂಗ್ರಹ ನಿಂದ ಓದಲಾಗುತ್ತದೆ. ಸದ್ಯ lock ಆಗಿರುವ ಕೀ ಸಂಗ್ರಹ, lock ಆದ session ಅಥವಾ ನಿದ್ರಿಸುತ್ತಿರುವ ಪರದೆಯ ಕಾರಣ, ಹಾಳಾದ ಕೀ ಸಂಗ್ರಹ ದಿಂದ ಪ್ರತ್ಯೇಕವಾಗಿ ಗುರುತಿಸಲ್ಪಡುತ್ತದೆ: bae ಗ್ರಂಥಾಲಯವನ್ನು lock ಆಗಿದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ ಮತ್ತು unlock ನಂತರ ಮರುಪ್ರಯತ್ನಿಸುತ್ತದೆ, ಗ್ರಂಥಾಲಯ ಬಳಸಲಾಗದು ಎಂದು ಹೇಳುವ ಬದಲು. ಸಾಧನ ಕೀಗಳನ್ನು ಮರೆಯಲೂ ಬಹುದು, ಹಾಗಾದರೆ ಆ ಸಾಧನದಲ್ಲಿ ಗ್ರಂಥಾಲಯವನ್ನು ಮತ್ತೆ unlock ಮಾಡುವವರೆಗೆ ಅದು lock ಆಗಿಯೇ ಇರುತ್ತದೆ.

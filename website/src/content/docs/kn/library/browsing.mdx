## ಬ್ರೌಸಿಂಗ್

ಆಲ್ಬಮ್, ಕಲಾವಿದ, ವರ್ಷ, ಸೇರಿಸಿದ ದಿನಾಂಕದಿಂದ ಬ್ರೌಸ್ ಮಾಡಿ.

## bae

ಹೆಚ್ಚು ಸಾಧನಗಳನ್ನು sync ಮಾಡಲು bae ಸ್ಥಳೀಯ ಗುರುತು, library key, cloud home ಬಳಸುತ್ತದೆ.

## ಸಂಗ್ರಹಣೆ

ಫೈಲ್‌ಗಳು self-managed, local-managed, ಅಥವಾ cloud-managed ಆಗಿರಬಹುದು.

## ಎನ್‌ಕ್ರಿಪ್ಷನ್

Opaque cloud home ಡೇಟಾ ಸಾಧನ ಬಿಡುವ ಮೊದಲು ಎನ್‌ಕ್ರಿಪ್ಟ್ ಮಾಡುತ್ತದೆ.

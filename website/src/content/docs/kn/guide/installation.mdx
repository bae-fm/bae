## ಎರಡು ಆವೃತ್ತಿಗಳು

ಪ್ರತಿಯೊಂದು ವೇದಿಕೆ ಒಂದೇ ಮೂಲದಿಂದ ಕಟ್ಟಿದ ಎರಡು ಆವೃತ್ತಿಗಳಲ್ಲಿ ಬರುತ್ತದೆ:

- **bae**, ಪೂರ್ಣ ಆಪ್: S3, Google Drive, Dropbox, OneDrive, ಮತ್ತು iCloud ಸಮನ್ವಯ.
- **baeium**, proprietary ಭಾಗಗಳಿಲ್ಲ: S3-compatible ಸಂಗ್ರಹ ಮಾತ್ರ, OAuth ಒದಗಿಸುವವರು ಇಲ್ಲ, iCloud/CloudKit ಇಲ್ಲ, telemetry ಇಲ್ಲ.

ಇವು ಒಂದರ ಪಕ್ಕದಲ್ಲಿ ಮತ್ತೊಂದು ಸ್ಥಾಪನೆಯಾಗುತ್ತವೆ, ಪ್ರತಿಯೊಂದಕ್ಕೂ ತನ್ನದೇ ಗ್ರಂಥಾಲಯ ಮತ್ತು ತನ್ನದೇ (iCloud-Keychain ಮೂಲಕ ಸಮನ್ವಯಗೊಂಡ) ಕೀಗಳು. ಕೆಳಗಿನಿಂದ ನಿಮಗೆ ಬೇಕಾದುದನ್ನು ಆರಿಸಿ.

## iOS

iOS builds sideloading ಗಾಗಿ **unsigned `.ipa` ಕಡತಗಳು**. [AltStore](https://altstore.io) ಅಥವಾ [Sideloadly](https://sideloadly.io) ಬಳಸಿ ಸ್ಥಾಪಿಸಿ, ಅಥವಾ ನಿಮ್ಮದೇ Apple ID ಬಳಸಿ Xcode ನಲ್ಲಿ ಮತ್ತೆ sign ಮಾಡಿ (ಉಚಿತ Apple ID baeium ಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ). App Store distribution ಇನ್ನೂ ಸಿದ್ಧಪಡಿಸಲಾಗಿಲ್ಲ.

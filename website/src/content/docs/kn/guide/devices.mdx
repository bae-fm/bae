bae ಖಾತೆ ಇಲ್ಲ. ಗ್ರಂಥಾಲಯದ ಪ್ರತಿಯೊಬ್ಬ ವ್ಯಕ್ತಿಗೂ ತನ್ನದೇ ಕೀಗಳಿವೆ, ಅವನ್ನು ಅವರ ಎಲ್ಲಾ ಸಾಧನಗಳು ಹಂಚಿಕೊಳ್ಳುತ್ತವೆ ಮತ್ತು ಕಾರ್ಯಾಚರಣಾ ವ್ಯವಸ್ಥೆಯ ಕೀ ಸಂಗ್ರಹ ನಲ್ಲಿ ಇಡುತ್ತವೆ; ಗ್ರಂಥಾಲಯವು ಜನರನ್ನು ಆ ಕೀಗಳಿಂದ ಗುರುತಿಸುತ್ತದೆ. ಯಾರು ಸೇರಿದ್ದಾರೆ ಎಂಬುದರ ಪ್ರತಿಯೊಂದು ಬದಲಾವಣೆ ಸಹಿ ಮಾಡಲ್ಪಟ್ಟು ಮೇಘ ಮನೆಯಲ್ಲಿ ಇಡಲ್ಪಡುತ್ತದೆ; ಮಧ್ಯದಲ್ಲಿ ಯಾರೂ ಇಲ್ಲ.

ಎರಡು ಬೇರೆ ಬಾಗಿಲುಗಳು, ಎರಡು ಬೇರೆ ಸಂದರ್ಭಗಳಿಗೆ:

- **ಮರುಪಡೆಯುವುದು**: ನಿಮ್ಮದೇ ಹೊಸ ಅಥವಾ ಮರುಸ್ಥಾಪಿಸಿದ ಸಾಧನ ನಿಮ್ಮ restore code ಬಳಸಿ ಸೇರುತ್ತದೆ. ಬೇರೆ ಯಾವ ಸಾಧನವೂ ಅನುಮೋದಿಸುವುದಿಲ್ಲ: ಕೋಡ್ ನಿಮ್ಮ ಕೀಗಳನ್ನು ಹೊಂದಿದೆ, ಆದ್ದರಿಂದ ಸಾಧನ ನಿಮ್ಮದು ಎಂದು ಅದೇ ಸಾಬೀತುಪಡಿಸುತ್ತದೆ.
- **ಸೇರುವುದು**: ಇನ್ನೊಬ್ಬ ವ್ಯಕ್ತಿ admin ನ ಆಹ್ವಾನದಿಂದ ಸೇರುತ್ತಾರೆ; admin ಅವರ ವಿನಂತಿಯನ್ನು ಅನುಮೋದಿಸುತ್ತಾರೆ.

## ನಿಮ್ಮದೇ ಸಾಧನ ಸೇರಿಸುವುದು

ಹೊಸ ಸಾಧನದಲ್ಲಿ **Restore from cloud** ಆರಿಸಿ, ಮತ್ತು restore code ಅನ್ನು ಈ ಮೂರರಲ್ಲಿ ಯಾವುದಾದರೂ ರೀತಿಯಲ್ಲಿ ಕೊಡಿ:

- ನಿಮ್ಮ ಬೇರೊಂದು ಸಾಧನದಲ್ಲಿ ಸೆಟ್ಟಿಂಗ್‌ಗಳು, Library ಯಲ್ಲಿ **Show restore code...** ಅಡಿಯಲ್ಲಿ ತೋರುವ QR ಕೋಡ್ ಅನ್ನು **ಸ್ಕ್ಯಾನ್** ಮಾಡಿ.
- Apple ಸಾಧನಗಳಲ್ಲಿ ಅದನ್ನು iCloud Keychain ನಿಂದ **ಆರಿಸಿ**: ನಿಮ್ಮ ಬೇರೆ ಸಾಧನಗಳು ಅಲ್ಲಿ ಉಳಿಸಿದ restore code ಗಳನ್ನು bae ಪಟ್ಟಿಮಾಡುತ್ತದೆ.
- ಅದನ್ನು **ಅಂಟಿಸಿ** ಅಥವಾ ಟೈಪ್ ಮಾಡಿ.

ಕೇಳಿದಾಗ ಸಂಗ್ರಹ ಒದಗಿಸುವವರಿಗೆ sign in ಮಾಡಿ. S3 ನಲ್ಲಿ ಸಾಧನಕ್ಕೆ ನಿಮ್ಮ access key ಕೂಡ ಬೇಕು: QR ಕೋಡ್ ಅದನ್ನು ಕೋಡ್ ಜೊತೆಗೇ ತರುತ್ತದೆ, ಆದ್ದರಿಂದ ಸ್ಕ್ಯಾನ್ ಮಾಡಿದರೆ ಸಾಕು, ಟೈಪ್ ಮಾಡಿದ ಕೋಡ್ ಕೀ ಕೇಳುತ್ತದೆ. ನಂತರ ಹೊಸ ಸಾಧನ ಗ್ರಂಥಾಲಯವನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ಸಮನ್ವಯ ಆರಂಭಿಸುತ್ತದೆ.

ಗ್ರಂಥಾಲಯ ಲೋಡ್ ಆಗುವವರೆಗೆ ಸಾಧನ ಅದರ ಹೆಸರಲ್ಲ, ಅದು ಎಲ್ಲಿ ಸಂಗ್ರಹವಾಗಿದೆ ಎಂಬುದನ್ನು ತೋರಿಸುತ್ತದೆ: Dropbox ಮತ್ತು OneDrive ಗೆ ಖಾತೆಯ ಇಮೇಲ್, S3 ಗೆ bucket ಮತ್ತು endpoint, ಅಥವಾ iCloud. ಲೋಡ್ ಆದ ನಂತರ ಗ್ರಂಥಾಲಯದ ಈಗಿನ ಹೆಸರನ್ನು ತೋರಿಸುತ್ತದೆ.

## ವ್ಯಕ್ತಿಯನ್ನು ಆಹ್ವಾನಿಸುವುದು

admin ಒಬ್ಬರು ಸೆಟ್ಟಿಂಗ್‌ಗಳು, Library, **Invite a Person...** ತೆರೆಯುತ್ತಾರೆ, ಪಾತ್ರವನ್ನು ಆರಿಸುತ್ತಾರೆ ಮತ್ತು ಆ ವ್ಯಕ್ತಿಯ ಖಾತೆಯ ಇಮೇಲ್ ನಮೂದಿಸುತ್ತಾರೆ; S3 ನಲ್ಲಿ ಅದರ ಬದಲು ಅವರಿಗಾಗಿ ರಚಿಸಿದ access key. bae ಗ್ರಂಥಾಲಯದ ಕಡತಕೋಶವನ್ನು ಆ ಖಾತೆಯೊಂದಿಗೆ ಹಂಚುತ್ತದೆ ಮತ್ತು ಆಹ್ವಾನವನ್ನು QR ಕೋಡ್ ಆಗಿ ತೋರಿಸುತ್ತದೆ.

ತಮ್ಮ ಸಾಧನದಲ್ಲಿ ಆ ವ್ಯಕ್ತಿ **Join a library** ಆರಿಸುತ್ತಾರೆ, ಆಹ್ವಾನವನ್ನು ಸ್ಕ್ಯಾನ್ ಮಾಡುತ್ತಾರೆ ಅಥವಾ ಅಂಟಿಸುತ್ತಾರೆ, ತಮ್ಮ ಹೆಸರನ್ನು ಟೈಪ್ ಮಾಡುತ್ತಾರೆ ಮತ್ತು ತಮ್ಮದೇ ಖಾತೆಗೆ sign in ಮಾಡುತ್ತಾರೆ. ವಿನಂತಿ admin ಸಾಧನದಲ್ಲಿ **Waiting to join** ಅಡಿಯಲ್ಲಿ ಕಾಣುತ್ತದೆ, ಮತ್ತು admin ಅದನ್ನು ಅನುಮೋದಿಸುತ್ತಾರೆ ಅಥವಾ ತಿರಸ್ಕರಿಸುತ್ತಾರೆ. ಅನುಮೋದನೆಯ ನಂತರ ಹೊಸ ಸಾಧನ ಗ್ರಂಥಾಲಯವನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುತ್ತದೆ, ಮತ್ತು ಪ್ರತಿಯೊಂದು ಸಾಧನ ಹೊಸ ವ್ಯಕ್ತಿಯನ್ನು ಹೆಸರಿನಿಂದ ತೋರಿಸುತ್ತದೆ. ಆಹ್ವಾನ ಒಂದು ದಿನದಲ್ಲಿ ಅವಧಿ ಮೀರುತ್ತದೆ, ಮತ್ತು ಅದನ್ನು ರಚಿಸಿದ ಸಾಧನ ಮಾತ್ರ ಅದರ ವಿನಂತಿಯನ್ನು ಅನುಮೋದಿಸಬಹುದು. ವಿವರಗಳು [ಗುರುತು ಮತ್ತು ಸದಸ್ಯತ್ವ](/kn/reference/membership) ನಲ್ಲಿ.

## ಸದಸ್ಯರು ಮತ್ತು ಪಾತ್ರಗಳು

ಸೆಟ್ಟಿಂಗ್‌ಗಳು, Library ಪ್ರತಿಯೊಬ್ಬ ವ್ಯಕ್ತಿ ಮತ್ತು ಅವರ ಸಾಧನಗಳನ್ನು ಪಟ್ಟಿಮಾಡುತ್ತದೆ, ಮತ್ತು ಅವುಗಳಲ್ಲಿ ಈ ಸಾಧನ ಯಾವುದು ಎಂಬುದನ್ನೂ. ಗ್ರಂಥಾಲಯವನ್ನು ಮೇಘಕ್ಕೆ ಸಂಪರ್ಕಿಸುವ ವ್ಯಕ್ತಿ ಅದರ ಮೊದಲ **admin**; admin ಗಳು ಇತರರನ್ನು **admin** ಅಥವಾ **ಸದಸ್ಯ** ಆಗಿ ಆಹ್ವಾನಿಸುತ್ತಾರೆ ಮತ್ತು ಯಾರ ಪಾತ್ರವನ್ನಾದರೂ ಬದಲಾಯಿಸಬಹುದು. ಎಲ್ಲರೂ ಗ್ರಂಥಾಲಯವನ್ನು ಓದುತ್ತಾರೆ ಮತ್ತು ತಿದ್ದುತ್ತಾರೆ. admin ಗಳು ಮಾತ್ರ ಜನರನ್ನು ಆಹ್ವಾನಿಸುತ್ತಾರೆ, ತೆಗೆದುಹಾಕುತ್ತಾರೆ ಮತ್ತು ಗ್ರಂಥಾಲಯದ ಹೆಸರು ಬದಲಾಯಿಸುತ್ತಾರೆ.

## ಸಾಧನ ತೆಗೆದುಹಾಕುವುದು

ಪ್ರತಿಯೊಬ್ಬರೂ ತಮ್ಮದೇ ಸಾಧನಗಳನ್ನು ತೆಗೆದುಹಾಕಬಹುದು, ಮತ್ತು admin ಯಾರ ಸಾಧನವನ್ನಾದರೂ ತೆಗೆದುಹಾಕಬಹುದು, ಆದ್ದರಿಂದ ಎಲ್ಲಾ ಸಾಧನಗಳನ್ನು ಕಳೆದುಕೊಂಡ ವ್ಯಕ್ತಿ ಸಿಲುಕಿಕೊಳ್ಳುವುದಿಲ್ಲ. ಅದರ ನಂತರ ತೆಗೆದುಹಾಕಿದ ಸಾಧನ ಕಳುಹಿಸುವುದೇನೂ ಲೆಕ್ಕಕ್ಕೆ ಬರುವುದಿಲ್ಲ. ಒದಗಿಸುವವರ ಬಳಿ ಇನ್ನೂ ಮಾಡಬೇಕಾದುದನ್ನು bae ಕೂಡ ತೋರಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ ಆ ಸಾಧನವನ್ನು ನಿಮ್ಮ ಖಾತೆಯಿಂದ sign out ಮಾಡುವುದು: Dropbox, OneDrive ಮತ್ತು iCloud ಒಂದು ಖಾತೆಯ ಒಂದೇ ಸಾಧನವನ್ನು ತಾವಾಗಿ ಬೇರ್ಪಡಿಸಲಾರವು.

ವ್ಯಕ್ತಿಯನ್ನು ತೆಗೆದುಹಾಕುವುದು, admin ಮಾತ್ರ ಮಾಡಬಹುದಾದ್ದು, ಅವರ ಸಾಧನಗಳನ್ನು ಮತ್ತು ಅವರು ಖಾಸಗಿಯಾಗಿ ಇಟ್ಟಿದ್ದೆಲ್ಲವನ್ನೂ ತೆಗೆದುಹಾಕುತ್ತದೆ. ಮನೆಯೊಂದಿಗೆ ಹಂಚಿದ ಅವರ ratings, ಇತಿಹಾಸ ಮತ್ತು playlists ಅವರ ಹೆಸರಿನಲ್ಲೇ ಉಳಿಯುತ್ತವೆ. ಗ್ರಂಥಾಲಯದ ಕೀಗಳು ಬದಲಾಗುತ್ತವೆ, ಆದ್ದರಿಂದ ನಂತರ ಬರೆಯಲ್ಪಟ್ಟ ಯಾವುದೂ ಅವರಿಗೆ ಓದಲು ಸಾಧ್ಯವಿಲ್ಲ. ಅವರು ಈಗಾಗಲೇ ನಕಲಿಸಿಕೊಂಡದ್ದು ಅವರ ಬಳಿಯೇ ಉಳಿಯುತ್ತದೆ: ಕಳುಹಿಸಿದ ದತ್ತಾಂಶವನ್ನು ಹಿಂಪಡೆಯಲಾಗುವುದಿಲ್ಲ.

## ಮರುಸ್ಥಾಪನೆ ಕೋಡ್‌ಗಳು

restore code ಒಂದು ಗ್ರಂಥಾಲಯಕ್ಕಾಗಿ ನಿಮ್ಮ ಕೀಗಳನ್ನು ಮತ್ತು ಅದು ಎಲ್ಲಿ ಸಂಗ್ರಹವಾಗಿದೆ ಎಂಬುದನ್ನು ಒಂದೇ string ನಲ್ಲಿ ಹೊಂದಿದೆ. ಅದರಲ್ಲಿ ಸಂಗ್ರಹದ ಗುಪ್ತಪದ, sign-in ಅಥವಾ ಗ್ರಂಥಾಲಯದ ಹೆಸರು ಇಲ್ಲ. ಸೆಟ್ಟಿಂಗ್‌ಗಳು, Library ಯಲ್ಲಿ **Show restore code...** ಅದನ್ನು ತೋರಿಸುತ್ತದೆ; password manager ಮಾದರಿಯ ಸುರಕ್ಷಿತ ಸ್ಥಳದಲ್ಲಿ ಇಡಿ.

Apple ವೇದಿಕೆಗಳಲ್ಲಿ ಕೋಡ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ iCloud Keychain ನಲ್ಲೂ ಇಡಲ್ಪಡುತ್ತದೆ, ಆದ್ದರಿಂದ ನಿಮ್ಮ Apple Account ಗೆ sign in ಆಗಿರುವ ಹೊಸ Mac ಅಥವಾ iPhone ಅದನ್ನು ಪಟ್ಟಿಯಿಂದ ಆರಿಸಬಹುದು.

ಕೋಡ್ ಮತ್ತು ನಿಮ್ಮ ಸಂಗ್ರಹಕ್ಕೆ ಪ್ರವೇಶ ಇರುವ ಯಾರಾದರೂ ನಿಮ್ಮಂತೆಯೇ ಗ್ರಂಥಾಲಯವನ್ನು ತೆರೆಯಬಹುದು, ಆದ್ದರಿಂದ ಅದನ್ನು ರಹಸ್ಯವಾಗಿಡಿ.

## ಲಾಕ್ ಮಾಡುವುದು

ಗ್ರಂಥಾಲಯದ ಎನ್‌ಕ್ರಿಪ್ಶನ್ ಕೀಗಳು ಕಾರ್ಯಾಚರಣಾ ವ್ಯವಸ್ಥೆಯ ಕೀ ಸಂಗ್ರಹ ನಲ್ಲಿ ಇರುತ್ತವೆ. ಕೀ ಸಂಗ್ರಹ lock ಆಗಿರುವವರೆಗೆ, ಉದಾಹರಣೆಗೆ ನಿಮ್ಮ session lock ಆಗಿರುವಾಗ, bae ಗ್ರಂಥಾಲಯವನ್ನು lock ಆಗಿದೆ ಎಂದು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಕೀ ಸಂಗ್ರಹ unlock ಆದ ತಕ್ಷಣ ತೆರೆಯುತ್ತದೆ; **Try again** ಕೈಯಾರೆ ಮರುಪ್ರಯತ್ನಿಸುತ್ತದೆ.

## ಫೋನ್‌ನಲ್ಲಿ

iOS ಮತ್ತು Android ಇದೇ ರೀತಿಯಲ್ಲಿ ಸೇರುತ್ತವೆ ಮತ್ತು ಮರುಪಡೆಯುತ್ತವೆ; ಅದೇ ಅವುಗಳ ಸಂಪೂರ್ಣ ಆರಂಭ. ಫೋನ್ ಗ್ರಂಥಾಲಯವನ್ನು ತನ್ನಿಂದ ತೆಗೆದುಹಾಕಲೂ ಬಹುದು: ಮೊದಲು ತನ್ನನ್ನು ಗ್ರಂಥಾಲಯದ ಸದಸ್ಯರಿಂದ ತೆಗೆದುಹಾಕುತ್ತದೆ, ಅದಕ್ಕೆ ನಿಮ್ಮ ಸಂಗ್ರಹದೊಂದಿಗೆ ಸಂಪರ್ಕ ಬೇಕು, ನಂತರ ತನ್ನ ಸ್ಥಳೀಯ ಪ್ರತಿಯನ್ನು ಅಳಿಸುತ್ತದೆ. ಮೇಘದಲ್ಲಿರುವ ಗ್ರಂಥಾಲಯ ಉಳಿಯುತ್ತದೆ.

## MCP ಸರ್ವರ್

ಸೆಟ್ಟಿಂಗ್‌ಗಳು, Automation ನಲ್ಲಿ MCP ಸರ್ವರ್ ಅನ್ನು ಆನ್ ಮಾಡಿ. ಇದು Model Context Protocol ಅನ್ನು HTTP ಮೂಲಕ ಸ್ಥಳೀಯ ಪೋರ್ಟ್‌ನಲ್ಲಿ ಒದಗಿಸುತ್ತದೆ (ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ 47777), ಆದ್ದರಿಂದ Claude ನಂತಹ MCP ಕ್ಲೈಂಟ್‌ಗಳು ನಿಮ್ಮ ಗ್ರಂಥಾಲಯವನ್ನು ಬ್ರೌಸ್ ಮಾಡಬಹುದು, ಬಿಡುಗಡೆಗಳನ್ನು ಹುಡುಕಬಹುದು, ಮತ್ತು ಅವುಗಳ ಮೇಲೆ ಕ್ರಿಯೆ ಮಾಡಬಹುದು. ಪ್ರವೇಶಕ್ಕೆ bearer token ಬೇಕು: ಅದನ್ನು ಅದೇ ಫಲಕದಿಂದ ನಕಲಿಸಿ; ಅದನ್ನು ಹೊಂದಿದ್ದ ಎಲ್ಲದರ ಪ್ರವೇಶವನ್ನು ಕಡಿತಗೊಳಿಸಲು ಬೇಕಾದಾಗ ಅಲ್ಲಿ rotate ಮಾಡಿ.

ಸರ್ವರ್ ಪೂರ್ವನಿಯೋಜಿತವಾಗಿ ಆಫ್ ಆಗಿರುತ್ತದೆ ಮತ್ತು ಆಪ್ ನಡೆಯುವಾಗ ಮಾತ್ರ ನಡೆಯುತ್ತದೆ.

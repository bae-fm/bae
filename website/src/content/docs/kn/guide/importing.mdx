rips ಇರುವ ಕಡತಕೋಶಕ್ಕೆ ತನ್ನ ಬಗ್ಗೆ ಬಹುತೇಕ ಏನೂ ಗೊತ್ತಿರುವುದಿಲ್ಲ. ಅದು ಬಂದ ಬಿಡುಗಡೆ, ಪ್ರೆಸಿಂಗ್, ಲೇಬಲ್, ಕ್ರೆಡಿಟ್‌ಗಳು, ಟ್ರ್ಯಾಕ್ 12 ನಿಜವಾಗಿ ಎಲ್ಲಿಗೆ ಮುಗಿಯುತ್ತದೆ: ಇವೆಲ್ಲವೂ ನಿಮ್ಮ ಕಡತಹೆಸರುಗಳಲ್ಲಿ ಅಲ್ಲ, MusicBrainz ಮತ್ತು Discogs ಮಾದರಿಯ ಡೇಟಾಬೇಸ್‌ಗಳಲ್ಲಿ ಇರುತ್ತವೆ. ಆಮದು ಎಂದರೆ bae ಎರಡನ್ನೂ ಜೋಡಿಸುವ ವಿಧಾನ: ನೀವು ನಿಮ್ಮ ಸಂಗೀತದ ಕಡೆ ತೋರಿಸುತ್ತೀರಿ, ಅದು ಪ್ರತಿಯೊಂದು ಕಡತಕೋಶ ಯಾವ ಬಿಡುಗಡೆ ಎಂಬುದನ್ನು ಕಂಡುಹಿಡಿಯುತ್ತದೆ, ಮತ್ತು ಗ್ರಂಥಾಲಯ ಆ ಕಡತಕೋಶವನ್ನು ಆ ಬಿಡುಗಡೆ ಆಗಿ ದಾಖಲಿಸುತ್ತದೆ.

ಆಮದು ಡೆಸ್ಕ್‌ಟಾಪ್‌ನಲ್ಲಿ (macOS, Windows) ನಡೆಯುತ್ತದೆ. ನಿಮ್ಮ ಕಡತಗಳನ್ನು ಓದಲಾಗುತ್ತದೆ, ಬದಲಾಯಿಸಲಾಗುವುದಿಲ್ಲ: bae ಯಾವುದನ್ನೂ ಸರಿಸುವುದಿಲ್ಲ, ಮರುಹೆಸರಿಸುವುದಿಲ್ಲ, retag ಮಾಡುವುದಿಲ್ಲ, ಅಥವಾ re-encode ಮಾಡುವುದಿಲ್ಲ. ಆಮದು ನಂತರ ಕಡತಗಳು ಎಲ್ಲಿರುತ್ತವೆ ಎನ್ನಲು [ಸಂಗ್ರಹ ಮತ್ತು ಆಫ್‌ಲೈನ್](/kn/guide/storage) ನೋಡಿ.

## ಗಮನಿಸುವ ಕಡತಕೋಶಗಳು

**Import** ವಿಭಾಗಕ್ಕೆ ಬದಲಿಸಿ ಮತ್ತು ಕಡತಕೋಶ ಸೇರಿಸಿ: ಅದನ್ನು ಆರಿಸಿ, ಕಿಟಕಿಯ ಮೇಲೆ ಎಳೆಯಿರಿ, ಅಥವಾ <kbd>⌘I</kbd> ಒತ್ತಿ. bae ಆ ಕ್ಷಣದಿಂದ ಕಡತಕೋಶವನ್ನು ಗಮನಿಸುತ್ತದೆ. ಅದಕ್ಕೆ ಹಾಕಿದ ಹೊಸ ಸಂಗೀತ ತಾನೇ ಹೊಸ ಅಭ್ಯರ್ಥಿಗಳಾಗಿ ಕಾಣುತ್ತದೆ; ಕೈಯಾರೆ ಮರು-ಸ್ಕ್ಯಾನ್ ಬೇಡ. ಇನ್ನೂ ಡೌನ್‌ಲೋಡ್ ಆಗುತ್ತಿರುವ ಕಡತಕೋಶಗಳನ್ನು ಅವು ಮುಗಿಯುವವರೆಗೆ ಕಡೆಗಣಿಸಲಾಗುತ್ತದೆ.

ಸ್ಕ್ಯಾನ್ rips ನಿಜವಾಗಿ ಕಾಣುವ ರೂಪಗಳಲ್ಲಿ ಬಿಡುಗಡೆಗಳನ್ನು ಗುರುತಿಸುತ್ತದೆ:

| ವಿನ್ಯಾಸ | ಅದು ಹೇಗೆ ಕಾಣುತ್ತದೆ |
|--------|-------------------|
| ಪ್ರತಿ ಟ್ರ್ಯಾಕ್‌ಗೆ ಕಡತ | `01 - Song.flac`, `02 - Song.flac`, ... |
| CUE + image | `album.cue` + `album.flac`, ಸಂಪೂರ್ಣ ಡಿಸ್ಕ್‌ಗೆ ಒಂದು ಕಡತ |
| ಬಹು-ಡಿಸ್ಕ್ | `CD1/`, `CD2/` ಉಪಕಡತಕೋಶಗಳು, ಒಳಗೆ ಯಾವುದಾದರೂ ರೂಪ |
| ಸಂಗ್ರಹಗಳು | ಕಡತಕೋಶಗಳಿರುವ ಕಡತಕೋಶ, ಪ್ರತಿಯೊಂದು ತನ್ನದೇ ಬಿಡುಗಡೆ |

bae ಅದು ಪ್ಲೇ ಮಾಡುವ ಸ್ವರೂಪಗಳನ್ನು ಆಮದು ಮಾಡುತ್ತದೆ: FLAC, MP3, APE, ALAC ಮತ್ತು `.m4a` ಯಲ್ಲಿರುವ AAC, WAV, AIFF, Ogg Vorbis, Opus, WavPack, ಮತ್ತು DSD (`.dsf`/`.dff`). ಕಡತಕೋಶದಲ್ಲಿರುವ ಕಲೆಚಿತ್ರ ಮತ್ತು ದಾಖಲೆಗಳು (CUE sheets, rip logs, ಪಠ್ಯ ಕಡತಗಳು) ಗುರುತಿಸಿ ಬಿಡುಗಡೆ ಜೊತೆಗೆ ಇಡಲಾಗುತ್ತದೆ.

## ಬಿಡುಗಡೆ ಗುರುತಿಸುವುದು

ಅಭ್ಯರ್ಥಿಯನ್ನು ಆರಿಸಿದರೆ bae ಅದನ್ನು ಗುರುತಿಸಲು ಆರಂಭಿಸುತ್ತದೆ. ಟ್ಯಾಗ್‌ಗಳಿಂದ ಊಹಿಸುವುದಕ್ಕಿಂತ, ಅದು ಕಡತಕೋಶದಲ್ಲಿರುವ ಸಾಕ್ಷ್ಯವನ್ನು ಓದಿ ಪ್ರತಿಯೊಂದು ಭಾಗವನ್ನು ಹುಡುಕುತ್ತದೆ:

- **Disc ID.** CD ಯ ನಿಖರ ಟ್ರ್ಯಾಕ್ ವಿನ್ಯಾಸದ ಬೆರಳಚ್ಚು, rip log ಅಥವಾ CUE sheet ನಿಂದ ಗಣನೆ ಮಾಡಲಾಗುತ್ತದೆ. ಹೊಂದಿದಾಗ, ಅದು ನಿಖರ CD edition ಗುರುತಿಸುತ್ತದೆ.
- **Barcode.** ಕಡತಕೋಶದಲ್ಲಿರುವ ಮುಖಪುಟ ಸ್ಕ್ಯಾನ್‌ಗಳಿಂದ ಪಠ್ಯ ಗುರುತಿಸುವಿಕೆ ಬಳಸಿ, ಅಥವಾ CUE sheet ನಿಂದ ಓದಲಾಗುತ್ತದೆ.
- **Catalog numbers and text.** ಕಲೆಚಿತ್ರ ಮತ್ತು ಕಡತ/ಕಡತಕೋಶ ಹೆಸರುಗಳಲ್ಲಿ ಕಂಡ catalog numbers, ಫಲಿತಾಂಶಗಳನ್ನು ಕಿರಿದುಗೊಳಿಸಲು ಬಳಸಲಾಗುತ್ತದೆ.

ಸೂಚನೆಗಳನ್ನು MusicBrainz ಮತ್ತು Discogs ವಿರುದ್ಧ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಹುಡುಕಲಾಗುತ್ತದೆ, ಮತ್ತು ಫಲಿತಾಂಶಗಳನ್ನು ಪರಸ್ಪರ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ. ಪ್ರತಿಯೊಂದು ಸೂಚನೆ ಫಲಿತಾಂಶಗಳ ಮೇಲಿನ badge ಆಗಿ ಕಾಣುತ್ತದೆ: ಏನು ಕಂಡುಬಂದಿತು, ಅದು ಎಲ್ಲಿಂದ ಬಂದಿತು (ಮೂಲಕ್ಕಾಗಿ hover ಮಾಡಿ: disc TOC, CUE sheet, cover scan, ಕಡತಕೋಶದ ಹೆಸರು), ಮತ್ತು ಒಂದು ತಪ್ಪು ದಾರಿಯಲ್ಲಿ ನಡೆಸಿದರೆ ಪ್ರತ್ಯೇಕ ಸೂಚನೆಗಳನ್ನು off ಮಾಡಬಹುದು.

ಮೂರು ಫಲಿತಾಂಶಗಳು:

- **Found.** ಸಾಕ್ಷ್ಯ ಒಂದು ಬಿಡುಗಡೆ ಗುಂಪಿನ ಮೇಲೆ ಒಪ್ಪುತ್ತದೆ. ಅದರ ಪಟ್ಟಿಯಿಂದ ನಿಖರ ಪ್ರೆಸಿಂಗ್ ಆರಿಸುತ್ತೀರಿ.
- **Conflict.** ಎರಡು ಸೂಚನೆಗಳು ಬೇರೆ ಬಿಡುಗಡೆಗಳ ಕಡೆ ತೋರಿಸುತ್ತವೆ, ಉದಾಹರಣೆಗೆ disc ID ಮತ್ತು barcode ಒಪ್ಪುವುದಿಲ್ಲ. bae ಎರಡೂ ಬದಿಗಳನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಯಾವುದನ್ನು ನಂಬಬೇಕು ಎಂದು ನೀವು ಆರಿಸುತ್ತೀರಿ, ಅಥವಾ ಒಂದು ಸೂಚನೆಯನ್ನು ಕಡೆಗಣಿಸುತ್ತೀರಿ.
- **Nothing found.** ಕೈಯಾರೆ ಹುಡುಕಿ: ಕಲಾವಿದ ಮತ್ತು ಆಲ್ಬಮ್, catalog number, ಅಥವಾ barcode, ಯಾವುದಾದರೂ ಡೇಟಾಬೇಸ್ ವಿರುದ್ಧ. ಕಲೆಚಿತ್ರದಿಂದ ಗುರುತಿಸಿದ ಪಠ್ಯವನ್ನು autocomplete ಆಗಿ ನೀಡಲಾಗುತ್ತದೆ.

ನೀವು **skip identifying** ಮಾಡಬಹುದು ಮತ್ತು ಅಜ್ಞಾತ ಬಿಡುಗಡೆ ಆಗಿ ಆಮದು ಮಾಡಬಹುದು. ಆಗ bae ಹೆಸರುಗಳಿಗಾಗಿ ನಿಮ್ಮ ಕಡತಗಳ embedded tags ಗೆ fallback ಆಗುತ್ತದೆ, ಮತ್ತು ಬಿಡುಗಡೆ ಡೇಟಾಬೇಸ್‌ನಲ್ಲಿ ಬಂದಾಗ ಅಥವಾ ಉತ್ತಮ ಸಾಕ್ಷ್ಯ ಸಿಕ್ಕಾಗ ನಂತರ ಮತ್ತೆ ಗುರುತಿಸಬಹುದು.

## ನಿಖರ ಅಥವಾ ಅಂದಾಜು

ಹೊಂದಾಣಿಕೆ ಆರಿಸಿದಾಗ, bae ಅದನ್ನು ನಿಮ್ಮ ಕಡತಗಳ ವಿರುದ್ಧ ಪರಿಶೀಲಿಸಿ ಟ್ರ್ಯಾಕ್ ಸಂಖ್ಯೆಯ ವ್ಯತ್ಯಾಸವನ್ನು ಗುರುತಿಸುತ್ತದೆ. ನಂತರ ಹೊಂದಾಣಿಕೆ ಏನು ಎಂದು ನೀವು ಘೋಷಿಸುತ್ತೀರಿ:

- **Exact**: ನಿಮ್ಮ ಕಡತಗಳು ಇದೇ ಪ್ರೆಸಿಂಗ್.
- **Metadata only**: ಸರಿಯಾದ ಆಲ್ಬಮ್, ಆದರೆ ಇದೇ ನಿಖರ ಪ್ರೆಸಿಂಗ್ ಅಗತ್ಯವಿಲ್ಲ. bae ಮೆಟಾಡೇಟಾ ಬಳಸುತ್ತದೆ ಮತ್ತು ಪ್ರೆಸಿಂಗ್ ಅಂದಾಜು ಎಂದು ನೆನಪಿಡುತ್ತದೆ.

ಬಿಡುಗಡೆ ಈಗಾಗಲೇ ನಿಮ್ಮ ಗ್ರಂಥಾಲಯದಲ್ಲಿದ್ದರೆ, ಅಥವಾ ಅದೇ ಆಲ್ಬಮ್‌ನ ಮತ್ತೊಂದು ಪ್ರೆಸಿಂಗ್ ಇದ್ದರೆ, duplicate ಆಮದು ಮಾಡುವ ಮೊದಲು bae ನಿಮಗೆ ಹೇಳುತ್ತದೆ.

## ದೃಢಪಡಿಸಿ ಮತ್ತು ಆಮದು ಮಾಡಿ

ದೃಢೀಕರಣ ಫಲಕವು ಆಮದು ಬರೆಯಲಿರುವ ಎಲ್ಲವನ್ನೂ ತೋರಿಸುತ್ತದೆ:

- **Cover.** ಡೇಟಾಬೇಸ್‌ಗಳ ಕಲೆ, ನಿಮ್ಮ ಕಡತಕೋಶದ ಚಿತ್ರಗಳು, ಅಥವಾ ಕಡತಗಳಲ್ಲಿ embedded art ನಿಂದ ಆರಿಸಲಾಗುತ್ತದೆ. ನಂತರ ಬದಲಾಯಿಸಬಹುದು.
- **ಮೆಟಾಡೇಟಾ.** ಆಲ್ಬಮ್, ಕಲಾವಿದ, ವರ್ಷ, ಲೇಬಲ್, catalog number, ದೇಶ, barcode, ಮತ್ತು ಪ್ರತಿಯೊಂದು ಟ್ರ್ಯಾಕ್: ಏನಾದರೂ ಉಳಿಯುವ ಮೊದಲು ಇಲ್ಲಿಯೇ ತಿದ್ದಬಹುದು.
- **ಸಂಗ್ರಹ.** ಮೇಘ ಮನೆ ಸಂಪರ್ಕಿತವಾಗಿದ್ದರೆ, bae ಕಡತಗಳನ್ನು ನಿಮ್ಮ ಮೇಘದಲ್ಲಿ ನಿರ್ವಹಿಸಬೇಕೇ, ಮತ್ತು ಸ್ಥಳೀಯ ಪ್ರತಿಯನ್ನೂ ಇಡಬೇಕೇ ಎಂದು ಆರಿಸಿ. [ಸಂಗ್ರಹ ಮತ್ತು ಆಫ್‌ಲೈನ್](/kn/guide/storage) ನೋಡಿ.

ಆಮದು ಹಿನ್ನೆಲೆಯಲ್ಲೇ ನಡೆಯುತ್ತದೆ: bae ಪ್ರತಿಯೊಂದು ಟ್ರ್ಯಾಕ್ ಸ್ವಚ್ಛವಾಗಿ decode ಆಗುತ್ತದೆ ಎಂದು ಪರಿಶೀಲಿಸುತ್ತದೆ, ಆಲ್ಬಮ್ ಮತ್ತು ಪ್ರತಿಯೊಂದು ಟ್ರ್ಯಾಕ್‌ಗೆ loudness ಅಳೆಯುತ್ತದೆ, ಬಿಡುಗಡೆ ಉಳಿಸುತ್ತದೆ, ಮತ್ತು ನಿರ್ವಹಿತ ಆಮದುಗಳಿಗಾಗಿ ಅಪ್‌ಲೋಡ್ ಆರಂಭಿಸುತ್ತದೆ. ಅಭ್ಯರ್ಥಿಗಳ ಪಟ್ಟಿ ಮುಂದಿನ ಕಡತಕೋಶಕ್ಕೆ ಸಾಗುತ್ತದೆ, ಮತ್ತು ಬಿಡುಗಡೆ ತಕ್ಷಣ ಪ್ಲೇ ಮಾಡಲು ಸಿದ್ಧ.

## ದತ್ತಾಂಶ ಮೂಲಗಳು

**MusicBrainz** ಗೆ ಖಾತೆ ಅಥವಾ ಕೀ ಬೇಕಿಲ್ಲ. **Discogs** ಗೆ ನಿಮ್ಮದೇ ಉಚಿತ API token ಬೇಕು; ಸೆಟ್ಟಿಂಗ್‌ಗಳು ನಲ್ಲಿ ಅಂಟಿಸಿ, ಅದು ಕೆಲಸ ನಿಲ್ಲಿಸಿದರೆ bae ಹೇಳುತ್ತದೆ. token ಇಲ್ಲದೆ Discogs ಹುಡುಕಾಟ ಮತ್ತು Discogs-ಮೂಲದ ಮೆಟಾಡೇಟಾ ಲಭ್ಯವಿಲ್ಲ, ಉಳಿದದ್ದೆಲ್ಲ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಎರಡೂ ಸೇವೆಗಳು ದರ-ಮಿತಿಯಲ್ಲಿವೆ; bae ಮಿತಿಗಳೊಳಗೆ ಉಳಿಯಲು ವಿನಂತಿಗಳನ್ನು ಅಂತರದಿಂದ ಕಳುಹಿಸುತ್ತದೆ.

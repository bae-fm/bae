ಕಡತಕೋಶವು ಆಮದಿಗಾಗಿ ಆಡಿಯೋ ಮತ್ತು ಇತರ ಕಡತಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ. ಅದರ ತಿದ್ದಬಹುದಾದ ಮೆಟಾಡೇಟಾ ಆನ್‌ಲೈನ್ ಬಿಡುಗಡೆಯಿಂದ, ಕಡತಕೋಶದ ಸ್ವಂತ ಮೆಟಾಡೇಟಾದಿಂದ, ಅಥವಾ ಖಾಲಿ ಫಾರ್ಮ್‌ನಿಂದ ಆರಂಭವಾಗಬೇಕೇ ಎಂದು ನೀವು ಆರಿಸುತ್ತೀರಿ.

ಆಮದು ಡೆಸ್ಕ್‌ಟಾಪ್‌ನಲ್ಲಿ (macOS, Windows) ನಡೆಯುತ್ತದೆ. ನಿಮ್ಮ ಕಡತಗಳನ್ನು ಓದಲಾಗುತ್ತದೆ, ಬದಲಾಯಿಸಲಾಗುವುದಿಲ್ಲ: bae ಯಾವುದನ್ನೂ ಸರಿಸುವುದಿಲ್ಲ, ಮರುಹೆಸರಿಸುವುದಿಲ್ಲ, retag ಮಾಡುವುದಿಲ್ಲ, ಅಥವಾ re-encode ಮಾಡುವುದಿಲ್ಲ. ಆಮದು ನಂತರ ಕಡತಗಳು ಎಲ್ಲಿರುತ್ತವೆ ಎನ್ನಲು [ಸಂಗ್ರಹ ಮತ್ತು ಆಫ್‌ಲೈನ್](/kn/guide/storage) ನೋಡಿ.

## ಗಮನಿಸುವ ಕಡತಕೋಶಗಳು

**Import** ವಿಭಾಗಕ್ಕೆ ಬದಲಿಸಿ ಮತ್ತು ಕಡತಕೋಶ ಸೇರಿಸಿ: ಅದನ್ನು ಆರಿಸಿ, ಕಿಟಕಿಯ ಮೇಲೆ ಎಳೆಯಿರಿ, ಅಥವಾ <kbd>⌘I</kbd> ಒತ್ತಿ. bae ಆ ಕ್ಷಣದಿಂದ ಕಡತಕೋಶವನ್ನು ಗಮನಿಸುತ್ತದೆ. ಅದಕ್ಕೆ ಹಾಕಿದ ಹೊಸ ಸಂಗೀತ ತಾನೇ ಹೊಸ ಅಭ್ಯರ್ಥಿಗಳಾಗಿ ಕಾಣುತ್ತದೆ; ಕೈಯಾರೆ ಮರು-ಸ್ಕ್ಯಾನ್ ಬೇಡ. ಇನ್ನೂ ಡೌನ್‌ಲೋಡ್ ಆಗುತ್ತಿರುವ ಕಡತಕೋಶಗಳನ್ನು ಅವು ಮುಗಿಯುವವರೆಗೆ ಕಡೆಗಣಿಸಲಾಗುತ್ತದೆ.

ಸ್ಕ್ಯಾನ್ rips ನಿಜವಾಗಿ ಕಾಣುವ ರೂಪಗಳಲ್ಲಿ ಬಿಡುಗಡೆಗಳನ್ನು ಗುರುತಿಸುತ್ತದೆ:

| ವಿನ್ಯಾಸ | ಅದು ಹೇಗೆ ಕಾಣುತ್ತದೆ |
|--------|-------------------|
| ಪ್ರತಿ ಟ್ರ್ಯಾಕ್‌ಗೆ ಕಡತ | `01 - Song.flac`, `02 - Song.flac`, … |
| CUE + image | `album.cue` + `album.flac`, ಸಂಪೂರ್ಣ ಡಿಸ್ಕ್‌ಗೆ ಒಂದು ಕಡತ |
| ಬಹು-ಡಿಸ್ಕ್ | `CD1/`, `CD2/` ಉಪಕಡತಕೋಶಗಳು, ಒಳಗೆ ಯಾವುದಾದರೂ ರೂಪ |
| ಸಂಗ್ರಹಗಳು | ಕಡತಕೋಶಗಳಿರುವ ಕಡತಕೋಶ, ಪ್ರತಿಯೊಂದು ತನ್ನದೇ ಬಿಡುಗಡೆ |

bae ಅದು ಪ್ಲೇ ಮಾಡುವ ಸ್ವರೂಪಗಳನ್ನು ಆಮದು ಮಾಡುತ್ತದೆ: FLAC, MP3, APE, ALAC ಮತ್ತು `.m4a` ಯಲ್ಲಿರುವ AAC, WAV, AIFF, Ogg Vorbis, Opus, WavPack, ಮತ್ತು DSD (`.dsf`/`.dff`). ಕಡತಕೋಶದಲ್ಲಿರುವ ಕಲೆಚಿತ್ರ ಮತ್ತು ದಾಖಲೆಗಳು (CUE sheets, rip logs, ಪಠ್ಯ ಕಡತಗಳು) ಗುರುತಿಸಿ ಬಿಡುಗಡೆ ಜೊತೆಗೆ ಇಡಲಾಗುತ್ತದೆ.

## ಮೆಟಾಡೇಟಾ ಡ್ರಾಫ್ಟ್ ತುಂಬಿಸಿ

ಪ್ರತಿಯೊಂದು ಅಭ್ಯರ್ಥಿಗೂ ಒಂದು ತಿದ್ದಬಹುದಾದ ಮೆಟಾಡೇಟಾ ಡ್ರಾಫ್ಟ್ ಇರುತ್ತದೆ. ಅದು ಖಾಲಿಯಾಗಿ ಆರಂಭವಾಗಬಹುದು, ಆನ್‌ಲೈನ್ ಬಿಡುಗಡೆಯಿಂದ ತುಂಬಬಹುದು, ಅಥವಾ ಕಡತಕೋಶದ ಸ್ವಂತ ಕಡತಗಳು ಹೇಳುವುದರಿಂದ ತುಂಬಬಹುದು. ಖಾಲಿ ಡ್ರಾಫ್ಟ್‌ನಲ್ಲಿ ಟೈಪ್ ಮಾಡುವುದು ನೇರ ನಮೂದು, ಬೇರೊಂದು ಮೆಟಾಡೇಟಾ ಮೂಲವಲ್ಲ.

ಕಾರ್ಡ್‌ನ **Identify** ನಿಯಂತ್ರಣಗಳು Identify ಪುಟಕ್ಕೆ ಹೋಗಲು ಎರಡು ದಾರಿಗಳನ್ನು ನೀಡುತ್ತವೆ, ಅವು ಏನನ್ನು ಆರಂಭಿಸುತ್ತವೆ ಎಂಬುದರಲ್ಲಿ ಬೇರೆ. **Automatic** ಪುಟವನ್ನು ತೆರೆದು, ಅಭ್ಯರ್ಥಿಯಲ್ಲಿ ಈಗಾಗಲೇ ಏನಿದ್ದರೂ, ಪ್ರತಿ ಬಾರಿಯೂ ಹೊಸ ಗುರುತಿಸುವಿಕೆ ಓಟವನ್ನು ಕೇಳುತ್ತದೆ — ಈಗಾಗಲೇ ನಡೆಯುತ್ತಿರುವ ಓಟವನ್ನು ಹೊಸದಕ್ಕಾಗಿ ಕೈಬಿಡಲಾಗುತ್ತದೆ. **Search** ಅದೇ ಪುಟವನ್ನು ಅದರ ಟೈಪ್ ಮಾಡುವ ಹುಡುಕಾಟದಲ್ಲಿ ತೆರೆಯುತ್ತದೆ ಮತ್ತು ಏನನ್ನೂ ಆರಂಭಿಸುವುದಿಲ್ಲ. ಯಾವುದೂ ಡ್ರಾಫ್ಟ್ ಅನ್ನು ಬದಲಿಸುವುದಿಲ್ಲ; ಫಲಿತಾಂಶವನ್ನು ಅನ್ವಯಿಸಿದರೆ ಡ್ರಾಫ್ಟ್ ಬದಲಾಗಿ ತಿದ್ದಬಹುದಾದ ಕಾರ್ಡ್‌ಗೆ ಮರಳುತ್ತದೆ. ಕಾರ್ಡ್‌ನ menu ಯಲ್ಲಿ ಡ್ರಾಫ್ಟ್ ಅನ್ನು ಇದ್ದಲ್ಲೇ ಮರುಬರೆಯುವ ಎರಡು ಆಜ್ಞೆಗಳಿವೆ: **Reset to file metadata**, ಅದು ಡ್ರಾಫ್ಟ್ ಅನ್ನು ಅಭ್ಯರ್ಥಿಯ ಸ್ವಂತ ಕಡತಗಳು, sheets ಮತ್ತು ಕಡತಕೋಶದ ಹೆಸರು ಹೇಳುವುದರಿಂದ ಬದಲಿಸುತ್ತದೆ, ಮತ್ತು **Clear metadata**, ಅದು ಅದನ್ನು ಖಾಲಿ ಮಾಡುತ್ತದೆ. ಪ್ರತಿಯೊಂದೂ ಮೊದಲು ಕೇಳುತ್ತದೆ, ಮತ್ತು ಯಾವುದೂ ಅಭ್ಯರ್ಥಿಯ ಕಡತಗಳನ್ನು ಅಥವಾ ಟ್ರ್ಯಾಕ್ ವಿನ್ಯಾಸವನ್ನು ಮುಟ್ಟುವುದಿಲ್ಲ.

### Identify

Identify ಪುಟ ಕಡತಕೋಶ ಯಾವ ಬಿಡುಗಡೆ ಎಂದು ಕಂಡುಹಿಡಿಯುತ್ತದೆ. ಅದು ಕಡತಕೋಶದಿಂದ ಸಾಕ್ಷ್ಯ ಓದುತ್ತದೆ ಮತ್ತು ಪ್ರತಿಯೊಂದು ತುಣುಕನ್ನೂ ಹುಡುಕಿ ನೋಡುತ್ತದೆ:

- **ಡಿಸ್ಕ್ ID.** CD ಯ ನಿಖರ ಟ್ರ್ಯಾಕ್ ವಿನ್ಯಾಸದ fingerprint, rip log ಅಥವಾ CUE sheet ನಿಂದ ಲೆಕ್ಕಹಾಕಿದ್ದು. ಅದು ಹೊಂದಿದಾಗ, ನಿಖರ CD ಆವೃತ್ತಿಯನ್ನು ಗುರುತಿಸುತ್ತದೆ.
- **Barcode.** ಕಡತಕೋಶದ ಮುಖಪುಟ scans ನಿಂದ ಪಠ್ಯ ಗುರುತಿಸುವಿಕೆ ಬಳಸಿ ಓದಿದ್ದು, ಅಥವಾ CUE sheet ನಿಂದ.
- **Catalog numbers ಮತ್ತು ಪಠ್ಯ.** ಕಲೆಚಿತ್ರದಲ್ಲಿ ಮತ್ತು ಕಡತ ಹಾಗೂ ಕಡತಕೋಶದ ಹೆಸರುಗಳಲ್ಲಿ ಸಿಕ್ಕ catalog numbers, ಫಲಿತಾಂಶಗಳನ್ನು ಕಿರಿದಾಗಿಸಲು ಬಳಸಲಾಗುತ್ತದೆ.

ಸೂಚನೆಗಳನ್ನು MusicBrainz ಮತ್ತು Discogs ಎರಡರಲ್ಲೂ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಹುಡುಕಲಾಗುತ್ತದೆ, ಮತ್ತು ಫಲಿತಾಂಶಗಳನ್ನು ಪರಸ್ಪರ ತಾಳೆ ನೋಡಲಾಗುತ್ತದೆ. ಪ್ರತಿಯೊಂದು ಸೂಚನೆ ಫಲಿತಾಂಶಗಳ ಮೇಲೆ badge ಆಗಿ ಕಾಣುತ್ತದೆ: ಏನು ಸಿಕ್ಕಿತು, ಅದು ಎಲ್ಲಿಂದ ಬಂತು (ಮೂಲಕ್ಕಾಗಿ hover ಮಾಡಿ: disc TOC, CUE sheet, ಮುಖಪುಟ scan, ಕಡತಕೋಶದ ಹೆಸರು) ಎಂದು ನೋಡಬಹುದು, ಮತ್ತು ಯಾವುದಾದರೂ ಸೂಚನೆ ದಾರಿತಪ್ಪಿಸುತ್ತಿದ್ದರೆ ಅದನ್ನು ಪ್ರತ್ಯೇಕವಾಗಿ ಆಫ್ ಮಾಡಬಹುದು.

ಮೂರು ಫಲಿತಾಂಶಗಳು:

- **ಸಿಕ್ಕಿತು.** ಸಾಕ್ಷ್ಯ ಒಂದು release group ಮೇಲೆ ಒಪ್ಪುತ್ತದೆ. ಅದರ ಪಟ್ಟಿಯಿಂದ ನೀವು ನಿಖರ ಪ್ರೆಸಿಂಗ್ ಆರಿಸುತ್ತೀರಿ.
- **ಸಂಘರ್ಷ.** ಎರಡು ಸೂಚನೆಗಳು ಬೇರೆ ಬೇರೆ ಬಿಡುಗಡೆಗಳತ್ತ ತೋರಿಸುತ್ತವೆ, ಉದಾಹರಣೆಗೆ ಡಿಸ್ಕ್ ID ಮತ್ತು barcode ಒಪ್ಪುವುದಿಲ್ಲ. bae ಎರಡೂ ಕಡೆ ತೋರಿಸುತ್ತದೆ ಮತ್ತು ಯಾವುದನ್ನು ನಂಬಬೇಕು ಎಂದು ನೀವು ಆರಿಸುತ್ತೀರಿ, ಅಥವಾ ಒಂದು ಸೂಚನೆಯನ್ನು ಕಡೆಗಣಿಸುತ್ತೀರಿ.
- **ಏನೂ ಸಿಗಲಿಲ್ಲ.** ಕೈಯಾರೆ ಹುಡುಕಿ: ಕಲಾವಿದ ಮತ್ತು ಆಲ್ಬಮ್, catalog number, ಅಥವಾ barcode, ಯಾವುದಾದರೂ ಡೇಟಾಬೇಸ್‌ನಲ್ಲಿ. ಕಲೆಚಿತ್ರದಿಂದ ಗುರುತಿಸಿದ ಪಠ್ಯವನ್ನು autocomplete ಆಗಿ ನೀಡಲಾಗುತ್ತದೆ.

ಮೂಲ ವೀಕ್ಷಕ ಹುಡುಕಾಟ ಫಾರ್ಮ್, ಗುರುತಿಸುವಿಕೆಯ ಪ್ರಗತಿ, ಸೂಚನೆಗಳು ಮತ್ತು ಫಲಿತಾಂಶಗಳನ್ನು ಒಟ್ಟಿಗೆ ತೋರಿಸುತ್ತದೆ. ಫಲಿತಾಂಶವನ್ನು ಆರಿಸಿದರೆ, bae ಪೂರ್ಣ ಬಿಡುಗಡೆಯನ್ನು ತರುವಾಗ ಆ ಸಾಲು ಪ್ರಗತಿಯೊಂದಿಗೆ ತೆರೆದಿರುತ್ತದೆ, ನಂತರ ಅದನ್ನು ಡ್ರಾಫ್ಟ್‌ಗೆ ಅನ್ವಯಿಸುತ್ತದೆ. ಆಗುವ ಕಾರ್ಡ್ MusicBrainz ಅಥವಾ Discogs ಮೂಲ ಚಿಪ್ ತೋರಿಸುತ್ತದೆ. ಕಾರ್ಡ್‌ನ **Automatic** ಅದನ್ನು ಮೊದಲಿನಿಂದ ಮತ್ತೆ ನಡೆಸುತ್ತದೆ; **Search** ಈಗಾಗಲೇ ಸಿಕ್ಕದ್ದನ್ನು ಉಳಿಸಿಕೊಂಡು ಟೈಪ್ ಮಾಡುವ ಹುಡುಕಾಟಕ್ಕೆ ಮರಳುತ್ತದೆ.

ಸ್ವಯಂಚಾಲಿತ ಗುರುತಿಸುವಿಕೆಯೂ ಇದೇ ದಾರಿಯನ್ನು ಬಳಸುತ್ತದೆ. ಅಭ್ಯರ್ಥಿ ಸೇರಿಸಿದಾಗ, ಅದರ ಡ್ರಾಫ್ಟ್ ಅದರ ಕಡತಗಳು, sheets ಮತ್ತು ಕಡತಕೋಶದ ಹೆಸರಿನಿಂದ ರಚನೆಯಾಗುತ್ತದೆ. Settings, Import ನಲ್ಲಿನ **Identify automatically** ಸೆಟ್ಟಿಂಗ್ ತನ್ನ ಈಗಿನ ಕಡತಗಳಿಗೆ ಯಾವುದೇ ಫಲಿತಾಂಶ ಇಲ್ಲದ ಪ್ರತಿಯೊಂದು ಅಭ್ಯರ್ಥಿಗೂ ಗುರುತಿಸುವಿಕೆಯನ್ನು ನಡೆಸುತ್ತದೆ; ಅದು ಆಫ್ ಆಗಿದ್ದರೆ ಪ್ರತಿಯೊಂದು ಓಟವನ್ನೂ ನೀವೇ ಆರಂಭಿಸುತ್ತೀರಿ. ಮುಂಚಿತವಾಗಿ ತುಂಬಿದ ಡ್ರಾಫ್ಟ್ ಆರಂಭದ ಬಿಂದು, ಉತ್ತರವಲ್ಲ, ಆದ್ದರಿಂದ ಅದು ಓಟವನ್ನು ತಡೆಯುವುದಿಲ್ಲ.

### ಕಡತ ಮೆಟಾಡೇಟಾ

ಅಭ್ಯರ್ಥಿ ಸೇರಿಸಿದಾಗ ಮುಂಚಿತ ತುಂಬುವಿಕೆ ಅದನ್ನು ಓದುವಾಗ ಕಡತ ಮೆಟಾಡೇಟಾ ಓದಲಾಗುತ್ತದೆ, ಮತ್ತು **Reset to file metadata** ಆರಿಸಿದಾಗಲೆಲ್ಲ ಮತ್ತೆ. ಎರಡೂ ರೀತಿಯಲ್ಲಿ ಡ್ರಾಫ್ಟ್ ಆ ನಿಖರ ಓದಿನಿಂದ ಬದಲಾಗುತ್ತದೆ — ಅಡಕಗೊಳಿಸಿದ ಆಡಿಯೋ tags, CUE ಮೆಟಾಡೇಟಾ, ಮತ್ತು ಕಡತಕೋಶದ ಸ್ವಂತ ಹೆಸರು — ಮತ್ತು ಕಾರ್ಡ್ ಅದರ ಮೇಲೆ ಮತ್ತೆ ರಚನೆಯಾಗುತ್ತದೆ. ಓದಿನ ನಂತರ ಅಭ್ಯರ್ಥಿ ಅಥವಾ ಅದರ ಆಡಿಯೋ ಕಡತಗಳು ಬದಲಾದರೆ, ಗ್ರಂಥಾಲಯಕ್ಕೆ ಬರೆಯುವ ಮೊದಲೇ ಆಮದು ವಿಫಲವಾಗುತ್ತದೆ.

ಡ್ರಾಫ್ಟ್‌ನಲ್ಲಿ ಆ ಓದು ಇರುವವರೆಗೆ ತಿದ್ದಬಹುದಾದ ಕಾರ್ಡ್ ಒಂದು ಶಾಂತ File metadata ಚಿಪ್ ತೋರಿಸುತ್ತದೆ. ಟೈಪ್ ಮಾಡಿ ಮಾತ್ರ ತುಂಬಿದ ಡ್ರಾಫ್ಟ್‌ಗೆ ಮೂಲ ಚಿಪ್ ಇರುವುದಿಲ್ಲ.

## ದೃಢಪಡಿಸಿ ಮತ್ತು ಆಮದು ಮಾಡಿ

ದೃಢೀಕರಣ ಫಲಕವು ಆಮದು ಬರೆಯಲಿರುವ ಎಲ್ಲವನ್ನೂ ತೋರಿಸುತ್ತದೆ:

- **ಮುಖಪುಟ ಚಿತ್ರ.** ಡೇಟಾಬೇಸ್‌ಗಳ ಕಲೆಚಿತ್ರ, ನಿಮ್ಮ ಕಡತಕೋಶದ ಚಿತ್ರಗಳು, ಅಥವಾ ಕಡತಗಳಲ್ಲಿ ಅಡಕಗೊಳಿಸಿದ ಕಲೆಚಿತ್ರದಿಂದ ಆರಿಸಲಾಗುತ್ತದೆ. ಅಭ್ಯರ್ಥಿಯ gallery ಯಿಂದ ಒಂದು ಚಿತ್ರವನ್ನು ಮುಖಪುಟ ಚೌಕಕ್ಕೆ ಎಳೆಯಿರಿ, ಅಥವಾ ನಂತರ ಬದಲಿಸಿ.
- **ಮೆಟಾಡೇಟಾ.** ಆಲ್ಬಮ್, ಕಲಾವಿದ, ವರ್ಷ, ಲೇಬಲ್, catalog number, ದೇಶ, barcode, ಮತ್ತು ಪ್ರತಿಯೊಂದು ಟ್ರ್ಯಾಕ್: ಏನಾದರೂ ಉಳಿಯುವ ಮೊದಲು ಇಲ್ಲಿಯೇ ತಿದ್ದಬಹುದು.
- **ಸಂಗ್ರಹ.** ಮೇಘ ಮನೆ ಸಂಪರ್ಕಿತವಾಗಿದ್ದರೆ, ಬಿಡುಗಡೆಯನ್ನು ಅಲ್ಲಿಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಲು **Cloud** ಆರಿಸಿ, ಮತ್ತು ಅದರ ಕಡತಗಳನ್ನು ಈ ಸಾಧನದಲ್ಲೂ ಇಡಲು **Pinned**. ಇಲ್ಲದಿದ್ದರೆ ಬಿಡುಗಡೆ ಸ್ಥಳೀಯ: ಅದರ ಮಾಹಿತಿ ನಿಮ್ಮ ಬೇರೆ ಸಾಧನಗಳಿಗೆ ಸಮನ್ವಯ ಆಗುತ್ತದೆ, ಮತ್ತು ಅದರ ಆಡಿಯೋ ಈ ಸಾಧನದಲ್ಲೇ ಉಳಿಯುತ್ತದೆ. [ಸಂಗ್ರಹ ಮತ್ತು ಆಫ್‌ಲೈನ್](/kn/guide/storage) ನೋಡಿ.

ಆಮದು ಹಿನ್ನೆಲೆಯಲ್ಲೇ ನಡೆಯುತ್ತದೆ: bae ಪ್ರತಿಯೊಂದು ಟ್ರ್ಯಾಕ್ ಸ್ವಚ್ಛವಾಗಿ decode ಆಗುತ್ತದೆ ಎಂದು ಪರಿಶೀಲಿಸುತ್ತದೆ, ಆಲ್ಬಮ್ ಮತ್ತು ಪ್ರತಿಯೊಂದು ಟ್ರ್ಯಾಕ್‌ಗೆ loudness ಅಳೆಯುತ್ತದೆ, ಬಿಡುಗಡೆ ಉಳಿಸುತ್ತದೆ, ಮತ್ತು ಮೇಘ ಆಮದುಗಳಿಗಾಗಿ ಅಪ್‌ಲೋಡ್ ಆರಂಭಿಸುತ್ತದೆ. ಅಭ್ಯರ್ಥಿಗಳ ಪಟ್ಟಿ ಮುಂದಿನ ಕಡತಕೋಶಕ್ಕೆ ಸಾಗುತ್ತದೆ, ಮತ್ತು ಬಿಡುಗಡೆ ತಕ್ಷಣ ಪ್ಲೇ ಮಾಡಬಹುದು.

## ದತ್ತಾಂಶ ಮೂಲಗಳು

**MusicBrainz** ಗೆ ಖಾತೆ ಅಥವಾ ಕೀ ಬೇಕಿಲ್ಲ. **Discogs** ಗೆ ನಿಮ್ಮದೇ ಉಚಿತ API token ಬೇಕು; Settings, Import ನಲ್ಲಿ ಅಂಟಿಸಿ, ಅದು ಕೆಲಸ ನಿಲ್ಲಿಸಿದರೆ bae ಹೇಳುತ್ತದೆ. token ಇಲ್ಲದೆ Discogs ಹುಡುಕಾಟ ಮತ್ತು Discogs-ಮೂಲದ ಮೆಟಾಡೇಟಾ ಲಭ್ಯವಿಲ್ಲ, ಉಳಿದದ್ದೆಲ್ಲ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಎರಡೂ ಸೇವೆಗಳು ದರ-ಮಿತಿಯಲ್ಲಿವೆ; bae ಮಿತಿಗಳೊಳಗೆ ಉಳಿಯಲು ವಿನಂತಿಗಳನ್ನು ಅಂತರದಿಂದ ಕಳುಹಿಸುತ್ತದೆ.

---

ಬಂಧನರಹಿತತೆ ಎರಡೂ ದಿಕ್ಕುಗಳಲ್ಲಿ ಅನ್ವಯಿಸುತ್ತದೆ: bae ಒಳಗೆ ಬರುವಾಗ ನಿಮ್ಮ ಕಡತಗಳನ್ನು ಬದಲಾಯಿಸುವುದಿಲ್ಲ, ಹೊರಗೆ ಹೋಗುವಾಗ ಅವನ್ನು ತಡೆಹಿಡಿಯುವುದಿಲ್ಲ. ಸ್ಥಳೀಯ release ಈಗಾಗಲೇ ನಿಮ್ಮ ಕಡತಕೋಶಗಳಲ್ಲಿರುವ ಕಡತಗಳೇ. ಮೋಡದಲ್ಲಿರುವ release ಅನ್ನು ಯಾವಾಗ ಬೇಕಾದರೂ byte-for-byte ಮತ್ತೆ ಸ್ಥಳೀಯವಾಗಿಸಬಹುದು. ಮತ್ತು ನಿಮಗೆ *ಬೇರೆ* ರೂಪ ಬೇಕಾದಾಗ, ಉದಾಹರಣೆಗೆ ಫೋನ್‌ಗೆ ಸೂಕ್ತವಾದ encode, Save as… ಮೂಲ ಕಡತಗಳನ್ನು ಮುಟ್ಟದೆ ಅದನ್ನು ಮಾಡುತ್ತದೆ.

## ಎರಡು ರಫ್ತುಗಳು

- **Export…**: album menu ಅಥವಾ Storage managerನಲ್ಲಿ, release ನ ಕಡತಗಳನ್ನು byte-for-byte ಒಂದು ಕಡತಕೋಶಕ್ಕೆ ನಕಲಿಸುತ್ತದೆ.
- **Save as…**: track ಮೇಲೆ, ಅಥವಾ release ಗಾಗಿ album menuನಲ್ಲಿ, ನೀವು ಆರಿಸಿದ formatಗೆ ಪರಿವರ್ತಿಸುತ್ತದೆ, ಉದಾಹರಣೆಗೆ ಕಾರು ಅಥವಾ ಫೋನ್‌ಗಾಗಿ FLAC ಇಂದ MP3. ಇದು ಹೊಸ ಕಡತಗಳನ್ನು ಬರೆಯುತ್ತದೆ; ಮೂಲ ಕಡತಗಳು ಇದ್ದಂತೆಯೇ ಇರುತ್ತವೆ.

ಎರಡೂ ಪ್ರಗತಿ ತೋರಿಸುವ queueನಲ್ಲಿ ಓಡುತ್ತವೆ. ನೀವು ಅವನ್ನು pause ಮತ್ತು cancel ಮಾಡಬಹುದು; ವಿಫಲವಾದ ಕೆಲಸ ನೀವು cancel ಮಾಡುವವರೆಗೂ ತನ್ನ ದೋಷದೊಂದಿಗೆ queueನಲ್ಲಿ ಉಳಿಯುತ್ತದೆ. Save queueಗೆ ಹಾಕಿದಾಗಿನ format ಮತ್ತು settings ಅನ್ನು ಉಳಿಸಿಕೊಳ್ಳುತ್ತದೆ, ಆದ್ದರಿಂದ ನಂತರ ಅವನ್ನು ಬದಲಿಸಿದರೆ queueನಲ್ಲಿ ಈಗಾಗಲೇ ಇರುವುದು ಬದಲಾಗುವುದಿಲ್ಲ.

## Formats

Format ಎಂದರೆ ಒಂದು ಹೆಸರು ಮತ್ತು ಒಂದು codec: FLAC, WAV, AIFF, MP3, AAC ಅಥವಾ Opus. ಅವು Settings, Save asನಲ್ಲಿ **Formats** ಅಡಿಯಲ್ಲಿ ಇರುತ್ತವೆ. **Add format…** ಒಂದನ್ನು ಸೇರಿಸುತ್ತದೆ, ಮತ್ತು ಅದರ menuನ **Edit…** ಮತ್ತು **Delete…** ಅದನ್ನು ಬದಲಿಸುತ್ತವೆ ಅಥವಾ ತೆಗೆಯುತ್ತವೆ. Formatಗೆ ಒಂದು **Name**, ಒಂದು **Format** ಮತ್ತು ಗುಣಮಟ್ಟದ ಒಂದು setting ಇರುತ್ತದೆ. ಹೆಸರುಗಳು ಅನನ್ಯ, ಆದರೆ ಎರಡು format ಒಂದೇ ಫಲಿತಾಂಶವನ್ನು ಬರೆಯಬಹುದು. ಹೊಸ formatಗೆ ಅದರ codec ಹೆಸರು ಬರುತ್ತದೆ, ಹೆಸರು ಬಳಕೆಯಲ್ಲಿದ್ದರೆ ಸಂಖ್ಯೆ ಸೇರುತ್ತದೆ ("FLAC", "FLAC (2)"). FLAC ಮತ್ತು MP3 ಮೊದಲೇ ಇವೆ.

ಪ್ರತಿಯೊಂದು format track ಮತ್ತು release ಎರಡಕ್ಕೂ ಕೆಲಸ ಮಾಡುತ್ತದೆ. Save as windowನಲ್ಲಿ **Format** pop-up ಎಲ್ಲಾ formatಗಳನ್ನು ತೋರಿಸುತ್ತದೆ ಮತ್ತು ನೀವು ಕೊನೆಯದಾಗಿ ಬಳಸಿದ್ದರಿಂದ ಶುರುವಾಗುತ್ತದೆ. ಅದರ ಕೊನೆಯ ಅಂಶ **Edit formats…** settingsನಲ್ಲಿ Save as ತೆರೆಯುತ್ತದೆ; pop-up ಅಲ್ಲಿ ಮಾಡಿದ ಬದಲಾವಣೆಗಳನ್ನು ಅನುಸರಿಸುತ್ತದೆ, ಮತ್ತು ಅಲ್ಲಿ ಸೇರಿಸಿದ format ತಕ್ಷಣ ಆಯ್ಕೆಯಾಗುತ್ತದೆ.

## ಗುಣಮಟ್ಟ

- **Bit depth**, FLAC, WAV ಮತ್ತು AIFF ಗಾಗಿ: **Same as source** ಅಥವಾ **16-bit**. Lossy ಮೂಲಕ್ಕೆ ತನ್ನದೇ ಆದ depth ಇರುವುದಿಲ್ಲ, ಆದ್ದರಿಂದ ಅದನ್ನು 16 bitನಲ್ಲಿ ಬರೆಯಲಾಗುತ್ತದೆ.
- **Bitrate**, MP3, AAC ಮತ್ತು Opus ಗಾಗಿ: ಆ codecನ encoder ಬರೆಯುವ bitrateಗಳ ಪಟ್ಟಿ. MP3: 32, 40, 48, 56, 64, 80, 96, 112, 128, 160, 192, 224, 256, 320 kbps. AAC: 96, 128, 160, 192, 256, 320 kbps. Opus: 64, 96, 128, 160, 192, 256 kbps.

## ಹೆಸರುಗಳು

Settings, Save asನಲ್ಲಿ **Names** ಅಡಿಯಲ್ಲಿ, ಒಂದು **File name** pattern ಮತ್ತು ಒಂದು **Folder name** pattern ಎಲ್ಲಾ formatಗಳಿಗೆ ಅನ್ವಯಿಸುತ್ತವೆ. Pattern ಎಂದರೆ ನೀವು ಮರುಜೋಡಿಸುವ, ತೆಗೆಯುವ ಮತ್ತು ಸೇರಿಸುವ ಭಾಗಗಳ ಸಾಲು, ಮತ್ತು ಅದು ಮಾಡುವ ಹೆಸರಿನ preview ತೋರಿಸುತ್ತದೆ. ಕಡತದ ಹೆಸರಿನಲ್ಲಿ title, artist, album, year, track number, disc number ಮತ್ತು ಒಟ್ಟು track ಬಳಸಬಹುದು. ಕಡತಕೋಶದ ಹೆಸರಿನಲ್ಲಿ artist, album, year, label ಮತ್ತು catalog number ಬಳಸಬಹುದು; release ತಿಳಿಸದ ಭಾಗ ಬಿಟ್ಟುಹೋಗುತ್ತದೆ.

Track ಮೇಲೆ Save as… patternನ ಹೆಸರನ್ನು ಸೂಚಿಸುತ್ತದೆ, ಮತ್ತು ಬೇರೆ format ಆರಿಸಿದರೆ extension ಮಾತ್ರ ಬದಲಾಗುತ್ತದೆ. Release save ಮಾಡಿದರೆ ಅದರ ಕಡತಗಳು folder patternನಿಂದ ಹೆಸರಿಸಿದ ಕಡತಕೋಶಕ್ಕೆ ಬರೆಯಲ್ಪಡುತ್ತವೆ. Release save ಎಂದಿಗೂ ಕಡತವನ್ನು ಬದಲಿಸುವುದಿಲ್ಲ: ನಿಮ್ಮ drive ಮೇಲೆ ಎರಡು ಹೆಸರುಗಳು ಒಂದೇ ಕಡತವಾಗುವುದಾದರೆ save ವಿಫಲವಾಗುತ್ತದೆ. ಒಂದು track ಮೇಲೆ Save as… ಇರುವ ಕಡತವನ್ನು ನೀವು ದೃಢಪಡಿಸಿದಾಗ ಮಾತ್ರ ಬದಲಿಸುತ್ತದೆ.

## ಪ್ರತಿ trackಗೆ ಒಂದು ಕಡತ

ಪ್ರತಿ save ಪ್ರತಿ trackಗೆ ಒಂದು ಕಡತ ಬರೆಯುತ್ತದೆ, ಅಂತರಗಳಿಗೆ ಒಂದೇ ನಿಯಮದೊಂದಿಗೆ. Pregap, ಸಂಗ್ರಹಿಸಿದ್ದು ಅಥವಾ ಸೃಷ್ಟಿಸಿದ್ದು, ಹಿಂದಿನ trackನ ಕೊನೆಗೆ ಹೋಗುತ್ತದೆ, ಮತ್ತು track 1ರ ಮೊದಲಿನ ಅಡಗಿದ audio track 1ರ ಆರಂಭದಲ್ಲಿ ಉಳಿಯುತ್ತದೆ. ಒಂದು image ಮತ್ತು CUE sheet ಆಗಿ ಸಂಗ್ರಹಿಸಿದ release track ಗುರುತುಗಳಲ್ಲಿ ಒಡೆಯಲ್ಪಡುತ್ತದೆ. Save as… CUE sheet ಬರೆಯುವುದಿಲ್ಲ.

## Encode ಮಾಡುವ ಬದಲು ನಕಲು

ಆರಿಸಿದ lossless formatನಲ್ಲಿ ಈಗಾಗಲೇ ಇರುವ, format ಬರೆಯುವ depthನಲ್ಲಿರುವ ಪೂರ್ಣ ಕಡತವಾದ track ಅನ್ನು ಮರು-encode ಮಾಡುವ ಬದಲು ನಕಲಿಸಲಾಗುತ್ತದೆ. WAV ಮತ್ತು AIFF 16 ಅಥವಾ 24 bitನಲ್ಲಿ ಎಣಿಕೆಯಾಗುತ್ತವೆ. ಅದರ tags, cover ಮತ್ತು ಹೆಸರು ಹೊಸದಾಗಿ ಬರೆಯಲ್ಪಡುತ್ತವೆ. Lossy format ಯಾವಾಗಲೂ encode ಮಾಡುತ್ತದೆ.

## ಹೆಚ್ಚುವರಿ

Settings, Save asನಲ್ಲಿ **Extras** ಅಡಿಯಲ್ಲಿ ಮೂರು switchಗಳು ಪ್ರತಿ formatಗೂ ಅನ್ವಯಿಸುತ್ತವೆ. ಎಲ್ಲವೂ ಆರಂಭದಲ್ಲಿ ಆನ್ ಆಗಿರುತ್ತವೆ.

- **Embed cover art**: ಪ್ರತಿ ಕಡತದಲ್ಲಿ cover ಇಡುತ್ತದೆ.
- **Cover image in the folder**: release save ಅದರ ಕಡತಕೋಶದಲ್ಲಿ `cover.jpg` ಕೂಡ ಬರೆಯುತ್ತದೆ.
- **Loudness tags**: import ಸಮಯದಲ್ಲಿ bae ಅಳೆದ loudnessನಿಂದ ಪ್ರತಿ ಕಡತದಲ್ಲಿ track ಮತ್ತು albumನ ReplayGain gain ಮತ್ತು peak ಬರೆಯುತ್ತದೆ.

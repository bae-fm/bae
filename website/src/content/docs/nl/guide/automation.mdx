## De MCP-server

Zet de MCP-server aan in Settings, Automation. Hij serveert het Model Context Protocol via HTTP op een lokale poort (standaard 47777), zodat MCP-clients zoals Claude door je bibliotheek kunnen bladeren, releases kunnen opzoeken en erop kunnen handelen. Toegang vereist een bearer token: kopieer die uit hetzelfde instellingenpaneel, en roteer hem daar wanneer je alles wat hem had wilt afsluiten.

De server staat standaard uit en draait alleen terwijl de app draait.

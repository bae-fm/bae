## Installatie

Download bae of baeium voor je platform. macOS gebruikt een dmg, iOS een handmatig geïnstalleerde ipa, Android een apk en Windows een uitgepakte exe. baeium gebruikt alleen S3-compatibele opslag.

## bae

bae gebruikt lokale identiteiten, een bibliotheeksleutel, vervangbare cloud homes en versleutelde changesets om meerdere apparaten te synchroniseren.

## Opslag

Bestanden kunnen zelfbeheerd, lokaal beheerd of cloudbeheerd zijn. Lokale bestanden spelen offline; cloudbestanden synchroniseren via cloud home.

## Versleuteling

Een opaque cloud home versleutelt data voordat die het apparaat verlaat. Een browsable cloud home bewaart onversleutelde bestanden op leesbare paden.

---

bae je správce hudební knihovny, který používá decentralizovanou identitu a end-to-end šifrování nad zaměnitelným úložištěm pro synchronizaci více zařízení bez vlastního serveru.

## Identita

Každé zařízení má místně vygenerovaný pár klíčů (Ed25519/X25519). Veřejné klíče jsou identity. Neexistuje centrální server identity.

## Šifrování

Jeden symetrický klíč na knihovnu, sdílený mezi zařízeními knihovny. Vše v cloud home se šifruje před opuštěním zařízení. Poskytovatel úložiště vidí opakní bloby. Viz [Šifrování](/cs/architecture/encryption).

## Úložiště

Zaměnitelné. Libovolný komerční cloudový poskytovatel (Google Drive, Dropbox, OneDrive, iCloud Drive), libovolný bucket kompatibilní se S3 (AWS, B2, R2, Wasabi, MinIO) nebo pouze místní režim bez cloudu. Jediný trait `CloudHome` abstrahuje rozdíly. Viz [Cloud Home](/cs/architecture/cloud-home).

## Synchronizace

Zařízení se synchronizují přes cloud home pomocí šifrovaných změnových sad. Každá úprava vytvoří kompaktní binární diff; ostatní zařízení ho stáhnou a použijí. Konflikty se řeší automaticky pravidlem poslední zápis vyhrává s hybridními logickými hodinami. Knihovna se synchronizuje mezi zařízeními přes členský řetěz a podepsané změnové sady. Viz [Synchronizace](/cs/storage/sync).

## Knihovny a umístění úložiště

**Knihovna** je hlavní entita: hudební kolekce s vlastní identitou (`library_id`), názvem a šifrovacím klíčem. Žije v **domově knihovny** na disku (`~/.bae/libraries/{uuid}/`), kam desktopová aplikace zapisuje autoritativní databázi.

Knihovna může volitelně mít **cloud home**: jedno cloudové umístění, například složku Google Drive nebo bucket S3, které slouží jako centrum synchronizace více zařízení. Jeden cloud home na knihovnu, nastavený v `config.yaml`. Podrobnosti jsou v [Cloud Home](/cs/architecture/cloud-home).

Soubory vydání mohou být v jednom nebo více těchto umístění:

- **Domov knihovny** (`~/.bae/libraries/{uuid}/storage/`) — místní kopie, dostupná offline
- **Cloud home** (`cloud-home/storage/`) — šifrovaná kopie, dostupná pro synchronizaci
- **Nespravované** — soubory zůstávají tam, kde jsou na disku; bae je jen indexuje

Vydání může být jen místní, jen cloudové nebo obojí. Jen cloudové soubory nejsou dostupné pro offline přehrávání.

## Rozvržení adresářů

### Domov knihovny

```
~/.bae/libraries/{uuid}/
  config.yaml                  # nastavení konkrétního zařízení (nesynchronizuje se)
  library.db                   # SQLite -- všechna metadata
  images/ab/cd/{id}            # obrázky knihovny (obaly, fotky interpretů)
  storage/ab/cd/{file_id}      # soubory vydání
```

`config.yaml` obsahuje nastavení konkrétního zařízení. Nesynchronizuje se. Přihlašovací údaje patří do klíčenky operačního systému, ne sem.

Soubory v `images/` a `storage/` používají rozvržení podle hashe: první 2 znaky ID tvoří prefixový adresář, další 2 podadresář. Na disku nejsou názvy souborů ani přípony; původní názvy a typy obsahu jsou v databázi. Stejné rozvržení je v domově knihovny i v cloud home.

### Cloud home

Cloud home zrcadlí data knihovny a přidává synchronizaci a řízení přístupu:

| Cesta | Účel |
|---|---|
| `snapshot.db.enc` | Úplný snapshot databáze pro nové zařízení |
| `changes/{device_id}/{seq}.enc` | Inkrementální změnové sady |
| `heads/{device_id}.json.enc` | Sekvenční čísla podle zařízení |
| `images/ab/cd/{id}` | Šifrované obrázky knihovny |
| `storage/ab/cd/{file_id}` | Šifrované soubory vydání |
| `membership/{pubkey}/{seq}.enc` | Položky členského řetězu |
| `keys/{user_pubkey}.enc` | Šifrovací klíče zabalené pro zařízení |

### Položky klíčenky

Spravuje je `KeyService` pomocí klíčenky operačního systému. Na macOS jde o chráněné datové úložiště se synchronizací iCloud Keychain. Všechny položky jsou namespacované podle `library_id`, pokud není uvedeno jinak.

| Položka | Rozsah | Účel |
|---|---|---|
| `encryption_master_key` | na knihovnu | Šifrování souborů a metadat |
| `cloud_home_credentials` | na knihovnu | Serializovaný enum: S3 přístup+secret, OAuth token nebo none (iCloud) |
| `discogs_api_key` | na knihovnu | Přístup k API Discogs |
| `bae_user_signing_key` | globální | Podepisovací klíč Ed25519 |
| `bae_user_public_key` | globální | Veřejný klíč Ed25519 |

## Dvě třídy souborů

### Soubory vydání

Všechny soubory, které přišly s vydáním: audio, obrázky, CUE sheety, logy atd. Jsou to data uživatele. bae je ukládá přesně tak, jak byla importována, aby bylo možné originály exportovat beze změny.

### Obrázky metadat

Obrázky, které bae vytváří a spravuje odděleně od souborů vydání:

- **Obaly vydání** — obrázky pro mřížky alb, detailní zobrazení a přehrávání. Jeden na vydání. Mohou pocházet ze souboru ve vydání nebo z MusicBrainz/Discogs. bae vytváří vlastní kopii, aby mohl ořezávat nebo měnit velikost bez vlivu na originál.
- **Obrázky interpretů** — načítané z externích zdrojů při importu.

## Toky prvního spuštění

**Nová knihovna**: při prvním spuštění desktopová aplikace ukáže uvítací obrazovku. Uživatel vytvoří novou knihovnu, což vygeneruje UUID, vytvoří adresářovou strukturu a spustí aplikaci. Adresář `storage/` začíná prázdný; soubory se objeví při importu.

**Obnovení z cloud home**: uživatel poskytne přihlašovací údaje cloud home a šifrovací klíč. bae stáhne snapshot, použije novější změnové sady a stáhne obrázky. Místní `storage/` začíná prázdné; soubory vydání se streamují z cloud home na vyžádání.

**Přechod z místního do cloudu**: uživatel se přihlásí ke cloudovému poskytovateli. bae vygeneruje šifrovací klíč, pokud je potřeba, odešle úplný snapshot, obrázky a soubory vydání a potom přejde na inkrementální synchronizaci.

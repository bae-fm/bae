bae během importu používá externí služby pro metadata a obrázky. Tady je, co každá služba poskytuje a jak ji nastavit.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> je otevřená hudební encyklopedie a hlavní zdroj metadat bae. Poskytuje:

- Úplné seznamy stop
- Informace o skupinách vydání
- Kódy ISRC
- Shodu CD TOC pro přesnou identifikaci CD
- Propojené externí adresy URL, včetně křížových odkazů Discogs

### Ověření

API klíč není potřeba. MusicBrainz je zdarma a otevřený.

### Limity požadavků

MusicBrainz vynucuje průměr 1 požadavek za sekundu na IP adresu. Při překročení vrací chyby 503 a může IP dočasně blokovat. bae požadavky automaticky rozkládá, aby limit dodržel.

### Další informace

Viz <a href="https://musicbrainz.org/doc/MusicBrainz_API" target="_blank">dokumentace MusicBrainz API</a> a <a href="https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting" target="_blank">podrobnosti k limitům</a>.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> je hudební databáze a tržiště. Hodí se hlavně pro:

- Vinylová vydání a lisování
- Detailní kredity: producent, zvukař atd.
- Katalogová čísla a čárové kódy
- Informace o labelech

### Ověření

Discogs vyžaduje osobní API token. Nastavíte ho při počáteční konfiguraci bae a potřebujete vlastní token.

### Limity požadavků

Discogs povoluje 60 ověřených požadavků za minutu. bae to spravuje automaticky.

### Začít

Token získáte v <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a>. Vložte ho při nastavení.

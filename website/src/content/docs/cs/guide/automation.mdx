Knihovnu může ovládat software, který spouštíte: AI agenti přes MCP a skripty přes nástroj příkazového řádku. Obě rozhraní zpřístupňují stejné operace, které používá uživatelské rozhraní: vyhledávání, detaily vydání, importy, akce s úložištěm a stav přehrávání.

## Server MCP

Server MCP zapnete v Settings, Automation. Poskytuje Model Context Protocol přes HTTP na místním portu (ve výchozím nastavení 47777), takže klienti MCP jako Claude mohou procházet knihovnu, vyhledávat vydání a provádět s nimi akce. Přístup vyžaduje bearer token: zkopírujte ho ve stejném panelu nastavení a tam ho také kdykoli obměňte, pokud chcete zrušit přístup všemu, co ho mělo.

Server je ve výchozím nastavení vypnutý a běží jen tehdy, když běží aplikace.

## Příkazový řádek

CLI `bae` ovládá stejné operace z terminálu: JSON dovnitř, JSON ven, vhodné pro skripty. Může také fungovat jako klient MCP a přemostit server desktopové aplikace na stdio pro nástroje, které očekávají místní proces MCP.

## Dvě edice

Každá platforma se dodává ve dvou edicích postavených ze stejného zdroje:

- **bae**, úplná aplikace: synchronizace přes S3, Google Drive, Dropbox, OneDrive a iCloud.
- **baeium**, bez proprietárních částí: jen úložiště kompatibilní se S3, žádní poskytovatelé OAuth, žádný iCloud/CloudKit, žádná telemetrie.

Instalují se vedle sebe, každá s vlastní knihovnou a vlastními klíči synchronizovanými přes iCloud Keychain. Níže vyberte tu, kterou chcete.

3. Otevřete ji z Applications

Obě edice se automaticky aktualizují přes vlastní kanál Sparkle.

## iOS

Sestavení pro iOS jsou **nepodepsané soubory `.ipa` pro ruční instalaci mimo App Store**. Nainstalujte je pomocí [AltStore](https://altstore.io) nebo [Sideloadly](https://sideloadly.io), případně je znovu podepište v Xcode vlastním Apple ID (bezplatné Apple ID funguje pro baeium). Distribuce přes App Store zatím není nastavená.

## Windows

Sestavení pro Windows jsou **nepodepsané** zipy aplikace bez instalačního balíčku. Rozbalte je a spusťte `bae.exe` / `baeium.exe`. SmartScreen může při prvním spuštění varovat.

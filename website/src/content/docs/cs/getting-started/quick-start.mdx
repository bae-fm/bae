## Přehled

bae pomáhá vytvořit a uspořádat hudební knihovnu. Můžete:

1. **Importovat hudbu** z místních souborů, jednotlivých stop nebo alb CUE/FLAC
2. **Doplnit metadata** automaticky z MusicBrainz a Discogs
3. **Procházet knihovnu** podle interpreta, alba, žánru nebo roku

## První import

### Import místních souborů

Nejjednodušší začátek je import hudby, kterou už máte:

1. Klikněte na **Import** v postranním panelu
2. Vyberte **Místní soubory**
3. Zvolte složku s hudbou
4. bae složku prohledá a ukáže, co našel
5. Vyberte odpovídající vydání z MusicBrainz nebo Discogs
6. Klikněte na **Import**

bae načte metadata, stáhne obrázky a uloží soubory podle zvolené možnosti úložiště.

### Umístění knihovny

Ve výchozím stavu bae ukládá metadata knihovny do:

- **macOS**: `~/.bae/libraries/<library-id>/`

Zvukové soubory se buď zašifrují a nahrají do cloud home, nebo se indexují na místě v samostatně spravovaném režimu. Podrobnosti jsou v [Přehledu úložiště](/cs/storage/overview).

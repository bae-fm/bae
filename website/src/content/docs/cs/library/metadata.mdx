bae při importu naplňuje knihovnu metadaty z online databází.

## Co se ukládá

Při importu alba bae uloží:

- **Informace o albu**: název, interpret, rok
- **Informace o stopách**: názvy, délky, čísla disků a stop
- **Obrázky**: obaly z MusicBrainz Cover Art Archive a Discogs
- **Informace o vydání**: label, katalogové číslo, čárový kód, země, formát
- **Externí ID**: ID vydání Discogs, ID vydání a interpreta MusicBrainz

Všechna metadata pocházejí z MusicBrainz a Discogs a ukládají se v databázi bae. bae nečte ani nezapisuje vložené tagy. Vaše soubory se nikdy nemění. Ať jsou spravované, tedy přesunuté do úložiště bae, nebo nespravované a ponechané na místě, bajty zůstávají stejné.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> je otevřená hudební encyklopedie a hlavní zdroj metadat bae. Poskytuje úplné seznamy stop, informace o skupinách vydání, kódy ISRC a shodu CD TOC pro přesnou identifikaci.

API klíč není potřeba. MusicBrainz je zdarma a otevřený. Vynucuje průměr 1 požadavek za sekundu na IP adresu; bae požadavky automaticky rozkládá.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> je hudební databáze a tržiště, zvlášť užitečné pro vinylová vydání, detailní kredity, katalogová čísla a informace o labelech.

Discogs vyžaduje osobní API token. Získejte ho v <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a> a vložte při nastavení. Limit je 60 ověřených požadavků za minutu; bae to spravuje automaticky.

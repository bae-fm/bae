bae synchronizuje knihovnu mezi více zařízeními přes cloud home. Každá úprava, import a smazání se automaticky přenese.

## Nastavení synchronizace

1. Přejděte do **Nastavení > Synchronizace**
2. Přihlaste se ke cloudovému poskytovateli (Google Drive, Dropbox, OneDrive), použijte iCloud Drive (macOS) nebo zadejte přihlašovací údaje S3
3. bae vygeneruje ID zařízení a začne synchronizovat

## Jak to funguje

Změny se synchronizují inkrementálně: každá úprava vytvoří malou změnovou sadu, která se zašifruje a nahraje do cloud home. Ostatní zařízení nové změnové sady stáhnou a použijí. bae synchronizuje po každé změně a každých 30 sekund zjišťuje změny z jiných zařízení. Pokud je cloud home nedostupný, synchronizace to zkusí v dalším cyklu.

Nová zařízení startují z pravidelného úplného snapshotu a potom použijí jen změnové sady po něm.

## Řešení konfliktů

Když dvě zařízení upraví stejná data, bae řeší konflikty automaticky pravidlem poslední zápis vyhrává. Pokud dvě zařízení upraví různá pole stejného vydání, obě změny zůstanou. Skutečné konflikty, tedy stejné pole na obou stranách, se řeší podle časové značky. Smazání vyhrává nad souběžnými úpravami.

## Co se synchronizuje

- Metadata: alba, stopy, interpreti, labely
- Obrázky alb a interpretů
- Soubory vydání, pokud jsou spravované bae

Nastavení konkrétního zařízení (`config.yaml`) se nesynchronizuje.

## Režimy

Synchronizace není všechno nebo nic:

- **Pouze místně** — bez cloud home, bez synchronizace. Vše zůstává na jednom zařízení.
- **Synchronizované mezi vašimi zařízeními** — změnové sady se synchronizují mezi zařízeními přes cloud home, každé s vlastním ID zařízení.

## Šifrování

Všechna data v cloud home jsou před nahráním zašifrována. Cloudový poskytovatel nikdy nevidí čitelný text. Viz [Šifrování](/cs/architecture/encryption).

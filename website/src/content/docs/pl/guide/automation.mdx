## Serwer MCP

Włącz serwer MCP w Settings, Automation. Udostępnia Model Context Protocol przez HTTP na lokalnym porcie (domyślnie 47777), więc klienci MCP, tacy jak Claude, mogą przeglądać bibliotekę, wyszukiwać wydania i wykonywać na nich działania. Dostęp wymaga tokenu bearer: skopiuj go z tego samego panelu ustawień i obróć go tam, gdy chcesz odciąć wszystko, co go miało.

Serwer jest domyślnie wyłączony i działa tylko wtedy, gdy działa aplikacja.

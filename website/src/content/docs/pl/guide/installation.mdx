## Dwie edycje

Każda platforma ma dwie edycje, zbudowane z tego samego źródła:

- **bae**, pełna aplikacja: synchronizacja z S3, Google Drive, Dropbox, OneDrive i iCloud.
- **baeium**, bez części własnościowych: tylko przechowywanie zgodne z S3, bez dostawców OAuth, bez iCloud/CloudKit, bez telemetrii.

Instalują się obok siebie, każda z własną biblioteką i własnymi kluczami synchronizowanymi przez iCloud Keychain. Wybierz poniżej tę, której chcesz używać.

1. Otwórz pobrany `.dmg`
2. Przeciągnij aplikację do folderu Applications
3. Otwórz ją z Applications

Obie edycje aktualizują się automatycznie przez własny kanał Sparkle.

## iOS

Kompilacje iOS to **niepodpisane pliki `.ipa` do sideloadingu**. Zainstaluj je przez [AltStore](https://altstore.io) albo [Sideloadly](https://sideloadly.io), albo podpisz ponownie w Xcode własnym Apple ID (darmowy Apple ID działa dla baeium). Dystrybucja przez App Store nie jest jeszcze skonfigurowana.

## Windows

Kompilacje Windows to **niepodpisane** archiwa zip niespakietowanej aplikacji. Rozpakuj i uruchom `bae.exe` / `baeium.exe`. SmartScreen może ostrzec przy pierwszym uruchomieniu.

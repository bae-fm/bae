## Przegląd

bae pomaga tworzyć i porządkować bibliotekę muzyczną. Możesz:

1. **Importować muzykę** z plików lokalnych: pojedynczych ścieżek albo albumów CUE/FLAC
2. **Uzupełniać metadane** automatycznie z MusicBrainz i Discogs
3. **Przeglądać bibliotekę** według wykonawcy, albumu, gatunku albo roku

## Pierwszy import

### Import plików lokalnych

Najprościej zacząć od importu muzyki, którą już masz:

1. Kliknij **Import** na pasku bocznym
2. Wybierz **Pliki lokalne**
3. Wskaż folder z muzyką
4. bae przeskanuje folder i pokaże, co znalazł
5. Wybierz pasujące wydanie MusicBrainz albo Discogs
6. Kliknij **Import**

bae pobiera metadane, pobiera grafikę i zapisuje pliki zgodnie z wybraną opcją przechowywania.

### Lokalizacja biblioteki

Domyślnie bae zapisuje metadane biblioteki w:

- **macOS**: `~/.bae/libraries/<library-id>/`

Pliki audio są szyfrowane i wysyłane do cloud home albo indeksowane w miejscu w trybie samodzielnie zarządzanym. Szczegóły są w [Przeglądzie przechowywania](/pl/storage/overview).

title: Synchronizacja
description: Synchronizuj bibliotekę między urządzeniami
---

bae synchronizuje bibliotekę na wielu urządzeniach przez cloud home. Każda edycja, import i usunięcie rozchodzi się automatycznie.

## Konfiguracja synchronizacji

1. Przejdź do **Ustawienia > Synchronizacja**
2. Zaloguj się u dostawcy cloud (Google Drive, Dropbox, OneDrive), użyj iCloud Drive (macOS) albo wpisz dane S3
3. bae generuje ID urządzenia i zaczyna synchronizację

## Jak to działa

Zmiany synchronizują się przyrostowo: każda edycja tworzy mały changeset, który jest szyfrowany i wysyłany do cloud home. Inne urządzenia pobierają i stosują nowe changesety. bae synchronizuje po każdej zmianie i odpytuje co 30 sekund, aby odebrać zmiany z innych urządzeń. Jeśli cloud home jest niedostępny, synchronizacja ponawia próbę w następnym cyklu.

Nowe urządzenia startują z okresowego pełnego snapshotu, a potem stosują tylko późniejsze changesety.

## Rozwiązywanie konfliktów

Gdy dwa urządzenia edytują te same dane, bae rozwiązuje konflikty automatycznie metodą ostatni zapis wygrywa. Jeśli dwa urządzenia edytują różne pola tego samego wydania, obie zmiany zostają. Prawdziwe konflikty, czyli to samo pole po obu stronach, są rozwiązywane według znacznika czasu. Usunięcia wygrywają z równoczesnymi edycjami.

## Co się synchronizuje

- Metadane: albumy, ścieżki, wykonawcy, labele
- Grafika albumów i obrazy wykonawców
- Pliki wydań, jeśli są zarządzane przez bae

Ustawienia specyficzne dla urządzenia (`config.yaml`) nie synchronizują się.

## Tryby

Synchronizacja nie jest wszystko albo nic:

- **Tylko lokalnie** — bez cloud home, bez synchronizacji. Wszystko zostaje na jednym urządzeniu.
- **Synchronizowane między twoimi urządzeniami** — changesety synchronizują się między urządzeniami przez cloud home, każde z własnym ID urządzenia.

## Szyfrowanie

Wszystkie dane w cloud home są szyfrowane przed wysłaniem. Dostawca cloud nigdy nie widzi tekstu jawnego. Zobacz [Szyfrowanie](/pl/architecture/encryption).

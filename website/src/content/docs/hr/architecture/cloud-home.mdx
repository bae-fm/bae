Cloud home je jedna udaljena lokacija pohrane za biblioteku: Google Drive mapa, S3 bucket, Dropbox mapa. Sadrži datoteke izdanja, changesetove metapodataka, slike, snapshotove i lanac članstva. U **neprozirnom** homeu (zadano) povjerenje je u kriptografiji, ne u backendu pohrane: pružatelj sprema šifrirani tekst na prikrivenim ključevima. Home može biti i **pregledljiv**, spremati sve nešifrirano na stabilne putove temeljene na id-ovima sa stvarnim nazivima datoteka; pogledajte [Načini pohrane](/hr/architecture/encryption#nacini-pohrane-neproziran-i-pregledljiv).

## Trait CloudHome

Trait `CloudHome` je apstrakcija zbog koje je bae neovisan o backendu. Sve iznad traita je univerzalno. Sve ispod prilagođava se konkretnom cloud pružatelju.

### Što je univerzalno (iznad traita)

- **Raspored cloud homea** — `changes/`, `heads/`, `snapshot.db`, `images/`, `storage/`, `membership/`, `keys/`. Isti logički putovi bez obzira na backend. Neprozirni home dijeli audio i slike pod `storage/` i `images/` prema hashu njihova id-ja; pregledljivi home ih stavlja pod ista dva prefiksa u stabilne id-putove sa stvarnim nazivima (`storage/{album_id}/{release_id}/{import_folder}/01 Track.flac`, `images/{album_id}/{release_id}/cover.jpg`).
- **Šifriranje** — jedan simetrični ključ po biblioteci; u neprozirnom homeu sve se šifrira prije izlaska s uređaja. Pregledljivi home preskače šifriranje i sprema čisti tekst; sufiks `.enc` se ne koristi.
- **Protokol sinkronizacije** — changesetovi, snapshotovi, rješavanje sukoba pravilom zadnji zapis pobjeđuje. Isti algoritam svugdje.
- **Lanac članstva** — append-only dnevnik s Ed25519 potpisima i ključem šifriranja omotanim za javni ključ svakog člana.

### Što varira (ispod traita)

- **API pohrane** — kako se datoteke stvarno čitaju i pišu: S3 API, Google Drive API, lokalni datotečni sustav itd.
- **Upravljanje pristupom** — kako novi uređaj dobiva pristup pohrani: pristup mapi ili izdavanje vjerodajnica.
- **Autentikacija** — kako se novi uređaj autentificira: vaš cloud račun ili ugrađene vjerodajnice.
- **Obavijesti o promjenama** — potrošački cloudovi podržavaju push obavijesti; S3 traži polling.

### Sučelje traita

```rust
trait CloudHome {
    // Storage -- same interface, different API underneath
    fn write(path, data) -> Result;
    fn read(path) -> Result<Bytes>;
    fn read_range(path, start, end) -> Result<Bytes>;
    fn list(prefix) -> Result<Vec<String>>;
    fn delete(path) -> Result;
    fn exists(path) -> Result<bool>;

    // Access management -- varies by backend
    fn grant_access(member_email_or_id) -> Result<JoinInfo>;
    fn revoke_access(member_email_or_id) -> Result;
}

Pozivatelji, poput sinkronizacijskog mehanizma, prijenosa slika i pohrane datoteka, izravno koriste ovo sučelje. Ne moraju znati s kojim backendom razgovaraju.
```

## Upravljanje pristupom

Kako rade `grant_access` i `revoke_access` ovisi o backendu. Potrošački cloudovi (Google Drive, Dropbox, OneDrive) dijele mapu preko API-ja pružatelja: prijavite se u račun na novom uređaju i mapa je već dostupna. S3-kompatibilni backendovi izdaju ograničene IAM vjerodajnice za svaki uređaj, ugrađene u pozivni kod.

U oba slučaja ključ šifriranja isporučuje se odvojeno preko lanca članstva, omotan za javni ključ novog uređaja.

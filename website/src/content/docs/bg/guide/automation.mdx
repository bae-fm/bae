Библиотеката може да се управлява от софтуер, който стартирате сами: AI агенти през MCP и скриптове през инструмент за командния ред. И двата пътя дават достъп до същите операции, които използва интерфейсът: търсене, подробности за издания, импортиране, действия със съхранението и състояние на възпроизвеждането.

## MCP сървърът

Включете MCP сървъра от Settings, Automation. Той предоставя Model Context Protocol през HTTP на локален порт (по подразбиране 47777), така че MCP клиенти като Claude могат да преглеждат библиотеката, да търсят издания и да действат върху тях. Достъпът изисква токен, който сам по себе си дава достъп: копирайте го от същия панел с настройки и го сменете там, когато искате да прекъснете достъпа на всичко, което го е имало.

Сървърът е изключен по подразбиране и работи само докато приложението работи.

## Командният ред

Инструментът `bae` за командния ред управлява същите операции от терминал: JSON на входа, JSON на изхода, подходящо за скриптове. Той може да действа и като MCP клиент, като свързва сървъра на настолното приложение към stdio за инструменти, които очакват локален MCP процес.

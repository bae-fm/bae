---
title: Преглед на съхранението
description: Как bae съхранява музикалните ви файлове
---

Файловете на издание могат да са на до три места. При импорт избирате **managed** или **unmanaged**. Managed файловете се копират в bae storage; unmanaged остават където са.

## Накратко

|                              | Unmanaged        | Managed — local    | Managed — cloud    |
|------------------------------|------------------|--------------------|--------------------|
| Файловете са в               | Вашето място     | `~/.bae/libraries/` | Cloud provider     |
| bae копира при импорт        | Не               | Да                 | Да                 |
| Offline достъп               | Да               | Да                 | Не                 |
| Шифрирано в покой            | Не               | Не                 | Само opaque home   |
| Sync към cloud               | Не               | Да                 | —                  |
| Sync към други устройства    | Не               | Не                 | Да                 |
| Delete release маха файлове  | Не               | Да                 | Да                 |

Unmanaged режимът индексира вече организирани файлове без местене, копиране или промяна. Managed local пази копие в `~/.bae/libraries/{uuid}/`. Managed cloud използва cloud home за multi-device sync.

### Opaque или browsable

**Opaque** шифрира всеки обект с library key и го пази в obfuscated path. **Browsable** пази plaintext с real filenames под id-keyed paths като `storage/{album_id}/{release_id}/{import_folder}/01 Track.flac` и `images/{album_id}/{release_id}/cover.jpg`. Browsable не е public; достъпът се контролира от provider credentials. Вижте [Шифриране](/bg/architecture/encryption#режими-на-съхранение-opaque-и-browsable).

### Поддържани providers

Google Drive, Dropbox и OneDrive използват OAuth. iCloud Drive на macOS използва iCloud container. S3-compatible включва AWS S3, Backblaze B2, Cloudflare R2, Wasabi, MinIO и изисква ръчна настройка.

## Как работи

1. Импортирайте издание и изберете **managed** или **unmanaged**
2. Managed import копира файловете в local library home
3. Ако има cloud home, файловете се качват и там: encrypted в opaque home, plaintext в browsable home
4. Други устройства със същия cloud home се sync-ват автоматично

Вижте [Синхронизация](/bg/storage/sync) и [Шифриране](/bg/architecture/encryption).

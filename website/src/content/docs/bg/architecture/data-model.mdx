## Библиотеки и места за съхранение

**Библиотека** е главният обект: музикална колекция с `library_id`, име и encryption key. Тя живее в **library home** на диска (`~/.bae/libraries/{uuid}/`), където desktop app пише authoritative database.

Библиотеката може да има **cloud home**: една cloud location, например Google Drive folder или S3 bucket. Един cloud home за библиотека, зададен в `config.yaml`. Вижте [Cloud Home](/bg/architecture/cloud-home).

Release files могат да са в library home (`~/.bae/libraries/{uuid}/storage/`), cloud home (`cloud-home/storage/`) или unmanaged.

## Directory layout

```
~/.bae/libraries/{uuid}/
  config.yaml                  # device-specific settings (not synced)
  library.db                   # SQLite -- all metadata
  images/ab/cd/{id}            # library images
  storage/ab/cd/{file_id}      # release files
```

Credentials се пазят в OS keyring. `images/` и `storage/` използват hash layout. Original filenames и content types са в database.

### Cloud home

| Path | Purpose |
|---|---|
| `snapshot.db.enc` | Full database snapshot |
| `changes/{device_id}/{seq}.enc` | Incremental sync changesets |
| `heads/{device_id}.json.enc` | Per-device sequence numbers |
| `images/ab/cd/{id}` | Encrypted library images |
| `storage/ab/cd/{file_id}` | Encrypted release files |
| `membership/{pubkey}/{seq}.enc` | Membership chain entries |
| `keys/{user_pubkey}.enc` | Wrapped encryption keys |

## Файлови класове

Release files са audio, images, CUE sheets, logs и други потребителски данни. Metadata images са копия на covers и artist images, които bae управлява.

## First-run flows

New library създава UUID и directory structure. Restore from cloud home изтегля snapshot и changesets. Going from local to cloud качва snapshot, images и release files, после включва incremental sync.

## Duas edições

Cada plataforma é publicada em duas edições, criadas a partir do mesmo código-fonte:

- **bae** — o app completo: sincronização com S3, Google Drive, Dropbox, OneDrive e iCloud.
- **baeium** — sem partes proprietárias: apenas armazenamento compatível com S3, sem provedores OAuth, sem iCloud/CloudKit e sem telemetria. Todo o código é Apache-2.0.

Elas podem ser instaladas lado a lado, cada uma com sua própria biblioteca e suas próprias chaves sincronizadas pelo iCloud Keychain. Escolha a edição abaixo.

As duas edições são atualizadas automaticamente pelo próprio feed do Sparkle.

## iOS

Os builds de iOS são **arquivos `.ipa` não assinados para sideloading**. Instale com [AltStore](https://altstore.io) ou [Sideloadly](https://sideloadly.io), ou assine novamente no Xcode com seu próprio Apple ID. Um Apple ID gratuito funciona para baeium. A distribuição pela App Store não está configurada.

## Windows

Os builds de Windows são zips **não assinados** do app sem empacotamento. Extraia e execute `bae.exe` ou `baeium.exe`. O SmartScreen pode avisar no primeiro início.

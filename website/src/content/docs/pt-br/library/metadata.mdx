bae preenche sua biblioteca com metadados de bancos de dados online durante a importação.

## O que é armazenado

Ao importar um álbum, bae salva:

- **Informações do álbum**: título, artista, ano
- **Informações das faixas**: nomes, durações, números de disco e faixa
- **Arte**: capas do MusicBrainz Cover Art Archive e Discogs
- **Informações da edição**: gravadora, número de catálogo, código de barras, país, formato
- **IDs externos**: ID de edição do Discogs, IDs de edição e artista do MusicBrainz

Todos os metadados vêm do MusicBrainz e Discogs e são armazenados no banco de dados do bae. bae não lê nem grava tags embutidas. Seus arquivos nunca são modificados. Sejam gerenciados, movidos para o armazenamento do bae, ou não gerenciados, deixados no lugar, os bytes permanecem iguais.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> é uma enciclopédia musical aberta e a fonte principal de metadados do bae. Ela fornece listas completas de faixas, informações de grupos de edições, códigos ISRC e correspondência de TOC de CD para identificação precisa.

Nenhuma chave de API é necessária. MusicBrainz é gratuito e aberto. Ele impõe média de 1 solicitação por segundo por endereço IP; bae espaça solicitações automaticamente.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> é um banco de dados musical e mercado, especialmente útil para edições em vinil, créditos detalhados, números de catálogo e informações de gravadoras.

Discogs exige um token pessoal de API. Obtenha o seu em <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a> e cole durante a configuração. O limite é 60 solicitações autenticadas por minuto; bae gerencia isso automaticamente.

title: Visão geral
description: Como bae é organizado
---

bae é um gerenciador de biblioteca musical que usa identidade descentralizada e criptografia de ponta a ponta sobre armazenamento intercambiável para sincronização multidispositivo sem servidor próprio.

## Identidade

Cada dispositivo tem um par de chaves gerado localmente (Ed25519/X25519). Chaves públicas são identidades. Não há servidor central de identidade.

## Criptografia

Uma chave simétrica por biblioteca, compartilhada entre os dispositivos da biblioteca. Tudo no cloud home é criptografado antes de sair do dispositivo. O provedor de armazenamento vê blobs opacos. Veja [Criptografia](/pt-br/architecture/encryption).

## Armazenamento

Intercambiável. Qualquer provedor cloud comercial (Google Drive, Dropbox, OneDrive, iCloud Drive), qualquer bucket compatível com S3 (AWS, B2, R2, Wasabi, MinIO) ou uso somente local sem nuvem. Um único trait `CloudHome` abstrai as diferenças. Veja [Cloud Home](/pt-br/architecture/cloud-home).

## Sincronização

Dispositivos sincronizam pelo cloud home usando changesets criptografados. Cada edição gera um diff binário compacto; outros dispositivos o baixam e aplicam. Conflitos são resolvidos automaticamente com last-writer-wins e relógios lógicos híbridos. Uma biblioteca sincroniza em vários dispositivos por meio de uma cadeia de membros e changesets assinados. Veja [Sincronização](/pt-br/storage/sync).

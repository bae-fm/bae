title: Sincronização

---

bae sincroniza sua biblioteca em vários dispositivos por meio do seu cloud home. Cada edição, importação e exclusão se propaga automaticamente.

## Configurar sincronização

1. Vá para **Configurações > Sincronização**
2. Entre com um provedor cloud (Google Drive, Dropbox, OneDrive), use iCloud Drive (macOS) ou informe credenciais S3
3. bae gera um ID de dispositivo e começa a sincronizar

## Como funciona

Mudanças são sincronizadas de forma incremental: cada edição gera um pequeno changeset que é criptografado e enviado ao cloud home. Outros dispositivos baixam e aplicam novos changesets. bae sincroniza após cada mudança e consulta a cada 30 segundos para pegar mudanças de outros dispositivos. Se o cloud home estiver inacessível, a sincronização tenta novamente no próximo ciclo.

Dispositivos novos começam a partir de um snapshot completo periódico e depois aplicam apenas os changesets posteriores.

## Resolução de conflitos

Quando dois dispositivos editam os mesmos dados, bae resolve conflitos automaticamente com last-writer-wins. Se dois dispositivos editam campos diferentes da mesma edição, as duas mudanças sobrevivem. Conflitos reais, o mesmo campo editado nos dois lados, são resolvidos por timestamp. Exclusões vencem edições concorrentes.

## O que sincroniza

- Metadados: álbuns, faixas, artistas, gravadoras
- Arte de álbum e imagens de artistas
- Arquivos de edições, se gerenciados pelo bae

Configurações específicas do dispositivo (`config.yaml`) não sincronizam.

## Modos

A sincronização não é tudo ou nada:

- **Somente local** — sem cloud home, sem sincronização. Tudo fica em um dispositivo.
- **Sincronizado entre seus dispositivos** — changesets sincronizam entre seus dispositivos pelo cloud home, cada um com seu próprio ID de dispositivo.

## Criptografia

Todos os dados no cloud home são criptografados antes do envio. O provedor cloud nunca vê texto em claro. Veja [Criptografia](/pt-br/architecture/encryption).

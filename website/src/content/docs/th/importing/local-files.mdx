## นำเข้า

bae สแกนโฟลเดอร์ หา release และอ่าน CUE/FLAC

## bae

bae ใช้ตัวตนในเครื่อง library key และ cloud home เพื่อ sync หลายอุปกรณ์

## พื้นที่จัดเก็บ

ไฟล์อาจเป็น self-managed, local-managed หรือ cloud-managed

## การเข้ารหัส

Opaque cloud home เข้ารหัสข้อมูลก่อนออกจากอุปกรณ์

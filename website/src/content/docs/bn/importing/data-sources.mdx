## মেটাডেটা

bae অ্যালবাম, ট্র্যাক, কভার, লেবেল, বারকোড এবং বাইরের ID সংরক্ষণ করে। অডিও ট্যাগ বদলায় না।

## bae

bae স্থানীয় পরিচয়, লাইব্রেরি কী এবং cloud home দিয়ে বহু ডিভাইস সিঙ্ক করে।

## স্টোরেজ

ফাইল self-managed, local-managed বা cloud-managed হতে পারে।

## এনক্রিপশন

Opaque cloud home ডেটা ডিভাইস ছাড়ার আগে এনক্রিপ্ট করে।

## দুই সংস্করণ

প্রতিটি প্ল্যাটফর্ম একই উৎস থেকে তৈরি দুই edition-এ আসে:

- **bae**, পূর্ণ app: S3, Google Drive, Dropbox, OneDrive, এবং iCloud সিঙ্ক।
- **baeium**, proprietary অংশ ছাড়া: শুধু S3-compatible সংরক্ষণ, কোনো OAuth provider নেই, কোনো iCloud/CloudKit নেই, কোনো telemetry নেই।

দুটিই পাশাপাশি ইনস্টল হয়, প্রতিটির নিজের লাইব্রেরি এবং নিজের (iCloud-Keychain-synced) কী থাকে। নিচে যেটি চান বেছে নিন।

## iOS

iOS build sideloading-এর জন্য **unsigned `.ipa` ফাইল**। [AltStore](https://altstore.io) বা [Sideloadly](https://sideloadly.io) দিয়ে ইনস্টল করুন, বা আপনার নিজের Apple ID দিয়ে Xcode-এ re-sign করুন (free Apple ID baeium-এর জন্য চলে)। App Store distribution এখনও set up নয়।

## Windows

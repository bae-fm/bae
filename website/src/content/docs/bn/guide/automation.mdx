## MCP সার্ভার

Settings, Automation-এ MCP সার্ভার চালু করুন। এটি স্থানীয় পোর্টে HTTP দিয়ে Model Context Protocol দেয় (ডিফল্ট 47777), তাই Claude-এর মতো MCP ক্লায়েন্ট আপনার লাইব্রেরি দেখতে, রিলিজ খুঁজতে, এবং সেগুলোর উপর কাজ করতে পারে। প্রবেশাধিকার পেতে bearer টোকেন লাগে: একই সেটিংস প্যান থেকে সেটি কপি করুন, আর যার কাছে আগে ছিল তাদের সবার প্রবেশ বন্ধ করতে চাইলে সেখানেই বদলে দিন।

সার্ভার ডিফল্টভাবে বন্ধ থাকে এবং অ্যাপ চলার সময়ই চলে।

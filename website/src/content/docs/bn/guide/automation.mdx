আপনার চালানো সফটওয়্যার দিয়েও লাইব্রেরি চালানো যায়: MCP দিয়ে AI এজেন্ট, আর কমান্ড-লাইন টুল দিয়ে স্ক্রিপ্ট। দুটিই UI যে কাজগুলো করে সেগুলোই দেয়: খোঁজা, রিলিজের বিবরণ দেখা, ইম্পোর্ট, সংরক্ষণ-সংক্রান্ত কাজ, আর প্লেব্যাকের অবস্থা।

## MCP সার্ভার

Settings, Automation-এ MCP সার্ভার চালু করুন। এটি স্থানীয় পোর্টে HTTP দিয়ে Model Context Protocol দেয় (ডিফল্ট 47777), তাই Claude-এর মতো MCP ক্লায়েন্ট আপনার লাইব্রেরি দেখতে, রিলিজ খুঁজতে, এবং সেগুলোর উপর কাজ করতে পারে। প্রবেশাধিকার পেতে bearer টোকেন লাগে: একই সেটিংস প্যান থেকে সেটি কপি করুন, আর যার কাছে আগে ছিল তাদের সবার প্রবেশ বন্ধ করতে চাইলে সেখানেই বদলে দিন।

সার্ভার ডিফল্টভাবে বন্ধ থাকে এবং অ্যাপ চলার সময়ই চলে।

## কমান্ড লাইন

`bae` CLI টার্মিনাল থেকে একই কাজগুলো চালায়: JSON ঢোকে, JSON বের হয়, স্ক্রিপ্টের জন্য উপযোগী। এটি MCP ক্লায়েন্ট হিসেবেও কাজ করতে পারে, ডেস্কটপের সার্ভারকে stdio-তে এনে এমন টুলের সঙ্গে যুক্ত করে যেগুলো স্থানীয় MCP প্রক্রিয়া আশা করে।

## समक्रमण

sync तुमच्या cloud home मधून होते. प्रत्येक बदल encrypted changeset तयार करतो.

## bae

अनेक डिव्हाइस sync करण्यासाठी bae स्थानिक ओळख, library key आणि cloud home वापरते.

## साठवण

फाइल्स self-managed, local-managed किंवा cloud-managed असू शकतात.

## कूटबद्धीकरण

Opaque cloud home डेटा डिव्हाइस सोडण्यापूर्वी कूटबद्ध करते.

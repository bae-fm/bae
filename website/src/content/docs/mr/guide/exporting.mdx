बंधनमुक्ती दोन्ही दिशांना लागू होते: bae आत येताना तुमच्या फाइल बदलत नाही, आणि बाहेर जाताना त्या अडवून ठेवत नाही. स्थानिक आवृत्ती आधीच तुमच्या संचयिकांमधील फाइल आहेत. क्लाउडमधील आवृत्ती कधीही byte-for-byte पुन्हा स्थानिक करता येते. आणि तुम्हाला *वेगळा* आकार हवा असेल, उदाहरणार्थ फोनसाठी योग्य encode, तेव्हा Save as… मूळ फाइलींना स्पर्श न करता तो तयार करते.

## दोन निर्याती

- **Export…**: album menu किंवा Storage manager मध्ये, आवृत्तीच्या फाइल byte-for-byte एका संचयिकेत कॉपी करते.
- **Save as…**: ट्रॅकवर, किंवा आवृत्तीसाठी album menu मध्ये, तुम्ही निवडलेल्या format मध्ये रूपांतर करते, उदाहरणार्थ कार किंवा फोनसाठी FLAC मधून MP3. ते नवीन फाइल लिहिते; मूळ फाइल आहेत तशाच राहतात.

दोन्ही प्रगती दाखवणाऱ्या रांगेत चालतात. तुम्ही त्यांना थांबवू आणि रद्द करू शकता; अयशस्वी काम तुम्ही रद्द करेपर्यंत त्याच्या त्रुटीसह रांगेत राहते. Save रांगेत ठेवताना असलेले format आणि settings राखते, त्यामुळे नंतर ते बदलल्याने रांगेत आधीपासून असलेल्या कशातही बदल होत नाही.

## Formats

Format म्हणजे एक नाव आणि एक codec: FLAC, WAV, AIFF, MP3, AAC किंवा Opus. ते Settings, Save as मध्ये **Formats** खाली ठेवलेले असतात. **Add format…** एक जोडते, आणि त्याच्या menu मधील **Edit…** आणि **Delete…** ते बदलतात किंवा काढतात. Format ला एक **Name**, एक **Format** आणि गुणवत्तेचे एक setting असते. नावे अद्वितीय असतात, पण दोन format एकच गोष्ट लिहू शकतात. नवीन format ला त्याच्या codec चे नाव मिळते, आणि नाव घेतलेले असल्यास क्रमांक जोडला जातो ("FLAC", "FLAC (2)"). FLAC आणि MP3 आधीपासून आहेत.

प्रत्येक format ट्रॅक आणि आवृत्ती दोन्हींसाठी चालतो. Save as window मध्ये **Format** pop-up सर्व format दाखवतो आणि तुम्ही शेवटी वापरलेल्यापासून सुरू होतो. त्याची शेवटची नोंद **Edit formats…** settings मध्ये Save as उघडते; pop-up तिथे झालेल्या बदलांचे अनुसरण करतो, आणि तिथे जोडलेला format लगेच निवडला जातो.

## गुणवत्ता

- **Bit depth**, FLAC, WAV आणि AIFF साठी: **Same as source** किंवा **16-bit**. Lossy स्रोताची स्वतःची depth नसते, म्हणून तो 16 bit वर लिहिला जातो.
- **Bitrate**, MP3, AAC आणि Opus साठी: त्या codec चा encoder जे bitrate लिहितो त्यांची यादी. MP3: 32, 40, 48, 56, 64, 80, 96, 112, 128, 160, 192, 224, 256, 320 kbps. AAC: 96, 128, 160, 192, 256, 320 kbps. Opus: 64, 96, 128, 160, 192, 256 kbps.

## नावे

Settings, Save as मध्ये **Names** खाली, एक **File name** pattern आणि एक **Folder name** pattern सर्व formatना लागू होतात. Pattern म्हणजे भागांची एक ओळ, जी तुम्ही पुन्हा लावता, काढता आणि जोडता, आणि ती जे नाव बनवते त्याचे preview दिसते. फाइलच्या नावात शीर्षक, कलाकार, अल्बम, वर्ष, ट्रॅक क्रमांक, डिस्क क्रमांक आणि एकूण ट्रॅक येऊ शकतात. संचयिकेच्या नावात कलाकार, अल्बम, वर्ष, label आणि catalog क्रमांक येऊ शकतात; आवृत्तीत नमूद नसलेला भाग वगळला जातो.

ट्रॅकवर Save as… patternचे नाव सुचवते, आणि दुसरा format निवडल्याने फक्त extension बदलते. आवृत्ती save केल्यास तिच्या फाइल folder patternने नाव दिलेल्या संचयिकेत लिहिल्या जातात. आवृत्ती save कधीही फाइल बदलत नाही: तुमच्या drive वर दोन नावे एकच फाइल होत असतील तर save अयशस्वी होते. एका ट्रॅकवर Save as… विद्यमान फाइल तुम्ही पुष्टी केल्यावरच बदलते.

## प्रत्येक ट्रॅकची एक फाइल

प्रत्येक save प्रत्येक ट्रॅकची एक फाइल लिहितो, अंतरांसाठी एकच नियम. Pregap, साठवलेला किंवा तयार केलेला, आधीच्या ट्रॅकच्या शेवटी जातो, आणि ट्रॅक 1 आधीचा लपलेला audio ट्रॅक 1 च्या सुरुवातीला राहतो. एक image आणि CUE sheet म्हणून साठवलेली आवृत्ती ट्रॅक खुणांवर विभागली जाते. Save as… CUE sheet लिहीत नाही.

## Encode करण्याऐवजी कॉपी

जो ट्रॅक पूर्ण फाइल आहे आणि निवडलेल्या lossless format मध्ये आधीच आहे, format जी depth लिहितो त्या depth वर, तो पुन्हा encode करण्याऐवजी कॉपी केला जातो. WAV आणि AIFF 16 किंवा 24 bit वर गणले जातात. त्याचे tags, cover आणि नाव नव्याने लिहिले जातात. Lossy format नेहमी encode करतो.

## अतिरिक्त

Settings, Save as मध्ये **Extras** खाली तीन switch प्रत्येक formatला लागू होतात. सर्व सुरुवातीला चालू असतात.

- **Embed cover art**: प्रत्येक फाइलमध्ये cover ठेवते.
- **Cover image in the folder**: आवृत्ती save त्याच्या संचयिकेत `cover.jpg` देखील लिहिते.
- **Loudness tags**: import च्या वेळी bae ने मोजलेल्या loudness वरून प्रत्येक फाइलमध्ये ट्रॅक आणि अल्बमचे ReplayGain gain आणि peak लिहिते.

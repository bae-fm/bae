तुम्ही चालवलेल्या सॉफ्टवेअरमधून ग्रंथालय वापरता येते: MCP वरचे AI प्रतिनिधी आणि कमांड-लाइन साधनावरच्या स्क्रिप्ट. दोन्ही UI वापरते तीच कामे देतात: शोध, आवृत्तीचे तपशील, आयाती, संचय कृती, वाजवण्याची स्थिती.

## MCP सर्व्हर

सेटिंग्ज, स्वयंचलन मध्ये MCP सर्व्हर चालू करा. तो Model Context Protocol स्थानिक पोर्टवर HTTP द्वारे देतो (मूळतः 47777), त्यामुळे Claude सारखे MCP क्लायंट तुमचे ग्रंथालय पाहू शकतात, आवृत्त्या शोधू शकतात आणि त्यांवर कृती करू शकतात. प्रवेशासाठी bearer token लागतो: तो त्याच सेटिंग्ज पेनमधून कॉपी करा, आणि तो ज्यांच्याकडे होता त्यांचा प्रवेश बंद करायचा असेल तेव्हा तिथेच बदलून टाका.

सर्व्हर मूळतः बंद असतो आणि अॅप चालू असतानाच चालतो.

## कमांड लाइन

`bae` CLI टर्मिनलमधून तीच कामे चालवते: JSON आत, JSON बाहेर, स्क्रिप्टसाठी योग्य. स्थानिक MCP प्रक्रिया अपेक्षित असलेल्या साधनांसाठी डेस्कटॉपचा सर्व्हर stdio वर जोडणारा MCP क्लायंट म्हणूनही ती काम करू शकते.

title: نظرة عامة على التخزين

يمكن أن توجد ملفات الإصدار في ما يصل إلى ثلاثة أماكن. عند استيراد إصدار تختار بين **مدار** و **غير مدار**. الملفات المدارة تنسخ إلى تخزين bae؛ الملفات غير المدارة تبقى في مكانها.

## لمحة

|                              | غير مدار        | مدار — محلي    | مدار — سحابي    |
|------------------------------|------------------|----------------|-----------------|
| مكان الملفات                 | موقعك أنت        | `~/.bae/libraries/` | مزود السحابة |
| bae ينسخ الملفات عند الاستيراد | لا               | نعم            | نعم             |
| متاح دون اتصال               | نعم              | نعم            | لا              |
| مشفر أثناء التخزين           | لا               | لا             | opaque home فقط |
| يمكن رفعه إلى السحابة        | لا               | نعم            | —               |
| يتزامن مع أجهزة أخرى         | لا               | لا             | نعم             |
| حذف الإصدار يحذف الملفات     | لا               | نعم            | نعم             |

يمكن أن تكون للإصدار المدار ملفات محلية أو سحابية أو الاثنان معًا. إذا كان cloud home معدًا، فالاستيراد المدار يكتب إلى الاثنين.

## غير مدار

وجه bae إلى ملفات رتبتها مسبقًا. يفهرسها bae لكنه لا ينقلها ولا ينسخها ولا يغيرها. إذا كانت لديك مجموعة كبيرة مرتبة بطريقتك، فهذا يضيفها إلى الفهرس دون تكرار الملفات.

الحد هنا أن bae لا يستطيع تشفير الملفات غير المدارة أو مزامنتها أو نسخها احتياطيًا.

## مدار — محلي

لكل مكتبة مجلد home على جهازك (`~/.bae/libraries/{uuid}/`). يحتفظ bae فيه بقاعدة البيانات والصور، وبنسخة محلية من ملفات الإصدارات المدارة.

عند استيراد إصدار كمدار، ينسخ bae الملفات إلى library home. تبقى ملفاتك الأصلية كما هي. النسخة المحلية هي التي يشغلها bae.

## مدار — سحابي

cloud home موقع تخزين بعيد واحد يحفظ ملفات الإصدارات، وتغييرات البيانات الوصفية، والصور، واللقطات. إعداده يتيح المزامنة بين الأجهزة والنسخ السحابي.

عند استيراد إصدار مدار مع إعداد cloud home، ينسخ bae الملفات إلى library home ويرفعها أيضًا إلى cloud home. يحدث الأمران وقت الاستيراد.

الإصدار الموجود فقط في cloud home، مثل إصدار تزامن من جهاز آخر ولم ينزل بعد، لا يكون متاحًا للتشغيل دون اتصال حتى تسحب ملفاته محليًا.

### Opaque أو browsable

عند إعداد cloud home تختار طريقة تخزين الكائنات، وهذا متاح لكل مزود:

- **Opaque** (الافتراضي) يشفر كل كائن بمفتاح المكتبة ويخزنه في مسار مبهم. يرى المزود النص المشفر فقط.
- **Browsable** يخزن كل شيء بلا تشفير مع أسماء الملفات الحقيقية، في مسارات ثابتة مبنية على المعرفات مثل `storage/{album_id}/{release_id}/{import_folder}/01 Track.flac` لملفات الإصدار و `images/{album_id}/{release_id}/cover.jpg` للصور. يمكنك فتح التخزين وتشغيل ملفاتك أو نسخها بأي أداة. ليس browsable عامًا؛ الوصول ما زال محكومًا ببيانات اعتماد المزود.

راجع [التشفير](/ar/architecture/encryption#أوضاع-التخزين-opaque-و-browsable) للمقارنة الكاملة.

### المزودون المدعومون

- **Google Drive** — تسجيل دخول OAuth، وينشئ bae مجلدًا في Drive
- **Dropbox** — تسجيل دخول OAuth
- **OneDrive** — تسجيل دخول OAuth
- **iCloud Drive** (macOS) — يستخدم حاوية iCloud، بلا تسجيل دخول
- **متوافق مع S3** — أي bucket مثل AWS S3 و Backblaze B2 و Cloudflare R2 و Wasabi و MinIO

مزودو السحابة الاستهلاكية يستخدمون OAuth ولا يحتاجون إلى مفاتيح API أو إعداد bucket. iCloud Drive على macOS يستخدم حاوية iCloud الحالية. مزودو S3 يحتاجون إلى إعداد بيانات الاعتماد يدويًا.

## طريقة العمل

1. استورد إصدارًا واختر **مدار** أو **غير مدار**
2. الاستيراد المدار ينسخ الملفات إلى library home محليًا
3. إذا كان cloud home معدًا، ترفع الملفات إليه أيضًا: مشفرة في opaque home، وواضحة في browsable home
4. الأجهزة الأخرى المتصلة بنفس cloud home تتزامن تلقائيًا

راجع [المزامنة](/ar/storage/sync) و [التشفير](/ar/architecture/encryption).

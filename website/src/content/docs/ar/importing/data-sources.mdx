---

يستخدم bae خدمات خارجية أثناء الاستيراد لجلب البيانات الوصفية والصور. هذه هي وظيفة كل خدمة وطريقة إعدادها.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> موسوعة موسيقية مفتوحة، وهي المصدر الأساسي للبيانات الوصفية في bae. توفر:

- قوائم مقطوعات كاملة
- معلومات مجموعات الإصدارات
- رموز ISRC
- مطابقة CD TOC لتحديد الأقراص بدقة
- روابط خارجية، بما فيها مراجع Discogs

### المصادقة

لا يلزم مفتاح API. MusicBrainz مجاني ومفتوح.

### حدود الطلبات

يفرض MusicBrainz متوسط طلب واحد في الثانية لكل عنوان IP. عند تجاوز ذلك يعيد أخطاء 503 وقد يحظر عنوان IP مؤقتًا. يباعد bae بين الطلبات تلقائيًا للبقاء داخل الحد.

### المزيد

راجع <a href="https://musicbrainz.org/doc/MusicBrainz_API" target="_blank">توثيق MusicBrainz API</a> و <a href="https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting" target="_blank">تفاصيل حدود الطلبات</a>.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> قاعدة بيانات وسوق للموسيقى، وهي مفيدة خصوصًا في:

- إصدارات الفينيل والطبعات
- الاعتمادات التفصيلية مثل المنتج والمهندس
- أرقام الكتالوج والرموز الشريطية
- معلومات شركات النشر

### المصادقة

يتطلب Discogs رمز API شخصيًا. تعده أثناء الإعداد الأولي في bae، وتحتاج إلى رمزك الخاص.

### حدود الطلبات

يسمح Discogs بـ 60 طلبًا موثقًا في الدقيقة. يتعامل bae مع ذلك تلقائيًا.

### البدء

احصل على الرمز من <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a>، ثم الصقه أثناء الإعداد.

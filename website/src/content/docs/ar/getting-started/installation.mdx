## إصداران

كل منصة تصدر بإصدارين مبنيين من المصدر نفسه:

- **bae** — التطبيق الكامل: مزامنة S3 و Google Drive و Dropbox و OneDrive و iCloud.
- **baeium** — بلا أجزاء مملوكة: تخزين متوافق مع S3 فقط، بلا مزودي OAuth، بلا iCloud/CloudKit، وبلا قياسات استخدام. كل السطور مرخصة Apache-2.0.

يمكن تثبيت الإصدارين معًا، ولكل واحد مكتبة ومفاتيح خاصة به. اختر الإصدار المناسب أدناه.

## iOS

بناءات iOS هي **ملفات `.ipa` غير موقعة للتثبيت الجانبي**. ثبّتها باستخدام [AltStore](https://altstore.io) أو [Sideloadly](https://sideloadly.io)، أو أعد توقيعها في Xcode باستخدام Apple ID الخاص بك (حساب مجاني يعمل مع baeium). توزيع App Store غير معد بعد.

## Windows

بناءات Windows هي ملفات zip **غير موقعة** للتطبيق غير المعبأ. فك الضغط وشغّل `bae.exe` أو `baeium.exe`. قد يظهر تحذير SmartScreen عند التشغيل الأول.

membership لمكتبة هو مجموعة الأجهزة المصرح لها بقراءتها والكتابة إليها. تشرح هذه الصفحة الآليات التقنية وراء ذلك: الهوية، و membership chain، وحزم التغييرات الموقعة، ولف المفاتيح.

## الهوية

لكل جهاز زوج مفاتيح Ed25519/X25519 يولد عند أول استخدام ويحفظ في keyring نظام التشغيل. المفاتيح العامة هي الهويات. لا يوجد دليل مركزي أو خادم حسابات. يتم تبادل المفاتيح العامة خارج النظام.

## Membership chain

تتبع membership المكتبة بسلسلة إلحاقية من إدخالات موقعة محفوظة في cloud home عند `membership/{pubkey}/{seq}.enc`. كل إدخال يسجل عملية Add أو Remove، والمفتاح العام للجهاز الهدف ودوره، ويوقعه owner حالي.

الإدخال الأول دائمًا هو الجهاز المنشئ، مضافًا كـ owner. عند بناء السلسلة يتم التحقق منها؛ الإدخالات ذات التوقيعات غير الصالحة أو القادمة من غير owner ترفض.

## حزم التغييرات الموقعة

كل حزمة تغييرات تدفع إلى cloud home يوقعها جهاز المؤلف بمفتاح Ed25519. عند السحب، يتحقق bae من أن المؤلف كان جهازًا مصرحًا عند إنشاء الحزمة، وذلك بفحص membership chain. الحزم من أجهزة غير مصرح لها أو بتوقيعات غير صالحة تهمل.

## لف المفتاح

مفتاح تشفير المكتبة يلف، أي يشفر بأسلوب sealed box، إلى مفتاح X25519 العام لكل جهاز، ويحفظ في cloud home عند `keys/{user_pubkey}.enc`. لا يستطيع فتحه إلا المستلم المقصود بمفتاحه الخاص. عند إلغاء جهاز، يولد مفتاح تشفير جديد ويعاد لفه لكل الأجهزة الباقية.

## رموز الدعوة

رمز الدعوة يجمع كل ما يحتاجه الجهاز المنضم:

- مفتاح تشفير المكتبة، مشفرًا بأسلوب sealed box إلى المفتاح العام للجهاز الجديد
- إحداثيات cloud home: نوع المزود، معرف المجلد أو bucket
- بيانات اعتماد التخزين: في S3 بيانات IAM مولدة، وفي السحابات الاستهلاكية تتم مشاركة المجلد عبر API المزود
- إدخال membership موقع يضيف الجهاز الجديد

ينشئ جهاز owner الرمز بعد استلام المفتاح العام للجهاز الجديد. يلصقه الجهاز الجديد في bae، فيفتح مفتاح التشفير، ويتصل بـ cloud home، ويبدأ المزامنة.

لا يملك bae خادمًا خاصًا به. كل جهاز عميل يقرأ ويكتب cloud home مشتركًا؛ كل المزامنة تمر عبر ذلك التخزين، لا عبر آلة يديرها bae.

## cloud home هو نقطة الالتقاء

[cloud home](/ar/architecture/cloud-home) للمكتبة هو bucket أو مجلد في خلفية تخزين تتحكم بها: تخزين متوافق مع S3، أو Google Drive، أو Dropbox، أو OneDrive، أو iCloud. كل جهاز:

- يدفع حزم تغييرات قاعدة البيانات وملفات الإصدارات المشفرة إلى cloud home
- يسحب تغييرات الأجهزة الأخرى منه في كل دورة مزامنة

أجهزتك لا تتحدث مع بعضها مباشرة. تصل إلى الحالة نفسها لأنها تتزامن مع cloud home نفسه.

## ما الذي يوجد في cloud home

- ملفات إصدارات مشفرة مثل الصوت والصور
- لقطات قاعدة بيانات وحزم تغييرات مشفرة
- صور مكتبة مشفرة
- membership chain التي تسجل من يستطيع القراءة أو الكتابة

## تخزين لا يعرف المحتوى

خلفية التخزين لا تحمل المفاتيح ولا تفك التشفير. كل blob يشفر على العميل قبل الرفع ويفك على العميل بعد التنزيل. لا يعرف cloud home محتويات مكتبتك ولا بياناتها الوصفية ولا مفاتيح التشفير، ولا يستطيع قراءة موسيقاك أو البحث فيها أو فهرستها. هو تخزين فقط.

إضافة جهاز آخر هي منح [membership](/ar/architecture/membership) على التخزين المشترك نفسه؛ لا يوجد خادم للاتصال به.

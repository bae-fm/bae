يمكن تشغيل المكتبة ببرامج تشغّلها أنت: وكلاء AI عبر MCP، وسكربتات عبر أداة سطر أوامر. يعرّض كلاهما العمليات نفسها التي تستخدمها الواجهة: البحث، تفاصيل الإصدارات، الاستيراد، إجراءات التخزين، وحالة التشغيل.

## خادم MCP

شغّل خادم MCP من Settings، Automation. يقدّم Model Context Protocol عبر HTTP على منفذ محلي (47777 افتراضيًا)، بحيث تستطيع عملاء MCP مثل Claude تصفح مكتبتك، والبحث عن الإصدارات، والتصرف عليها. يتطلب الوصول رمز bearer token: انسخه من لوحة الإعدادات نفسها، وبدّله هناك عندما تريد قطع الوصول عن كل ما كان يحمله.

الخادم متوقف افتراضيًا، ولا يعمل إلا أثناء عمل التطبيق.

## سطر الأوامر

تشغّل واجهة `bae` CLI العمليات نفسها من الطرفية: JSON يدخل، وJSON يخرج، بما يناسب السكربتات. ويمكنها أيضًا العمل كعميل MCP، فتصل خادم سطح المكتب إلى stdio للأدوات التي تتوقع عملية MCP محلية.

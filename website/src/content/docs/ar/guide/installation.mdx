## إصداران

يصدر كل نظام بإصدارين، مبنيين من المصدر نفسه:

- **bae**، التطبيق الكامل: مزامنة S3، وGoogle Drive، وDropbox، وOneDrive، وiCloud.
- **baeium**، بلا أجزاء مملوكة: تخزين متوافق مع S3 فقط، بلا مزودي OAuth، ولا iCloud/CloudKit، ولا telemetry.

يُثبَّتان جنبًا إلى جنب، ولكل واحد مكتبته ومفاتيحه الخاصة (المتزامنة عبر iCloud Keychain). اختر ما تريد أدناه.

## iOS

بُنى iOS هي **ملفات `.ipa` غير موقعة للتحميل الجانبي**. ثبّتها باستخدام [AltStore](https://altstore.io) أو [Sideloadly](https://sideloadly.io)، أو أعد توقيعها في Xcode باستخدام Apple ID الخاص بك (يعمل Apple ID مجاني مع baeium). توزيع App Store غير معد بعد.

## Windows

بُنى Windows هي ملفات zip **غير موقعة** للتطبيق غير المحزوم. استخرجها وشغّل `bae.exe` / `baeium.exe`. قد يحذر SmartScreen عند أول تشغيل.

يملأ bae مكتبتك ببيانات وصفية من قواعد بيانات على الإنترنت أثناء الاستيراد.

## ما الذي يحفظ

عند استيراد ألبوم، يحفظ bae:

- **معلومات الألبوم**: العنوان، الفنان، السنة
- **معلومات المقطوعات**: الأسماء، المدد، أرقام الأقراص والمقطوعات
- **الصور**: أغلفة من MusicBrainz Cover Art Archive و Discogs
- **معلومات الإصدار**: شركة النشر، رقم الكتالوج، الرمز الشريطي، البلد، الصيغة
- **معرفات خارجية**: Discogs release ID و MusicBrainz release ID و artist ID

كل البيانات الوصفية تأتي من MusicBrainz و Discogs وتحفظ في قاعدة بيانات bae. لا يقرأ bae ولا يكتب الوسوم المضمنة في الملفات. سواء كانت الملفات مدارة أو غير مدارة، تبقى بايتات الملفات كما هي.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> موسوعة موسيقية مفتوحة والمصدر الأساسي للبيانات الوصفية في bae. توفر قوائم مقطوعات كاملة، ومعلومات مجموعات الإصدارات، ورموز ISRC، ومطابقة CD TOC للتعرف الدقيق.

لا يلزم مفتاح API. MusicBrainz مجاني ومفتوح. يفرض متوسط طلب واحد في الثانية لكل IP، ويفصل bae الطلبات تلقائيًا.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> قاعدة بيانات وسوق للموسيقى، مفيدة خصوصًا لإصدارات الفينيل، والاعتمادات التفصيلية، وأرقام الكتالوج، ومعلومات شركات النشر.

يتطلب Discogs رمز API شخصيًا. احصل عليه من <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a> والصقه أثناء الإعداد. الحد هو 60 طلبًا موثقًا في الدقيقة، ويتعامل معه bae تلقائيًا.

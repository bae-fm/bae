## Two editions

Every platform ships in two editions, built from the same source:

- **bae**, the full app: S3, Google Drive, Dropbox, OneDrive, and iCloud sync.
- **baeium**, no proprietary parts: S3-compatible storage only, no OAuth providers, no iCloud/CloudKit, no telemetry.

They install side by side, each with its own library and its own (iCloud-Keychain-synced) keys. Pick whichever you like below.

1. Open the downloaded `.dmg`
2. Drag the app to your Applications folder
3. Open it from Applications

Both editions auto-update through their own Sparkle feed.

## iOS

iOS builds are **unsigned `.ipa` files for sideloading**. Install with [AltStore](https://altstore.io) or [Sideloadly](https://sideloadly.io), or re-sign in Xcode with your own Apple ID (a free Apple ID works for baeium). App Store distribution isn't set up yet.

## Windows

The Windows download is an installer that installs per-user and keeps itself up to date. Builds are not code-signed, so SmartScreen may warn on first launch. A portable zip that runs in place is also attached to each [GitHub release](https://github.com/bae-fm/bae/releases).

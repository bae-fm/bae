bae இல் எங்கும் கணக்கு அமைப்பு இல்லை. நூலகத்தின் ஒவ்வொரு நபரும் ஒரு coven *உறுப்பினர்*: சீரற்ற, நிலையான உறுப்பினர் id உம் இரண்டு திறவுகோல் இணைகளும், ஒன்று கையொப்பத்துக்கு, ஒன்று திறவுகோல்கள் அதற்கு முத்திரையிடப்படுவதற்கு; அந்த நபரின் எல்லாச் சாதனங்களும் அவற்றைப் பகிர்ந்து ஒவ்வொரு சாதனத்தின் OS திறவுகோல் காப்பகத்திலும் வைத்திருக்கும். சாதனம் என்பது ஒரு நிறுவல், தன் சொந்த id உடன், ஓர் உறுப்பினருக்குச் சொந்தமானது. நூலகத்தில் யார் உள்ளனர் என்பது மேக இல்லத்தில் உள்ள கையொப்பமிட்ட பதிவுகளின் தொகுப்பு; ஒவ்வொரு உறுப்பினரின் சாதனமும் அவற்றைச் சரிபார்க்கும், எந்தச் சேவையகமும் வழங்குவதில்லை. அமைப்பு [coven](https://coven.bae.fm) உடையது; bae அதை எப்படிப் பயன்படுத்துகிறது என்பதை இந்தப் பக்கம் காட்டுகிறது.

## Membership records

மேக இல்லத்தில் நூலகத்தின் முழு வரலாறும் ஒரு எண்ணிட்ட வரிசை, ஒவ்வொரு சாதனமும் அதை ஒரே ஒழுங்கில் பயன்படுத்தும். உறுப்பினர் நிலை அல்லது அமைப்புகளின் மாற்றம் அந்த வரிசையில் ஒரு *admin entry*, எழுதியவரின் திறவுகோலால் கையொப்பமிடப்பட்டு, அதற்கு உடனடியாக முந்தைய நிலையின் அடிப்படையில் தீர்மானிக்கப்படும்; அதனால் ஒவ்வொரு சாதனமும் தானாகவே அதே முடிவை அடையும். எழுதியவருக்கு அதைச் செய்யும் உரிமை இருந்தால் மட்டுமே entry கணக்கில் எடுக்கப்படும், நூலகம் எப்போதும் குறைந்தது ஒரு admin ஐ வைத்திருக்கும்.

சாதனம் அனுப்பும் ஒவ்வொரு மாற்றமும் இந்தப் பதிவுக்கு எதிராகச் சரிபார்க்கப்படும்: தற்போதைய உறுப்பினரின் கையொப்பம், அகற்றப்படாத சாதனத்திலிருந்து. அகற்றப்பட்ட சாதனங்கள் அல்லது உறுப்பினர்களிடமிருந்து, ஒருபோதும் சேர்க்கப்படாத திறவுகோல்களிடமிருந்து, அல்லது தவறான கையொப்பங்களுடன் வரும் மாற்றங்கள் கணக்கில் எடுக்கப்படாது. வழங்குநர் பதிவுகளை வைத்திருப்பார், ஆனால் போலியாக்க முடியாது.

## Roles

**Admin** மற்றும் **உறுப்பினர்** இருவரும் நூலகத்தைப் படித்து எழுதுவர்: coven நூலகத்தில் எழுதும் போது எந்த அனுமதியையும் சரிபார்ப்பதில்லை, அதனால் படிக்க-மட்டும் பங்கு நிலைக்க முடியாது. admin கள் கூடுதலாக நபர்களை அழைக்கவும் அகற்றவும், பங்குகளை மாற்றவும், நூலகத்தின் பெயரை மாற்றவும் செய்வர். நூலகத்துக்கு அதன் மேக இல்லத்தைத் தரும் நபர் அதன் முதல் admin.

| செயல் | யார் |
|---|---|
| நபரை அழைத்தல் | admin |
| சாதனத்தைச் சேர்த்தல் | நபரே, புதிய சாதனத்திலிருந்து, தன் restore code உடன் |
| சாதனத்தை அகற்றுதல் | அதன் நபர், அல்லது எந்த admin உம் |
| நபரை அகற்றுதல் | admin |
| நூலகத்தின் பெயரை மாற்றுதல் | admin |

நபரின் profile, மதிப்பீடுகள், வரலாறு, playlists ஆகியவை owner வரிசைகள்: அந்த நபரின் சாதனங்கள் மட்டுமே அவற்றை மாற்ற முடியும், அதனால் ஒருவர் பெயரில் பதிவான மதிப்பீடு உண்மையில் அவருடையதே.

## உங்கள் சொந்த சாதனத்தைச் சேர்த்தல்

restore code சாதனம் அதன் நபருக்குச் சொந்தமானது என்பதை நிரூபிக்கும், அதனால் எந்த ஒப்புதலும் தேவையில்லை:

1. புதிய சாதனம் குறியீட்டைப் பெறும்: நபரின் மற்றொரு சாதனம் காட்டும் QR குறியீட்டை ஸ்கேன் செய்து, Apple சாதனங்களில் iCloud Keychain இலிருந்து, அல்லது தட்டச்சு செய்து.
2. அது சேமிப்பை அடையும்: Dropbox, OneDrive இல் நபரின் சொந்தக் கணக்கில் உள்நுழைந்து, S3 இல் அவரின் access key மூலம், அதை QR குறியீடு குறியீட்டுடன் கொண்டுவரும்.
3. அது நூலகத்தை ஏற்றி, குறியீட்டின் திறவுகோல்கள் தற்போதைய உறுப்பினருடையவை எனச் சரிபார்த்து, அந்தத் திறவுகோல்களால் கையொப்பமிட்ட entry மூலம் தன்னைப் புதிய சாதனமாகப் பதிவு செய்யும்.

திறவுகோல்கள் பின்னர் மாறிய குறியீடு தோல்வியடையும். மீட்டெடுத்தல் எப்போதும் புதிய சாதனத்தை உருவாக்கும்; அது மற்றொரு நிறுவலின் அனுப்பப்படாத திருத்தங்களைக் காப்பாற்றாது.

## ஒரு நபரை அழைத்தல்

1. admin நபரின் வழங்குநர் கணக்கை உள்ளிட்டு அவரின் பங்கைத் தேர்ந்தெடுப்பார். bae நூலகத்தின் அடைவை அந்தக் கணக்குடன் பகிரும், அல்லது S3 இல் அவருக்காக access key உருவாக்கும், பின் அழைப்பைக் காட்டும்: நூலகத்தின் இடம், அந்த நபருக்காகத் தேர்ந்த உறுப்பினர் id, ஒருமுறை பயன்படும் ரகசியம், நூலகத்தின் தற்போதைய பெயர் கொண்ட QR குறியீடு. அது உருவாக்கப்பட்டு ஒரு நாளுக்குப் பின் காலாவதியாகும்.
2. நபரின் சாதனம் அதை ஸ்கேன் செய்து, அவரின் சொந்தக் கணக்கில் உள்நுழைந்து, அவரின் திறவுகோல் இணைகளை உருவாக்கி, சேமிப்பில் சேரும் கோரிக்கையை எழுதும்; அது அழைப்பின் ரகசியத்திலிருந்து பெற்ற திறவுகோலால் மறைகுறியாக்கப்பட்டு, அவரின் புதிய திறவுகோலால் கையொப்பமிடப்பட்டது.
3. ரகசியத்தை வைத்திருக்கும் ஒரே சாதனமான admin இன் சாதனம் கோரிக்கையைக் காட்டும், admin அதற்கு ஒப்புதல் அளிப்பார்.
4. ஒப்புதல் ஒவ்வொரு store key ஐயும் நபரின் புதிய முத்திரைத் திறவுகோலுக்கு முத்திரையிட்டு, பின் அவரை ஏற்கும் entry ஐச் சேர்க்கும்.
5. புதிய சாதனம் தன் திறவுகோல்களைத் திறந்து, நூலகத்தை ஏற்றி, தன்னைப் பதிவு செய்து, நபர் தட்டச்சு செய்த பெயருடன் அவரின் profile ஐ எழுதும்.

அழைப்பை மறுத்தால், அல்லது காலாவதியாக விட்டால், அது வழங்கிய வழங்குநர் அணுகல் திரும்பப் பெறப்படும்.

## அகற்றுதல்

சாதனத்தையோ நபரையோ அகற்றுவது ஒரு admin entry; வரிசையில் அதன் இடம் வரலாற்றில் ஒரு கோடு: அகற்றப்பட்ட சாதனம் அல்லது நபர் அதன் பின் அனுப்புவது கணக்கில் எடுக்கப்படாது, முன்பே வந்தது அப்படியே இருக்கும். நபரை அகற்றுவது அவரின் சாதனங்களையும் தனிப்பட்ட circle ஐயும் அகற்றும், அவரிடம் இருந்த திறவுகோல்கள் மேலும் தரவு எழுதப்படும் முன் மாற்றப்படும் ([மறைகுறியாக்கம்](/ta/reference/encryption#திறவுகோல்-சுழற்சி) பார்க்கவும்). சேமிப்பு அணுகலைத் துண்டிப்பது வழங்குநரின் வேலை: நூலகம் உள்ள கணக்கின் சாதனம் அடைவின் பகிர்வை நிறுத்தும், S3 இல் நபரின் access key நீக்கப்படும். அகற்றப்பட்ட சாதனத்தில் ஏற்கனவே ஒத்திசைந்தது அதனிடமே இருக்கும்; தரவைத் திரும்பப் பெற முடியாது.

## மீட்டெடுப்புக் குறியீடுகள்

restore code இல் உறுப்பினரின் id உம் அவரின் தற்போதைய தனிப்பட்ட திறவுகோல் இணைகளும், நூலகத்தின் store id உம் அதன் சேமிப்பு இடமும் உள்ளன; சேமிப்புச் சான்றுகள், உள்நுழைவு token கள், நூலகத்தின் பெயர் ஒருபோதும் இல்லை. அது கேட்கும் போது காட்டப்படும், Apple தளங்களில் தானாகவே iCloud Keychain இல் சேமிக்கப்படும், நூலகத்தைப் போலவே உணர்திறன் மிக்கது: அதையும் சேமிப்பு அணுகலையும் வைத்திருப்பவர் நூலகத்துக்கு அந்த நபரே. ஒவ்வொரு சாதனத்தையும் தன் குறியீட்டையும் இழந்தவரை admin அவரின் தற்போதைய உறுப்பினர் id க்கு மீண்டும் அழைக்கலாம்; இது அவரின் திறவுகோல்களை மாற்றும்.

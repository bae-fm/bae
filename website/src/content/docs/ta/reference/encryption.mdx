bae மேக இல்லத்தில் வைக்கும் அனைத்தும் சாதனத்தை விட்டு வெளியேறும் முன் மறைகுறியாக்கப்படும்; மறைகுறியாக்கம் இல்லாத முறை இல்லை. bae தன் சொந்த cryptography ஐச் செயல்படுத்துவதில்லை: முழுத் திட்டமும் [coven](https://coven.bae.fm) உடையது, bae அதை எப்படிப் பயன்படுத்துகிறது என்பதை இந்தப் பக்கம் விவரிக்கிறது.

## திறவுகோல்கள்

| திறவுகோல் | என்ன செய்கிறது |
|---|---|
| store key | நூலகத்தையும் அதன் உறுப்பினர் பதிவுகளையும் மறைகுறியாக்கும் |
| ஒவ்வொரு நபரின் circle key | நபர் தனிப்பட்டதாக வைப்பதை மறைகுறியாக்கும்: அவரின் தனிப்பட்ட கேட்டல் வரலாறும் playlists உம் |
| ஒவ்வொரு கோப்பின் திறவுகோல் | ஒரு கோப்பை மறைகுறியாக்கும், அதன் வரிசையின் மறைகுறியாக்கப்பட்ட மாற்றங்களுக்குள் மட்டுமே பயணிக்கும் |
| நபரின் கையொப்பத் திறவுகோல் இணை | அவரின் சாதனங்கள் அனுப்பும் ஒவ்வொரு மாற்றத்திலும் கையொப்பமிடும் |
| நபரின் முத்திரைத் திறவுகோல் இணை | அந்த நபருக்காக முத்திரையிட்ட திறவுகோல்களைத் திறக்கும் |

store key சீரற்றது, நூலகத்துக்கு மேக இல்லம் கிடைக்கும் போது உருவாகிறது. நபரின் திறவுகோல் இணைகளை அவரின் எல்லாச் சாதனங்களும் பகிர்கின்றன. தனிப்பட்ட திறவுகோல்களும் நூலகத்தின் திறவுகோல்களும் OS திறவுகோல் காப்பகத்தில் இருக்கும், கோப்பிலோ தரவுத்தளத்திலோ ஒருபோதும் இல்லை. அவை சாதனத்தை இரண்டு வழிகளில் அடைகின்றன, இரண்டும் [அடையாளமும் உறுப்பினர் நிலையும்](/ta/reference/membership) இல் விவரிக்கப்பட்டுள்ளன: restore code நபரின் சொந்தத் திறவுகோல் இணைகளைக் கொண்டு செல்லும், அழைப்புக்கு ஒப்புதல் அளிக்கும் admin store key களைப் புதிய நபரின் முத்திரைத் திறவுகோலுக்கு முத்திரையிடுவார்.

## திறவுகோல் சுழற்சி

திறவுகோல் ஒருபோதும் இருந்த இடத்தில் மாற்றப்படுவதில்லை; புதியது சேர்க்கப்படும். ஒரு நபர் அகற்றப்பட்ட பின், மீதமுள்ள உறுப்பினரின் சாதனம் மேலும் தரவை எழுதும் முன் புதிய store key ஐயும், அவர் இருந்த ஒவ்வொரு circle க்கும் புதிய திறவுகோலையும் சேர்க்கும்: பின்னர் எழுதப்படும் அனைத்தும் அவருக்குப் படிக்க முடியாதவை; மீதமுள்ள உறுப்பினர்கள் ஒவ்வொரு பழைய திறவுகோலையும் வைத்து முழு வரலாற்றையும் படிக்கலாம். ஒரு சாதனத்தை அகற்றுவது எதையும் சுழற்றாது, ஏனெனில் நபரின் பிற சாதனங்கள் அதன் திறவுகோல்களைப் பகிர்கின்றன; அகற்றிய பின் அந்தச் சாதனம் அனுப்புவது கணக்கில் எடுக்கப்படாது.

## எது sealed ஆகிறது

இல்லத்தின் ஒவ்வொரு உருப்படியும்: மாற்றங்கள், snapshots, உறுப்பினர் பதிவுகள், கோப்புகள். உள்ளடக்கம் XChaCha20-Poly1305 மூலம் மறைகுறியாக்கப்படும், ஒவ்வொரு மாற்றமும் Ed25519 மூலம் கையொப்பமிடப்படும், திறவுகோல்கள் நபர்களுக்கு X25519 sealed boxes மூலம் முத்திரையிடப்படும். கோப்புகள் 64 KiB chunks ஆக மறைகுறியாக்கப்படும், ஒவ்வொரு chunk உம் தனியாக அங்கீகரிக்கப்பட்டுத் தன் இடத்துடன் பிணைக்கப்பட்டது; அதனால் எந்த chunk ஐயும் கண்டறியப்படாமல் மாற்றவோ, இடம் மாற்றவோ, மறுவரிசைப்படுத்தவோ முடியாது. chunking காரணமாகவே ஓட்டம் வேலை செய்கிறது: player தான் பெறும் chunks ஐ மட்டுமே மறைவிலக்க முடியும்.

## Provider பார்க்கக்கூடியவை

உருப்படிகளின் எண்ணிக்கை, உருப்படிகளின் அளவு, பதிவேற்ற நேரம், எந்தக் கணக்கு ஒவ்வொரு உருப்படியையும் எழுதுகிறது, எந்தச் சாதனம் ஒவ்வொரு கோப்பையும் snapshot ஐயும் பதிவேற்றியது, ஏனெனில் அவற்றின் பாதைகளில் சாதனத்தின் பெயர் உள்ளது. பெயர்கள் இல்லை, metadata இல்லை, ஒலி இல்லை, கலைப்படம் இல்லை. கோப்புகள் சீரற்ற பெயர்களின் கீழ் இருக்கும், அவற்றின் உள்ளடக்கத்தின் hash இன் கீழ் ஒருபோதும் இல்லை. சேவையகப் பக்க மீட்பு இல்லை: எல்லோரும் ஒவ்வொரு சாதனத்தையும் ஒவ்வொரு restore code ஐயும் இழந்தால் நூலகம் இழக்கப்படும்; இதுவே வடிவமைப்பின் நோக்கம்.

## திறவுகோல் காப்பகத்தின் பங்கு

நூலகத்தைத் திறக்கும் போது அதன் திறவுகோல்கள் OS திறவுகோல் காப்பகத்திலிருந்து படிக்கப்படும். பூட்டிய அமர்வு அல்லது உறங்கும் திரை காரணமாகத் தற்போது பூட்டியுள்ள காப்பகம், சேதமடைந்த காப்பகத்திலிருந்து வேறுபடுத்தி அறியப்படும்: நூலகம் பயன்படுத்த முடியாதது என்று சொல்வதற்குப் பதிலாக bae அதைப் பூட்டியதாகக் காட்டி, திறந்த பின் மீண்டும் முயற்சிக்கும். ஒரு சாதனம் திறவுகோல்களை மறக்கவும் முடியும்; அப்போது அந்தச் சாதனத்தில் நூலகம் மீண்டும் திறக்கப்படும் வரை பூட்டியே இருக்கும்.

## மெட்டாடேட்டா விதைகள்

ஒவ்வொரு வேட்பாளருக்கும் ஒரு வெளிப்படையான மெட்டாடேட்டா விதை உள்ளது: **பார்வை**, சேமிக்கப்பட்ட **கோப்பு குறிச்சொற்கள்** ஸ்னாப்ஷாட் அல்லது **கைமுறை** உள்ளீட்டில் தேர்ந்தெடுக்கப்பட்ட வெளிப்புற வெளியீடு. மேற்பரப்புகளை மாற்றுவது அந்த விதையை மீண்டும் எழுதாது.

### தேடல்

லுக்அப் என்பது டிஸ்க் ஐடியைப் பிரித்தெடுக்கும் ஒரே பாதையாகும், பார்கோடுகள் மற்றும் அட்டவணை உரையை அங்கீகரிக்கிறது, வழங்குநர்களை வினவுகிறது மற்றும் முடிவுகளுடன் பொருந்துகிறது. பின்னணி ஸ்வீப் தானியங்கு தேடுதல் இயக்கப்பட்டால் மட்டுமே இந்த பாதையை இயக்கும் மற்றும் உள்ளமைக்கப்பட்ட இயல்புநிலை தேடலுக்குத் தீர்க்கப்படும். அந்த அமைப்பைப் பொருட்படுத்தாமல் ஒரு வெளிப்படையான தேடல் செயல் அதை இயக்க முடியும். கோப்பு குறிச்சொற்கள் அல்லது கையேட்டைத் திறப்பது ஒருபோதும் பிரித்தெடுத்தல், வழங்குநர் வினவல்கள் அல்லது பொருத்தத்தைத் தொடங்காது.

உட்பொதிக்கப்பட்ட ஆடியோ குறிச்சொற்கள் லுக்அப் ஆதாரம் அல்ல: அவை குறியிடுபவர் எதை நம்பினார் என்பதை விவரிக்கின்றன, அழுத்துவது என்ன என்பதை அல்ல. தேடல் முடிவுகள் அவற்றின் ஆதாரத்தைக் கொண்டுள்ளன, எனவே ஒவ்வொரு முடிவும் ஏன் வழங்கப்படுகிறது என்பதை இடைமுகம் விளக்க முடியும்.

### கோப்புக் குறிச்சொற்கள்

கோப்பு குறிச்சொற்கள் உட்பொதிக்கப்பட்ட ஆடியோ குறிச்சொற்கள் மற்றும் CUE மெட்டாடேட்டாவை சோம்பேறித்தனமாக படிக்கும். வேட்பாளரின் ஸ்கேன் உருவாக்கம், கோப்பு-திருத்து திருத்தம் மற்றும் கவனிக்கப்பட்ட ஆடியோ கோப்புகளுடன் முத்திரையிடப்பட்ட ஸ்னாப்ஷாட்டை முன்னோட்டம் சேமிக்கிறது. **கோப்பு குறிச்சொற்களைப் பயன்படுத்து** என்பதைத் தேர்ந்தெடுப்பது அந்த ஸ்னாப்ஷாட்டைத் தேர்ந்தெடுக்கும். கமிட் அதே ஸ்னாப்ஷாட்டைப் பயன்படுத்துகிறது மற்றும் நூலகத்தின் முத்திரை அல்லது அவதானிப்புகள் மாறினால் எழுதுவதற்கு முன் தோல்வியடையும்; அது வேறு பதிலை அமைதியாகப் படிக்கவில்லை.

### கைமுறை

கைமுறை எந்த மெட்டாடேட்டா உள்ளீடு அல்லது வெளியீடு செய்கிறது. **கைமுறையாக உள்ளிடவும்** என்பதைத் தேர்ந்தெடுப்பது, ஸ்கேன் செய்யப்பட்ட இயற்பியல் தட அமைப்பைத் தக்கவைத்துக்கொண்டு, ஒரு வெற்றுத் திருத்தக்கூடிய வெளியீட்டை உருவாக்குகிறது.

**விதையிடப்படாத வேட்பாளர்களை இதில் திற** என்ற அமைப்பு, விதை இல்லாத வேட்பாளர்களுக்கான தொடக்கக் காட்சியைத் தேர்ந்தெடுக்கிறது. அதன் நிலையான தேர்வுகள் தேடல், கோப்புக் குறிச்சொற்கள் மற்றும் கைமுறை; **கடைசியாகப் பயன்படுத்தியது** என்பது பயனர் வெளிப்படையாகத் தேர்ந்தெடுத்த கடைசி முறையை குறிக்கிறது. காட்சி நிலை சேமிக்கப்பட்ட விதையிலிருந்து தனியாக இருக்கும்.

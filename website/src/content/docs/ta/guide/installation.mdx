## இரண்டு பதிப்புகள்

ஒவ்வொரு தளமும் ஒரே மூலத்திலிருந்து கட்டப்பட்ட இரண்டு பதிப்புகளாக வருகிறது:

- **bae**, முழு பயன்பாடு: S3, Google Drive, Dropbox, OneDrive, மற்றும் iCloud ஒத்திசைவு.
- **baeium**, தனியுரிமை பகுதிகள் இல்லாதது: S3-compatible சேமிப்பு மட்டும், OAuth வழங்குநர்கள் இல்லை, iCloud/CloudKit இல்லை, telemetry இல்லை.

இவை ஒன்றோடொன்று இணையாக நிறுவப்படும்; ஒவ்வொன்றுக்கும் தனி நூலகமும் தனி (iCloud Keychain வழியாக ஒத்திசைக்கப்படும்) திறவுகோல்களும் இருக்கும். கீழே உங்களுக்கு ஏற்றதைத் தேர்ந்தெடுக்கவும்.

1. பதிவிறக்கிய `.dmg` ஐத் திறக்கவும்
2. பயன்பாட்டை உங்கள் Applications அடைவுக்கு இழுத்து விடவும்
3. Applications இலிருந்து அதைத் திறக்கவும்

இரு பதிப்புகளும் தங்களது Sparkle ஊட்டம் வழியாக தானாக புதுப்பிக்கப்படும்.

## iOS

iOS கட்டுதல்கள் **sideloading க்கான கையொப்பமிடாத `.ipa` கோப்புகள்**. [AltStore](https://altstore.io) அல்லது [Sideloadly](https://sideloadly.io) கொண்டு நிறுவவும், அல்லது உங்கள் சொந்த Apple ID கொண்டு Xcode இல் மீண்டும் கையொப்பமிடவும் (இலவச Apple ID baeium க்கு போதும்). App Store விநியோகம் இன்னும் அமைக்கப்படவில்லை.

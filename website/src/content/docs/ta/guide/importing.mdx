ஓர் அடைவு இறக்குமதிக்கான ஒலியையும் பிற கோப்புகளையும் வழங்குகிறது. அதன் திருத்தக்கூடிய விவரத் தரவு ஓர் இணைய வெளியீட்டிலிருந்தா, அடைவின் சொந்த விவரத் தரவிலிருந்தா, அல்லது வெற்றுப் படிவத்திலிருந்தா தொடங்க வேண்டும் என்பதை நீங்கள் தேர்ந்தெடுக்கிறீர்கள்.

இறக்குமதி மேசைக்கணினியில் நடக்கும் (macOS, Windows). உங்கள் கோப்புகள் படிக்கப்படும், மாற்றப்படாது: bae எதையும் நகர்த்தாது, பெயர் மாற்றாது, tag மாற்றாது, மறுவடிவாக்காது. இறக்குமதி பிறகு கோப்புகள் எங்கே வாழ்கின்றன என்பதை [சேமிப்பும் இணைப்பில்லா பயன்பாடும்](/ta/guide/storage) இல் பார்க்கவும்.

## கண்காணிக்கப்படும் அடைவுகள்

**Import** பகுதிக்கு மாறி அடைவு ஒன்றைச் சேர்க்கவும்: அதைத் தேர்ந்தெடுக்கவும், சாளரத்தின் மேல் இழுத்துப் போடவும், அல்லது <kbd>⌘I</kbd> அழுத்தவும். அதன்பிறகு bae அந்த அடைவைக் கண்காணிக்கும். அதில் விடப்படும் புதிய இசை தனியாகவே புதிய வாய்ப்புகளாக தோன்றும்; கையால் மீண்டும் ஆய்வு செய்ய வேண்டாம். இன்னும் பதிவிறங்கிக் கொண்டிருக்கும் அடைவுகள் முடியும் வரை புறக்கணிக்கப்படும்.

ஒரு ஆய்வு, rips உண்மையில் வரும் வடிவங்களை வெளியீடுகளாக அடையாளம் காண்கிறது:

| அமைப்பு | அது எப்படி தெரியும் |
|--------|-------------------|
| தடம் ஒன்றுக்கு கோப்பு | `01 - Song.flac`, `02 - Song.flac`, … |
| CUE + படிமம் | `album.cue` + `album.flac`, முழு வட்டுக்கும் ஒரு கோப்பு |
| பல வட்டு | `CD1/`, `CD2/` துணை அடைவுகள், உள்ளே எந்த வடிவமாகவும் இருக்கலாம் |
| தொகுப்புகள் | அடைவுகளின் அடைவு; ஒவ்வொன்றும் தனி வெளியீடு |

bae அது இயக்கும் வடிவங்களையே இறக்குமதி செய்கிறது: FLAC, MP3, APE, ALAC மற்றும் `.m4a` இல் AAC, WAV, AIFF, Ogg Vorbis, Opus, WavPack, DSD (`.dsf`/`.dff`). அடைவில் உள்ள அட்டைப்படங்கள் மற்றும் ஆவணங்கள் (CUE sheets, rip logs, உரைக் கோப்புகள்) அடையாளம் காணப்பட்டு வெளியீட்டுடன் வைக்கப்படும்.

## விவரத் தரவு வரைவை நிரப்புதல்

ஒவ்வொரு வாய்ப்புக்கும் திருத்தக்கூடிய ஒரு விவரத் தரவு வரைவு உண்டு. அது வெற்றாகத் தொடங்கலாம், ஓர் இணைய வெளியீட்டிலிருந்து நிரப்பப்படலாம், அல்லது அடைவின் சொந்தக் கோப்புகள் சொல்வதிலிருந்து நிரப்பப்படலாம். வெற்று வரைவில் தட்டச்சு செய்வது நேரடி உள்ளீடு, தனியான விவரத் தரவு மூலம் அல்ல.

அட்டையின் **Identify** கட்டுப்பாடுகள் Identify பக்கத்துக்குச் செல்ல இரண்டு வழிகளைத் தருகின்றன; அவை எதைத் தொடங்குகின்றன என்பதில் வேறுபடுகின்றன. **Automatic** அந்தப் பக்கத்தைத் திறந்து, வாய்ப்பிடம் ஏற்கனவே என்ன இருந்தாலும், ஒவ்வொரு முறையும் புதிய அடையாள ஓட்டத்தைக் கோரும் — ஏற்கனவே நடக்கும் ஓட்டம் புதியதற்காகக் கைவிடப்படும். **Search** அதே பக்கத்தை அதன் தட்டச்சுத் தேடலில் திறக்கும், எதையும் தொடங்காது. இரண்டுமே வரைவை மாற்றுவதில்லை; ஒரு முடிவைப் பயன்படுத்தினால் வரைவு மாற்றப்பட்டு திருத்தக்கூடிய அட்டைக்குத் திரும்பும். அட்டையின் மெனுவில் வரைவை இருக்கும் இடத்திலேயே மறுஎழுதும் இரண்டு கட்டளைகள் உள்ளன: **Reset to file metadata**, வாய்ப்பின் சொந்தக் கோப்புகள், sheets, அடைவுப் பெயர் சொல்வதைக் கொண்டு வரைவை மாற்றும்; **Clear metadata**, அதை வெறுமையாக்கும். ஒவ்வொன்றும் முதலில் கேட்கும்; இரண்டுமே வாய்ப்பின் கோப்புகளையோ தட அமைப்பையோ தொடாது.

### Identify

Identify பக்கம் ஓர் அடைவு எந்த வெளியீடு என்பதைக் கண்டுபிடிக்கும். அது அடைவிலிருந்து சான்றுகளைப் படித்து, ஒவ்வொன்றையும் தேடிப் பார்க்கும்:

- **வட்டு ID.** CD இன் சரியான தட அமைப்பின் கைரேகை, rip log அல்லது CUE sheet இலிருந்து கணக்கிடப்படுவது. அது பொருந்தும்போது, துல்லியமான CD பதிப்பை அடையாளம் காட்டும்.
- **Barcode.** அடைவில் உள்ள அட்டைப்பட scan களிலிருந்து உரை அடையாளம் மூலம் படிக்கப்படுவது, அல்லது CUE sheet இலிருந்து.
- **பதிப்பு எண்களும் உரையும்.** கலைப்படத்திலும் கோப்பு, அடைவுப் பெயர்களிலும் கண்ட பதிப்பு எண்கள், முடிவுகளைச் சுருக்கப் பயன்படும்.

சிக்னல்கள் MusicBrainz, Discogs இரண்டிலும் ஒரே நேரத்தில் தேடப்பட்டு, முடிவுகள் ஒன்றோடொன்று சரிபார்க்கப்படும். ஒவ்வொரு சிக்னலும் முடிவுகளுக்கு மேலே ஒரு வில்லையாகத் தோன்றும்: என்ன கிடைத்தது, அது எங்கிருந்து வந்தது (மூலத்தைக் காண hover செய்யவும்: disc TOC, CUE sheet, அட்டைப்பட scan, அடைவுப் பெயர்) என்பதைப் பார்க்கலாம்; ஒரு சிக்னல் தவறாக வழிநடத்தினால் அதைத் தனியாக அணைக்கலாம்.

மூன்று விளைவுகள்:

- **கிடைத்தது.** சான்றுகள் ஒரே release group இல் ஒத்துப்போகின்றன. அதன் பட்டியலிலிருந்து சரியான பதிப்பை நீங்கள் தேர்ந்தெடுக்கிறீர்கள்.
- **முரண்.** இரண்டு சிக்னல்கள் வெவ்வேறு வெளியீடுகளைச் சுட்டுகின்றன, உதாரணமாக வட்டு ID யும் barcode உம் ஒத்துப்போகவில்லை. bae இரு பக்கங்களையும் காட்டும்; எதை நம்புவது என்று நீங்கள் தேர்ந்தெடுக்கலாம், அல்லது ஒரு சிக்னலைப் புறக்கணிக்கலாம்.
- **எதுவும் கிடைக்கவில்லை.** கையால் தேடவும்: கலைஞர் மற்றும் ஆல்பம், பதிப்பு எண், அல்லது barcode, எந்தத் தரவுத்தளத்திலும். கலைப்படத்திலிருந்து அடையாளம் கண்ட உரை autocomplete ஆக வழங்கப்படும்.

மூல உலாவி தேடல் படிவம், அடையாளம் காணும் முன்னேற்றம், சிக்னல்கள், முடிவுகள் ஆகியவற்றை ஒன்றாகக் காட்டும். ஒரு முடிவைத் தேர்ந்தெடுத்தால், bae முழு வெளியீட்டைப் பெறும் வரை அந்த வரி முன்னேற்றத்துடன் திறந்திருக்கும், பின்னர் அது வரைவுக்குப் பயன்படுத்தப்படும். அதன் விளைவான அட்டை MusicBrainz அல்லது Discogs மூலச் சில்லைக் காட்டும். அட்டையில் உள்ள **Automatic** அதை முதலிலிருந்து மீண்டும் இயக்கும்; **Search** ஏற்கனவே கிடைத்தவற்றை வைத்தபடியே தட்டச்சுத் தேடலுக்குத் திரும்பும்.

தானியங்கி அடையாளம் காணுதல் இதே பாதையைப் பயன்படுத்துகிறது. ஒரு வாய்ப்பு சேர்க்கப்படும்போது, அதன் வரைவு அதன் கோப்புகள், sheets, அடைவுப் பெயர் ஆகியவற்றிலிருந்து உருவாக்கப்படும். Settings, Import இல் உள்ள **Identify automatically** அமைப்பு, தற்போதுள்ள கோப்புகளுக்கு எந்த முடிவும் இல்லாத ஒவ்வொரு வாய்ப்புக்கும் அடையாளம் காணுதலை இயக்கும்; அது அணைக்கப்பட்டிருந்தால் ஒவ்வொரு ஓட்டத்தையும் நீங்களே தொடங்குவீர்கள். முன்பே நிரப்பப்பட்ட வரைவு ஒரு தொடக்கப் புள்ளி, பதில் அல்ல; அதனால் அது ஓட்டத்தைத் தடுப்பதில்லை.

### கோப்பு விவரத் தரவு

வாய்ப்பு சேர்க்கப்படும்போது முன்நிரப்புதல் அதைப் படிக்கும்போது கோப்பு விவரத் தரவு படிக்கப்படும்; **Reset to file metadata** தேர்ந்தெடுக்கப்படும் ஒவ்வொரு முறையும் மீண்டும். எந்த வழியிலும் வரைவு அந்தச் சரியான வாசிப்பால் மாற்றப்படும் — உட்பொதிந்த ஒலி tags, CUE விவரத் தரவு, அடைவின் சொந்தப் பெயர் — அட்டை அதன் மேல் மீண்டும் வரையப்படும். வாசிப்புக்குப் பிறகு வாய்ப்போ அதன் ஒலிக் கோப்புகளோ மாறினால், நூலகத்தில் எழுதும் முன்பே இறக்குமதி தோல்வியடையும்.

வரைவில் அந்த வாசிப்பு இருக்கும் வரை திருத்தக்கூடிய அட்டை அமைதியான File metadata சில்லைக் காட்டும். தட்டச்சு மூலம் மட்டுமே நிரப்பப்பட்ட வரைவுக்கு மூலச் சில் இல்லை.

## உறுதிப்படுத்தி இறக்குமதி செய்தல்

உறுதிப்படுத்தல் பலகம் இறக்குமதி எழுதப்போகும் அனைத்தையும் காட்டும்:

- **அட்டைப்படம்.** தரவுத்தளங்களின் கலைப்படம், உங்கள் அடைவில் உள்ள படங்கள், அல்லது கோப்புகளில் உட்பொதிந்த கலைப்படம் ஆகியவற்றிலிருந்து தேர்ந்தெடுக்கப்படும். வாய்ப்பின் படத்தொகுப்பிலிருந்து ஒரு படத்தை அட்டைப்படச் சதுரத்தில் இழுத்துப் போடவும், அல்லது பின்னர் மாற்றவும்.
- **விவரத் தரவு.** ஆல்பம், கலைஞர், ஆண்டு, பதிப்பகம், பதிப்பு எண், நாடு, barcode, மேலும் ஒவ்வொரு தடம்: எதுவும் சேமிக்கப்படும் முன் இங்கேயே அனைத்தும் திருத்தக்கூடியவை.
- **சேமிப்பு.** மேக இல்லம் இணைக்கப்பட்டிருந்தால், வெளியீட்டை அங்கே பதிவேற்ற **Cloud** ஐயும், அதன் கோப்புகளை இந்தச் சாதனத்திலும் வைக்க **Pinned** ஐயும் தேர்ந்தெடுக்கவும். இல்லையெனில் வெளியீடு உள்ளூர்: அதன் தகவல் உங்கள் மற்ற சாதனங்களுக்கு ஒத்திசைகிறது, அதன் ஒலி இந்தச் சாதனத்திலேயே இருக்கும். [சேமிப்பும் இணைப்பில்லா பயன்பாடும்](/ta/guide/storage) பார்க்கவும்.

இறக்குமதி பின்னணியில் இயங்கும்: ஒவ்வொரு தடமும் சுத்தமாக decode ஆகிறதா என bae சரிபார்த்து, ஆல்பத்துக்கும் ஒவ்வொரு தடத்துக்கும் loudness அளந்து, வெளியீட்டைச் சேமித்து, மேக இறக்குமதிகளுக்குப் பதிவேற்றத்தைத் தொடங்கும். வாய்ப்புப் பட்டியல் அடுத்த அடைவுக்கு நகரும், வெளியீட்டை உடனே இயக்கலாம்.

## தரவு மூலங்கள்

**MusicBrainz** க்கு கணக்கு அல்லது திறவுகோல் தேவையில்லை. **Discogs** உங்கள் சொந்த இலவச API அணுகல் குறியைத் தேவைப்படுத்துகிறது; அதை Settings, Import இல் paste செய்யவும், அது வேலை நிறுத்தினால் bae உங்களிடம் சொல்லும். அணுகல் குறி இல்லாமல் Discogs தேடலும் Discogs மூல விவரத் தரவும் கிடையாது; மற்ற அனைத்தும் இயங்கும். இரண்டு சேவைகளுக்கும் வேக வரம்புகள் உள்ளன; வரம்புகளுக்குள் இருக்க bae தனது கோரிக்கைகளை இடைவெளியுடன் அனுப்புகிறது.

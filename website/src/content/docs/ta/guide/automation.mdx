நீங்கள் இயக்கும் மென்பொருள் இந்த நூலகத்தை இயக்கலாம்: MCP வழியாக AI முகவர்கள், கட்டளை வரிக் கருவி வழியாக நிரல்கள். இரண்டும் பயனர் இடைமுகம் பயன்படுத்தும் அதே செயல்களைத் தருகின்றன: தேடல், வெளியீட்டு விவரங்கள், இறக்குமதிகள், சேமிப்பு நடவடிக்கைகள், இயக்க நிலை.

## MCP சேவையகம்

Settings, Automation இல் MCP சேவையகத்தை இயக்குங்கள். அது Model Context Protocol ஐ HTTP வழியாக உள்ளூர் port இல் வழங்குகிறது (இயல்பாக 47777); அதனால் Claude போன்ற MCP பயன்பாடுகள் உங்கள் நூலகத்தை உலாவலாம், வெளியீடுகளைத் தேடலாம், அவற்றில் செயல் செய்யலாம். அணுக bearer டோக்கன் தேவை: அதே அமைப்பு பலகையிலிருந்து அதை நகலெடுக்கவும்; அதை வைத்திருந்த அனைத்தையும் துண்டிக்க வேண்டியபோது அங்கேயே மாற்றவும்.

சேவையகம் இயல்பாக அணைக்கப்பட்டிருக்கும்; பயன்பாடு இயங்கும் வரை மட்டுமே அது இயங்கும்.

## கட்டளை வரி

`bae` CLI அதே செயல்களை கட்டளைச் சாளரத்திலிருந்து இயக்குகிறது: JSON உள்ளீடு, JSON வெளியீடு; நிரல்களுக்கு ஏற்றது. உள்ளூர் MCP செயலை எதிர்பார்க்கும் கருவிகளுக்காக, மேசைக்கணினி சேவையகத்தை stdio மீது இணைக்கும் MCP பயன்பாடாகவும் அது செயல்படலாம்.

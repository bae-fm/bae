## MCP சேவையகம்

Settings, Automation இல் MCP சேவையகத்தை இயக்குங்கள். அது Model Context Protocol ஐ HTTP வழியாக உள்ளூர் port இல் வழங்குகிறது (இயல்பாக 47777); அதனால் Claude போன்ற MCP பயன்பாடுகள் உங்கள் நூலகத்தை உலாவலாம், வெளியீடுகளைத் தேடலாம், அவற்றில் செயல் செய்யலாம். அணுக bearer டோக்கன் தேவை: அதே அமைப்பு பலகையிலிருந்து அதை நகலெடுக்கவும்; அதை வைத்திருந்த அனைத்தையும் துண்டிக்க வேண்டியபோது அங்கேயே மாற்றவும்.

சேவையகம் இயல்பாக அணைக்கப்பட்டிருக்கும்; பயன்பாடு இயங்கும் வரை மட்டுமே அது இயங்கும்.

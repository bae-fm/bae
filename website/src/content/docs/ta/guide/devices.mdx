description: உங்கள் சொந்த சாதனங்களைச் சேர்க்கவும், நபர்களை அழைக்கவும், சாதனங்களை அகற்றவும்
---

bae கணக்கு கிடையாது. நூலகத்தில் உள்ள ஒவ்வொரு நபருக்கும் சொந்தத் திறவுகோல்கள் உண்டு; அவரின் எல்லா சாதனங்களும் அவற்றைப் பகிர்ந்து, இயக்குதளத்தின் திறவுகோல் காப்பகத்தில் வைத்திருக்கும். நூலகம் நபர்களை அந்தத் திறவுகோல்களால் அடையாளம் காணும். யார் உள்ளனர் என்பதில் நிகழும் ஒவ்வொரு மாற்றமும் கையொப்பமிடப்பட்டு மேக இல்லத்தில் வைக்கப்படும்; நடுவில் யாரும் இல்லை.

இரண்டு நிலைகளுக்கு இரண்டு கதவுகள்:

- **மீட்டெடுத்தல்**: உங்கள் சொந்த புதிய அல்லது மீண்டும் நிறுவப்பட்ட சாதனம் உங்கள் restore code கொண்டு சேரும். வேறு எந்தச் சாதனமும் ஒப்புதல் அளிப்பதில்லை: குறியீட்டில் உங்கள் திறவுகோல்கள் உள்ளன, அதனால் சாதனம் உங்களுடையது என்பதை அதுவே நிரூபிக்கிறது.
- **சேருதல்**: மற்றொரு நபர் admin இன் அழைப்பின் மூலம் சேருவார்; admin அவரின் கோரிக்கைக்கு ஒப்புதல் அளிப்பார்.

## உங்கள் சொந்த சாதனத்தைச் சேர்த்தல்

புதிய சாதனத்தில் **Restore from cloud** ஐத் தேர்ந்தெடுத்து, restore code ஐ இந்த மூன்றில் ஏதேனும் ஒரு வழியில் கொடுக்கவும்:

- உங்கள் மற்றொரு சாதனத்தில் Settings, Library இல் **Show restore code...** இன் கீழ் தோன்றும் QR குறியீட்டை **ஸ்கேன்** செய்யவும்.
- Apple சாதனங்களில் அதை iCloud Keychain இலிருந்து **தேர்ந்தெடுக்கவும்**: உங்கள் மற்ற சாதனங்கள் அங்கு சேமித்த restore code களை bae பட்டியலிடும்.
- அதை **ஒட்டவும்** அல்லது தட்டச்சு செய்யவும்.

கேட்கப்படும் போது சேமிப்பு வழங்குநரில் உள்நுழையவும். S3 இல் சாதனத்துக்கு உங்கள் access key உம் தேவை: QR குறியீடு அதைக் குறியீட்டுடன் சேர்த்தே கொண்டுவரும், அதனால் ஸ்கேன் செய்தால் போதும்; தட்டச்சு செய்த குறியீடு திறவுகோலைக் கேட்கும். பின்னர் புதிய சாதனம் நூலகத்தைப் பதிவிறக்கி ஒத்திசைவைத் தொடங்கும்.

நூலகம் ஏற்றப்படும் வரை சாதனம் அதன் பெயரை அல்ல, அது எங்கே சேமிக்கப்பட்டுள்ளது என்பதைக் காட்டும்: Dropbox, OneDrive க்கு கணக்கின் மின்னஞ்சல், S3 க்கு bucket மற்றும் endpoint, அல்லது iCloud. ஏற்றிய பின் நூலகத்தின் தற்போதைய பெயரைக் காட்டும்.

## ஒரு நபரை அழைத்தல்

ஒரு admin Settings, Library, **Invite a Person...** ஐத் திறந்து, பங்கைத் தேர்ந்தெடுத்து, அந்த நபரின் கணக்கு மின்னஞ்சலை உள்ளிடுவார்; S3 இல் அதற்குப் பதிலாக அவருக்காக உருவாக்கிய access key. bae நூலகத்தின் அடைவை அந்தக் கணக்குடன் பகிர்ந்து, அழைப்பை QR குறியீடாகக் காட்டும்.

தன் சாதனத்தில் அந்த நபர் **Join a library** ஐத் தேர்ந்தெடுத்து, அழைப்பை ஸ்கேன் செய்து அல்லது ஒட்டி, தன் பெயரைத் தட்டச்சு செய்து, தன் சொந்தக் கணக்கில் உள்நுழைவார். கோரிக்கை admin இன் சாதனத்தில் **Waiting to join** இன் கீழ் தோன்றும்; admin அதை ஏற்பார் அல்லது மறுப்பார். ஒப்புதலுக்குப் பின் புதிய சாதனம் நூலகத்தைப் பதிவிறக்கும், ஒவ்வொரு சாதனமும் புதிய நபரைப் பெயருடன் காட்டும். அழைப்பு ஒரு நாளில் காலாவதியாகும், அதை உருவாக்கிய சாதனம் மட்டுமே அதன் கோரிக்கைக்கு ஒப்புதல் அளிக்க முடியும். விவரங்கள் [அடையாளமும் உறுப்பினர் நிலையும்](/ta/reference/membership) இல்.

## உறுப்பினர்களும் பொறுப்புகளும்

Settings, Library ஒவ்வொரு நபரையும் அவரின் சாதனங்களையும், அவற்றில் இந்தச் சாதனம் எது என்பதையும் பட்டியலிடும். நூலகத்தை மேகத்துடன் இணைக்கும் நபர் அதன் முதல் **admin**; admin கள் மற்றவர்களை **admin** ஆகவோ **உறுப்பினர்** ஆகவோ அழைப்பார்கள், யாருடைய பங்கையும் மாற்றலாம். அனைவரும் நூலகத்தைப் படித்துத் திருத்துவர். admin கள் மட்டுமே நபர்களை அழைக்கவும், அகற்றவும், நூலகத்தின் பெயரை மாற்றவும் முடியும்.

## சாதனத்தை நீக்குதல்

ஒவ்வொருவரும் தம் சொந்த சாதனங்களை அகற்றலாம்; admin எவருடைய சாதனத்தையும் அகற்றலாம், அதனால் எல்லாச் சாதனங்களையும் இழந்தவர் சிக்கிக்கொள்ள மாட்டார். அதன் பின் அகற்றப்பட்ட சாதனம் அனுப்புவது எதுவும் கணக்கில் எடுக்கப்படாது. வழங்குநரிடம் இன்னும் செய்ய வேண்டியதையும் bae காட்டும், உதாரணமாக அந்தச் சாதனத்தை உங்கள் கணக்கிலிருந்து வெளியேற்றுவது: Dropbox, OneDrive, iCloud ஆகியவை ஒரு கணக்கின் ஒரு சாதனத்தைத் தாமாகப் பிரிக்க முடியாது.

ஒரு நபரை அகற்றுவது, admin மட்டுமே செய்யக்கூடியது, அவரின் சாதனங்களையும் அவர் தனிப்பட்டதாக வைத்திருந்த அனைத்தையும் அகற்றும். வீட்டுடன் பகிர்ந்த அவரின் மதிப்பீடுகள், வரலாறு, playlists அவர் பெயரிலேயே இருக்கும். நூலகத்தின் திறவுகோல்கள் மாறும், அதனால் பின்னர் எழுதப்படும் எதையும் அவர் படிக்க முடியாது. அவர் ஏற்கனவே நகலெடுத்தது அவரிடமே இருக்கும்: அனுப்பிய தரவைத் திரும்பப் பெற முடியாது.

## மீட்டெடுப்புக் குறியீடுகள்

restore code ஒரு நூலகத்துக்கான உங்கள் திறவுகோல்களையும் அது எங்கே சேமிக்கப்பட்டுள்ளது என்பதையும் ஒரே சரமாகக் கொண்டுள்ளது. அதில் சேமிப்புக் கடவுச்சொல், உள்நுழைவு அல்லது நூலகத்தின் பெயர் இல்லை. Settings, Library இல் உள்ள **Show restore code...** அதைக் காட்டும்; கடவுச்சொல் மேலாளர் போன்ற பாதுகாப்பான இடத்தில் வைக்கவும்.

Apple தளங்களில் குறியீடு தானாகவே iCloud Keychain இலும் வைக்கப்படும்; அதனால் உங்கள் Apple Account இல் உள்நுழைந்த புதிய Mac அல்லது iPhone அதைப் பட்டியலிலிருந்து தேர்ந்தெடுக்க முடியும்.

குறியீடும் உங்கள் சேமிப்பை அணுகும் உரிமையும் உள்ள எவரும் உங்களைப் போலவே நூலகத்தைத் திறக்க முடியும்; அதனால் அதை ரகசியமாக வைக்கவும்.

## பூட்டுதல்

நூலகத்தின் மறைகுறி திறவுகோல்கள் இயக்குதளத்தின் திறவுகோல் காப்பகத்தில் இருக்கும். காப்பகம் பூட்டியிருக்கும் வரை, உதாரணமாக உங்கள் அமர்வு பூட்டியிருக்கும் போது, bae நூலகத்தைப் பூட்டியதாகக் காட்டி, காப்பகம் திறந்தவுடன் அதைத் திறக்கும்; **Try again** கைமுறையாக மீண்டும் முயற்சிக்கும்.

## கைப்பேசியில்

iOS மற்றும் Android இதே முறையில் சேர்ந்து மீட்கின்றன; அதுவே அவற்றின் முழு தொடக்க நடை. கைப்பேசி நூலகத்தைத் தன்னிடமிருந்து அகற்றவும் முடியும்: முதலில் தன்னை நூலகத்தின் உறுப்பினர்களிலிருந்து அகற்றும், இதற்கு உங்கள் சேமிப்புடன் இணைப்பு தேவை; பின்னர் தன் உள்ளூர் நகலை நீக்கும். மேகத்தில் உள்ள நூலகம் அப்படியே இருக்கும்.

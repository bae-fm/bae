பிணைப்பின்மை இரு திசைகளிலும் வேலை செய்யும்: bae உள்ளே வரும் உங்கள் கோப்புகளை மாற்றாது, வெளியே போகும் போது அவற்றைத் தடுக்காது. உள்ளூர் வெளியீடுகள் ஏற்கனவே உங்கள் அடைவுகளில் உள்ள கோப்புகளே. மேகத்தில் உள்ள வெளியீடுகளை எப்போது வேண்டுமானாலும் byte-for-byte மீண்டும் உள்ளூராக்கலாம். உங்களுக்கு *வேறு* வடிவம் தேவைப்படும் போது, எடுத்துக்காட்டாக கைப்பேசிக்கு ஏற்ற encode, Save as… மூலக் கோப்புகளைத் தொடாமல் அதை உருவாக்கும்.

## இரண்டு ஏற்றுமதிகள்

- **Export…**: ஆல்ப மெனு அல்லது Storage managerல், ஒரு வெளியீட்டின் கோப்புகளை byte-for-byte ஒரு அடைவுக்குப் பிரதி எடுக்கும்.
- **Save as…**: தடத்தில், அல்லது வெளியீட்டுக்கு ஆல்ப மெனுவில், நீங்கள் தேர்ந்த வடிவத்திற்கு மாற்றும்; எடுத்துக்காட்டாக கார் அல்லது கைப்பேசிக்கு FLAC இலிருந்து MP3. இது புதிய கோப்புகளை எழுதும்; மூலக் கோப்புகள் இருப்பதுபோலவே இருக்கும்.

இரண்டும் முன்னேற்றம் காட்டும் வரிசையில் இயங்கும். இவற்றை இடைநிறுத்தவும் ரத்து செய்யவும் முடியும்; தோல்வியடைந்தது நீங்கள் ரத்து செய்யும் வரை அதன் பிழையுடன் வரிசையில் இருக்கும். Save வரிசையில் சேர்க்கப்பட்ட நேரத்தின் format மற்றும் settings ஐ வைத்திருக்கும்; எனவே பின்னர் அவற்றை மாற்றுவது வரிசையில் ஏற்கனவே உள்ளவற்றில் எதையும் மாற்றாது.

## Formats

Format என்பது ஒரு பெயரும் ஒரு codec உம்: FLAC, WAV, AIFF, MP3, AAC அல்லது Opus. அவை Settings, Save as இல் **Formats** கீழ் வைக்கப்படும். **Add format…** ஒன்றைச் சேர்க்கும்; அதன் மெனுவின் **Edit…** மற்றும் **Delete…** அதை மாற்றும் அல்லது நீக்கும். Format க்கு ஒரு **Name**, ஒரு **Format** மற்றும் தரத்திற்கான ஒரு setting உண்டு. பெயர்கள் தனித்துவமானவை, ஆனால் இரண்டு format ஒரே விஷயத்தை எழுதலாம். புதிய format க்கு அதன் codec இன் பெயர் வரும்; பெயர் எடுக்கப்பட்டிருந்தால் எண் சேரும் ("FLAC", "FLAC (2)"). FLAC மற்றும் MP3 ஏற்கனவே உள்ளன.

ஒவ்வொரு format உம் தடங்களுக்கும் வெளியீடுகளுக்கும் வேலை செய்யும். Save as சாளரத்தில் **Format** pop-up எல்லா format களையும் காட்டி, நீங்கள் கடைசியாகப் பயன்படுத்தியதிலிருந்து தொடங்கும். அதன் கடைசி உருப்படி **Edit formats…** settings இல் Save as ஐத் திறக்கும்; pop-up அங்கே செய்யும் மாற்றங்களைப் பின்தொடரும், அங்கே சேர்த்த format உடனே தேர்ந்தெடுக்கப்படும்.

## தரம்

- **Bit depth**, FLAC, WAV மற்றும் AIFF க்கு: **Same as source** அல்லது **16-bit**. Lossy மூலத்திற்குச் சொந்த depth இல்லை; எனவே அது 16 bit இல் எழுதப்படும்.
- **Bitrate**, MP3, AAC மற்றும் Opus க்கு: அந்த codec இன் encoder எழுதும் bitrate களின் பட்டியல். MP3: 32, 40, 48, 56, 64, 80, 96, 112, 128, 160, 192, 224, 256, 320 kbps. AAC: 96, 128, 160, 192, 256, 320 kbps. Opus: 64, 96, 128, 160, 192, 256 kbps.

## பெயர்கள்

Settings, Save as இல் **Names** கீழ், ஒரு **File name** pattern உம் ஒரு **Folder name** pattern உம் எல்லா format களுக்கும் பயன்படும். Pattern என்பது நீங்கள் மறுவரிசைப்படுத்தி, நீக்கி, சேர்க்கும் பகுதிகளின் வரிசை; அது உருவாக்கும் பெயரின் preview காட்டப்படும். கோப்பின் பெயரில் தலைப்பு, கலைஞர், ஆல்பம், ஆண்டு, தட எண், disc எண், மொத்தத் தடங்கள் ஆகியவை வரலாம். அடைவின் பெயரில் கலைஞர், ஆல்பம், ஆண்டு, label, catalog எண் ஆகியவை வரலாம்; வெளியீடு குறிப்பிடாத பகுதி விடப்படும்.

தடத்தில் Save as… patternன் பெயரைப் பரிந்துரைக்கும்; வேறு format ஐத் தேர்ந்தால் extension மட்டுமே மாறும். வெளியீட்டைச் save செய்தால் அதன் கோப்புகள் folder pattern பெயரிட்ட அடைவில் எழுதப்படும். வெளியீடு save ஒருபோதும் கோப்பை மாற்றாது: உங்கள் drive இல் இரண்டு பெயர்கள் ஒரே கோப்பாகும் என்றால் save தோல்வியடையும். ஒரு தடத்தில் Save as… ஏற்கனவே உள்ள கோப்பை நீங்கள் உறுதிசெய்தால் மட்டுமே மாற்றும்.

## ஒரு தடத்திற்கு ஒரு கோப்பு

ஒவ்வொரு save உம் ஒரு தடத்திற்கு ஒரு கோப்பு எழுதும்; இடைவெளிகளுக்கு ஒரே விதி. Pregap, சேமிக்கப்பட்டதோ உருவாக்கப்பட்டதோ, முந்தைய தடத்தின் முடிவில் போகும்; தடம் 1க்கு முன்னுள்ள மறைந்த audio தடம் 1ன் தொடக்கத்தில் இருக்கும். ஒரு image மற்றும் CUE sheet ஆகச் சேமிக்கப்பட்ட வெளியீடு தடக் குறியீடுகளில் பிரிக்கப்படும். Save as… CUE sheet எழுதாது.

## Encode செய்வதற்குப் பதில் நகலெடுத்தல்

தேர்ந்த lossless format இல் ஏற்கனவே இருக்கும், format எழுதும் depth இல் உள்ள முழுக் கோப்பாக இருக்கும் தடம் மீண்டும் encode செய்யப்படாமல் நகலெடுக்கப்படும். WAV மற்றும் AIFF 16 அல்லது 24 bit இல் கணக்கில் வரும். அதன் tags, cover, பெயர் புதிதாக எழுதப்படும். Lossy format எப்போதும் encode செய்யும்.

## கூடுதல்

Settings, Save as இல் **Extras** கீழ் மூன்று switch கள் ஒவ்வொரு format க்கும் பொருந்தும். எல்லாம் தொடக்கத்தில் இயக்கத்தில் இருக்கும்.

- **Embed cover art**: ஒவ்வொரு கோப்பிலும் cover ஐ வைக்கும்.
- **Cover image in the folder**: வெளியீடு save அதன் அடைவில் `cover.jpg` ஐயும் எழுதும்.
- **Loudness tags**: import நேரத்தில் bae அளந்த loudness இலிருந்து ஒவ்வொரு கோப்பிலும் தடம் மற்றும் ஆல்பத்தின் ReplayGain gain மற்றும் peak ஐ எழுதும்.

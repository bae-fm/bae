## Cloud home

cloud home là một vị trí từ xa của thư viện, như thư mục Google Drive, Dropbox hoặc S3 bucket.

## bae

bae dùng danh tính cục bộ, khóa thư viện, cloud home thay thế được và changeset mã hóa để đồng bộ nhiều thiết bị.

## Lưu trữ

File có thể tự quản lý, quản lý cục bộ hoặc quản lý trên cloud. File cục bộ phát offline; file cloud đồng bộ qua cloud home.

## Mã hóa

Opaque cloud home mã hóa dữ liệu trước khi rời thiết bị. Browsable cloud home lưu file không mã hóa ở đường dẫn đọc được.

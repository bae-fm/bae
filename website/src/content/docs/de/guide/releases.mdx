Die meisten Musik-Apps modellieren „ein Album“: ein Titel, ein Cover, eine Trackliste. Echte Sammlungen funktionieren nicht so. Du besitzt vielleicht die ursprüngliche CD, das Remaster und eine Vinyl-Pressung derselben Platte, und sie unterscheiden sich in Tracklisten, Laufzeiten, Artwork und Mitwirkenden. bae modelliert **Releases**: Jeder Import ist eine bestimmte Pressung, und Pressungen desselben Albums werden zusammengefasst.

## Alben gruppieren Releases

In der Mediathek ist ein Album mit mehreren Pressungen ein Eintrag. Die Albumseite zeigt eine Release-Auswahl; jedes Release behält seine eigene Trackliste, sein Cover, Jahr, Label, seine Katalognummer und Mitwirkenden. Ein Release ist das **primäre**: das, das Albumraster und Wiedergabe standardmäßig verwenden. Lege mit **Als primäre Veröffentlichung festlegen** im Albummenü ein beliebiges Release als primär fest und wähle jederzeit ein anderes Release zum Hören; bae merkt sich deine Auswahl pro Album.

## Was ein Release weiß

Identifizierte Releases tragen das Wissen der Datenbanken, nicht nur Tracknamen:

- Pressungsdetails: Label, Katalognummer, Barcode, Land, Format, Jahr.
- Mitwirkende: Ausführende, Produzenten, Ingenieure, pro Release und pro Track.
- Klassische Struktur: Komponisten, Werke und ihre Teile, verknüpft mit den Aufnahmen davon. Die Komponistenansicht der Mediathek wird daraus gebaut; siehe [Durchsuchen und Suche](/de/guide/browsing).
- Identität: welches genaue MusicBrainz oder Discogs Release es ist.

Einmal übernommen, gehören diese Werte dem Release selbst: bae behält keine Verbindung zur Quelle, und Änderungen ändern sie an Ort und Stelle.

## Bearbeiten

Metadaten kannst du selbst korrigieren. **Bearbeiten…** im Albummenü öffnet den Release-Editor, dasselbe Formular, das auch der Import verwendet: Albumtitel und Künstler, Pressungsdetails sowie Titel, Künstler und Nummerierung jedes Tracks. **Speichern** schreibt deine Änderungen; **Abbrechen** verwirft sie.

Änderungen leben nur in der Datenbank von bae. Die eingebetteten Tags deiner Dateien werden nie neu geschrieben; die Dateien bleiben Byte für Byte so, wie sie importiert wurden.

## Erneut identifizieren

Wenn ein Release als unbekannt importiert wurde, der falschen Pressung zugeordnet wurde oder die Datenbank seitdem besser geworden ist, führen die **Identifizieren**-Steuerelemente des Editors die Identifizierung für das vorhandene Release erneut aus: **Automatisch** identifiziert es anhand seiner Dateien, und **Suchen** öffnet die eingetippte Suche. Die Wahl einer Pressung ersetzt sofort die Werte im Editor; **Speichern** behält sie, und **Abbrechen** behält, was du hattest.

## Cover

Jedes Release hat ein Anzeigecover. **Cover ändern** bietet das Artwork der Datenbanken und die Bilddateien, die mit dem Release kamen. bae behält eine eigene Kopie des gewählten Covers in Anzeigegröße, sodass der ursprüngliche Scan in deinem Ordner unberührt bleibt. Tippe irgendwo auf ein Cover, um die vollständige Galerie der Bilder eines Releases zu öffnen.

## Löschen

Das Löschen eines Releases entfernt es aus der Mediathek und, bei einem Release in der Cloud, seine Kopien aus deinem Cloud-Zuhause. Deine eigenen Dateien werden nie gelöscht: bae vergisst sie nur.

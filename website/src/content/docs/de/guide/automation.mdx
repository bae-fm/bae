## Der MCP-Server

Aktiviere den MCP-Server unter Einstellungen, Automatisierung. Er stellt das Model Context Protocol per HTTP auf einem lokalen Port bereit (standardmäßig 47777), damit MCP-Clients wie Claude deine Mediathek durchsuchen, Releases nachschlagen und Aktionen darauf ausführen können. Der Zugriff erfordert ein Bearer-Token: Kopiere es aus demselben Einstellungsbereich und rotiere es dort, wenn du allem, was es hatte, den Zugriff entziehen willst.

Der Server ist standardmäßig ausgeschaltet und läuft nur, solange die App läuft.

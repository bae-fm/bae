title: Speicher und offline
description: Wo deine Musik liegt und was ohne Netzwerk spielt
---

Deine Dateien bleiben deine. bae verschiebt, benennt oder schreibt sie nie neu; die Frage, die Speicher beantwortet, lautet nur, wo die *abspielbare Kopie* jedes Releases liegt: auf dem Gerät, in deiner Cloud oder an beiden Orten.

## Lokal und in der Cloud

Jedes Release ist eines von beiden, beim Import gewählt und jederzeit änderbar:

- **Lokal**: bae katalogisiert deine Dateien dort, wo sie sind, und spielt sie von dort ab. Nichts wird kopiert. Die Angaben des Releases werden synchronisiert, sodass jedes Gerät das Album, seine Tracks und sein Cover zeigt, aber sein Audio bleibt auf dem Rechner, der es importiert hat, und andere Geräte können es nicht abspielen.
- **In der Cloud**: Die Dateien werden verschlüsselt und ins Cloud-Zuhause hochgeladen. Jetzt kann jedes Gerät das Release abspielen, es bei Bedarf streamen oder für offline herunterladen. Deine Originaldateien bleiben durch den Upload unberührt.

Beim Import, mit verbundenem Cloud-Zuhause, lädt **Cloud** das neue Release hoch, und **Angeheftet** behält seine Dateien zusätzlich auf diesem Gerät. Später lädt **In die Cloud verschieben** ein lokales Release hoch; bae prüft zuerst, dass jede Datei seit dem Import unverändert ist, und eine geänderte Datei stoppt den Upload. **Lokal machen…** kopiert die Dateien eines Cloud-Releases in einen Ordner deiner Wahl, prüft jede Kopie und spielt das Release von dort ab; sie gehören dir wieder als normale Dateien, und andere Geräte können es nicht mehr abspielen.

## Streaming und Cache

Releases in der Cloud spielen überall, sofern das Netzwerk es zulässt: Die Wiedergabe streamt die Datei aus deiner Cloud, und die Bytes werden in einem lokalen Cache behalten, sodass das nächste Abspielen sofort und ohne Netzwerk erfolgt. Der Cache verwaltet sich innerhalb eines Budgets (20 GB für Audio auf jedem Gerät) und entfernt, was du nicht abgespielt hast, wenn der Platz knapp wird. Cover und Künstlerbilder werden getrennt gecacht, sodass ein großes Album dein Artwork nicht verdrängen kann.

## Für offline pinnen

Ein Release zu pinnen lädt es vollständig herunter und behält es: Gepinnte Musik wird nie aus dem Cache entfernt und spielt immer offline. Pinne aus dem Speicherbereich des Releases oder dem Speichermanager; Entpinnen gibt die Dateien in den normalen Cache zurück, wo sie abspielbar bleiben, aber wieder freigegeben werden können. Auf dem Telefon zeigen gepinnte Downloads ihren Fortschritt direkt in der Mediathek.

## Der Speichermanager

Der Speichermanager des Desktops (<kbd>⌘0</kbd>) zeigt das ganze Bild in einem Fenster:

- Jedes Release mit Größe und Status: lokal, in der Cloud, wird hochgeladen. Filtern, sortieren, mehrere auswählen, auf alle gleichzeitig handeln.
- **Downloads**: laufende gepinnte Downloads, pausierbar, wiederholbar.
- **Exporte**: die Exportwarteschlange. Siehe [Exportieren](/de/guide/exporting).
- **Uploads**: der Synchronisierungs-Postausgang mit Fortschritt pro Release, Durchsatz und verbleibender Zeit, ausstehenden Löschungen, Pause und Fortsetzen.

## Löschen

Das Löschen eines Releases in der Cloud entfernt es aus der Mediathek und seine Kopien aus dem Cloud-Zuhause. Das Löschen eines lokalen Releases entfernt nur den Katalogeintrag. So oder so löscht bae nie deine eigenen Dateien.

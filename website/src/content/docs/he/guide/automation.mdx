אפשר להפעיל את הספרייה דרך תוכנה שאתה מריץ: סוכני בינה מלאכותית דרך MCP, וסקריפטים דרך כלי שורת פקודה. שניהם חושפים את אותן פעולות שהממשק משתמש בהן: חיפוש, פרטי הוצאה, ייבוא, פעולות אחסון ומצב ניגון.

## שרת MCP

מפעילים את שרת MCP תחת Settings, Automation. הוא מספק את Model Context Protocol דרך HTTP ביציאה מקומית (47777 כברירת מחדל), כך שלקוחות MCP כמו Claude יכולים לעיין בספרייה, לחפש הוצאות ולפעול עליהן. הגישה דורשת אסימון bearer: מעתיקים אותו מאותו חלון הגדרות, ומחליפים אותו שם בכל פעם שרוצים לחסום את כל מי שהחזיק בו.

השרת כבוי כברירת מחדל ורץ רק בזמן שהיישום רץ.

## שורת הפקודה

כלי שורת הפקודה `bae` מפעיל את אותן פעולות ממסוף: JSON נכנס, JSON יוצא, מתאים לסקריפטים. הוא יכול לפעול גם כלקוח MCP, ולגשר את שרת המחשב השולחני אל stdio עבור כלים שמצפים לתהליך MCP מקומי.

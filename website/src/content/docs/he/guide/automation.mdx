## שרת MCP

מפעילים את שרת MCP תחת Settings, Automation. הוא מספק את Model Context Protocol דרך HTTP ביציאה מקומית (47777 כברירת מחדל), כך שלקוחות MCP כמו Claude יכולים לעיין בספרייה, לחפש הוצאות ולפעול עליהן. הגישה דורשת אסימון bearer: מעתיקים אותו מאותו חלון הגדרות, ומחליפים אותו שם בכל פעם שרוצים לחסום את כל מי שהחזיק בו.

השרת כבוי כברירת מחדל ורץ רק בזמן שהיישום רץ.

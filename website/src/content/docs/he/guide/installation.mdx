## שתי מהדורות

bae נשלח בשתי מהדורות, שנבנות מאותו מקור:

- **bae**, היישום המלא: סנכרון S3, Google Drive, Dropbox, OneDrive ו-iCloud.
- **baeium**, בלי חלקים קנייניים: אחסון תואם S3 בלבד, בלי ספקי OAuth, בלי iCloud/CloudKit, בלי טלמטריה.

הן מותקנות זו לצד זו, כל אחת עם הספרייה שלה והמפתחות שלה (שמסונכרנים דרך iCloud Keychain). בחר למטה את מה שמתאים לך.

## iOS

בניות iOS הן **קובצי `.ipa` לא חתומים להתקנה צדדית**. התקן עם [AltStore](https://altstore.io) או [Sideloadly](https://sideloadly.io), או חתום מחדש ב-Xcode עם Apple ID משלך (Apple ID חינמי עובד עבור baeium). הפצה ב-App Store עדיין לא מוגדרת.

## Windows

ההורדה ל-Windows היא מתקין שמתקין את היישום עבור המשתמש הנוכחי ומעדכן את עצמו. הבניות אינן חתומות, ולכן SmartScreen עשוי להזהיר בהפעלה הראשונה. לכל [שחרור ב-GitHub](https://github.com/bae-fm/bae/releases) מצורף גם קובץ zip נייד שרץ במקום. ל-Windows משוחררת המהדורה המלאה בלבד.

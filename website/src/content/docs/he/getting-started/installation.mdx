## שני מהדורות

כל פלטפורמה יוצאת בשתי מהדורות שנבנות מאותו קוד מקור:

- **bae** — האפליקציה המלאה: סנכרון עם S3, Google Drive, Dropbox, OneDrive ו-iCloud.
- **baeium** — ללא חלקים קנייניים: אחסון תואם S3 בלבד, בלי ספקי OAuth, בלי iCloud/CloudKit ובלי מדידת שימוש. כל הקוד ברישיון Apache-2.0.

אפשר להתקין את שתי המהדורות זו לצד זו. לכל אחת ספרייה ומפתחות משלה. בחרו את המהדורה שמתאימה לכם.

## iOS

בניות iOS הן **קובצי `.ipa` לא חתומים להתקנה צדדית**. התקינו עם [AltStore](https://altstore.io) או [Sideloadly](https://sideloadly.io), או חתמו מחדש ב-Xcode עם Apple ID משלכם. Apple ID חינמי עובד עבור baeium. הפצה דרך App Store עדיין לא מוגדרת.

## Windows

בניות Windows הן קובצי zip **לא חתומים** של האפליקציה הלא ארוזה. חלצו והריצו `bae.exe` או `baeium.exe`. SmartScreen עשוי להציג אזהרה בהפעלה הראשונה.

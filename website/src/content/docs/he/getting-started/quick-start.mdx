## סקירה

bae עוזר לבנות ולארגן ספריית מוזיקה. אפשר:

1. **לייבא מוזיקה** מקבצים מקומיים, כקבצי רצועות נפרדים או כאלבומי CUE/FLAC
2. **להשלים נתונים** אוטומטית מ-MusicBrainz ומ-Discogs
3. **לדפדף בספרייה** לפי אמן, אלבום, סגנון או שנה

## הייבוא הראשון

### ייבוא קבצים מקומיים

הדרך הישירה להתחיל היא לייבא מוזיקה שכבר נמצאת אצלכם:

1. לחצו על **Import** בסרגל הצד
2. בחרו **Local Files**
3. בחרו תיקייה עם מוזיקה
4. bae סורק את התיקייה ומציג מה נמצא
5. בחרו את המהדורה המתאימה ב-MusicBrainz או Discogs
6. לחצו **Import**

bae מייבא נתונים, מוריד תמונות, ושומר את הקבצים לפי אפשרות האחסון שבחרתם.

### מיקום הספרייה

כברירת מחדל, bae שומר את נתוני הספרייה ב:

- **macOS**: `~/.bae/libraries/<library-id>/`

קובצי השמע מוצפנים ומועלים ל-cloud home, או נשארים במקומם ונכנסים לאינדקס במצב בניהול עצמי. ראו [סקירת אחסון](/he/storage/overview).

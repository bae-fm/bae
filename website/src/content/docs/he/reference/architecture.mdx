bae הוא ליבת Rust אחת שלובשת ארבעה יישומים מקוריים. כל מה שמגדיר את המוצר, מודל הספרייה, ייבוא, ניגון, סנכרון והצפנה, חי ב-Rust ומתנהג אותו הדבר בכל פלטפורמה; כל יישום הוא ממשק מקורי דק מעליה.

## השכבות

- **`bae-core`**: המוצר. מודל הספרייה והמטא־נתונים, צינורות הייבוא והזיהוי, מנוע הניגון של FFmpeg, ניתוח עוצמת שמע, ייצוא והחיבור ל-coven שמתחתיו. ייבוא וזיהוי נבנים רק במחשב שולחני; בניות מובייל הן לקוחות סנכרון וניגון.
- **[coven](https://coven.bae.fm)**: שכבת הנתונים, ספרייה נפרדת. coven מחזיקה את חיבור SQLite, לוכדת כל שינוי ש-bae שומר, ומסנכרנת את השינויים האלה בהצפנה מקצה לקצה דרך אחסון הענן של המשתמש. היא מחזיקה גם אחסון blob (בתי שמע, אמנות), את המטמון המקומי, מפתחות זהות וחברות. bae מצמיד גרסת coven מדויקת ומטביע אותה בכל קובץ בינארי; היא מגדירה את דור תאימות הסנכרון בין בניות.
- **`bae-bridge`**: גבול UniFFI. טיפוסי הגשר מוגדרים פעם אחת ב-Rust ונוצרים ל-Swift ו-Kotlin בזמן הבנייה.
- **היישומים**: SwiftUI ב-macOS ו-iOS, Jetpack Compose ב-Android, ויישום Windows מקורי. כל אחד גם מממש את חלקי הפלטפורמה שהליבה מבקשת: פלט שמע, זיהוי טקסט באמנות, פקדי מדיה, גישה למחזיק מפתחות ודיווח קריסות.

לצד היישומים: `bae-mcp` (שרת MCP) ו-`bae-automation`.

## ספרייה אחת בדיסק

ספרייה חיה בשתי תיקיות (תיקיות נתוני פלטפורמה במובייל): המאגר של coven, ולצידו ההגדרות של bae עצמו.

```
~/.bae/stores/<id>/       # המאגר של coven, נפתח רק דרך coven
  store.db                # SQLite: קטלוג, קרדיטים, מפרטי ניגון, ניהול החשבונות של coven
  files/                  # העותקים של coven לקבצים של bae עצמו (עטיפות, תמונות אמנים, אווטארים)
  cache/                  # עותקים במטמון ומוצמדים של קבצים שהועלו
~/.bae/libraries/<id>/    # של bae עצמו; לעולם לא מסתנכרן
  preferences.toml        # הגדרות bae
  cache/                  # אמנות שנמשכה מהקטלוגים
```

מסד הנתונים נפתח רק דרך coven, ששומרת את טבלאות הניהול שלה (רשומות מיזוג, תור העלאה, מצב קבצים) לצד הסכמה של bae ומריצה את ההגירה של bae. קובצי השמע של הוצאה מקומית אינם תחת `~/.bae` כלל: מסד הנתונים מפנה אליהם בנתיבים שבהם יובאו.

סודות לעולם לא חיים בקבצים האלה. מפתחות חברים, המפתחות של הספרייה, כניסות לענן ואסימוני API חיים במחזיק המפתחות של מערכת ההפעלה (Keychain בפלטפורמות Apple, המקבילות של הפלטפורמה במקומות אחרים); בפלטפורמות Apple קוד השחזור נשמר גם במחזיק המפתחות של iCloud.

## מהדורות

שתי מהדורות בזמן בנייה קיימות בכל פלטפורמה. **bae** מקמפלת פנימה את ספקי OAuth (Dropbox, OneDrive), CloudKit וטלמטריה. **baeium** מקמפלת את כל זה החוצה: אחסון תואם S3 בלבד, ובלי טלמטריה, שום דבר קנייני בעץ התלויות. המהדורות הן אותו מקור ואותה ליבה; דגל תכונה קובע את רשימת הספקים ואת חיבור האבחון.

## גרסאות

יישומים מקבלים גרסה כ-`MAJOR.MINOR` לכל פלטפורמה. המספר הראשי הוא תקופת התאימות, משותפת לכל יישום: מכשירים באותו מספר ראשי יכולים לסנכרן ספרייה. הוא עולה רק כשפורמט תעבורה או דיסק נשבר, לרוב גרסת coven המוצמדת. המספר המשני סופר הוצאות לכל יישום ואינו ניתן להשוואה בין פלטפורמות.

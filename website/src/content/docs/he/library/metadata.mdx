בזמן ייבוא, bae ממלא את הספרייה בנתונים ממסדי נתונים מקוונים.

## מה נשמר

כשמייבאים אלבום, bae שומר:

- **מידע על אלבום**: כותרת, אמן, שנה
- **מידע על רצועות**: שמות, משכים, מספרי דיסק ורצועה
- **תמונות**: עטיפות מ-MusicBrainz Cover Art Archive ומ-Discogs
- **מידע על מהדורה**: לייבל, מספר קטלוגי, ברקוד, מדינה, פורמט
- **מזהים חיצוניים**: Discogs release ID, MusicBrainz release ID ו-artist ID

כל הנתונים מגיעים מ-MusicBrainz ומ-Discogs ונשמרים במסד הנתונים של bae. bae לא קורא ולא כותב תגיות מוטמעות בקבצים. בין אם הקבצים מנוהלים או לא מנוהלים, הבייטים שלהם אינם משתנים.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> היא אנציקלופדיית מוזיקה פתוחה ומקור הנתונים הראשי של bae. היא מספקת רשימות רצועות מלאות, מידע על קבוצות מהדורות, קודי ISRC והתאמת CD TOC לזיהוי מדויק.

אין צורך במפתח API. MusicBrainz חינמי ופתוח. הוא אוכף ממוצע של בקשה אחת לשנייה לכל כתובת IP, ו-bae מרווח בקשות אוטומטית.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> הוא מסד נתונים ושוק מוזיקה, שימושי במיוחד למהדורות תקליטים, קרדיטים מפורטים, מספרים קטלוגיים ומידע על לייבלים.

Discogs דורש API token אישי. קבלו אותו מ-<a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a> והדביקו אותו בזמן ההגדרה. מגבלת הקצב היא 60 בקשות מאומתות בדקה, ו-bae מטפל בזה אוטומטית.

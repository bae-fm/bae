bae משתמש בשירותים חיצוניים בזמן הייבוא כדי להביא נתונים ותמונות. כך כל שירות משתלב ומה צריך להגדיר.

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> היא אנציקלופדיית מוזיקה פתוחה ומקור הנתונים הראשי של bae. היא מספקת:

- רשימות רצועות מלאות
- מידע על קבוצות מהדורות
- קודי ISRC
- התאמת CD TOC לזיהוי מדויק של דיסקים
- קישורים חיצוניים, כולל הפניות ל-Discogs

### אימות

אין צורך במפתח API. MusicBrainz חינמי ופתוח.

### מגבלות קצב

MusicBrainz אוכף ממוצע של בקשה אחת לשנייה לכל כתובת IP. אם עוברים את המגבלה, MusicBrainz מחזיר שגיאות 503 ועשוי לחסום זמנית את ה-IP. bae מרווח בקשות אוטומטית כדי להישאר בתוך המגבלה.

### מידע נוסף

ראו <a href="https://musicbrainz.org/doc/MusicBrainz_API" target="_blank">תיעוד MusicBrainz API</a> ו<a href="https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting" target="_blank">פרטי מגבלות הקצב</a>.

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> הוא מסד נתונים ושוק מוזיקה, חזק במיוחד עבור:

- מהדורות ותקליטים
- קרדיטים מפורטים כמו מפיק ומהנדס
- מספרים קטלוגיים וברקודים
- מידע על לייבלים

### אימות

Discogs דורש API token אישי. מגדירים אותו בזמן ההגדרה הראשונית של bae, וצריך להשתמש בטוקן שלכם.

### מגבלות קצב

Discogs מאפשר 60 בקשות מאומתות בדקה. bae מטפל בזה אוטומטית.

### התחלה

קבלו את הטוקן מ-<a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a>, והדביקו אותו בזמן ההגדרה.

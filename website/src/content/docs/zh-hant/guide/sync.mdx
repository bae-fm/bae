同步通常代表別人的伺服器：帳號、訂閱、可以讀取你資料庫的公司。bae 透過**你的**雲端同步，也就是你已有的儲存空間，且完全不執行伺服器。你的裝置會把加密變更寫入該儲存空間，並讀取彼此的變更；提供者持有位元組，但無法讀取。

一個資料庫、每個裝置，唯一涉及的帳號就是你已擁有的帳號。

## 雲端主目錄

資料庫的雲端主目錄是你儲存空間中的一個位置：你 Dropbox 或 OneDrive 中的資料夾、你的 iCloud，或任何 S3 相容 bucket（AWS、Backblaze B2、Cloudflare R2、Wasabi、MinIO、...）。它保存資料庫同步的一切：資料庫的變更、圖片，以及你移至雲端的發行版本音訊。

在「設定」「資料庫」中透過 **設定同步...** 設定：

1. 選擇提供者。
   - **Dropbox** 與 **OneDrive** 透過瀏覽器登入，接著詢問資料庫放在哪個資料夾。在 Dropbox 上是一個共用資料夾，讓你能邀請家人加入；如果還沒有，就在 Dropbox 中分享一個資料夾，然後選擇 **重新尋找**。在 OneDrive 上可以是任何資料夾，你也能在那裡建立新資料夾。登入資訊由 coven 保管；bae 從不接觸其 token。
   - **iCloud** 使用裝置目前登入的 Apple Account。
   - **S3** 只詢問 bucket、region、endpoint 與存取金鑰。**進階** 中有選用的 key prefix 與服務設定檔，預設為自動；對於 bae 無法辨識的服務，**偵測設定** 會用你的金鑰測試 bucket 並顯示它找到的結果。如果設定被拒絕，bae 會說明原因。
2. bae 開始同步。

沒有雲端主目錄的資料庫本身也是完整的。純本機是一種模式，不是限制；中斷雲端主目錄會回到該模式。

## 永遠加密

每個雲端主目錄保存的都是同一種東西：以隨機名稱存放的加密物件。每項變更、每張圖片與每個音訊檔都會先在你的裝置上加密再上傳。你的專輯不是 Dropbox 中任何人都能瀏覽的資料夾，提供者也看不到任何專輯、藝人或檔案名稱。請見[加密](/zh-hant/reference/encryption)。

## 同步什麼

- 資料庫：專輯、發行版本、曲目、名單、作品與藝人。每個裝置都會取得全部內容，包括音訊仍留在匯入裝置上的發行版本。
- 人員：每個人的名字與頭像、評分、播放紀錄與播放清單。你的紀錄與每個播放清單都可以只對你可見，或與家庭分享。
- 圖片：封面、藝人圖片與頭像會主動擷取，因此格狀清單可在各處呈現。
- 音訊：只針對你已移至雲端的發行版本。本機發行版本會出現在每個裝置上，但在你把它移至雲端之前，只能在匯入它的裝置上播放。請見[儲存與離線](/zh-hant/guide/storage)。

各裝置狀態不會同步：播放位置、音量、佇列與裝置設定會留在裝置上。

## 何時同步

同步會自行執行：變更後、定時，以及使用 **立即同步** 要求時。在一般條件下，編輯會在數秒後出現在其他裝置上。兩台裝置同時編輯時，只要沒有碰撞，兩邊都會保留：bae 會逐欄合併並行編輯，雙方都改過的欄位以較晚的編輯為準，而刪除的發行版本即使同時在別處被編輯，仍會保持刪除。沒有任何內容會要求你解決衝突。

## 失敗時

同步失敗不會中斷資料庫；bae 重試時，你仍可在本機瀏覽、播放與匯入。「設定」「資料庫」會為同步顯示一行：**已同步**，或有多少項目在等待，例如 **等待項目：3**。開啟它，就能以淺白的文字看到每個項目，以及你可以採取的動作：提供者要求重新登入時的 **登入**、把上傳前被移動的檔案放回原處、**重試**、**重新連線**、**繼續上傳** 或 **更新應用程式**。你幫不上忙的等待，例如等另一台裝置上線，不會提供任何動作。這份清單是唯一需要查看的地方；上傳也可以在 [Storage Manager](/zh-hant/guide/storage#storage-manager) 中暫停與檢查。

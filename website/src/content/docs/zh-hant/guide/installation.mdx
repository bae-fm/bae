## 兩個版本

每個平台都提供兩個版本，來自同一份原始碼：

- **bae**，完整 App：S3、Google Drive、Dropbox、OneDrive 與 iCloud 同步。
- **baeium**，不含專有部分：僅 S3 相容儲存，沒有 OAuth 提供者，沒有 iCloud/CloudKit，沒有遙測。

兩者可並存安裝，各自有自己的資料庫與自己的（會透過 iCloud Keychain 同步的）金鑰。請在下方選擇你要的版本。

1. 開啟下載的 `.dmg`
2. 將 App 拖到「Applications」資料夾
3. 從「Applications」開啟它

兩個版本都會透過各自的 Sparkle feed 自動更新。

## iOS

iOS 建置是**未簽署的 `.ipa` 檔，供側載使用**。使用 [AltStore](https://altstore.io) 或 [Sideloadly](https://sideloadly.io) 安裝，或在 Xcode 中用你自己的 Apple ID 重新簽署（免費 Apple ID 可用於 baeium）。App Store 發佈尚未設定。

## Windows

Windows 建置是未封裝 App 的**未簽署** zip。解壓縮並執行 `bae.exe` / `baeium.exe`。SmartScreen 可能在第一次啟動時警告。

你的檔案仍屬於你。bae 永遠不會移動、重新命名或重寫它們；儲存回答的問題只是每個發行版本的*可播放副本*位於哪裡：在裝置上、在你的雲端中，或兩者皆有。

## 不受管理與受管理

每個發行版本都是兩者之一，在匯入時選擇，且可隨時變更：

- **不受管理**：bae 在原位置把你的檔案編入目錄，並從那裡播放。不會複製任何內容。該發行版本會存在於每個同步裝置的目錄中，但其音訊只存在於匯入它的機器上。
- **受管理**：檔案會被加密並上傳到雲端主目錄。現在每個裝置都能播放該發行版本，視需要串流或下載離線使用。上傳不會改動你的原始檔；是否在本機繼續使用它們由你決定（匯入時的 **Keep local copy** 會固定它們）。

兩者之間的移動是發行版本層級的動作：**Manage** 會上傳不受管理的發行版本；**Make local** 會把受管理發行版本的檔案下載到你選擇的資料夾，重新成為你擁有的一般檔案。

## 串流與快取

受管理發行版本可在任何地方播放，只要網路允許：播放會從你的雲端串流檔案，位元組會保存在本機快取中，所以下次播放會立即開始且不需再次傳輸。快取會在預算內自行管理（每台裝置 20 GB 音訊），空間不足時移除你未播放的內容。封面與藝人圖片分開快取，因此大型專輯不會把圖片擠出去。

## 固定供離線使用

固定發行版本會下載全部內容並保留：固定的音樂永遠不會被移除，且永遠可離線播放。可從發行版本的儲存表單或 Storage Manager 固定；取消固定會把檔案交回一般快取，它們仍可播放，但可被回收。手機上，固定下載會直接在資料庫中顯示進度。

## Storage Manager

桌面端的 Storage Manager（<kbd>⌘0</kbd>）會在一個視窗中顯示完整情況：

- 每個發行版本及其大小與狀態：不受管理、受管理、上傳中。可篩選、排序、選取多個，並一次對它們執行動作。
- **Downloads**：進行中的固定下載，可暫停、可重試。
- **Exports**：匯出佇列。請見[匯出](/zh-hant/guide/exporting)。
- **Uploads**：同步寄件匣，含每個發行版本的進度、輸送量與剩餘時間、待處理刪除、暫停與繼續。

## 刪除

刪除受管理發行版本會從資料庫與雲端主目錄移除它。刪除不受管理發行版本只會移除目錄項目：bae 永遠不會刪除不是它放在那裡的檔案。

title: 匯入
description: 選擇每個資料夾如何提供匯入中繼資料
---

資料夾為匯入提供音訊與其他檔案。你可以選擇讓可編輯的中繼資料從線上發行版本、資料夾本身的中繼資料或空白表單開始。

匯入發生在桌面端（macOS、Windows）。你的檔案只會被讀取，不會被改動：bae 不會移動、重新命名、重寫標籤或重新編碼任何內容。匯入後檔案存放位置請見[儲存與離線](/zh-hant/guide/storage)。

## 監看資料夾

切換到 **匯入** 區段並加入資料夾：選取它、拖到視窗上，或按 <kbd>⌘I</kbd>。bae 從此會監看該資料夾。放入其中的新音樂會自行顯示為新候選項目；你不用手動重新掃描。仍在下載的資料夾會被忽略，直到完成為止。

掃描會辨識擷取實際會出現的版面：

| 版面 | 看起來像 |
|--------|-------------------|
| 每曲一檔 | `01 - Song.flac`、`02 - Song.flac`、… |
| CUE + 映像檔 | `album.cue` + `album.flac`，整張光碟一個檔案 |
| 多碟 | `CD1/`、`CD2/` 子資料夾，裡面可為任一版面 |
| 合集 | 資料夾裡有多個資料夾，每個都是自己的發行版本 |

bae 匯入它可播放的格式：FLAC、MP3、APE、ALAC 與 `.m4a` 中的 AAC、WAV、AIFF、Ogg Vorbis、Opus、WavPack，以及 DSD（`.dsf`/`.dff`）。資料夾中的圖片與文件（CUE sheet、擷取記錄、文字檔）會被辨識並與發行版本一起保留。

## 填寫中繼資料草稿

每個候選項目都有一份可編輯的中繼資料草稿。它可以從空白開始、由線上發行版本填入，或由資料夾本身檔案記載的內容填入。在空白草稿中輸入是直接輸入，不是另一個中繼資料來源。

卡片上的 **識別** 控制項提供兩種進入識別頁面的方式，差別在於它們會啟動什麼。**自動** 會開啟該頁面，並且每次都要求重新執行一次識別，不論候選項目已有什麼內容——正在進行的執行會被捨棄，改由新的執行取代。**搜尋** 會在手動搜尋上開啟同一個頁面，不啟動任何工作。兩者都不會改變草稿；套用結果會取代草稿並回到可編輯卡片。卡片選單中有兩個就地改寫草稿的指令：**重設為檔案中繼資料**，會以候選項目自己的檔案、sheet 與資料夾名稱所記載的內容取代草稿；以及 **清除中繼資料**，會清空草稿。兩者都會先詢問，也都不會碰候選項目的檔案或曲目版面。

### 識別

識別頁面會找出資料夾是哪一個發行版本。它會從資料夾讀取證據，並逐項查詢：

- **光碟 ID。** CD 精確曲目版面的指紋，從擷取記錄或 CUE sheet 計算而來。相符時，它能識別出確切的 CD 版本。
- **條碼。** 以文字辨識從資料夾中的封面掃描讀取，或從 CUE sheet 讀取。
- **目錄編號與文字。** 在圖片以及檔案與資料夾名稱中找到的目錄編號，用來縮小結果範圍。

這些訊號會同時在 MusicBrainz 與 Discogs 中查詢，結果會互相交叉核對。每個訊號會以標記顯示在結果上方：你可以看到找到了什麼、來自哪裡（游標停留可看來源：光碟 TOC、CUE sheet、封面掃描、資料夾名稱），並在某個訊號造成誤導時個別關閉它。

三種結果：

- **找到。** 證據一致指向同一個發行群組。你從其清單中選擇確切的壓片版本。
- **衝突。** 兩個訊號指向不同的發行版本，例如光碟 ID 與條碼不一致。bae 會顯示雙方，由你選擇要相信哪一個，或忽略某個訊號。
- **找不到。** 手動搜尋：在任一資料庫中依藝人與專輯、目錄編號或條碼搜尋。從圖片辨識出的文字會作為自動完成建議。

來源瀏覽器會同時顯示搜尋表單、識別進度、訊號與結果。選取結果後，該列會保持展開並顯示進度，同時 bae 擷取完整發行版本，然後把它套用到草稿。產生的卡片會顯示 MusicBrainz 或 Discogs 來源標籤。卡片上的 **自動** 會從頭再執行一次；**搜尋** 會回到手動搜尋，先前找到的內容仍會保留。

自動識別也使用同一條路徑。加入候選項目時，它的草稿會由其檔案、sheet 與資料夾名稱建立。「設定」「匯入」中的 **自動識別** 設定 會為每個對其目前檔案尚無結果的候選項目執行識別；關閉時，每次執行都由你自己啟動。預先填入的草稿只是起點，不是答案，因此不會阻止執行。

### 檔案中繼資料

檔案中繼資料會在加入候選項目、預先填入讀取它時讀取，之後每次選擇 **重設為檔案中繼資料** 時也會再次讀取。不論哪種情況，草稿都會被那次讀取的結果完全取代——內嵌音訊標籤、CUE 中繼資料，以及資料夾本身的名稱——卡片也會依此重新繪製。如果候選項目或其音訊檔在讀取後有所變更，匯入會在寫入資料庫前失敗。

當草稿保存的是那次讀取的內容時，可編輯卡片會顯示一個低調的「檔案中繼資料」來源標籤。只靠輸入填寫的草稿沒有來源標籤。

## 確認並匯入

確認窗格會顯示匯入將寫入的所有內容：

- **封面。** 從資料庫的圖片、你資料夾中的圖片或內嵌在檔案中的圖片中選擇。把圖片從候選項目圖庫拖到封面方塊上，或稍後再變更。
- **中繼資料。** 專輯、藝人、年份、廠牌、目錄編號、國家、條碼，以及每首曲目：所有項目都能在儲存前於此編輯。
- **儲存。** 如果已連接雲端主目錄，選擇 **雲端** 把發行版本上傳到那裡，選擇 **已釘選** 也在此裝置上保留它的檔案。否則發行版本就是本機的：它的資訊會同步到你的其他裝置，音訊則留在這台裝置上。請見[儲存與離線](/zh-hant/guide/storage)。

匯入會在背景執行：bae 會驗證每首曲目都能正確解碼、測量專輯與每首曲目的響度、儲存發行版本，並在雲端匯入中開始上傳。候選清單會前進到下一個資料夾，而發行版本會立即可播放。

## 資料來源

**MusicBrainz** 不需要帳號也不需要金鑰。**Discogs** 需要你自己的免費 API token；將它貼到「設定」「匯入」中，bae 會在它停止運作時告知。沒有 token 時，Discogs 搜尋與 Discogs 來源的中繼資料不可用，其餘功能照常運作。兩項服務都有速率限制；bae 會調整請求節奏以維持在限制內。

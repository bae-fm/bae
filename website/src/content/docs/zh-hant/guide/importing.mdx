---
title: 匯入
description: 將資料夾對應到真實發行版本
---

擷取出的資料夾對自身幾乎一無所知。它來自哪個發行版本、哪個壓片、哪個廠牌、有哪些名單、曲目 12 實際在哪裡結束：這些都存在 MusicBrainz 與 Discogs 這類資料庫中，而不是存在檔名裡。匯入就是 bae 連接兩者的方式：你把音樂指給它，它判斷每個資料夾是哪個發行版本，然後資料庫把該資料夾記錄為那個發行版本。

匯入發生在桌面端（macOS、Windows）。你的檔案只會被讀取，不會被改動：bae 不會移動、重新命名、重寫標籤或重新編碼任何內容。匯入後檔案存放位置請見[儲存與離線](/zh-hant/guide/storage)。

## 監看資料夾

切換到 **Import** 區段並加入資料夾：選取它、拖到視窗上，或按 <kbd>⌘I</kbd>。bae 從此會監看該資料夾。放入其中的新音樂會自行顯示為新候選項目；你不用手動重新掃描。仍在下載的資料夾會被忽略，直到完成為止。

掃描會辨識擷取實際會出現的版面：

| 版面 | 看起來像 |
|--------|-------------------|
| 每曲一檔 | `01 - Song.flac`、`02 - Song.flac`、... |
| CUE + 映像檔 | `album.cue` + `album.flac`，整張光碟一個檔案 |
| 多碟 | `CD1/`、`CD2/` 子資料夾，裡面可為任一版面 |
| 合集 | 資料夾裡有多個資料夾，每個都是自己的發行版本 |

bae 匯入它可播放的格式：FLAC、MP3、APE、ALAC 與 `.m4a` 中的 AAC、WAV、AIFF、Ogg Vorbis、Opus、WavPack，以及 DSD（`.dsf`/`.dff`）。資料夾中的圖片與文件（CUE sheet、擷取記錄、文字檔）會被辨識並與發行版本一起保留。

## 識別發行版本

選取候選項目後，bae 會開始識別。它不是從標籤猜測，而是讀取資料夾中的證據並逐項查詢：

- **Disc ID。** CD 精確曲目版面的指紋，從擷取記錄或 CUE sheet 計算。相符時可識別精確的 CD 版次。
- **條碼。** 使用文字辨識從資料夾中的封面掃描讀出，或從 CUE sheet 讀取。
- **目錄編號與文字。** 在圖片、檔名與資料夾名稱中找到的目錄編號，用來縮小結果範圍。

這些訊號會同時在 MusicBrainz 與 Discogs 查詢，結果會交叉檢查。每個訊號都會以徽章顯示在結果上方：你可以看到找到什麼、來源是哪裡（停留可看來源：disc TOC、CUE sheet、封面掃描、資料夾名稱），也可以在某個訊號誤導時關閉它。

三種結果：

- **找到。** 證據指向同一個發行群組。你從其清單中選擇精確壓片版本。
- **衝突。** 兩個訊號指向不同發行版本，例如 disc ID 與條碼不一致。bae 會顯示兩邊，讓你選擇信任哪個，或忽略某個訊號。
- **找不到。** 手動搜尋：藝人與專輯、目錄編號或條碼，可對任一資料庫搜尋。從圖片辨識出的文字會作為自動完成提供。

你也可以 **skip identifying**，以未知發行版本匯入。bae 接著會退回使用檔案內嵌標籤作為名稱；等該發行版本存在於資料庫中，或你有更好的證據時，可稍後重新識別。

## 精確或近似

選取相符項目時，bae 會用你的檔案檢查它，並標出曲目數量不一致。接著你宣告相符性：

- **Exact**：你的檔案就是這個壓片版本。
- **Metadata only**：專輯正確，但不一定是這個精確壓片。bae 會使用中繼資料，並記住壓片是近似的。

如果該發行版本已在你的資料庫中，或同一張專輯的另一個壓片版本已存在，bae 會在你匯入重複項目前告知。

## 確認並匯入

確認窗格會顯示匯入將寫入的所有內容：

- **封面。** 從資料庫圖片、資料夾中的圖片，或檔案內嵌圖片中選擇。稍後仍可變更。
- **中繼資料。** 專輯、藝人、年份、廠牌、目錄編號、國家、條碼，以及每首曲目：所有項目都能在儲存前於此編輯。
- **儲存。** 如果已連接雲端主目錄，選擇 bae 是否應在雲端管理檔案，以及是否也保留本機副本。請見[儲存與離線](/zh-hant/guide/storage)。

匯入會在背景執行：bae 會驗證每首曲目都能正確解碼、測量專輯與每首曲目的響度、儲存發行版本，並在受管理匯入中開始上傳。候選清單會前進到下一個資料夾，而發行版本會立即可播放。

## 資料來源

**MusicBrainz** 不需要帳號也不需要金鑰。**Discogs** 需要你自己的免費 API token；將它貼到「設定」中，bae 會在它停止運作時告知。沒有 token 時，Discogs 搜尋與 Discogs 來源的中繼資料不可用，其餘功能照常運作。兩項服務都有速率限制；bae 會調整請求節奏以維持在限制內。

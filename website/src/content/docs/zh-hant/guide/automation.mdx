資料庫可以由你執行的軟體操作：AI 代理可透過 MCP，腳本可透過命令列工具。兩者都公開 UI 使用的同一組操作：搜尋、發行版本詳細資料、匯入、儲存動作、播放狀態。

## MCP 伺服器

在「設定」、「自動化」中開啟 MCP 伺服器。它會在本機連接埠（預設為 47777）透過 HTTP 提供 Model Context Protocol，因此 Claude 等 MCP 用戶端可以瀏覽你的資料庫、查詢發行版本並對它們執行動作。存取需要 bearer token：從同一個設定窗格複製它；想讓所有持有舊 token 的項目失效時，也在那裡輪替。

伺服器預設關閉，且只在 App 執行期間運作。

## 命令列

`bae` CLI 從終端機操作同一組功能：輸入 JSON，輸出 JSON，適合腳本使用。它也可以作為 MCP 用戶端，把桌面端的伺服器橋接到 stdio，供預期本機 MCP 行程的工具使用。

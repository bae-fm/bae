## 資料模型

資料庫有本機 library home，也可以有一個 cloud home。發行版本檔案可位於本機、雲端或原始位置。

## bae

bae 使用本機身分、資料庫金鑰、可替換的 cloud home，以及加密變更集來同步多台裝置。

## 儲存空間

檔案可以是自管理、本機受管理或雲端受管理。本機檔案可離線播放；雲端檔案會透過 cloud home 同步到其他裝置。

## 加密

Opaque cloud home 會在資料離開裝置前以資料庫金鑰加密。Browsable cloud home 則以可讀路徑保存未加密檔案。

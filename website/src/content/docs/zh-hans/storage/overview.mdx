---
title: 存储概览
description: bae 如何保存音乐文件
---

发行版本文件最多可以存在于三个位置。导入发行版本时，你会在**受管理**和**非受管理**之间选择。受管理文件会被复制到 bae 的存储中；非受管理文件保持原位。

## 一览

|                              | 非受管理        | 受管理 — 本地    | 受管理 — 云端    |
|------------------------------|------------------|--------------------|--------------------|
| 文件位置                     | 你原来的位置    | `~/.bae/libraries/` | 云存储提供商       |
| 导入时 bae 复制文件          | 否               | 是                | 是                |
| 可离线使用                   | 是              | 是                | 否                 |
| 静态加密                     | 否               | 否                 | 仅 opaque home     |
| 可同步到云端                 | 否               | 是                | —                  |
| 同步到其他设备               | 否               | 否                 | 是                |
| 删除发行版本会删除文件       | 否               | 是                | 是                |

受管理发行版本可以只有本地文件、只有云端文件，或两者都有。如果配置了 cloud home，受管理导入会同时写入本地和云端。

## 非受管理

将 bae 指向你已经整理好的文件。bae 会建立索引，但不会移动、复制或修改任何内容。如果你已经有按自己方式整理的大量音乐，这可以在不复制文件的情况下把它们加入资料库。

限制是：bae 无法加密、同步或备份非受管理文件。

## 受管理 — 本地

每个资料库在本机都有一个 home 目录（`~/.bae/libraries/{uuid}/`）。bae 在这里保存数据库、图片，以及受管理发行版本的本地文件副本。

导入为受管理时，bae 会把文件复制到 library home。原始文件不会被修改。本地副本用于播放。

## 受管理 — 云端

cloud home 是一个远程存储位置，保存发行版本文件、元数据变更集、封面和快照。配置 cloud home 后，就可以进行多设备同步和云端备份。

如果导入受管理发行版本时已配置 cloud home，bae 会把文件复制到 library home，并上传到 cloud home。这两步都在导入时完成。

只存在于 cloud home 的发行版本（例如从另一台设备同步来、但尚未下载到本机）在文件拉取到本地前不能离线播放。

### Opaque 或 browsable

配置 cloud home 时，你会选择它如何保存对象；所有提供商都支持这个选择：

- **Opaque**（默认）使用资料库密钥加密每个对象，并把对象保存到混淆路径。提供商只能看到密文。
- **Browsable** 不加密保存内容，保留真实文件名，并使用稳定的 ID 路径，例如发行版本文件位于 `storage/{album_id}/{release_id}/{import_folder}/01 Track.flac`，封面位于 `images/{album_id}/{release_id}/cover.jpg`。你可以用提供商网页界面或文件浏览器直接查看、播放或复制文件。browsable 不是公开访问；访问仍由提供商凭据控制。

完整比较见[加密](/zh-hans/architecture/encryption#存储模式opaque-和-browsable)。

### 支持的提供商

- **Google Drive** — 用 OAuth 登录，bae 在你的 Drive 中创建文件夹
- **Dropbox** — 用 OAuth 登录
- **OneDrive** — 用 OAuth 登录
- **iCloud Drive**（macOS）— 使用你的 iCloud 容器，无需登录
- **兼容 S3** — 任意 bucket（AWS S3、Backblaze B2、Cloudflare R2、Wasabi、MinIO 等）

Google Drive、Dropbox 等消费云提供商使用 OAuth 登录，不需要 API key 或 bucket 配置。iCloud Drive（仅 macOS）使用已有 iCloud 容器。兼容 S3 的提供商需要手动配置凭据，面向更熟悉云存储的用户。

## 工作方式

1. 导入发行版本，选择**受管理**或**非受管理**
2. 受管理导入会把文件复制到 library home（本地）
3. 如果配置了 cloud home，受管理导入还会上传到那里：opaque home 中为加密数据，browsable home 中为明文文件
4. 连接到同一 cloud home 的其他设备会自动同步

多设备同步见[同步](/zh-hans/storage/sync)，文件加密见[加密](/zh-hans/architecture/encryption)。

---
title: 同步
description: 在多台设备之间同步资料库
---

bae 通过 cloud home 在多台设备之间同步资料库。每次编辑、导入和删除都会自动传播。

## 设置同步

1. 打开 **Settings > Sync**
2. 登录云提供商（Google Drive、Dropbox、OneDrive），使用 iCloud Drive（macOS），或输入 S3 凭据
3. bae 生成设备 ID 并开始同步

## 工作方式

同步是增量的：每次编辑都会产生一个小的变更集，变更集被加密并推送到 cloud home。其他设备会拉取并应用新的变更集。bae 会在每次变更后同步，并每 30 秒轮询一次以获取其他设备的变更。如果 cloud home 暂时不可访问，同步会在下一轮重试。

新设备会先从定期生成的完整快照启动，然后只应用该快照之后的变更集。

## 冲突处理

两台设备编辑同一数据时，bae 使用“最后写入者胜出”自动解决冲突。如果两台设备编辑同一发行版本的不同字段，两处更改都会保留。真正的冲突（同一字段被两端编辑）按时间戳解决。删除会覆盖并发编辑。

## 同步内容

- 元数据（专辑、曲目、艺人、厂牌）
- 专辑封面和艺人图片
- 发行版本文件（如果由 bae 管理）

设备专属设置（`config.yaml`）不会同步。

## 模式

同步不是非开即关：

- **仅本地** — 没有 cloud home，没有同步；所有内容停留在一台设备上。
- **在你的设备之间同步** — 变更集通过 cloud home 在你的设备之间同步，每台设备都有自己的设备 ID。

## 加密

cloud home 中的所有数据都会在上传前加密。云提供商看不到明文。见[加密](/zh-hans/architecture/encryption)。

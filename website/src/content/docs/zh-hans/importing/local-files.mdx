---
title: 导入
description: 从本地文件导入音乐
---

bae 从你的电脑导入 FLAC 文件。你选择一个文件夹，bae 扫描其中的发行版本；你把每个结果匹配到 MusicBrainz 或 Discogs 条目，然后 bae 导入元数据。

## 开始

点击标题栏中的 **Import**，选择 **Local Files**，再选择一个文件夹。

bae 会递归扫描该文件夹，识别发行版本，并把结果显示为候选项。你逐个确认候选项：识别发行版本、选择封面、选择存储方式，然后导入。

## 支持的格式

仅支持 FLAC，包括单曲文件和 CUE+FLAC 光盘镜像。

| 布局 | 示例 |
|--------|-------------------|
| 每首歌一个文件 | `01 - Song.flac`, `02 - Song.flac`, ... |
| CUE+FLAC | `album.cue` + `album.flac`（单个文件，由 cue sheet 切分） |
| 多碟 CUE+FLAC | `CD1/disc1.cue` + `CD1/disc1.flac`, `CD2/...` |

## 目录扫描

如果一个目录直接包含音频文件，或它的子目录看起来像光盘目录（例如 `CD1`、`CD2`、`Disc 1`、`Disc 2`，或 `1`、`2` 这样的数字），该目录会被视为一个发行版本。

光盘目录识别使用启发式规则：子目录名称必须较短（15 个字符以内），并且要么全是数字，要么共享至少 2 个字符的公共前缀。这能把多碟发行版本和多个独立专辑的集合区分开。

非叶子目录会继续向下扫描，最大深度为 10。文件会被归类为音频、封面图片（JPG、PNG、WEBP、GIF、BMP）或文档（CUE、LOG、TXT、M3U）。隐藏文件、零字节文件和损坏文件（错误的 FLAC 头、截断的音频）会被跳过。

## 识别

每个检测到的发行版本都需要匹配到 MusicBrainz 或 Discogs 条目，这样 bae 才能导入元数据。

- **自动识别** — 计算并查找 <a href="https://musicbrainz.org/doc/Disc_ID" target="_blank">MusicBrainz disc ID</a>。可从两类输入计算：
  - LOG 文件（EAC、XLD 等）
  - CUE sheet + FLAC 文件
- **手动搜索** — 通过以下信息搜索 MusicBrainz 和 Discogs：
  - 艺人和专辑名
  - 目录号
  - 条码

选择结果后，bae 会检查曲目数量是否与本地文件一致。不一致会被标出。

## 确认

匹配后，你会查看发行版本详情：

- **封面** — bae 从 MusicBrainz Cover Art Archive 和 Discogs 获取封面。文件夹中的图片（`cover.jpg`、`front.png` 等）也可使用。艺人图片从 Discogs 获取。
- **存储** — bae 管理（文件复制到 bae 存储；如果配置了 cloud home，会加密并上传）或自管理（bae 在原位置建立索引，不复制文件）。文件永远不会被修改。详情见[存储概览](/zh-hans/storage/overview)。

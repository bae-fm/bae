bae 在导入时使用外部服务获取元数据和封面。下面说明每个服务提供什么，以及如何配置。

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> 是开放的音乐百科，也是 bae 的主要元数据来源。它提供：

- 完整曲目列表
- 发行组信息
- ISRC 代码
- 用于准确识别 CD 的 CD TOC 匹配
- 外部链接，包括 Discogs 交叉引用

### 身份验证

不需要 API 密钥。MusicBrainz 是免费且开放的。

### 速率限制

MusicBrainz 要求同一 IP 平均每秒 1 个请求。超过限制时，MusicBrainz 会返回 503 错误，也可能临时封锁该 IP。bae 会自动间隔请求以保持在限制内。

### 了解更多

参阅 <a href="https://musicbrainz.org/doc/MusicBrainz_API" target="_blank">MusicBrainz API 文档</a>和<a href="https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting" target="_blank">速率限制说明</a>。

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> 是音乐数据库和市场，尤其适合：

- 黑胶发行版本和压片版本
- 详细人员名单（制作人、录音师等）
- 目录号和条码
- 厂牌信息

### 身份验证

Discogs 需要个人 API token。你会在 bae 初始配置中设置它，并且需要使用自己的 token。

### 速率限制

Discogs 允许每分钟 60 个已认证请求。bae 会自动处理这个限制。

### 开始

从 <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a> 获取 token，在设置时粘贴即可。

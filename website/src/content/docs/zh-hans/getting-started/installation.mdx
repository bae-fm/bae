## 两个版本

每个平台都有两个版本，二者来自同一套源码：

- **bae** — 完整应用：支持 S3、Google Drive、Dropbox、OneDrive 和 iCloud 同步。
- **baeium** — 不包含专有部分：只支持兼容 S3 的存储，没有 OAuth 提供商、没有 iCloud/CloudKit、没有遥测；全部代码按 Apache-2.0 授权。

两个版本可以并排安装。它们各自拥有独立的资料库和各自的密钥（可通过 iCloud 钥匙串同步）。按你的需要选择下面的版本。

1. 打开下载的 `.dmg`
2. 将应用拖到“应用程序”文件夹
3. 从“应用程序”中打开

两个版本都会通过各自的 Sparkle 更新源自动更新。

## iOS

iOS 构建是**用于侧载的未签名 `.ipa` 文件**。可用 [AltStore](https://altstore.io) 或 [Sideloadly](https://sideloadly.io) 安装，也可以在 Xcode 中用你自己的 Apple ID 重新签名（免费 Apple ID 可用于 baeium）。App Store 分发尚未配置。

## Windows

Windows 构建是**未签名**的免安装应用 zip。解压后运行 `bae.exe` 或 `baeium.exe`。首次启动时 SmartScreen 可能会提示警告。

## 从源码构建

baeium 构建不需要任何专有组件。请参阅 [repository README](https://github.com/bae-fm/bae#building-baeium-yourself)，其中包含各平台的自构建说明，包括使用免费 provisioning 构建 iOS。

## 概览

bae 帮助你建立并整理音乐资料库。你可以：

1. **导入音乐**：从本地文件导入单曲，或导入 CUE/FLAC 专辑镜像
2. **补全元数据**：从 MusicBrainz 和 Discogs 自动获取专辑、曲目和封面信息
3. **浏览资料库**：按艺人、专辑、类型或年份查看音乐

## 第一次导入

### 导入本地文件

最快的开始方式是导入已有音乐：

1. 点击侧边栏中的 **Import**
2. 选择 **Local Files**
3. 选择包含音乐的文件夹
4. bae 扫描文件夹并显示找到的内容
5. 选择匹配的 MusicBrainz 或 Discogs 发行版本
6. 点击 **Import**

bae 会导入元数据、下载封面，并按你选择的存储方式保存文件。

### 资料库位置

默认情况下，bae 将资料库元数据保存在：

- **macOS**：`~/.bae/libraries/<library-id>/`

音频文件会被加密并上传到 cloud home，或者在自管理模式下保持原位并建立索引。详情见[存储概览](/zh-hans/storage/overview)。

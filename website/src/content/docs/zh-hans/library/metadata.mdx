导入时，bae 会用在线数据库中的元数据填充资料库。

## 保存什么

导入专辑时，bae 会保存：

- **专辑信息**：标题、艺人、年份
- **曲目信息**：名称、时长、碟号和曲目号
- **封面**：来自 MusicBrainz Cover Art Archive 和 Discogs 的封面图
- **发行信息**：厂牌、目录号、条码、国家、格式
- **外部 ID**：Discogs release ID、MusicBrainz release ID 和 artist ID

所有元数据都来自 MusicBrainz 和 Discogs，并保存在 bae 数据库中。bae 不读取也不写入文件内嵌标签。无论文件是受管理（复制到 bae 存储）还是非受管理（保持原位），文件字节都不会改变。

## MusicBrainz

<a href="https://musicbrainz.org" target="_blank">MusicBrainz</a> 是开放音乐百科，也是 bae 的主要元数据来源。它提供完整曲目列表、发行组信息、ISRC 代码，以及用于准确识别的 CD TOC 匹配。

不需要 API key。MusicBrainz 免费且开放。它要求同一 IP 平均每秒 1 个请求；bae 会自动间隔请求。

## Discogs

<a href="https://www.discogs.com" target="_blank">Discogs</a> 是音乐数据库和市场，尤其适合黑胶发行、详细人员名单、目录号和厂牌信息。

Discogs 需要个人 API token。请从 <a href="https://www.discogs.com/settings/developers" target="_blank">Discogs Developer Settings</a> 获取，并在设置中粘贴。速率限制为每分钟 60 个已认证请求；bae 会自动处理。

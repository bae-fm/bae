---
title: 导出
description: 以你需要的形态取出音乐
---

不锁定也有两个方向：bae 不会在导入时改动你的文件，也不会在导出时扣住它们。非托管发行本来就是你文件夹中的文件。托管发行也可以随时重新变成本地文件，逐字节一致。而当你需要一种*不同*形态时，比如适合手机的编码或可刻录的镜像，导出会生成它，不触碰原件。

## 两种导出

- **曲目导出**：右键点击曲目，选择 **Save As**，选格式，完成。
- **发行导出**：从专辑菜单或 Storage Manager 导出整个发行到一个文件夹。它在队列中运行，带进度、暂停和重试。

原始文件会按原样导出。其他所有内容都会在导出途中编码。

## 预设

导出格式是在 Settings 中定义一次的预设：FLAC、MP3、Opus、WAV 或 AIFF，包含编解码器参数（无损格式的位深，有损格式的码率）以及由 title、artist、album、year、track number 这类 token 组成的文件名模板。为曲目和发行分别设置默认预设，并选择发行导出是每次询问目标位置，还是总是使用固定文件夹。

## 导出中的预间隙

带 pregap 的 CD 抓轨在导出时会提出一个真实问题：隐藏音频放在哪里？每个预设选择一种策略：

- **追加到上一曲**，常见约定；可选择第一曲之前隐藏的音频是保留在第一曲开头，还是丢弃。
- **排除**所有 pregap：曲目边界清楚，省略隐藏音频。
- **带 CUE 的单文件**：整张碟作为一个音频文件加一张 CUE sheet，精确保留原始布局。

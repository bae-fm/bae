文件夹为导入提供音频和其他文件。你可以选择让可编辑的元数据从在线发行、文件夹自身的元数据或空白表单开始。

导入发生在桌面端（macOS、Windows）。你的文件会被读取，但永远不会被改动：bae 不会移动、重命名、重写标签或重新编码任何内容。导入后文件放在哪里，见[存储和离线](/zh-hans/guide/storage)。

## 监视文件夹

切换到 **导入** 区域并添加文件夹：选择它、拖到窗口上，或按 <kbd>⌘I</kbd>。从那之后 bae 会监视该文件夹。新音乐放进去后会自动显示为新候选项；不需要手动重新扫描。仍在下载的文件夹会被忽略，直到下载完成。

扫描会识别抓轨实际采用的发行形态：

| 布局 | 看起来像什么 |
|--------|-------------------|
| 每轨一个文件 | `01 - Song.flac`、`02 - Song.flac`、… |
| CUE + 镜像 | `album.cue` + `album.flac`，整张碟一个文件 |
| 多碟 | `CD1/`、`CD2/` 子文件夹，内部可为任一形态 |
| 合集 | 一个包含多个文件夹的文件夹，每个子文件夹都是自己的发行 |

bae 导入它能播放的格式：FLAC、MP3、APE、ALAC 和 `.m4a` 中的 AAC、WAV、AIFF、Ogg Vorbis、Opus、WavPack，以及 DSD（`.dsf`/`.dff`）。文件夹中的图像和文档（CUE sheets、抓轨日志、文本文件）会被识别并与发行一起保留。

## 填写元数据草稿

每个候选项都有一个可编辑的元数据草稿。它可以从空白开始，可以由在线发行填充，也可以由文件夹自身文件中的信息填充。在空白草稿中输入内容属于直接录入，而不是单独的元数据来源。

卡片上的 **识别** 控件提供两种进入识别页面的方式，区别在于它们会启动什么。**自动** 会打开该页面，并且每次都请求一次全新的识别运行，无论候选项已有什么内容——已在进行的运行会被丢弃，换成新的运行。**搜索** 会在同一页面上打开手动输入的搜索，不启动任何操作。两者都不会改动草稿；应用某个结果会替换草稿并返回可编辑卡片。卡片菜单中有两个就地重写草稿的命令：**重置为文件元数据**，用候选项自身的文件、CUE sheet 和文件夹名称所提供的信息替换草稿；以及 **清除元数据**，清空草稿。两者都会先询问，并且都不会触碰候选项的文件或曲目布局。

### 识别

识别页面会找出一个文件夹对应的是哪个发行。它从文件夹中读取证据，并逐项查询：

- **碟片 ID。** 根据抓轨日志或 CUE sheet 计算出的 CD 精确曲目布局指纹。匹配时，它能识别出确切的 CD 版本。
- **条码。** 通过文字识别从文件夹中的封面扫描图读取，或从 CUE sheet 读取。
- **目录号和文本。** 在图像以及文件和文件夹名称中找到的目录号，用来缩小结果范围。

这些信号会同时在 MusicBrainz 和 Discogs 中查询，结果会相互核对。每个信号都会以徽章形式显示在结果上方：你可以看到找到了什么、来自哪里（悬停可查看来源：碟片 TOC、CUE sheet、封面扫描、文件夹名称），并在某个信号造成误导时单独关闭它。

三种结果：

- **已找到。** 证据都指向同一个发行组。你从其列表中选择确切的压制版本。
- **冲突。** 两个信号指向不同的发行，比如碟片 ID 和条码不一致。bae 会显示双方，由你选择信任哪一方，或忽略某个信号。
- **未找到。** 手动搜索：按艺人和专辑、目录号或条码，在任一数据库中搜索。从图像中识别出的文字会作为自动补全提供。

来源浏览器会同时显示搜索表单、识别进度、信号和结果。选择某个结果后，该行会保持展开并显示进度，同时 bae 获取完整发行，然后把它应用到草稿。生成的卡片会显示 MusicBrainz 或 Discogs 来源标签。卡片上的 **自动** 会从头再次运行识别；**搜索** 会回到手动搜索，之前已找到的内容仍然保留。

自动识别使用同一路径。添加候选项时，它的草稿由其文件、CUE sheet 和文件夹名称创建。“设置”“导入”中的 **自动识别** 设置 会为每个尚未针对当前文件得到结果的候选项运行识别；关闭后，每次运行都由你自己启动。预先填好的草稿只是起点，不是答案，因此不会阻止识别运行。

### 文件元数据

文件元数据会在添加候选项时由预填充读取，并在每次选择 **重置为文件元数据** 时再次读取。无论哪种情况，草稿都会被这次读取的确切结果替换——内嵌音频标签、CUE 元数据以及文件夹自身的名称——卡片也会据此重新绘制。如果候选项或其音频文件在这次读取之后发生变化，导入会在写入资料库之前失败。

当草稿持有的是这次读取的内容时，可编辑卡片会显示一个不显眼的“文件元数据”来源标签。仅通过输入填写的草稿没有来源标签。

## 确认并导入

确认窗格会显示导入将写入的一切：

- **封面。** 从数据库的图像、文件夹中的图片或文件中内嵌的图像中选择。把图片从候选项图库拖到封面方块上，或以后再更改。
- **元数据。** 专辑、艺人、年份、厂牌、目录号、国家或地区、条码，以及每一轨：在保存任何内容前都可在这里编辑。
- **存储。** 如果已连接云端主目录，选择 **云端** 把发行上传到那里，选择 **已固定** 在本设备上也保留它的文件。否则发行就是本地的：它的信息会同步到你的其他设备，音频则留在这台设备上。见[存储和离线](/zh-hans/guide/storage)。

导入在后台运行：bae 会验证每一轨都能完整解码，为专辑和每一轨测量响度，保存发行，并且对于云端导入开始上传。候选列表会移到下一个文件夹，发行会立即可播放。

## 数据来源

**MusicBrainz** 不需要账号或密钥。**Discogs** 需要你自己的免费 API token；把它粘贴到“设置”“导入”中，如果它停止工作，bae 会告诉你。没有 token 时，Discogs 搜索和来自 Discogs 的元数据不可用，其他功能照常工作。两个服务都有速率限制；bae 会控制请求节奏，使其保持在限制内。

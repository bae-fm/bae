## 两个版本

bae 提供两个版本，来自同一份源代码：

- **bae**，完整应用：S3、Google Drive、Dropbox、OneDrive 和 iCloud 同步。
- **baeium**，不含专有部分：仅支持 S3-compatible storage，无 OAuth providers，无 iCloud/CloudKit，无 telemetry。

它们可以并排安装，各自拥有自己的资料库和自己的（通过 iCloud Keychain 同步的）密钥。下面选择你需要的版本。

1. 打开下载的 `.dmg`
2. 将应用拖到 Applications 文件夹
3. 从 Applications 打开它

两个版本都会通过各自的 Sparkle feed 自动更新。

## iOS

iOS 构建是**用于侧载的未签名 `.ipa` 文件**。使用 [AltStore](https://altstore.io) 或 [Sideloadly](https://sideloadly.io) 安装，或在 Xcode 中用你自己的 Apple ID 重新签名（免费 Apple ID 可用于 baeium）。App Store 分发尚未设置。

## Windows

Windows 下载的是安装程序，按用户安装并自动保持更新。构建未签名，SmartScreen 可能会在首次启动时警告。每个 [GitHub 发布](https://github.com/bae-fm/bae/releases) 还附带一个可原地运行的便携 zip。Windows 只发布完整版本。

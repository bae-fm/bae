资料库可以由你运行的软件驱动：AI 代理通过 MCP，脚本通过命令行工具。两者暴露的操作与 UI 使用的相同：搜索、发行详情、导入、存储操作、播放状态。

## MCP 服务器

在 Settings、Automation 中打开 MCP 服务器。它通过本地端口上的 HTTP 提供 Model Context Protocol（默认 47777），因此 Claude 这类 MCP 客户端可以浏览你的资料库、查找发行并对其执行操作。访问需要 bearer token：从同一个设置面板复制；想切断所有持有旧 token 的访问时，也在那里轮换它。

服务器默认关闭，并且只在应用运行时运行。

## 命令行

`bae` CLI 从终端驱动相同的操作：输入 JSON，输出 JSON，适合脚本。它也可以充当 MCP 客户端，把桌面应用的服务器桥接到 stdio，供需要本地 MCP 进程的工具使用。

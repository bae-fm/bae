---
title: 存储和离线
description: 你的音乐在哪里，以及无网络时能播放什么
---

你的文件仍属于你。bae 永远不会移动、重命名或重写它们；存储要回答的只是每个发行的*可播放副本*在哪里：在设备上、在你的云端，或两者都有。

## 本地和云端

每个发行都是二者之一，在导入时选择，并可随时更改：

- **本地**：bae 在文件原位置建目录，并从那里播放。不复制任何内容。发行的信息会同步，因此每台设备都会显示专辑、曲目和封面，但音频只留在导入它的机器上，其他设备无法播放。
- **云端**：文件会加密并上传到云端主目录。现在每台设备都能播放该发行，可按需串流或下载以离线使用。上传不会触碰你的原始文件。

导入时，如果已连接云端主目录，**云端** 会上传新发行，**已固定** 还会在本设备上保留它的文件。之后，**移至云端** 可上传本地发行；bae 会先检查每个文件自导入以来未被改动，改动过的文件会使上传停止。**设为本地…** 会把云端发行的文件复制到你选择的文件夹，校验每份副本，并从那里播放该发行；它们再次成为你的普通文件，其他设备也就无法再播放它。

## 串流和缓存

只要网络允许，云端发行可在任何地方播放：播放会从你的云端串流文件，并把字节保存在本地缓存中，所以下次播放会直接读取本地。缓存会在预算内自行管理（每台设备 20 GB 音频），空间不足时清除你未播放的内容。封面和艺人图像分开缓存，因此大型专辑不会挤出你的图像缓存。

## 固定为离线

固定发行会下载它的全部内容并保留：固定音乐永远不会被清除，并且始终可离线播放。从发行的存储面板或 Storage Manager 固定；取消固定会把文件放回普通缓存，它们仍可播放，但可被回收。在手机上，固定下载的进度会直接显示在资料库中。

## Storage Manager

桌面端 Storage Manager（<kbd>⌘0</kbd>）把全貌放在一个窗口中：

- 每个发行及其大小和状态：本地、云端、上传中。可筛选、排序、选择多个，并一次性对它们执行操作。
- **Downloads**：正在进行的固定下载，可暂停、可重试。
- **Exports**：导出队列。见[导出](/zh-hans/guide/exporting)。
- **Uploads**：同步发件箱，带每个发行的进度、吞吐量和剩余时间、待处理删除、暂停和恢复。

## 删除

删除云端发行会把它从资料库中移除，并从云端主目录中移除它的副本。删除本地发行只会移除目录项。无论哪种情况，bae 都不会删除你自己的文件。

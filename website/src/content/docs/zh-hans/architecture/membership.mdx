---
title: Membership
description: 身份、membership chain 和已签名变更集
---

资料库的 membership 是被授权读写该资料库的设备集合。本页说明背后的技术机制：身份、membership chain、已签名变更集和密钥封装。

## 身份

每台设备都有一个 Ed25519/X25519 密钥对，在首次使用时生成并保存在操作系统钥匙串中。公钥就是身份。没有中央目录或账号服务器。公钥通过系统外方式交换。

## Membership chain

资料库的 membership 由保存在 cloud home 中的追加式签名条目链记录，路径为 `membership/{pubkey}/{seq}.enc`。每个条目记录 Add 或 Remove 操作、目标设备的公钥和角色，并由当前 owner 签名。

第一条记录总是把创建资料库的设备加入为 owner。构建链时会校验所有条目；签名无效或来自非 owner 的条目会被拒绝。

## 已签名变更集

推送到 cloud home 的每个变更集都由作者设备的 Ed25519 密钥签名。拉取时，bae 会检查作者在创建该变更集时是否是已授权设备（通过 membership chain 判断）。来自未授权设备或签名无效的变更集会被丢弃。

## 密钥封装

资料库加密密钥会通过 sealed box 加密给每台设备的 X25519 公钥，并保存在 cloud home 的 `keys/{user_pubkey}.enc`。只有目标设备能用自己的私钥打开它。设备被撤销时，会生成新的加密密钥，并重新封装给所有剩余设备。

## 邀请码

邀请码包含新设备加入所需的一切：

- 资料库加密密钥，sealed box 加密给新设备的公钥
- cloud home 坐标（提供商类型、文件夹 ID 或 bucket）
- 存储凭据（S3 中为生成的 IAM 凭据；消费云中通过提供商 API 共享文件夹）
- 一条已签名的 membership 条目，用于加入新设备

owner 设备在收到新设备公钥后生成该代码。新设备把代码粘贴到 bae 中，打开加密密钥，连接 cloud home，并开始同步。

# AndroidSyncStatus

How the library syncs, in Settings on Android, with the same props as `MacSyncStatus`. When this device last synced is a line at the bottom of the same tile, not a row of its own.

**In the code:** Android: `AndroidSyncStatus` (`bae-android/app/src/main/java/fm/bae/app/ui/settings/SyncScreen.kt`).

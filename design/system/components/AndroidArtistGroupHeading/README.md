# AndroidArtistGroupHeading

Heads an artist's albums when the grid is grouped by artist: round picture, name, album count. `pinned` once scrolled under the header: smaller, with a line under it.

**In the code:** Android: `AndroidArtistGroupHeading` (`ui/library/AndroidArtistGroupHeading.kt`), placed by the album grid (`ui/library/LibraryGrid.kt`).

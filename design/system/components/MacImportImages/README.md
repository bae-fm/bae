# MacImportImages

The folder's images on the import pane, under the release: a ruled Images heading, then each image at 128pt in a row, each a button named by its file that opens the lightbox at that image (`images`: "artwork title|file name", comma-separated). A Found folder's pane and an imported release's both show it.

The heading is a `MacFormHeading`.

**In the code:** macOS: `MacImportImages` (`Views/Import/Mapping/ImportMappingGallery.swift`): the ruled heading and `ImportMappingGallery`.

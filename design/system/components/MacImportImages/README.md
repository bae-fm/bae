# MacImportImages

The folder's images on the import pane, under the release: a ruled Images heading, then each image at 128pt in a row. A Found folder's pane and an imported release's both show it.

**In the code:** macOS: `MacImportImages` (`Views/Import/Mapping/ImportMappingGallery.swift`): the ruled heading and `ImportMappingGallery`.

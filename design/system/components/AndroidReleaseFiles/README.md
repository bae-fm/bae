# AndroidReleaseFiles

An album page's Files: the release's files that no track plays from, under the Files eyebrow. Each file is a divider over a line with its name at the start and its kind at the end, in the secondary text.

| Prop | What it does |
|---|---|
| `files` | The files, as `name|kind` entries separated by semicolons. |

**In the code:** Android: `AndroidReleaseFiles` (`ui/albumdetail/AndroidReleaseFiles.kt`).

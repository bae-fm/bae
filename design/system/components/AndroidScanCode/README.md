# AndroidScanCode

A code another device scans: one thing at a time. What to do above, the QR code, then the buttons that hand over the code as text (Copy code, Share) and nothing else, then when it ends below. The code's text is never shown beside the QR code.

**In the code:** Android: `AndroidScanCode` (`ui/components/AndroidScanCode.kt`), the instruction, the QR code of what it is given at 240dp, and Copy code and Share, which hand out the code to type; Add device's dialog and the invite's dialog draw it.

# MacActivity

The toolbar's Activity panel, where bae lists what it needs the person for and what it's moving. Needs Attention comes first, each problem a quiet row of its box (no fill, the glyph in its tone), a line between rows: problems the caller passes in (children, each a `MacNotice`, such as a sign-in settings file that's missing or a library that wouldn't close), bae couldn't read sync's status (`error`, no button) and sync's own (`attention`, a record and its reason, then Open Sync Settings, which closes the panel and opens sync settings). Nothing in the panel retries in place: a notice takes the person to where the problem is handled. Then Transfers (syncing, uploads with bytes, downloads), or “Everything is up to date.” A row has no Details: clicking it opens an alert with the explanation and the error's causes (`MacAlert` with `details`). Each problem has an × that dismisses it from the panel; that doesn't fix it, and it still shows where it's fixed (such as Settings → Sync). A problem shows here and nowhere else in the window; the toolbar's button shows the warning glyph while a problem that hasn't been dismissed is listed; once every problem is dismissed, it goes back to its usual look.

**In the code:** macOS: BaeKit's `SyncActivityList` in `SyncActivityButton`'s popover, which today holds only sync's own problems.

# MacActivity

The toolbar's Activity panel, where bae lists what it needs the person for and what it's moving. Needs Attention comes first, each problem a quiet row of its box (no fill, the glyph in its tone), a line between rows: problems the caller passes in (children, each a `MacNotice`, such as a sign-in settings file that's missing or a library that wouldn't close), bae couldn't read sync's status (`error`, no button) and sync's own (`attention`, a record and its reason, then Open Sync Settings, which closes the panel and opens sync settings). Nothing in the panel retries in place: a notice takes the person to where the problem is handled. Then Transfers, one line each, its words, how far it has got and a bar: Syncing changes (no count, so its bar moves), Uploading "1 of 2 releases", Pinning "1 of 3 releases", Making local "0 of 1 release". Every count is in releases, a release done once all its files are; every bar is filled by the bytes of the batch done, so it moves while a release transfers and its count waits. The count is what's done of everything the queue has held since it was last empty, so it only grows. A queue's hold (Paused, Waiting for network) stands in place of its count. Making local has its own line: a make-local changes where files live for every device, a pin only keeps a copy here, so neither is counted as the other. No icons; Transfers is its own box, so its lines start at the box's inset, never on the problems' text edge, or “Everything is up to date.” A row has no Details: clicking it opens an alert with the explanation and the error's causes (`MacAlert` with `details`). Each problem has an × that dismisses it from the panel; that doesn't fix it, and it still shows where it's fixed (such as Settings → Sync). A problem shows here and nowhere else in the window; the toolbar's button shows the warning glyph while a problem that hasn't been dismissed is listed; once every problem is dismissed, it goes back to its usual look. Each queue's line ends in a Pause button, Resume (a play symbol) while that queue is paused; Pinning and Making local are one queue, so their buttons pause and resume both. Syncing changes has none. Under Transfers, Open Storage Manager. While a queue is held (Paused, Waiting for network) and nothing moves, the button shows a pause symbol, so the hold can be seen and undone from here.

**In the code:** macOS: BaeKit's `SyncActivityList` in `SyncActivityButton`'s popover, which today holds only sync's own problems.

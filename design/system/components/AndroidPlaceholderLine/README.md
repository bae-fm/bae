# AndroidPlaceholderLine

A bar in `missing-art` where text or a picture will be while it loads, as `MacPlaceholderLine`: `width` and `height` in dp, `radius` for a picture's corners (a bar's own corners otherwise), and `fixed` so a row never narrows it. `AndroidQueuePlaceholderRow` draws one for the cover and one for each line.

**In the code:** Android: `AndroidPlaceholderLine` (`ui/playback/AndroidQueuePlaceholderRow.kt`).

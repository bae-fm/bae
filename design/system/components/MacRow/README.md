# MacRow

`chevron` when the row opens something. `action` for a row that is itself the action, at the end of the list it adds to: "Invite…". `selected` for the chosen row in a choice list. `nested` for a setting that belongs to the switch row above it, with no divider between them: "Countdown" under "Pause between sides and discs".

**In the code:** macOS: `LabeledContent` in a grouped `Form`.

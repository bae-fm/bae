# MacBackButton

The round back button before a page's heading, named Back to and where it goes back to (`to`): a Settings page under another (`MacSettingsWindow`'s `back`), and a playlist open in the side pane (`MacPlaylistPage`), which goes back to the playlists.

**In the code:** macOS: the back button of `SettingsPageHeader` (`Views/Settings/SettingsPageHeader.swift`); the side pane has none yet.

# AndroidInviteFields

The invite form's fields on Android, as `MacInviteFields` draws them, with a text button under the S3 key that switches between their key and yours. `storage` is `s3` (the default), `dropbox` or `onedrive`.

**In the code:** Android: `InviteFormFields` and `InviteAccessFields` (`bae-android/app/src/main/java/fm/bae/app/ui/settings/InviteDialog.kt`).

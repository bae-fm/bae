# MacPersonTag

A person's small picture, or initials, beside their name (`name`), as a history row ends in whose play it was. `strong` is a playlist header's owner line: the name in semibold at the size of the text around it.

**In the code:** macOS: `MacPersonTag` (`Views/Components/MacPersonTag.swift`), which `MacListRow` and `MacPlaylistHeader` draw.

# MacSortPill

One sort criterion of the library's sort: the field's menu, the direction (`direction`, up or down) and, while the sort has more than one criterion (`removable`), the × that removes it. `field` names the field. The pill fills with `control`, as a push button does.

The field and the + are menu buttons. The direction is a button named for the direction the sort goes, Ascending or Descending, and pressing it flips the direction.

**In the code:** macOS: `MacSortPill` (`Views/Library/Sort/MacSortPill.swift`).

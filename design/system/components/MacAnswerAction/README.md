# MacAnswerAction

A way to answer a folder that waits on you, at the foot of Identify's Automatic section: a small button, then a line in small tertiary text that says what it does. Identify offers "None of these" under releases it found, "Keep my info" where it found none, and "Not sure" where the releases are pressings of one album.

| Prop | What it does |
|---|---|
| `title` | The button's words. |
| `subtitle` | What the button does. |
| `off` | bae is importing the folder, so the button can't act. |

**In the code:** macOS: `MacAnswerAction` (`Views/Import/Search/MacAnswerAction.swift`).

# AndroidRow

`icon`: `chevron` when the row opens a page, `edit` when it opens a dialog to change the value. `action` for a row that is itself the action, with `leadingIcon` `add` when it adds to the list: "Add device", "Invite", last in the card. `value` puts the label's value at the row's far end, in the secondary colour, as `MacRow`'s does: a member's details, a restore form's summary. `nested` for a setting that belongs to the switch row above it: joined to the switch's row in one piece of the card, with no gap, and set in from the card's edge so it reads as under the switch: "Resume automatically" under "Pause between sides and discs".

A row the person taps reads as one button named by its words, title then subtitle then value, as Compose merges a clickable row: one with `icon`, `action` or `destructive` is, and `button` marks the rest, such as a Settings page's entry or a row that opens a choice dialog ("Listening history", "Convert to"). A row that ends in controls of its own (a ⋮ menu) gives the button to its words alone. A row that only shows a value (Provider, Account) is no button. `off` dims a row that can't be used for now, as `MacRow`'s does: the other libraries and Add library while one is being removed.

**In the code:** Android: `AndroidRow` (`ui/components/AndroidRow.kt`), with `icon` (chevron or edit), `tag` as a status chip after the title, and `value` for a label and its value in a dialog.

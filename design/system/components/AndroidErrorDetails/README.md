# AndroidErrorDetails

`MacErrorDetails` on Android: the causes, one a line, in an inset panel with a copy icon button at its corner. It goes in a dialog: under the explanation, before the actions (the Activity sheet's problems open such a dialog).

| Prop | |
| --- | --- |
| `details` | The causes, one a line. |

**In the code:** Android: `AndroidErrorDetails` (`ui/components/AndroidNotice.kt`), in `ErrorDetailsDialog` (`ui/components/ErrorDetails.kt`).

# MacModalHeader

A modal's header: title (22pt with `large`), a second line (`subtitle`), then a release's edition line (`edition`) and copy line (`copy`), as the Edit release sheet names its release, buttons on the right.

**In the code:** macOS: `MacModalHeader` (`Views/Components/MacModalHeader.swift`), in `ReleaseEditorSheet`, `ReleaseStorageSheet` and `MacCoverGallery`.

# MacImportTrackRow

A track row: play/stop and the file (or a sheet entry's title) position, title, artist (“Album artist” when inherited), length (warning when the lengths differ). `playing` tints the row.

**In the code:** macOS: `ImportMappingTrackRow` and `ImportMappingSourceCell`.

No file, track or image carries a label saying which clue was read from it (a Disc ID from the rip log, a barcode from an image): those labels are removed from the import everywhere.

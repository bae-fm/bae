# AndroidLibraryScreen

The library's home: the view name as a menu (Albums, Artists, Composers), 32dp at the top and 22dp once scrolled (`collapsed`), then Search, sync activity and ⋮; the content; the now playing bar. `searching` swaps the header for the search field.

**In the code:** Android: `LibraryBrowser` with `LibraryHeader`, `LibraryMoreMenu` and `LibraryChrome`'s search bar (`ui/library/`).

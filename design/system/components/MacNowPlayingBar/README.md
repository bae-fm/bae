# MacNowPlayingBar

Along the bottom of the main window. Left: the track (opens its album). Centre: shuffle, previous, play/pause, next, repeat, and the seek bar. Right: cast, queue, mute, volume. `waiting` while the track is still arriving from the cloud home: the arc turns around play/pause.

**In the code:** macOS: `NowPlayingBar` (`Views/Playback/NowPlaying/NowPlayingBar.swift`).

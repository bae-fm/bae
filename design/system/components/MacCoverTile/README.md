# MacCoverTile

One image in the cover gallery: the image over its name (`name`), with no source line, since the section heading says where it comes from. The tile is one button, named by the image's name. `image` stands for the picture (the board draws artwork seeded by it, the name unless given). `selected` rings the image the preview shows, and VoiceOver reads that tile as selected.

**In the code:** macOS: `MacCoverTile` (`Views/Import/Confirmation/MacCoverTile.swift`).

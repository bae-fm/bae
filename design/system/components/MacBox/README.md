# MacBox

Holds `MacRow`s, `MacFieldRow`s and `MacRadio`s. Pass `empty` when it can have none: "No shared folders yet". No glyph above it.

**In the code:** macOS: `MacBox` (`Views/Settings/MacBox.swift`) for a box outside a form, such as a popover's; inside a settings form, `SettingsFormStyle` draws each section's box.

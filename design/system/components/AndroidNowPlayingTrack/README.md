# AndroidNowPlayingTrack

The playing track in the now playing bar: its cover beside its title and artist (`title`, `artist`), each on one line. `album` is the album whose cover the board draws (the title unless given); `noCover` draws a plain tile.

**In the code:** Android: none yet; `AndroidNowPlayingBar` (`ui/playback/AndroidNowPlayingBar.kt`) draws it inline.

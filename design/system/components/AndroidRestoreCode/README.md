# AndroidRestoreCode

The library's restore code in Settings on Android: the code in a card, hidden but for its ends unless `shown`, then Show code or Hide, Copy and Print, and a note on what the code is for.

| Prop | |
| --- | --- |
| `shown` | The code shows in full, and the first button is Hide. |
| `s3` | A second note says that an S3 library also needs its access key and secret. |

**In the code:** Android: `AndroidRestoreCode` (`bae-android/app/src/main/java/fm/bae/app/ui/settings/AndroidRestoreCode.kt`).

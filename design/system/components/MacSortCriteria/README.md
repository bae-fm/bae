# MacSortCriteria

The sort beside the library heading: one pill per criterion (`criteria`, "Field:up" or "Field:down", comma separated), each a field menu and a direction; Remove when there are several; + to add a field not used yet, which goes once every field of the list is in use (`fields`: the albums' Title, Artist, Year and Date added unless given). The pills and + fill with `control`, as push buttons do.

Each criterion is a `MacSortPill`.

**In the code:** macOS: `MacSortCriteria` and `MacSortPill` (`Views/Library/Sort/`).

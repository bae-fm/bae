# MacImportBulk

Several rows selected: the count, then the actions in groups with how many each applies to (faded when none); `running` adds the progress line and Cancel. With `cloud`, where the import goes (`to`) sits on the Import row, before its count, the same pop-up and the same stored choice as the draft card's.

Each action is a `MacBulkActionRow`.

**In the code:** macOS: `MacImportBulk` (`Views/Import/MacImportBulk.swift`).

# StatusChip

Each chip has a word, never color alone.

`android` draws the label in Android's chip type, in Roboto. Every chip on an Android screen passes it. The preview's tone rows draw the Mac's chip, and its Android row draws Android's in the neutral tone.

**In the code:** macOS: BaeKit's `StatusChip`. Android: `StatusChip` (`ui/components/Status.kt`).

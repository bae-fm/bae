# MacHairline

A 1pt line across a pane, as between the composer's page and the work open under it.

`faint` draws the line at 60 percent, for a divider between rows inside a card, as between the welcome window's libraries. On the boards, `MacBox` draws its dividers between rows at the same 60 percent.

**In the code:** macOS: BaeKit's `MacHairline` (`BaeKit/Sources/BaeKit/Views/MacHairline.swift`), with `faint` for a divider between rows.

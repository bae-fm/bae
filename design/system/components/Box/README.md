# Box

A rounded group of rows on `surface`, radius `radius-card`, with a `hairline` edge and a hairline between each child.

- Children: `Row`, `Radio` or `TextField` with `row`. Pass `empty` for the sentence shown when there are none: "No shared folders yet". No glyph above it.
- `elevated` floats it on `elevated` with a `shadow`.
- Put a `Section` title over a box rather than a heading inside it.

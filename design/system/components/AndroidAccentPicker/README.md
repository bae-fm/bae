# AndroidAccentPicker

Under the Accent title, across the card.

The chosen colour is named on the Accent row's second line, in secondary text (“Pink”), as Theme and Tone show theirs: a swatch alone says nothing to someone who can't tell the colours apart. Each swatch's name is also what TalkBack reads.

**In the code:** Android: `AndroidAccentPicker` (`ui/settings/AppearanceSection.kt`).

# MacDetailHeader

Tops an artist's or composer's page: picture, name, count. `options` puts the page's ⋯ button at the right, its actions in the menu (an artist's: Edit artist…, Merge artist…), as an album's options button sits; it is named "Artist options" there.

**In the code:** macOS: `BrowseDetailHeader` (`Views/Library/Browse/BrowseDetailHeader.swift`).

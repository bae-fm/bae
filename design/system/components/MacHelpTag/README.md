# MacHelpTag

The short words macOS shows under the pointer after it rests on a control, drawn under the control it describes, its corner a little in from the control's left edge. `text` is the words; with none, only the control shows. The album header's inert Not on this device uses it to name the device that holds the files.

**In the code:** macOS: SwiftUI's `.help(_:)` on the control.

# MacCoverGallery

The cover gallery: Source, Current cover / Remote sources / Release files tiles, the preview with ‹ N of M ›, Use this cover. A tile shows its image and its name and no source line, since its section's heading says where it comes from; the gallery names the current cover's tile Cover, as a release's gallery names its cover, and core numbers each catalog image (Discogs · 1 · Front). The preview names the selected image and its source, which no heading says there. `remote: 'unlinked'` shows No linked release and drops Refresh, which has nothing to fetch.

**In the code:** macOS: `CoverGalleryView` (`Views/Import/Confirmation/CoverGalleryView.swift`) in `CoverSheetView`.

# MacCoverGallery

The cover gallery: Source, Current cover / Remote sources / Release files tiles, the preview with ‹ N of M ›, Use this cover. The current cover's tile is named Cover, with no source line under it, as a release's gallery names its cover. `remote: 'unlinked'` shows No linked release and drops Refresh, which has nothing to fetch.

**In the code:** macOS: `CoverGalleryView` (`Views/Import/Confirmation/CoverGalleryView.swift`) in `CoverSheetView`.

# Heart

A rating in a library whose rating system is Heart, read-only: one heart, filled (`on`) when the person gave three stars or more, an outline otherwise. The album header and track rows draw only the filled heart; the album's and the track's menus heart and clear. A screen reader reads the filled heart as a picture named Hearted, as it reads `Stars`, and skips the outline.

**In the code:** macOS: `Heart` (`Views/Components/Heart.swift`). Android: `Heart` (`ui/components/Heart.kt`).

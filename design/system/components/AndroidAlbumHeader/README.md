# AndroidAlbumHeader

Tops the album page: cover (opens the gallery when there is one), title, artists and the album's year, then the selected release on two lines when known. The pressing line: the release's own year when it differs from the album's, where it was released, its media and details, its audio and its length. The labels line: each label with the catalog numbers it gives the pressing, as core groups them, so a label is never named on both lines.

**In the code:** Android: `AndroidAlbumHeader` in `ui/albumdetail/AlbumDetailScreen.kt`.

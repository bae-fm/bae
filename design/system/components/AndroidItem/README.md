# AndroidItem

The row piece that holds a glyph (`lead`) level with the first line of its text, as `MacItem`: the lead centred in a box one body line tall, which it may overhang, then the content (the children), then `trail`. A notice's glyph and buttons sit this way on its title's line.

**In the code:** Android: `FirstLineBox` (`ui/components/Status.kt`).

# AndroidSeekBar

Elapsed, the line with its thumb, the length. In the full player it is Material 3's slider: a 16dp track, a bar for the handle and a stop dot at the end. The faint accent is what this device holds of the track; the solid accent is what has played.

**In the code:** Android: `PlaybackProgressAndroidView` with `HeldRangesDrawable` (`ui/playback/`).

# AndroidStorageUsage

Heads Settings → Storage: what bae keeps on this phone, the total, then one bar split by kind and a legend line per kind with its size, the kinds always in this order: The kinds are Pinned (releases kept whole to play offline), Cache (tracks played from the cloud, and covers and pictures, which download again), Library (the library's records) and From before the reset (shown only while that data is there). Local releases' originals stay in the person's folders and are not counted. Each kind keeps its colour whatever its size and whichever kinds show: Pinned blue, Cache gold, Library orchid, From before the reset mint, the accents' selection steps, the same in both themes (checked for colour-blind separation and 3:1 on the surface in both). The legend names each kind, so no colour stands alone. The same part as `MacStorageUsage`.

# AndroidSearchBar

The library's header while the person searches: the back arrow, named Close search, and the search field, a text field the person types in. It holds what they typed (`search`) with its Clear search button. While it is empty, the prompt Search albums, tracks, composers, and works shows as text under it.

**In the code:** Android: `AndroidSearchBar` (`ui/library/AndroidSearchBar.kt`), which `AndroidLibraryScreen` shows in the header's place while search is open.

# MacStorageState

A release's storage at rest, at the start of its Storage sheet's line: Local, Pinned or In cloud (`state`: local, pinned or cloud), as a word with no glyph: a glyph there would only repeat the word.

**In the code:** macOS: none yet; `MacStorageBand` (`Views/Library/AlbumDetail/MacStorageBand.swift`) draws it inline.

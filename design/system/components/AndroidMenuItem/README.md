# AndroidMenuItem

One line of an `AndroidMenu`. `selected` for the current choice; `check` (true or false) for an on/off item, its check shown when on; `heading` for a group's name; `divider` for a line.

**In the code:** Android: `ChoiceMenuItem` and `DropdownMenuItem` (`ui/library/LibraryMoreMenu.kt`, `LibraryHeader.kt`).

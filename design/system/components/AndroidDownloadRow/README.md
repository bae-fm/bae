# AndroidDownloadRow

A download: the release's name with Cancel (×) on its line (a release since removed from the library reads “Release no longer in library” in secondary text, so it isn't taken for a title), files and size, then waiting, a bar with bytes, or a quiet danger notice, “Download failed”, with Details (the error in a dialog) and Retry; Cancel.

**In the code:** Android: `DownloadRow` (`ui/downloads/DownloadRows.kt`).

# AndroidDownloadRow

One entry of the Pinning screen: the release's name with Cancel (×) on its line (a release since removed from the library reads “Release no longer in library” in secondary text, so it isn't taken for a title), files and size, then Queued to pin, a bar with bytes, or Couldn't pin, a quiet danger notice with Details (the error in a dialog) and Retry.

**In the code:** Android: `DownloadQueueRow` (`ui/downloads/DownloadRows.kt`).

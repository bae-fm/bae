# AndroidGalleryCaption

The gallery's caption, centred on the dark backdrop at the gallery's foot: the shown image's name (`label`), then its place among the release's images (`page` of `count`) when there are several. Android pages through the images by swiping, so the gallery shows no thumbnails. `AndroidLightbox` draws it.

**In the code:** Android: `GalleryCaption` (`ui/albumdetail/GalleryDialog.kt`).

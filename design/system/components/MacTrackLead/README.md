# MacTrackLead

A track row's lead, before the title:

- the track's number (`position`) at rest;
- Play under the pointer (`hover`), or Pause on the current track while it plays;
- the speaker, in the accent colour, on the current track (`current`).

**In the code:** macOS: `TrackPositionLabel` (`Views/Library/AlbumDetail/TrackRowView.swift`).

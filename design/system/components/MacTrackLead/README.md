# MacTrackLead

A track row's lead, before the title:

- the track's number (`position`) at rest;
- under the pointer (`hover`), a Play button, or a Pause button on the current track while it plays;
- the speaker, in the accent colour, on the current track (`current`), which a screen reader names Now playing.

**In the code:** macOS: `MacTrackLead` (`Views/Library/AlbumDetail/MacTrackLead.swift`).

# MacErrorDetails

An error's causes, one a line, in monospace in an inset panel, with Copy in its corner, showing only under the pointer. It's what an alert's `details` shows: a notice never shows the error itself; clicking it opens that alert.

| Prop | |
| --- | --- |
| `details` | The causes, one a line. |

**In the code:** macOS: `ErrorCausesPanel`, private in BaeKit's `Views/ErrorDetailsAlert.swift`.

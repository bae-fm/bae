# MacFormField

A labelled control in a sheet's form: its label (`label`) above the control, and a note (`note`) under it, all on the form's one left edge. A text field inside it takes no label of its own and runs the form's width; any other control, such as a `MacSegmentedControl`, keeps its own width. Stack several with the sheet's spacing between them.

**In the code:** macOS: `MacFormField` (`Views/Components/MacFormField.swift`).

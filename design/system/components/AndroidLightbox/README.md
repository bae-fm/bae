# AndroidLightbox

A release's images full screen on the dark backdrop: Close at the top end, the image (`title` names the release whose art it shows) fitted to the width, and the caption (`AndroidGalleryCaption`: `label`, `page`, `count`) at the foot. While the image loads (`loading`), a spinner over Loading the image… takes its place.

**In the code:** Android: `AndroidLightbox` (`ui/albumdetail/AndroidLightbox.kt`).

# AndroidActivity

The Activity sheet's list, opened from the library's top bar: the title, then Needs Attention, each problem a quiet row (no fill, the glyph in its tone) with a line between rows: (problems the caller passes in as children, each an `AndroidNotice`, bae couldn't read sync's status, with no button, and sync's own with Open Sync Settings, which closes the sheet and opens sync settings; nothing retries in place), then the transfers (the pinning line opens the Pinning screen), or up to date. Every line but the problems starts where a problem's text does, so the problems' icons stand in a column of their own at the edge. A row has no Details: tapping it opens a dialog with the explanation and the error's causes (`AndroidDialog` holding `AndroidErrorDetails`). Each problem has an × that dismisses it from the sheet; that doesn't fix it, and it still shows where it's fixed (such as Settings → Sync). A problem shows here and nowhere else on the screen; the top bar's button shows the warning glyph while a problem that hasn't been dismissed is listed; once every problem is dismissed, it goes back to its usual look. Put it in an `AndroidSheet`.

**In the code:** Android: `SyncActivityList` (`ui/sync/SyncActivity.kt`), which today holds only sync's own problems.

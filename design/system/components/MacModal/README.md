# MacModal

The modal host: a layer over the window that places the sheet at its top centre, and the content in the face every Mac sheet shares, as `MacSheet` draws it: the raised colour, the panel's corners and a shadow. The layer leaves the window undimmed, as a macOS sheet does: the sheet's shadow sets it apart.

**In the code:** macOS: `MacModal` (`Views/Components/MacModal.swift`).

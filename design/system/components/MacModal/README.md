# MacModal

The modal host: a scrim that dims the whole window, title bar included, under the window's traffic lights, which macOS draws over the app's content, and the content in the face every Mac sheet shares, as `MacSheet` draws it: the raised colour, the panel's corners and a shadow. A board places the modal inside its window, so the scrim takes the window's shape.

**In the code:** macOS: `MacModal` (`Views/Components/MacModal.swift`).

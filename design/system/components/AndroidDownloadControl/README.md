# AndroidDownloadControl

On the album page, under the releases: whether this release's files are on this phone, and the one action that changes it. Queued and Downloading show how many entries are `ahead` and what holds the queue back (`wait`: Paused or Waiting for network) in one fine line under the row. A failed download is the error in its box with Retry as its action, and Cancel below it. Copying here is a release moved to storage to be kept here, with Stop keeping here. On a release this phone can't play, one line saying where it is.

**In the code:** Android: `ReleaseDownloadControl` (`ui/albumdetail/ReleaseDownloadControl.kt`).

# MacAlert

The app's icon at the top left, then the title and the message under it, left-aligned and at one size, as macOS 26 draws every alert. Two buttons sit side by side at equal width with the default on the right; three or more stack. List the action first and Cancel last; each button is `size="alert"`, filling its row at the alert's button height. `destructive` on the action when it removes something. `warning` says what the choice costs, as a quiet warning notice between the title and the message ("Unsent changes will be lost"). `details` (an error's causes, one a line) adds a `MacErrorDetails` under the message: the Activity panel's problems open such an alert. `suppress` adds the checkbox that stops the alert asking again, under the message ("Do not show this again"; `suppressOn` ticks it); a setting where the choice belongs turns the alert back on.

**In the code:** macOS: BaeKit's `MacAlertView`, shown by `.macAlert(item:)` or `.macAlert(isPresented:)` in a clear panel attached to the frontmost window or sheet; `suppress` is the `MacAlertWords` suppression.

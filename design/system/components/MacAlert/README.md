# MacAlert

macOS's own alert, as the system draws it: the app icon at the top (read as an image named “application icon”, as macOS names it), then the title in bold and the message, left-aligned, on the system's face (`mac-system-surface`). Two pill buttons in the system's fill sit side by side at equal width with the default on the right, in the system's accent (`mac-system-accent`), whatever accent the app has; a destructive one is the system's red; three or more stack. List the action first and Cancel last; each button is `size="alert"`, filling its row at the alert's button height. `destructive` on the action when it removes something. `warning` says what the choice costs, as a quiet warning notice between the title and the message ("Unsent changes will be lost"). `details` (an error's causes, one a line) adds a `MacErrorDetails` under the message: the Activity panel's problems open such an alert. `suppress` adds the checkbox that stops the alert asking again, under the message ("Don't show this again"; `suppressOn` ticks it); a setting where the choice belongs turns the alert back on.

**In the code:** macOS: SwiftUI's `.alert`; with `suppress`, `.dialogSuppressionToggle`.

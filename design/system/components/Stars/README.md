# Stars

Exploration: a 1–5 star rating. `number` draws the read-only form instead: the number and one filled star ("4 ★"), as an album header shows the person's own rating, and nothing when the album is not rated (decision #1219). A screen reader reads the number form as one picture, "4 of 5 stars", and skips the number.

**In the code:** macOS: `Stars` (`Views/Components/Stars.swift`). Android: `Stars` (`ui/components/Stars.kt`).

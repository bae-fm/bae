# MacCoverPreview

The cover gallery's preview of the picked image: the image large (`image`, drawn as a tile's), a button named View in lightbox that opens it there, its name (`name`), where it comes from (`source`), and its place among the gallery's images (`position` of `count`) between the Previous image and Next image buttons.

**In the code:** macOS: `MacCoverPreview` (`Views/Import/Confirmation/MacCoverPreview.swift`), in `MacCoverGallery`.

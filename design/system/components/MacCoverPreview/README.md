# MacCoverPreview

The cover gallery's preview of the picked image: the image large (`image`, drawn as a tile's), its name (`name`), where it comes from (`source`), and its place among the gallery's images (`position` of `count`) between the previous and next arrows.

**In the code:** macOS: `MacCoverPreview` (`Views/Import/Confirmation/MacCoverPreview.swift`), in `MacCoverGallery`.

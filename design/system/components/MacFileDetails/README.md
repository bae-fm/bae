# MacFileDetails

A selected file's details: its name and the button that closes them (Close file details), then Folder, Kind, Format and Size in a `MacFactsGrid`, the size in tabular figures. Kind names the file's format with what it is, as the app words it: FLAC audio, JPEG image, Damaged image, Cue sheet, Rip log, AccurateRip report, Playlist, Text, PDF document, or File. Format shows only for an audio file.

**In the code:** macOS: `MacFileDetails` (`Views/Storage/MacFileDetails.swift`).

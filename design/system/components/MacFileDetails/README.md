# MacFileDetails

A selected file's details: name and close, then Folder, Kind, Format and Size in a `MacFactsGrid`, the size in tabular figures. Kind names the file's format with what it is, as the app words it: FLAC audio, JPEG image, Damaged image, Cue sheet, Rip log, AccurateRip report, Playlist, Text, PDF document, or File. Format shows only for an audio file.

**In the code:** macOS: `StorageFileDetails` (`Views/Storage/StorageFileDetails.swift`).

# MacThumbnailStrip

The lightbox's thumbnails of every image (`images`, each drawn as artwork seeded by it), along the foot under the caption. The shown image (`selected`, the first unless given) has a ring. `MacLightbox` draws it when the folder or release has more than one image.

**In the code:** macOS: `MacThumbnailStrip` (`Views/Components/MacThumbnailStrip.swift`), in `MacLightbox`.

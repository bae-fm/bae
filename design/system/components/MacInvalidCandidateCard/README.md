# MacInvalidCandidateCard

A skipped folder's card, read-only: why bae can't import the folder (`reason`) in a warning `MacNotice` where a release's Import would be, then the folder's cover (`cover`, or a plain tile) beside what its tags call the release, a `MacImportReleaseSummary` of `title` and `artist`. When the tags call it nothing, the folder's name (`folder`) shows in mono instead. It has no Identify row, fields, Release grid or records.

**In the code:** macOS: `MacInvalidCandidateCard` (`Views/Import/Mapping/MacInvalidCandidateCard.swift`), in `InvalidCandidatePane`.

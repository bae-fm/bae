# AndroidIconButton

For Back in the top bar, a menu, search. `tonal` makes it Material's filled tonal icon button at its extra-small size, a 32dp tinted container with a 48dp touch target, for a control inside a line, such as the Activity sheet's Pause. `tone` colours the glyph: `muted` (secondary text), `accent` or `warning`. `box` sets the touch box's side to 40 or 56dp where a bar or the full player needs it. Where a button looks different, the button takes the prop; the place it sits never restyles it.

**In the code:** Android: Material's `IconButton`; `tonal` is `FilledTonalIconButton`.

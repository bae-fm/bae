# MacPageHeading

A Settings pane's heading. On a page inside a pane, the round back button (`MacBackButton`) sits before it, named for where it goes back to. `MacSettingsWindow` draws it.

| Prop | |
| --- | --- |
| `title` | The pane's or page's name. |
| `back` | Where the back button goes back to, on a page inside a pane. |

**In the code:** macOS: `SettingsPaneHeading` (`Views/Settings/SettingsPane.swift`) and `SettingsPageHeader` (`Views/Settings/SettingsPageHeader.swift`).

# MacArtistGroupHeading

Heads an artist's albums when the grid is grouped by artist, across the whole row: the artist's picture, as the artist list draws it (44pt, with the artwork corner), 12pt from the name over the album count ("3 albums") in the detail type. The picture lines up with the covers below it. `noImage`: an artist with no picture shows the missing artwork.

**In the code:** macOS: `MacArtistGroupHeading` (`Views/Library/Grid/MacArtistGroupHeading.swift`), which `MacAlbumGrid` draws when grouped.

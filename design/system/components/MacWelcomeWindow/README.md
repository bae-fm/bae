# MacWelcomeWindow

The welcome window: traffic lights, no title and no sidebar, beside `MacMainWindow`, `MacSettingsWindow` and `MacStorageWindow`. The welcome screens, Create, joining and adding this device draw inside it; a `MacAlert` covers it.

**In the code:** macOS: `WelcomeWindowChrome` (`Views/Chrome/MainWindowChrome.swift`); `WelcomeWindow` there is the enum holding its size.

# MacSegmentedControl

For two or three choices side by side. `off` dims the whole control while none of its options can be chosen. `label` names the group, which VoiceOver reads; a `MacFormField` gives its own label.

**In the code:** macOS: `MacSegmentedControl` (`Views/Components/MacSegmentedControl.swift`), in `MacInviteFields`, `PlaylistFields`, `MacReleasePicker` and `MacStorageToolbar`.

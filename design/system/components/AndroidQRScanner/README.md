# AndroidQRScanner

The camera screen that scans a restore code or an invite. The camera's picture fills the screen, drawn black here. At the screen's foot, the instructions sit on a scrim over Cancel.

| Prop | What it does |
|---|---|
| `instructions` | What to scan. The screen shows no words when this is unset. |

**In the code:** Android: `AndroidQRScanner` (`ui/components/AndroidQRScanner.kt`).

# MacCheckbox

A checkbox and its label, for an on/off choice that sits in a row of controls: "Group by artist". It is as wide as its box and label. With `detail`, the label is in the detail type, as an alert's "Do not show this again" is.

**In the code:** macOS: BaeKit's `MacCheckbox` (`BaeKit/Sources/BaeKit/Views/MacCheckbox.swift`).

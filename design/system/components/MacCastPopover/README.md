# MacCastPopover

Opens upward from the cast button: while bae connects (`connecting`, the receiver's name), a `MacCastConnectingLine` over a hairline, then the receivers bae found, each a `MacCastRow` (the one being cast to, `casting`, saying "Casting" under its name with Disconnect at its right, each receiver once), (`devices`, "Name:cast", "Name:airplay", "Name:upnp"), or "No Cast devices found" in secondary text while it has found none, connecting or not.

**In the code:** macOS: `MacCastPopover`, which `CastButton` opens (`Views/Playback/NowPlaying/CastButton.swift`).

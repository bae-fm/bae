# MacCastPopover

Opens upward from the cast button: connecting, then the receivers bae found, each a `MacCastRow` (the one being cast to, `casting`, saying "Casting" under its name with Disconnect at its right, each receiver once), (`devices`, "Name:cast", "Name:airplay", "Name:upnp"), or "No Cast devices found".

**In the code:** macOS: the popover in `CastButton` (`Views/Playback/NowPlaying/CastButton.swift`).

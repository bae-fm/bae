# AndroidUploadLine

On the album page, over the download control: the upload phase core words ("Queued"), then, while none of the release's files is being sent, why they aren't moving (`wait`: Paused, Waiting for network, Waiting for Wi-Fi, Retrying at 6:40 PM, Waiting for 01 Harbor Lights.flac), joined by a dot. Nothing shows when no file of the release is queued.

**In the code:** Android: `ReleaseUploadLine` (`ui/albumdetail/ReleaseUploadLine.kt`).

# AndroidUploadLine

On the album page, over the pin control: the upload's phase in core's words, Queued to upload while the files wait. A missing original that holds them is a quiet warning notice naming the file (`missing`); a pause or the network shows on the Pinning screen and in the Activity sheet, not here. Nothing shows when no file of the release is queued.

**In the code:** Android: `ReleaseUploadLine` (`ui/albumdetail/ReleaseUploadLine.kt`).

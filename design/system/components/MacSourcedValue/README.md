# MacSourcedValue

One fact about a found pressing, as a pressing row shows it (`value`). When the pressing's records state the fact differently, it shows every record's value, each followed by its catalog's name in the tertiary colour: "1992 MusicBrainz / 1993 Discogs", written "1992:MusicBrainz|1993:Discogs". A fact one record states alone shows as stated. The value takes the type of the text around it.

**In the code:** macOS: drawn in `ImportSearchResultRow` (`bae-macos/bae/bae/Views/Import/Search/ImportSearchResultRow.swift`)

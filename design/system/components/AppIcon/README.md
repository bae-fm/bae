# AppIcon

An app icon as each platform shows it. macOS, iOS and Android put the sheep on the pale pink tile, since they shape every icon. Windows and Linux show the sheep with no tile. Android's `mask` is the launcher's shape: `circle`, `squircle` or `rounded`.

**In the code:** macOS: `AppIcon.icon`. Android: `res/mipmap-anydpi/ic_launcher.xml`. iOS, Windows and Linux: none yet.

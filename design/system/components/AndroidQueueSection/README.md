# AndroidQueueSection

A lane's heading in the queue: "Up next", "Playing from", "Your Library", "These tracks"; Clear, which `clear` names for the lane it clears (Clear up next, Clear playing from); shuffle on the context lane, accent while on.

**In the code:** Android: `AndroidQueueSection` (`ui/playback/AndroidQueueSection.kt`), called by `UpNextSectionLabel` and `ContextSectionLabel` (`ui/playback/QueueScreen.kt`).

# MacProgress

The words say what is happening now, ending in an ellipsis: "Checking the folder “Music”…". Leave out `value` when the length isn't known.

**In the code:** macOS: `MacProgress` (`Views/Components/MacProgress.swift`), a step's name over a bar drawn by `ProgressTrackDrawing` (`Views/Components/ProgressTrack.swift`); `ProgressTrackBar` for a bar alone.

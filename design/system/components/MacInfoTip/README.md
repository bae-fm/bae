# MacInfoTip

An ⓘ after a row's name, for what the name can't say in a word: "Search Discogs" ⓘ says what Discogs is and where to get a key. Clicking it opens a popover with the text, as macOS Settings does beside a setting that needs explaining; the row stays one line. `MacRow` draws it with `info`. A board draws the open popover with `MacPopover`, over the window, since a box crops what spills out of it.

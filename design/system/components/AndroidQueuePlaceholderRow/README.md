# AndroidQueuePlaceholderRow

A queued track not loaded yet: a placeholder tile where the cover goes and a bar for each of the row's three lines (title, artists, album), in the placeholder colour. It stands in the queue row's place until the track loads. Android's `MacQueuePlaceholderRow`.

**In the code:** Android: `QueueRowPlaceholder` (`ui/playback/QueueRowPlaceholder.kt`), in `QueueScreen`.

# MacStepper

The system stepper: an up and a down arrow in a small rounded box, beside the count it changes, named by what it counts (`label`, Number of CD). The release editor's Media row draws one after each carrier's ×count.

**In the code:** macOS: SwiftUI's `Stepper` with its label hidden, in `MediumCountRow` (`Views/Components/MetadataForm/MediaCountsEditor.swift`).

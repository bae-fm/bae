# MacCopyText

Text someone may want to paste elsewhere, such as the address a Subsonic app connects to: selectable, with a copy button after it that shows while the pointer is over the text, or while the button has keyboard focus. The button keeps its place while hidden, so the text never moves. Copying puts the text on the pasteboard and says nothing; the text is right there.

`after` adds words that follow the text but aren't copied, such as which network an address is on: “(Wi-Fi)”. A row takes it after its note with `copy` (“Apps connect at” then the address, or a list of them), or as its trailing part in place of a `value`.

**In the code:** macOS: none yet; Settings → Subsonic needs one (today the address is plain selectable text).

# MacImportSheetCaption

A CUE sheet's caption: the Disc pop-up showing which disc the sheet is (`disc`), CUE, the sheet's name as a button that opens it in the viewer, → and the Audio file pop-up showing the file its FILE line is bound to (“Choose audio…” in warning while unbound).

**In the code:** macOS: `ImportSheetCaptionRow` (`Views/Import/Mapping/`).

# MacImportSheetCaption

A CUE sheet's caption: the Disc pop-up showing which disc the sheet is (`disc`), CUE, the sheet's name as a button that opens it in the viewer, → and the Audio file pop-up showing the file its FILE line is bound to (“Choose audio…” in warning while unbound). In a library release's editor (`file`), the caption is the name of the image file the sheet's tracks play from, once, in mono: the editor binds no sheet and picks no disc.

**In the code:** macOS: `ImportSheetCaptionRow` (`Views/Import/Mapping/`).

# AndroidErrorBanner

The error box above the album grid when a later page failed: a quiet `AndroidNotice` in danger (no fill) with Retry as its action.

**In the code:** Android: `AndroidErrorBanner` (`ui/library/AndroidErrorBanner.kt`), placed by `AndroidErrorBannerContainer` (`ui/library/LibraryChrome.kt`), which reads the album page's failure.

# AndroidPinsAtOnce

The Pinning screen's choice of how many releases pin at once: Pins at once over a segmented control with one button per number up to `limit` (6 when unset), the `selected` one checked. A divider follows it on the screen, then the queue.

**In the code:** Android: `DownloadConcurrencySelector` (`ui/downloads/DownloadConcurrency.kt`).

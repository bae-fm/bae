# MacReleaseCard

A found album's header in a `MacPressingTable`: its cover at 40pt, then its title in strong text over its artist in secondary text, starting where the label column does, with a rule under them. `MacReleaseGroup` draws it over the album's pressings.

**In the code:** macOS: `MacReleaseCard` (`Views/Import/Search/MacReleaseCard.swift`).

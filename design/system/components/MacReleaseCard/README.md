# MacReleaseCard

A found album: its cover, its title over the artist and label, and a button per catalog that has answered (`sources`, none until one has) that opens the album on that catalog, with the arrow out beside its name. `MacReleaseGroup` draws it over the album's pressings.

**In the code:** macOS: `MacReleaseCard` (`Views/Import/Search/MacReleaseCard.swift`).

# MacIconButton

A 28pt glyph button: secondary at rest, a hover fill. `active` for a mode that is on (shuffle, repeat, the queue shown, casting). `faint` draws it in tertiary text, for a button that should sit back (a notice's ×).

**In the code:** macOS: a `Button` with `IconHoverButtonStyle` (`Views/Components/IconHoverButtonStyle.swift`).

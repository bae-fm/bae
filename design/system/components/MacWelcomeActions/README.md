# MacWelcomeActions

The welcome window's first choices when this Mac has no library: Create new library…, the primary button, over Scan code and Enter code, which add a library from a code another device shows. MacWelcomeActions takes no props.

**In the code:** macOS: `WelcomeChooseView` (`bae-macos/bae/bae/Views/Welcome/WelcomeChooseView.swift`) draws these buttons.

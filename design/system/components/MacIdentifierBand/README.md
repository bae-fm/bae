# MacIdentifierBand

The identifier chips: `chips` as "Label|value|filled|outlined|struck|dash|Source=count+Source=count", comma-separated. A chip holding several values (the folder's ISRCs, one per track; catalog numbers no release confirms) lists every one, separated by " · " and wrapping inside the chip: never the first alone, never "+n" or a count behind a disclosure.

**In the code:** macOS: `MacIdentifierBand` and `IdentifierChip` (`Views/Import/Search/`).

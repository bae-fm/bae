# MacImportEmptyState

The Import section before any folder is added, centred in the space it fills: the sheep, the line "Add a folder to import music from" in secondary text, then Import folder… and, while bae has no Discogs key it can use, Add Discogs key…, which opens Settings → Import. The sheep is bae's own artwork.

| Prop | What it does |
|---|---|
| `discogs` | bae has a Discogs key it can use: the window shows Import folder… alone. |

**In the code:** macOS: `MacImportEmptyState` (`Views/Import/MacImportEmptyState.swift`), with `AddDiscogsKeyButton`.

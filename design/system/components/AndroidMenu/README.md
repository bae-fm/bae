# AndroidMenu

A dropdown menu, placed with `top` and `left` or `right` inside its screen. Holds `AndroidMenuItem`s: a heading that names a group ("Sort by"), choices with the current one in accent, an item with a trailing check, dividers.

**In the code:** Android: Material's `DropdownMenu`, as `LibraryHeader` and `LibraryMoreMenu` open it (`ui/library/`).

# MacContentUnavailable

SwiftUI's empty-pane message: a title, an optional line under it, and the children as its actions in a row under the text, centered in what's left of the pane. A pane that failed to load passes `tone="danger"`, which puts the tone's glyph, muted and 40pt, above the title as the view's label image.

**In the code:** macOS: SwiftUI's `ContentUnavailableView`.

# MacContentUnavailable

SwiftUI's empty-pane message: a title, an optional line under it, and the children as its actions in a row under the text, centered in what's left of the pane. No glyph sits above the title, not even for a pane that failed to load: the title says what happened.

**In the code:** macOS: `MacContentUnavailable` (`Views/Components/MacContentUnavailable.swift`).

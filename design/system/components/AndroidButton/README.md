# AndroidButton

`filled` for the action a screen is for, `outlined` beside it, `text` in dialogs and rows. `large` is the full-width size of the welcome screen's actions. `destructive` turns it `danger`.

- Filled is `accent-fill` with `on-fill` text. Words are a verb, sentence case, no ellipsis.

**In the code:** Android: `PrimaryButton` (`ui/components/PrimaryButton.kt`) for filled; Material's `OutlinedButton` and `TextButton`.

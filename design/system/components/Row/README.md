# Row

One line of a `Box`: the label on the left; on the right, a grey `value`, any controls passed as children, and a chevron when the row opens something.

- Props: `label`, `note` (a second line in `detail`), `value`, `chevron`, `selected`, `onClick`.
- A selected row in a choice list takes `accent-tint`.
- Least height `size-row` (36px), inset 7px by `space-group`.

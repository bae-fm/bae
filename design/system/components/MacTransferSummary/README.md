# MacTransferSummary

A release's upload or pin in the inspector: the counts (the moving one bold in its color, the done one muted) with Cancel, then bytes, rate and a bar.

**In the code:** macOS: `MacTransferSummary` (`Views/Storage/MacTransferSummary.swift`), one view for both kinds, with `StorageTransferCounts` (`Views/Storage/`).

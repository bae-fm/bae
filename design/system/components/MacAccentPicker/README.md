# MacAccentPicker

At the end of the Accent row.

The chosen colour is named on the Accent row's second line, in secondary text (“Pink”), as Theme and Tone show theirs: a swatch alone says nothing to someone who can't tell the colours apart. Each swatch's name is also what VoiceOver reads.

**In the code:** macOS: the accent swatches in BaeKit's `AppearanceControls.swift`.

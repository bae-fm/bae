# MacImportRow

A candidate: cover, title with the record arrow (or the folder's name in mono), then the artist, then while it imports the import step with a bar, or while it uploads the upload; a skipped folder's reason (`error`) under the title and artist or the folder's name; trailing a badge chip or a wait mark. The arrow is named Identified, and hidden from screen readers where it only keeps the line's width; the wait marks are named Queued to identify and Queued to import. `grouped` indents it under its group.

**In the code:** macOS: `MacImportRow` and `InvalidCandidateRow` (`Views/Import/Candidates/`).

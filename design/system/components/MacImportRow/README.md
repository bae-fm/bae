# MacImportRow

A candidate: cover, title with the record arrow (or the folder's name in mono), then the artist, or the import step with a bar, or an upload; a skipped folder's reason (`error`) under the title and artist or the folder's name; trailing a badge chip or a wait mark. `grouped` indents it under its group.

**In the code:** macOS: `MacImportRow` and `InvalidCandidateRow` (`Views/Import/Candidates/`).

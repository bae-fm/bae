# MacAlbumCredits

An album's credits, in the open album under its tracks: the Credits heading (`MacFormHeading`) over the role and name pairs (`MacFactsGrid`). `credits` holds the pairs as "Role: name", separated by semicolons.

**In the code:** macOS: `MacAlbumCredits` (`Views/Library/AlbumDetail/MacAlbumCredits.swift`).

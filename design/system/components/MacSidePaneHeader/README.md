# MacSidePaneHeader

The side pane's head: the Queue, Playlists and History tabs centred (`tab`, Queue when unset) and Close at the end. On Playlists a + button (New playlist…) starts the head, and while a playlist is open the back button (`back`, where it goes back to) takes its place. `MacQueuePanel` draws it at its top.

**In the code:** macOS: none yet. `MacQueuePanel` (`Views/Playback/Queue/MacQueuePanel.swift`) draws the queue alone, with no tabs.

# AndroidInlineIconButton

An icon level with a line of text: it takes the line's room, 20dp, so the row keeps the text's height, and its 48dp touch area overhangs the row's padding. A notice's × (`AndroidNotice` `dismiss`) and a download's Cancel (`AndroidDownloadRow`). An icon that stands on its own, such as a top bar's, is an `AndroidIconButton`.

**In the code:** Android: `InlineIconButton` (`ui/components/InlineIconButton.kt`), in `AndroidNotice` and `AndroidDownloadRow`.

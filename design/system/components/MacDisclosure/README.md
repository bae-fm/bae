# MacDisclosure

For settings most people never change: "Advanced". Its own box: the chevron leads inside the label's row, pointing right, and turns down when open; the rows it shows join the box, indented so they line up with the label. Children are `MacRow`s.

On Android the same thing is `AndroidDisclosure`.

**In the code:** macOS: `DisclosureGroup` in a grouped `Form`.

# AndroidPageActions

An album or playlist page's actions, left-aligned under its header: Play (filled), then the page's options button (⋮), whose menu holds every other action of the page. `label` names the options button to screen readers: Album options unless given, Playlist options on a playlist.

**In the code:** Android: `AndroidPageActions` (`ui/components/AndroidPageActions.kt`), on the album page and the playlist page.

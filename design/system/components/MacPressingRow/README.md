# MacPressingRow

A pressing: year, labels, catalog number, the agreement badges, the summary; In library (dimmed), the sources, a chevron. Where the pressing's records state a fact differently (year, catalog number, barcode, country, format), the row shows every record's value, each followed by its catalog's name ("1992 MusicBrainz / 1993 Discogs"): written `1992:MusicBrainz|1993:Discogs`, in `summary` as one of its parts. A fact one record states alone is shown as stated, and the labels list every record's labels. `note` is the records' notes under the summary, every record's that states one, never the first alone.

**In the code:** macOS: `ImportSearchResultRow` (`Views/Import/Search/`).

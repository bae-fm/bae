# MacStorageFooter

Under the release list: how many releases and the total, then for each queue with work its rate, or in the rate's place what holds the whole queue back (Paused, Waiting for network, Waiting for Wi-Fi, Retrying at 6:40 PM), and a Pause button, Resume (a play symbol) only while the person has paused that queue. This is the one place on the Mac a queue's hold shows; no release row repeats it.

**In the code:** macOS: `StorageFooter` (`Views/Storage/StorageFooter.swift`).
